Shared Secret:
- Name: batch-gateway-secrets
- Mount: /etc/.secrets/ (read-only)
- Contains:
  - Redis connection URL
  - PostgreSQL connection URL
  - Inference API key
  - S3 credentials (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY)
- Provisioned by: Cluster administrator / Helm values
- Mounted by: All three workloads (apiserver, processor, gc)

RBAC Summary:
- No ClusterRoles or RoleBindings defined
- Workloads operate with default service account privileges

Authentication & Authorization:
- API server: No local authentication enforcement
- Auth delegated to platform Gateway / service mesh
- Authorization header passed through to llm-d inference gateway
- X-MaaS-Username header used for tenant scoping (not auth)
- Observability endpoints: No authentication (separate port 8081)

FIPS Compliance:
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime
- Runtime: Dynamic linking with OpenSSL via UBI 9
- TLS: Configurable min version (default 1.2), non-insecure cipher suites only
- Satisfies: Konflux check-payload FIPS gate

Certificate Management:
- TLS cert/key loaded from file paths (opt-in)
- Optionally managed by cert-manager
