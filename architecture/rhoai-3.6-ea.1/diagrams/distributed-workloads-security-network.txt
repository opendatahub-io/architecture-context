Security Characteristics:
- Authentication: Entirely platform-delegated (no component-level auth)
- Training pod communication: Unencrypted pod-to-pod (SSH for OpenMPI, c10d for DDP)
- Crypto libraries: cryptography ==46.0.5 (OpenSSL), pyjwt ==2.13.0 (JWT, transitive)
- FIPS: Inherited from AIPCC/UBI9 base image OpenSSL; no Go binaries deployed
- TLS: Inherited from base image; no explicit TLS config in training entrypoints
- Non-FIPS risk: Large transitive dependency set (vLLM, MLflow, DeepSpeed) not fully audited

Training Communication Protocols:
- OpenMPI runtimes: SSH on port 2222/TCP (unencrypted, pod-to-pod)
- PyTorch DDP: torch.distributed c10d rendezvous (unencrypted, pod-to-pod)
- DeepSpeed: NCCL/RCCL backend (unencrypted GPU-direct)
