Secrets:
- kube-auth-proxy-secret (Opaque) - OAuth client secret and cookie secret
  - Provisioned by: manifest
  - Auto-Rotate: Unknown

FIPS Compliance:
- Build flags: GOEXPERIMENT=strictfipsruntime, -tags strictfipsruntime
- Linking: Dynamic (CGO_ENABLED=1) for OpenSSL integration
- Base image: UBI9 ubi-minimal (OpenSSL FIPS provider)
- TLS: crypto/tls with min TLS 1.2, max TLS 1.3, configurable cipher suites
- Risk: Redis client InsecureSkipTLSVerify option (development use only)

Authentication Methods (ordered by precedence):
1. Kubernetes ServiceAccount Token → TokenReview API (programmatic access)
2. JWT/OAuth Bearer Token → OIDC provider validation
3. Basic Auth → htpasswd file
4. Cookie Session → Redis/in-memory lookup + refresh

Security Evidence:
- TokenReview API calls for bearer token validation
- TLS configuration via crypto/tls (FIPS-compliant via strictfipsruntime)
- CSRF protection on OAuth2 callback flow
