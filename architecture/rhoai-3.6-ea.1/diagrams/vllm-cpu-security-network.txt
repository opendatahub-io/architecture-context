RBAC Summary:
- No ClusterRoles or RoleBindings defined (application-level component, not an operator)
- RBAC is managed by the deploying platform (KServe / ModelMesh)

Authentication Summary:
- HTTP API: Optional Bearer token via ASGI middleware
  - Enabled: When VLLM_API_KEY env var or --api-key CLI flag is set
  - Guarded paths: /v1/*, /v2/*, /inference/*
  - Unguarded paths: /health, /ready, /readyz, /load, /docs, /ping
  - Token comparison: SHA-256 digest, constant-time (secrets.compare_digest)
- gRPC API: No built-in authentication
  - TLS must be provided by external service mesh or ingress proxy

Secrets / Environment Variables:
- VLLM_API_KEY (Opaque) — Bearer token for API authentication
- OPENAI_API_KEY (Opaque) — Downstream API key compatibility
- S3_SECRET_ACCESS_KEY (Opaque) — Object storage credentials
- GH_TOKEN / GITHUB_TOKEN (Opaque) — GitHub access tokens
- MODELSCOPE_API_TOKEN (Opaque) — ModelScope platform token
- EXA_API_KEY (Opaque) — Exa search API key

FIPS Compliance:
- Base image: UBI 9 (system OpenSSL)
- gRPC Python: Compiled with GRPC_PYTHON_BUILD_SYSTEM_OPENSSL=1 (no bundled BoringSSL)
- Recent FIPS fixes: Removed statically linked patchelf/maturin from runtime images
- Application-level TLS: Not configured (delegated to platform)
- Crypto library: System OpenSSL via UBI 9
- Risk: gRPC server binds insecure port — relies on platform for encryption
