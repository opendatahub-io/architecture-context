FIPS Compliance:
- Build: GRPC_PYTHON_BUILD_SYSTEM_OPENSSL=1 (grpcio uses system OpenSSL)
- Runtime: Python ssl/hashlib delegate to system OpenSSL on UBI9/RHEL 9
- Token validation: hashlib SHA-256 + secrets.compare_digest (FIPS-compatible)
- No non-FIPS cryptographic operations detected
- FIPS mode inherited from host OS (RHEL 9 FIPS-enabled kernel)

Authentication Summary:
- Conditional: Auth only active when --api-key or VLLM_API_KEY is configured
- Mechanism: Bearer token in Authorization header
- Validation: SHA-256 hash comparison (constant-time via secrets.compare_digest)
- Scope: /v1/*, /v2/*, /inference/* paths only
- Exclusions: Health/readiness probes always unauthenticated
