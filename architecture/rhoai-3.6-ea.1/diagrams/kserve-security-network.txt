Secrets:
  - kserve-webhook-server-cert (TLS) - Webhook server certificate, cert-manager provisioned
  - kserve-webhook-server-secret (Opaque) - Webhook configuration
  - storage-config (runtime) - S3/GCS/Azure credentials (AWS_ACCESS_KEY_ID, etc.)
  - HDFS_SECRET_DIR (env) - HDFS secret directory path
  - AZ_CLIENT_SECRET (env) - Azure client secret
  - GIT_PASSWORD (env) - Git credentials for model download

TLS Configuration:
  - Platform-aware: reads OpenShift TLS security profile from apiservers.config.openshift.io
  - Applies corresponding cipher suites and minimum TLS version
  - Fallback: Mozilla Intermediate cipher suites, TLS 1.2 minimum
  - Source: pkg/tls/tls_odh.go:73-100

FIPS Compliance:
  - kserve-module-controller: FIPS-compliant (CGO_ENABLED=1, strictfipsruntime)
  - Core manager (upstream Dockerfile): CGO_ENABLED=0 (not FIPS-compliant, Konflux overrides expected)
  - Python model servers: Inherit FIPS from UBI base OpenSSL (no explicit opt-in)
