- ServiceAccount: opendatahub-operator-controller-manager
  - ClusterRoleBinding: opendatahub-operator-controller-manager-rolebinding
  - ClusterRole: controller-manager-role
  - Permissions: Full CRUD on all component CRDs (DataSciencePipelines, Kueue,
    ModelRegistry, Ray, SparkOperator, Trainer, TrainingOperator, TrustyAI)
    and service CRDs (Auth, GatewayConfig, Monitoring)

- Editor/Viewer ClusterRoles (per-component):
  - {component}-editor-role: create, delete, get, list, patch, update, watch
  - {component}-viewer-role: get, list, watch
  - Components: dashboard, datasciencepipelines, kserve, kueue, modelregistry,
    ray, trainingoperator, trustyai, workbenches, auth, monitoring

TLS Configuration:
- Webhook server (9443): TLS from OpenShift service-ca operator
  - Certificate: opendatahub-operator-controller-webhook-cert (kubernetes.io/tls)
  - TLS version: Derived from cluster APIServer TLS security profile
  - Unsupported versions (1.0/1.1) floored to Intermediate profile
- Metrics server (8443→8080): TLS
  - Auth: opendatahub-operator-metrics-reader ClusterRole
- Health probes (8081): HTTP plaintext (unauthenticated by design)

  static Go crypto instead of OpenSSL, NOT FIPS-compliant)
