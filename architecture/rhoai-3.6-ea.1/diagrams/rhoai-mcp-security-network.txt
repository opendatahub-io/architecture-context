Authentication & Authorization:
- MCP API endpoints: Bearer JWT (OIDC via JWKS) or Bearer (K8s TokenReview)
  - Enforcement: OIDCAuthMiddleware (ASGI)
  - Configurable: RHOAI_MCP_OIDC_ENABLED (default: disabled)
  - When enabled: per-user impersonation + SubjectAccessReview tool filtering
- /health: Unauthenticated (K8s probes)
- /.well-known/oauth-protected-resource: Unauthenticated (RFC 9728 metadata)

Container Security:
- RunAsUser: 1000 (non-root)
- ReadOnlyRootFilesystem: true
- Capabilities: ALL dropped
- Seccomp: RuntimeDefault

Secrets:
- No secrets defined in deployment manifests
- Service account token auto-mounted for K8s API access
- OIDC configuration via environment variables (issuer URL, JWKS endpoint)

Crypto Dependencies:
- PyJWT[crypto] → cryptography → OpenSSL (system)
- TLS behavior inherits from container base image OpenSSL config
- No explicit FIPS mode configuration
