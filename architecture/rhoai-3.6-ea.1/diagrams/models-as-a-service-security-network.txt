  - core: secrets (get)

  - gateway.networking.k8s.io: gateways (get)

  - maas-api-supplemental → SA maas-api (namespace: opendatahub)

  - {maa-s-d-b-secret-name} (Opaque) - DB credentials, provisioned by controller

  - Gateway Level: API Key (sk-oai-*), Kubernetes TokenReview, OIDC JWT

  - Controller: ServiceAccount token (in-cluster)
  - Webhooks: Kubernetes admission (TLS)

  - Linking: Dynamic (CGO) against system OpenSSL
  - Base image: UBI 9 (OpenSSL included)
  - Risk: None detected; strictfipsruntime panics on non-FIPS crypto
