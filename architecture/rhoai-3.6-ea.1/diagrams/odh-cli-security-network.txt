RBAC Summary:
- No cluster roles or role bindings are bundled with the CLI
- RBAC enforcement: Pre-flight SelfSubjectAccessReview before privileged operations
- CLI inherits permissions from the user's kubeconfig identity
- Required permissions depend on subcommand (get, list, watch, create, update, delete
  on various resources)

Authentication Chain:
- Primary: kubeconfig credential chain (bearer token, client certificate, OIDC)
- Kubernetes API: ServiceAccount token or user credentials via rest.Config
- TrustYAI: Bearer token extracted from kubeconfig REST config
- MCP: No authentication (localhost-only)

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Runtime: Dynamic linking against OpenSSL via ose-cli-rhel9 base
- Crypto: stdlib crypto/tls backed by FIPS-validated OpenSSL
- Risk: InsecureSkipVerify=true on TrustYAI client (bypasses cert validation,
         does not affect cipher suite selection)

Secrets:
- No secrets are provisioned or managed by the CLI itself
- All credentials sourced from user's kubeconfig environment
