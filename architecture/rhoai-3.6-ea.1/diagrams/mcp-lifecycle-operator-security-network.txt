  - core: configmaps (CRUD + watch)

RBAC Aggregation:
- mcpserver-admin-role: aggregate-to-admin label
  - mcp.x-k8s.io: mcpservers (full CRUD + deletecollection)
- mcpserver-editor-role: aggregate-to-edit label
  - mcp.x-k8s.io: mcpservers (CRUD, no deletecollection)
- mcpserver-viewer-role: aggregate-to-view label
  - mcp.x-k8s.io: mcpservers (get, list, watch)

Authentication & Authorization:
- :8081/healthz, /readyz: No auth (health probes)
- :8443/metrics: TokenReview + SubjectAccessReview via controller-runtime
- Kubernetes API access: ServiceAccount token (in-cluster)
- MCP handshake: No auth required (graceful 401/403 handling)

TLS Configuration:
- Metrics endpoint: TLS with self-signed cert (default) or injected certs
- Kubernetes API: TLS 1.2+ (platform-provided)
- MCP handshake: HTTP (in-cluster, no TLS)
- Configurable: TLS_MIN_VERSION, TLS_CIPHER_SUITES environment variables
- FIPS: GOEXPERIMENT=strictfipsruntime ensures crypto backed by OpenSSL

Secrets:
- No operator-specific secrets defined
- References user-defined Secrets in MCPServer specs (watched, not owned)
