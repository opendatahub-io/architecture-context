RBAC Summary:

  Manager Role (mcp-lifecycle-operator-manager-role):
  - core:          configmaps, secrets → get, list, watch
  - core:          pods → get, list
  - core:          services → create, get, list, update, watch
  - events.k8s.io: events → create, patch
  - apps:          deployments → create, get, list, update, watch
  - mcp.x-k8s.io:  mcpservers → get, list, patch, update, watch
  - mcp.x-k8s.io:  mcpservers/finalizers → update
  - mcp.x-k8s.io:  mcpservers/status → get, patch, update
  - networking:    networkpolicies → create, get, list, update, watch

  Metrics Auth Role (mcp-lifecycle-operator-metrics-auth-role):
  - authentication.k8s.io: tokenreviews → create
  - authorization.k8s.io:  subjectaccessreviews → create

  RBAC Aggregation ClusterRoles:
  - mcpserver-admin-role:  mcpservers → full CRUD + deletecollection
  - mcpserver-editor-role: mcpservers → CRUD (no deletecollection)
  - mcpserver-viewer-role: mcpservers → get, list, watch (read-only)

  Leader Election Role (namespace-scoped):
  - core:              configmaps → full CRUD
  - coordination.k8s.io: leases → full CRUD
  - core:              events → create, patch

TLS Configuration:
  - Metrics server: Self-signed TLS cert (controller-runtime) or external
  - TLS min version: Configurable via TLS_MIN_VERSION env var
  - Cipher suites: Configurable via TLS_CIPHER_SUITES env var
  - FIPS: GOEXPERIMENT=strictfipsruntime with UBI9 OpenSSL backend
  - TLS propagation: PROPAGATE_TLS_ENV_VARS=true passes TLS config to managed pods

Secrets:
  - No operator-managed secrets defined
  - Controller-runtime auto-generates self-signed TLS cert for metrics
  - External cert path configurable via metricsCertPath flag

Network Policies:
  - Operator creates NetworkPolicy resources for managed MCP server pods
