RBAC Summary:
- No ClusterRoles or RoleBindings defined by ai4rag
- RBAC is delegated to the consuming pipeline component (KFP)
- Pipeline ServiceAccount must have permissions for the pipeline namespace

Secrets (Environment Variables - no K8s Secret manifests):
- AWS_ACCESS_KEY_ID (env var) - S3 access key, provisioned by runtime
- AWS_SECRET_ACCESS_KEY (env var) - S3 secret key, provisioned by runtime
- MILVUS_TOKEN (env var) - Milvus authentication token, provisioned by runtime
- PGVECTOR_PASSWORD (env var) - PostgreSQL password for PGVector, provisioned by runtime

Security Risks:
- RISK: MaaS client verify=False fallback — on SSL error (self-signed cert),
  TLS certificate verification is disabled. Logged but proceeds silently.
  Impact: Bypasses certificate chain validation required for FIPS compliance.
  Source: ai4rag/components/utils/maas_client.py:56-59

- RISK: S3 client verify parameter — defaults to True but can be set to False
  by callers, disabling certificate validation.
  Source: ai4rag/components/utils/s3.py:39

- NOTE: No explicit FIPS crypto provider selection. All TLS operations rely on
  system OpenSSL inherited from the runtime environment.

Network Notes:
- ai4rag is a Python library, NOT a network service
- No inbound network exposure (no HTTP endpoints, no Services, no Ingress)
- All network traffic is outbound (egress only) from the pipeline task pod
- No Kubernetes deployment manifests or Service definitions
- Vector store backend is pluggable (only one active at a time)
