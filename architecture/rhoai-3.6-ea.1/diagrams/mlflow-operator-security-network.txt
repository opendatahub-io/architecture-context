RBAC Summary:
- ClusterRole: mlflow-operator-manager-role
  - Core: namespaces, pods, secrets (get, list, watch)
  - CRDs: mlflowoperators, mlflows, mlflowconfigs (full CRUD)
  - Resources: configmaps, deployments, services, PVCs, cronjobs,
    jobs, networkpolicies, servicemonitors (full CRUD via Helm)
  - RBAC: clusterroles, clusterrolebindings, rolebindings (CRUD + bind)
  - Platform: consolelinks, httproutes (full CRUD)
  - Auth: services.platform.opendatahub.io/auths (get, list, watch)

- ClusterRole: mlflow-operator-metrics-auth-role
  - tokenreviews (create)
  - subjectaccessreviews (create)

- ClusterRole: mlflow-operator-mlflow-view (propagated to workspaces)
  - mlflows, mlflows/status (get, list, watch)
  - mlflowconfigs, datasets, experiments, etc. (get, list)

- ClusterRole: mlflow-operator-mlflow-edit (propagated to workspaces)
  - mlflows (full CRUD + deletecollection)
  - mlflowconfigs, datasets, experiments, etc. (create, delete, update)

Leader Election:
- Role: mlflow-operator-leader-election-role (Namespace: opendatahub)
  - configmaps, leases (full CRUD)
  - events (create, patch)

Service Accounts:
- mlflow-operator-controller-manager (Namespace: opendatahub)
  - Bound to: mlflow-operator-manager-role (ClusterRoleBinding)
  - Bound to: mlflow-operator-metrics-auth-role (ClusterRoleBinding)
  - Bound to: mlflow-operator-leader-election-role (RoleBinding)

Secrets:
- mlflow-artifact-connection (per workspace namespace)
  - Access restricted via RBAC resourceNames scoping
  - Only mlflow-operator-controller-manager SA can read
