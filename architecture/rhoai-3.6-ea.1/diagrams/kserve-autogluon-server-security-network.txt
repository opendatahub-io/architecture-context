FIPS Compliance:
- AutoGluon server: Python-only workload, no Go binaries
- Base image: registry.redhat.io/rhai/base-image-cpu-rhel9 (UBI9 with OpenSSL FIPS)
- Crypto: cryptography (>=46.0.5) delegates to OpenSSL
- TLS: Delegated to platform (no application-level TLS configuration)
- FIPS mode: Dependent on host system FIPS enablement

Authentication Gaps:
- AutoGluon model server exposes UNAUTHENTICATED HTTP/gRPC endpoints
- No authentication middleware in FastAPI application stack
- Authentication enforcement relies on:
  1. Platform ingress layer (Istio/Gateway API)
  2. kube-rbac-proxy sidecar (for operator metrics only)
  3. Kubernetes admission webhooks (for API-level validation)
- Health/readiness probes intentionally unauthenticated
