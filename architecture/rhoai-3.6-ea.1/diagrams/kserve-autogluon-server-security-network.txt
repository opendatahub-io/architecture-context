Security Notes:
- ⚠ AutoGluon model server has NO application-level authentication
  (no auth middleware detected in FastAPI/Starlette application)
- pyjwt dependency present in KServe SDK but NOT wired into autogluon
  server request path
- All authentication enforcement delegated to platform ingress / service mesh
- Webhook failure policy is Fail (hard dependency for CRD mutations)
- FIPS: AutoGluon container inherits FIPS posture from AIPCC base image
  (system OpenSSL via cryptography package)
