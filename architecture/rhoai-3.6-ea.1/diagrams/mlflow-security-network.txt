Authentication & Authorization:
- Mechanism: kubernetes-auth plugin (mlflow-kubernetes-plugins 1.5.0)
- Enforcement: Flask/Gunicorn application layer via --app-name entry point
- Policy: Authentication delegated to Kubernetes API at server startup
- Note: No ClusterRoles or RoleBindings defined in MLflow itself;
         RBAC is managed externally by the deploying operator/platform

RBAC Summary:
- No ClusterRoles defined in MLflow source
- No RoleBindings defined in MLflow source
- RBAC enforcement delegated to kubernetes-auth plugin and Kubernetes API

FIPS Compliance:
- Base image: UBI9 Minimal (ubi9/ubi-minimal:9.7) with system OpenSSL
- Crypto library: cryptography>=43.0.0,<49 (links to system OpenSSL)
- FIPS mode: Passive inheritance from host kernel; no explicit FIPS opt-in
- Risk: Application does not verify FIPS mode is active

Service Mesh Configuration:
- No PeerAuthentication policies defined
