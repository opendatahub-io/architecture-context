- No Kubernetes ClusterRoles or RoleBindings defined in this component.
- Application-level RBAC is enforced by mlflow/server/auth module:
  - Roles: Defined per workspace
  - Permissions: Per-resource (experiments, registered_models, gateway, workspaces)
  - Enforcement: Flask middleware in kubernetes-auth plugin

- Auth Mechanism: kubernetes-auth plugin (Kubernetes SA bearer token)

- Policy: RBAC with role-based per-resource permissions
- Token Source: /var/run/secrets/kubernetes.io/serviceaccount/token
- Workspace Routing: X-MLFLOW-WORKSPACE header → namespace isolation
