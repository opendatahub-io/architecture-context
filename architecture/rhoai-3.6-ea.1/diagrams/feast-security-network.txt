Authentication Model:
- Operator → Kubernetes API: ServiceAccount token (in-cluster, bearer)
- Feast services → Clients: CRD-configurable (exactly one of):
  - Kubernetes RBAC: namespace-scoped roles created by operator
  - OIDC: Secret-referenced OIDC provider, validated via PyJWT
- Metrics endpoint: TokenReview + SubjectAccessReview (controller-runtime)
- Health probes: Unauthenticated by design

FIPS Compliance:
- Go operator (Konflux build): CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime -tags strictfipsruntime
  - Dynamic linking against system OpenSSL (UBI9-minimal base)
- Go operator (upstream/dev build): CGO_ENABLED=0 (static, non-FIPS)
- Python offline server: Detects FIPS via /proc/sys/crypto/fips_enabled
  - Sets GRPC_SSL_CIPHER_SUITES before pyarrow.flight import
  - 6 FIPS-approved ciphers (ECDHE-RSA/ECDSA-AES128/256-GCM-SHA256/384, AES128/256-GCM-SHA256/384)
