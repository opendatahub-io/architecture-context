RBAC Summary:
  No RBAC resources (ClusterRoles, RoleBindings) are defined directly
  in odh-gitops. RBAC is managed by the individual operators deployed
  via OLM Subscriptions or Helm sub-charts.

Secrets:
  No secrets are defined or managed directly by odh-gitops.
  Secret management is delegated to individual operators
  (e.g., cert-manager for TLS certificates, storage-config for S3).

Authentication & Authorization:
  - KServe Inference Gateway: Authorino TLS bootstrap via Gateway annotation
  - MaaS Gateway: Authorino TLS bootstrap via Gateway annotation
  - Enforcement: OpenShift Gateway API with Authorino integration
  - Mechanism: security.opendatahub.io/authorino-tls-bootstrap annotation

FIPS Compliance:
  This repository contains only YAML configuration manifests.
  It does not compile or build binaries. FIPS compliance is delegated
  entirely to the operator images deployed by these manifests.
