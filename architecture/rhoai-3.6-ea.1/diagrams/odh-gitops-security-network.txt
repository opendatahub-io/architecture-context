Authentication & Authorization Summary:
- Authorino Listener: TLS client certificate, cert-manager provisioned server cert
- KServe Inference Gateway: TLS enabled by default via rhai-ca-issuer ClusterIssuer
- MaaS Gateway: TLS with configurable issuerRef, namespace-scoped route attachment
- All gateways default to allowedRoutes.namespaces.from = Same (explicit opt-in for cross-namespace)

Certificate Management:
- ClusterIssuer: rhai-ca-issuer (platform-managed internal CA)
- Authorino server cert: authorino-server-cert (cert-manager provisioned)
- Gateway TLS: cert-manager managed, configurable per gateway

Deployment Security:
- XKS: Helm hooks sequence CR creation after operator readiness
- OpenShift: OLM manages operator lifecycle and RBAC
- Gateway routes restricted to Same namespace by default (secure-by-default)

Note: odh-gitops is a configuration repository. No runtime services, RBAC roles,
or secrets are directly defined — it declares manifests that operators apply at
deploy time. Runtime security posture depends on deployed operator configurations.
