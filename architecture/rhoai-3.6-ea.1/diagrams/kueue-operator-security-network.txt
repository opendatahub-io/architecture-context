    flowcontrol, scheduling, node.k8s.io

  openshift-kueue-operator (ClusterRole):
  - Manages: CRDs, webhooks, RBAC, Deployments, Secrets, Services,

  - Bound to SA: openshift-kueue-operator (ns: openshift-kueue-operator)

  kueue-metrics-auth-role (ClusterRole):
  - TokenReviews + SubjectAccessReviews (metrics auth)

  User-facing roles:
  - *-editor-role: CRUD on specific resource types
  - *-viewer-role: read-only on specific resource types
  - Covers: clusterqueues, localqueues, workloads, resourceflavors,
    topologies, cohorts, jobs, jobsets, pytorchjobs, tfjobs, mpijobs,
    paddlejobs, xgboostjobs, mxjobs, rayclusters, rayjobs

Secrets:
  - kueue-webhook-server-cert (Opaque) - TLS cert for webhook server
    Provisioned by: manifest (cert-manager)
    Auto-Rotate: Unknown

FIPS Compliance:
  - Build flags: -tags strictfipsruntime
  - Linking: Dynamic (CGO, Red Hat Go builder)
  - OpenSSL: Yes (UBI9-minimal base)
  - Crypto: stdlib crypto/tls (FIPS-compliant via strictfipsruntime + OpenSSL)

Critical Security Note:
  All 35 admission webhooks use failurePolicy: Fail.
  If the webhook server is unavailable, workload creation/updates
  for Jobs, PyTorchJobs, RayClusters, Deployments, StatefulSets,
  and Pods are BLOCKED across the entire cluster.
