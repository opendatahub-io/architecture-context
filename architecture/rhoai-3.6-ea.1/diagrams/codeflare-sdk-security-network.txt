Authentication Mechanisms:
- Kubernetes API: kube-authkit auto-detection
  - Priority: kubeconfig > in-cluster SA token > Bearer token
  - Legacy: TokenAuthentication, KubeConfigFileAuthentication (deprecated)
  - TLS: Enforced by default; CA path via CF_SDK_CA_CERT_PATH env var
         or workbench trust bundle /etc/pki/tls/custom-certs/ca-bundle.crt
  - Risk: skip_tls=True option can disable TLS verification

- Ray Dashboard: HTTP-based
  - Auth: Configurable headers and cookies via RayJobClient constructor
  - TLS: Configurable via verify parameter
  - Risk: TLS verification can be disabled
