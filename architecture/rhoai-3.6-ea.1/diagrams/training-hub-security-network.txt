Training Hub - Security Network Diagram
========================================

Training Hub is a pure Python library (pip-installable package) with NO inbound
network surface. It does not expose HTTP endpoints, gRPC services, or Kubernetes
Services. All network flows are outbound-only, initiated by the library on
behalf of the caller.

RBAC Summary:
- No ClusterRoles defined (library, not an operator)
- No RoleBindings defined
- Inherits RBAC of the calling process (notebook SA, job SA, etc.)

Service Mesh Configuration:
- Not applicable (no Kubernetes services or pods)
- If deployed inside a service-mesh-enabled pod, inherits pod's mesh config

Secrets:
- OPENAI_API_KEY (environment variable) - LLM API key for GEPA, provisioned
  by runtime environment, rotation unknown
- MLflow credentials (if applicable) - provisioned by caller/environment

FIPS Compliance:
- No direct cryptographic module imports (no ssl, hashlib, hmac, crypto, tls)
- All TLS delegated to runtime dependencies (requests, urllib3, aiohttp, litellm)
- FIPS compliance inherited from execution environment (e.g., UBI-based container)
- No explicit FIPS opt-in or configuration in this repository

Network Surface Summary:
- Inbound:  NONE (library, not a service)
- Outbound: LLM Inference API (HTTPS, API key auth) - GEPA only
            MLflow Tracking Server (HTTP/HTTPS) - optional, GEPA only
- In-process: vLLM co-located engine (GRPO only, no network)
