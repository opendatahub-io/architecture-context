Secrets:
- anthropic-credentials (Opaque) - Anthropic API credentials, provisioned by manifest
- azure-credentials (Opaque) - Azure OpenAI credentials, provisioned by manifest
- openai-credentials (Opaque) - OpenAI API credentials, provisioned by manifest
- vertex-credentials (Opaque) - Vertex AI credentials, provisioned by manifest

Authentication & Authorization:
- Auth mechanism is CRD-configured per ExternalProvider
- Supported types: apikey, sigv4, oauth2
- Credential Secret must exist in same namespace as ExternalProvider
- Operator validates Secret existence; enforcement delegated to mesh/provider

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Linking: Dynamic (CGO_ENABLED=1)
- OpenSSL: Yes (via ubi9/ubi-minimal base)
- TLS: Delegated to Istio DestinationRule (SIMPLE TLS origination)
- Crypto: stdlib crypto/tls via controller-runtime (FIPS via OpenSSL with strictfipsruntime)
- Non-FIPS risks: None detected

CRDs Managed:
- inference.opendatahub.io/v1alpha1 ExternalModel (Namespaced)
- inference.opendatahub.io/v1alpha1 ExternalProvider (Namespaced)

Istio Resources Created:
- ServiceEntry (MESH_EXTERNAL, DNS resolution, HTTPS/443) per provider
- DestinationRule (SIMPLE TLS origination) per provider

Gateway API Resources Created:
- HTTPRoute per ExternalModel targeting maas-default-gateway
