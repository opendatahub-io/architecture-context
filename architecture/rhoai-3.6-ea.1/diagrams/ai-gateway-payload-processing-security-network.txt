Authentication Configuration (per ExternalProvider CR):
- Auth Types: apikey, sigv4, oauth2 (kubebuilder enum validation)
- Credential Source: SecretRef pointing to same-namespace Kubernetes Secret
- Enforcement: CRD-specified authentication configuration
- Design-time validation: Controller validates Secret exists during reconciliation
- Runtime injection: Plugin chain injects credentials into inference requests

FIPS Compliance:
- Build flags: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Linking: Dynamic (CGO) with UBI base image OpenSSL
- TLS: Istio DestinationRule TLS SIMPLE mode for provider egress
- Crypto: stdlib crypto/tls (FIPS via OpenSSL with strictfipsruntime)
- No non-FIPS crypto risks detected

Network Summary:
- Egress: Kubernetes API (6443/TCP, HTTPS/WSS, TLS 1.2+, ServiceAccount auth)
- Egress: External LLM providers (443/TCP, HTTPS, TLS SIMPLE via Istio)
- No ingress endpoints exposed (controller-only, no serving ports)
- No cluster services exposed (operator manages resources via K8s API)
