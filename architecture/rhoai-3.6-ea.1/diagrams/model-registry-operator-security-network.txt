RBAC Summary:
- ClusterRole: model-registry-operator-manager-role
  - API Groups: modelregistry.opendatahub.io, gateway.networking.k8s.io,
                route.openshift.io, rbac.authorization.k8s.io, apps, core,
                networking.k8s.io, user.openshift.io, migration.k8s.io,
                components.platform.opendatahub.io, services.platform.opendatahub.io
  - Resources: modelregistries, httproutes, routes, deployments, services,
               secrets, configmaps, networkpolicies, roles, rolebindings,
               clusterrolebindings, groups, storageversionmigrations, auths
  - Verbs: get, list, watch, create, update, patch, delete

- Per-Registry Roles:
  - registry-user-{name}: get endpoints, services (namespace-scoped user access)
  - {name}-auth-delegator: system:auth-delegator (SubjectAccessReview delegation)
  - model-catalog-admin: get, list, patch, update, watch configmaps, secrets
  - model-catalog: get endpoints, services (authenticated users)

Secrets:
- {name}-kube-rbac-proxy (kubernetes.io/tls) - TLS cert for kube-rbac-proxy sidecar
- {name}-postgres-credentials (Opaque) - PostgreSQL connection credentials
- model-catalog-kube-rbac-proxy (kubernetes.io/tls) - TLS cert for catalog proxy
- model-catalog-postgres (Opaque) - Catalog PostgreSQL credentials

FIPS Compliance:
- Build: CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime -tags strictfipsruntime
- Linking: Dynamic (CGO) against OpenSSL via UBI9
- TLS: Reads OpenShift cluster TLS security profile; applies profile ciphers and min version
- Crypto: stdlib crypto/tls routed through OpenSSL via strictfipsruntime
