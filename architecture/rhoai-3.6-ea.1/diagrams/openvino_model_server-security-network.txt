Authentication Summary:
- Default: No authentication enforced by OVMS itself
- Optional API key: In-process Bearer API key validation via HttpRestApiHandler::isAuthorized
- Optional mTLS sidecar: nginx reverse proxy with TLS 1.2 client certificate verification
  - Cipher suites: AES256+EECDH (excluding RSA, CAMELLIA, RC4, weak hashes)
  - HSTS headers enforced
- Platform-level: KServe / Istio service mesh may provide additional transport security

RBAC Summary:
- No ClusterRoles or RoleBindings defined by this component
- OVMS runs as a container within a KServe-managed pod
- RBAC is managed by KServe and the platform operator

Secrets:
- No secrets defined directly by this component
- Model storage credentials managed by KServe storage initializer
- TLS certificates for nginx-mtls sidecar provisioned externally

FIPS Compliance:
- No explicit FIPS build flags (C++ binary, not Go)
- Dynamic linking against system OpenSSL from UBI 9 base image
- FIPS compliance inherited from host node FIPS mode + UBI base image OpenSSL
- nginx sidecar uses system OpenSSL for TLS operations
