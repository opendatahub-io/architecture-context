- No secrets defined directly by this component.
- mTLS sidecar requires TLS certificates (server cert, CA cert) mounted as volumes.
- Model storage credentials (if using S3/cloud) managed by KServe storage initializer.

FIPS Compliance:
- C++ binary compiled against openssl-devel on UBI 9.
- No explicit FIPS mode enforcement at application level.
- Inherits system OpenSSL from UBI 9 base (supports FIPS when host enables it).
- nginx mTLS sidecar: TLSv1.2 with AES256+EECDH cipher suite.
- No explicit FIPS mode configured for nginx.
