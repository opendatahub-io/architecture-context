Authentication & Authorization:
- Endpoint: OGX API (port 8321)
- Mechanism: OAuth2 token with JWKS validation (conditional on AUTH_ISSUER)
- Enforcement: OGX server auth middleware
- Policy: Read unowned resources (public); create (authenticated); read/update/delete (owner only)
- CA cert: AUTH_TLS_CAFILE environment variable
- Key recheck: 3600 seconds

RBAC Summary:
- No Kubernetes ClusterRoles or RoleBindings defined in this component
- Access control is application-level via OAuth2 token ownership model

Secret Management:
- entrypoint.sh resolves 18 _FILE secret environment variables from K8s-mounted files
- Prevents secret leakage via /proc/1/environ
- Secrets include: API keys, database passwords, tokens for all providers

FIPS Compliance:
- Python component: No Go binaries produced
- TLS: Server runs --insecure; TLS delegated to platform ingress
- OpenSSL: Inherited from AIPCC UBI base image
- Per-provider TLS verify is configurable
- Milvus supports mTLS (ca_pem, client_pem, client_key)
- AUTH_TLS_CAFILE for JWKS CA verification
