Secrets:
- DATABASE_PASSWORD (env var) - MariaDB credentials, runtime environment provisioned
- QUARKUS_DATASOURCE_PASSWORD (env var) - MariaDB credentials (legacy name), runtime environment provisioned

Authentication Model:
- Primary: kube-rbac-proxy sidecar performs SubjectAccessReview against OpenShift RBAC
- HTTP bound to 127.0.0.1:8080 (loopback only) - not directly accessible from network
- No application-level authentication middleware registered in FastAPI
- Optional direct HTTPS on 0.0.0.0:4443 with TLS cert-based access (bypasses kube-rbac-proxy)

TLS Configuration:
- Service HTTP: No encryption (loopback only, behind kube-rbac-proxy)
- Service HTTPS: TLS via Hypercorn, certs at /etc/tls/internal/{tls.crt, tls.key}
- MariaDB: Optional TLS via DATABASE_TLS_CA_CERT environment variable
- cryptography>=48.0.1,<50 library for TLS support
- FIPS compliance: Not verified at application level (depends on base image)

RBAC Summary:
- No ClusterRoles or RoleBindings defined in component source
- Authentication delegated entirely to kube-rbac-proxy sidecar
- Platform operator (TrustyAI Operator / ODH Operator) expected to configure RBAC
