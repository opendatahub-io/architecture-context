Security Surface Summary:
- No network services exposed (no listening ports)
- No persistent state or storage
- No authentication mechanism of its own
- Read-only Kubernetes API access only
- Credentials: Inherited from oc adm must-gather caller's kubeconfig
- No RBAC roles defined by the component itself (uses framework-provided SA)

Distribution Detection (xks_util.sh):
- Examines: Infrastructure CRDs, kernel versions, provider IDs, OS images
- Classifies: OpenShift, CoreWeave, AKS, EKS, or generic Kubernetes
- OpenShift path: Uses `oc adm inspect`
- xKS path: Uses custom `kubectl_inspect` function

Data Sensitivity:
- Collects pod logs which may contain application data
- Collects resource definitions which may contain configuration secrets
- Collects Helm release values which may contain sensitive parameters
- All collected data is written to ephemeral pod storage then transferred to caller
