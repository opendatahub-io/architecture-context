FIPS Compliance:
- Go binaries: CGO_ENABLED=1, -tags strictfipsruntime (dynamic linking to system OpenSSL)
- Node.js backend: OpenSSL inherited from UBI9/nodejs-22 base (no explicit FIPS opt-in)
- All images: UBI9 base (ubi9/go-toolset, ubi9-minimal, nodejs-22)

Authentication Model (Two-Layer):
- Layer 1: kube-rbac-proxy (port 8443)
  - Validates OpenShift OAuth tokens
  - Injects identity headers for downstream consumption
- Layer 2: Go BFF sidecars (ports 8043-8843)
  - Independent Bearer token validation
  - SubjectAccessReviews for fine-grained authorization
  - Configurable auth-method: "internal" or "user_token"
  - agent-ops BFF: additional per-agent RBAC via SSAR
