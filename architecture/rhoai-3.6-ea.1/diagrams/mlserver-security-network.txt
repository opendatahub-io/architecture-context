RBAC Summary:
- No ClusterRoles or RoleBindings defined by MLServer
- Authentication delegated entirely to kube-rbac-proxy sidecar
- kube-rbac-proxy enforces OpenShift OAuth/ServiceAccount token validation

Security Controls:
- Trusted Runtimes Allowlist: /etc/mlserver/trusted-runtimes.json
  - Restricts which model implementation classes can be loaded
  - Prevents arbitrary code execution via model loading
  - Import paths validated against canonical patterns
  - Built-in aliases normalize legacy paths

Secrets:
- No application-level secrets defined
- Authentication credentials managed by platform (kube-rbac-proxy)

FIPS Compliance:
- No application-level TLS or cryptographic operations
- FIPS compliance inherited from AIPCC UBI base image OpenSSL
- System crypto policies enforced at OS level when FIPS mode enabled
- Base images: quay.io/aipcc/base-images/cpu:3.5 (CPU)
                quay.io/aipcc/base-images/cuda-12.9-el9.6:3.5 (CUDA)

Network Security Notes:
- MLServer binds ALL ports without TLS (plaintext HTTP/gRPC)
- gRPC server explicitly uses add_insecure_port
- REST server runs uvicorn without TLS configuration
- ALL encryption and authentication delegated to platform layer:
  - kube-rbac-proxy sidecar (auth enforcement)
  - Istio service mesh (mTLS between pods)
  - OpenShift Routes (external TLS termination)
