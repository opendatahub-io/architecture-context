SECURITY SUMMARY:

Authentication & Authorization:
- MLServer has NO application-level authentication
- All auth is platform-delegated to kube-rbac-proxy sidecar
- kube-rbac-proxy enforces OpenShift OAuth / ServiceAccount token validation
- 16 gRPC endpoints + 1 REST API group protected by kube-rbac-proxy

TLS / Encryption:
- REST Server (8080): Plaintext HTTP/1.1 - no SSL context configured
- gRPC Server (8081): Plaintext gRPC - explicit add_insecure_port binding
- Metrics Server (8082): Plaintext HTTP/1.1
- All TLS termination delegated to platform ingress chain
- FIPS: No application-level crypto; inherits OpenSSL from AIPCC/UBI base image

RBAC:
- No ClusterRoles or RoleBindings defined by MLServer itself
- RBAC enforcement is handled by kube-rbac-proxy sidecar at the pod level

Secrets:
- No secrets defined or managed by MLServer
- Model storage credentials managed by KServe platform

Runtime Security:
- Trusted runtimes allowlist (/etc/mlserver/trusted-runtimes.json)
  enforces which ML runtime implementations can be loaded
- Prevents arbitrary code execution via untrusted runtime imports
- Development mode (file absent) allows any valid runtime import path

Build Security:
- Konflux build pipeline
- Base image: quay.io/aipcc/base-images/cpu:3.6.0-ea.1 (AIPCC/UBI)
