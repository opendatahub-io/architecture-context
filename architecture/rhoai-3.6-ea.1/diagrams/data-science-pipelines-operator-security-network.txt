RBAC Summary:

ClusterRoles:
- manager-role (ServiceAccount: controller-manager)
  - 14+ API Groups, broadest RBAC footprint
  - Full CRUD on DSPA, Argo, Kubeflow, Pipeline, Seldon, Ray, CodeFlare resources
  - Auth token/SAR creation for webhook validation
  - Admission webhook management

- argo-cluster-role (ServiceAccount: argo)
  - Argo workflow execution permissions
  - Secret access RESTRICTED to argo-workflows-agent-ca-certificates (resourceNames)

- aggregate-dspa-admin-edit
  - Aggregates into OpenShift admin/edit ClusterRoles
  - Full CRUD on DSPA and Pipeline resources

- aggregate-dspa-admin-view
  - Aggregates into OpenShift view ClusterRole
  - Read-only on DSPA and Pipeline resources

- argo-aggregate-to-admin/edit/view
  - Tiered access to Argo Workflow resources
  - admin/edit: full CRUD; view: read-only

- leader-election-role (Role, not ClusterRole)
  - ConfigMaps, Leases, Events in operator namespace

Service Accounts:
- controller-manager (namespace: datasciencepipelinesapplications-controller)
  - Bound to: manager-role, manager-argo-role, leader-election-role
- argo (namespace: argo)
  - Bound to: argo-cluster-role, argo-role

FIPS Compliance:
- Build: GOFIPS140=v1.0.0, CGO_ENABLED=0, -tags no_openssl
- Runtime: Go native FIPS 140 crypto module (no OpenSSL dependency)
- TLS: Cipher suites from OpenShift APIServer TLS profile
- Fallback: Intermediate TLS profile on non-OpenShift clusters

Security Notes:
- No external ingress (operator is cluster-internal only)
- No secrets defined in architecture (uses existing cluster secrets)
- Health/readiness probes unauthenticated by design (port 8081)
- Metrics endpoint unauthenticated (port 8080, cluster-internal)
- Webhook server TLS auto-configured from cluster TLS profile
- SecurityProfileWatcher triggers graceful restart on TLS profile changes
