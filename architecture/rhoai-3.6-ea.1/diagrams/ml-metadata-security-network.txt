RBAC Summary:
- No Kubernetes RBAC roles defined in this repository
- RBAC is managed externally by the Data Science Pipelines Operator
- The MLMD server runs as a companion service within the DSP deployment

Authentication & Authorization:
- Endpoint: MetadataStoreService gRPC (all RPCs)
- Auth Mechanism: None by default
  - Optional mTLS via SSLConfig (application-level)
  - Platform-delegated: service mesh / network policies provide isolation
- No Kubernetes-native auth enforcement in this component

Secrets:
- No secrets defined in this repository
- Database credentials and TLS certificates are provisioned externally
  by the Data Science Pipelines Operator

FIPS Compliance:
- C++ binary links against system OpenSSL (dynamically linked)
- FIPS-validated when RHEL 9 host operates in FIPS mode
- No explicit application-level FIPS mode configuration
- Crypto libraries: gRPC C++ (OpenSSL), mariadb-connector-c (OpenSSL)

Network Exposure:
- No Kubernetes Service, Ingress, or Route defined in this repo
- Deployment and network exposure managed by DSP Operator
- Typical deployment: cluster-internal only (no external ingress)
