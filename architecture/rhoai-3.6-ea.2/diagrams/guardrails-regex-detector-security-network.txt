Security Concerns:
1. PLAIN HTTP: Service binds plain TCP with no TLS termination
   - Mitigation: Expected to run behind service mesh providing mTLS
2. NO AUTHENTICATION: No auth middleware; any caller on the network can invoke the API
   - Mitigation: Expected network-level isolation via NetworkPolicy or service mesh
3. PII LOGGING: Request payloads containing PII are logged at info level (src/detectors.rs:100)
   - Risk: Sensitive data (the content being scanned for PII) appears in application logs
4. ReDoS RISK: User-supplied regex patterns are compiled and executed without complexity limits
   - Risk: Maliciously crafted patterns could cause CPU exhaustion
5. SILENT FAILURES: Invalid custom regex patterns are silently skipped (warning log only)
   - Risk: Caller may receive empty results with no error indication

FIPS Compliance:
- Application performs no cryptographic operations (crypto-free)
- No TLS, no certificate handling, no crypto crate dependencies
- compat-openssl11 RPM installed in image but not used by application code
- Rust binary; no Go FIPS build flags applicable
