TLS Configuration:
- Dynamic from OpenShift cluster TLS security profile
- Fallback: Mozilla Intermediate (TLS 1.2+, ECDHE cipher suites, ALPN h2/http/1.1)
- Post-quantum support: X25519MLKEM768 curve
- FIPS: CGO_ENABLED=1, -tags strictfipsruntime, dynamic OpenSSL linking
- Base images: ubi9/ubi-minimal-pqc (Go), ubi9/nodejs-22 + DEFAULT:PQ policy (Node.js)

Multi-Tenancy:
- Tenant boundary: per-namespace + per-user (RBAC)
- User-scoped K8s API calls via token impersonation
- SubjectAccessReview for fine-grained per-resource access (e.g., agent-ops)
- Cluster-scoped CRDs (Dashboard, WorkspaceKind) are admin-only
