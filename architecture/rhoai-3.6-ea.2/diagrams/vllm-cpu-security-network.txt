RBAC Summary:
- No RBAC resources — this is an application container, not an operator.
- Runs as non-root (UID 2000, GID 0) for OpenShift compatibility.
- No ServiceAccount, ClusterRole, or RoleBinding defined.

Secrets:
- VLLM_API_KEY (env var) - Bearer token for API authentication, no auto-rotation
- OPENAI_API_KEY (env var) - Client authentication for benchmarks, no auto-rotation
- S3_SECRET_ACCESS_KEY (env var) - S3 storage access, no auto-rotation
- MODELSCOPE_API_TOKEN (env var) - ModelScope model download auth, no auto-rotation
- EXA_API_KEY (env var) - MCP tool integration, no auto-rotation
- GH_TOKEN / GITHUB_TOKEN (env var) - GitHub API access, no auto-rotation

FIPS Compliance Notes:
- Base image: ubi9-minimal-pqc (post-quantum UBI variant with system OpenSSL)
- Python ssl module links to system OpenSSL at runtime
- Default multimodal hasher: blake3 (NOT FIPS 140-3 compliant)
  - Mitigated via VLLM_MM_HASHER_ALGORITHM=sha256 or sha512
- ssl_cert_reqs defaults to CERT_NONE (no client certificate verification)
- gRPC server uses insecure port (no TLS)

Security Gaps:
1. Authentication is optional (only active when VLLM_API_KEY is set)
2. Many endpoints (/health, /tokenize, /generate, etc.) are never authenticated
3. gRPC server has no TLS or authentication
4. Default blake3 hasher is not FIPS-compliant
5. No NetworkPolicy resources — relies on platform-level network isolation
6. No hermetic build (no lock files, no hash-pinning)
7. ssl_cert_reqs=CERT_NONE by default (no mTLS)
