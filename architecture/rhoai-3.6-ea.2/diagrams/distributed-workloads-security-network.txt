RBAC Summary:
  This repository defines NO ClusterRoles.
  Tests run as cluster-admin ServiceAccount.

  Example/Workshop Role Bindings (non-production):
  - edit → distributed/stable-diffusion-nb (edit ClusterRole)
  - nfs-server-sa-anyuid → nfs/nfs-server-sa (system:openshift:scc:anyuid)
  - nfs-server-sa-privileged → nfs/nfs-server-sa (system:openshift:scc:privileged)

Secrets:
  - minio (Opaque) - MinIO credentials, example manifests, no auto-rotation
  - minio-secret (Opaque) - MinIO credentials for HPO example, no auto-rotation

Authentication Summary:
  - Kubernetes API: ServiceAccount token (cluster-admin for tests)
  - S3 Storage: AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY (env vars)
  - HuggingFace Hub: HF_TOKEN bearer token (env var)
  - MPI SSH: Auto-generated SSH keys (ephemeral per job)

TLS/Crypto Notes:
  - Test code uses InsecureSkipVerify: true for Prometheus, Ray, and S3 clients
    (test-only, does NOT affect production images)
  - Production images: cryptography==46.0.5, pyopenssl==26.4.0 (FIPS via base OpenSSL)
  - Certificate handling: System trust store via UBI/AIPCC base image
  - MPI inter-node: No encryption (RDMA/InfiniBand direct)

FIPS Compliance:
  - No Go binaries built for production (test-only Go code)
  - Python images inherit FIPS from UBI/AIPCC base image OpenSSL
  - One Ray image (2.58.0-py312-cu129-th081) uses CGO_ENABLED=1
    GOEXPERIMENT=strictfipsruntime for Training Hub Go binary
