RBAC Summary:
- No ClusterRoles shipped in repository manifests
- Required at deployment time:
  - ServiceAccount with TokenReview create permission
    (when --enable-k8s-token-validation is enabled)
  - API Group: authentication.k8s.io
  - Resource: tokenreviews
  - Verbs: create

Secrets:
- kube-auth-proxy-secret (Opaque) — OAuth client-id, client-secret, cookie-secret
  - Provisioned By: Manual (deployment-specific)
  - Auto-Rotate: No
  - Scope: All users of a single proxy instance share these credentials

TLS Configuration:
- Minimum TLS Version: 1.2 (default, configurable)
- Cipher Suites: Configurable via --tls-cipher-suites
- Curve Preferences: Configurable via --tls-curve-preferences
- Custom CA: Supported via --ca-file flag
- InsecureSkipVerify: Configurable via --ssl-insecure-skip-verify (disabled by default)

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, -tags strictfipsruntime
- Runtime Image: ubi9/ubi-minimal-pqc (post-quantum cryptography variant)
- Crypto: stdlib crypto/tls, crypto/sha256, crypto/x509; golang.org/x/crypto; go-jose
- Risk: InsecureSkipVerify flag exists but is disabled by default

Token Caching:
- TokenReview results cached with SHA-256 hashed keys (raw tokens not stored)
- Default TTL: 10 seconds
- Concurrent deduplication: singleflight-inspired pattern
- Lazy expiration sweep on writes
