RBAC Summary:
  No RBAC roles defined. This is a Python library, not a Kubernetes workload.
  All RBAC is inherited from the host vLLM deployment's ServiceAccount.

Authentication & Authorization:
  - Endpoint auth: NOT implemented by this library
  - All endpoints are read-only (GET only)
  - Auth enforcement delegated to:
    - vLLM server configuration
    - Platform ingress (Istio, OpenShift Route, etc.)
    - Kubernetes NetworkPolicy
  - Risk: Endpoints are open to anyone who can reach the vLLM server port

Secrets & Sensitive Data:
  - No Kubernetes secrets used directly
  - kv_connector_extra_config values redacted by default (may contain credentials)
  - Redaction controlled by LLM_D_INTROSPECTION_EXPOSE_KV_EXTRA_CONFIG env var
  - Device properties and KV cache metadata are non-sensitive operational data

Service Mesh Integration:
  - Inherited from host vLLM deployment
  - If vLLM pod has Istio/Service Mesh sidecar, plugins benefit from mTLS automatically
  - No PeerAuthentication or AuthorizationPolicy defined by this library

FIPS Compliance:
  - No cryptographic operations in this codebase
  - No TLS configuration — served via host vLLM HTTP server
  - FIPS compliance inherited from host container image (typically UBI-based vLLM)
