  - Read HardwareProfile CRs (infrastructure.opendatahub.io)
  - Access Kubernetes API for namespace-scoped operations

Security Findings:
⚠ Eval Hub API: verify_tls=False by default (components/evaluation/evalhub/kserve/component.py:51)
⚠ Tabular data loader: retries S3 downloads with verify=False after SSL errors
⚠ Kubeflow Model Registry: HTTP only (8080/TCP), no encryption, no auth
⚠ Milvus: gRPC (19530/TCP), no encryption, token auth optional

FIPS Compliance:
- Crypto policy: DEFAULT:PQ (post-quantum) set in init container Dockerfile
- OpenSSL: Present in UBI9 base and AIPCC bases
- cryptography==50.0.1 linked to OpenSSL
- Non-FIPS risk: verify_tls=False, verify=False patterns bypass TLS verification

Multi-Tenancy:
- Tenant boundary: per-namespace
- KServe CRs scoped to namespace
- Eval Hub uses X-Tenant header (defaults to namespace name)
- Milvus isolation: per-collection naming
- No NetworkPolicy resources defined by component
