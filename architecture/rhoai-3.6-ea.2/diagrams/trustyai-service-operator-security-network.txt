TLS Configuration:
- Operator reads OpenShift APIServer TLS profile at startup
- Resolves cipher suites and protocol versions from cluster profile
- ProfileWatcher monitors changes and triggers graceful manager restart
- Falls back to Intermediate defaults on non-OpenShift clusters
- FIPS-compliant: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime
- Runtime base: registry.redhat.io/ubi9/ubi-minimal-pqc

    Verbs: create, delete, get, list, patch, update, watch

Multi-Tenancy:
- EvalHub supports multi-tenant (namespace label selector) and single-tenant modes
- Per-namespace RBAC isolation: evalhub-tenant-admin, evalhub-user roles
- Cross-namespace ConfigMap propagation for providers and collections
- Placement guard prevents control-plane namespace from being a tenant
- No explicit NetworkPolicy created (relies on platform-level policies)
