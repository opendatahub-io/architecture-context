RBAC Summary:
- No ClusterRole or Role resources defined in the repository.
- Helm chart creates a ServiceAccount but no role bindings.
- Metrics endpoint optionally authenticated via kube-rbac-proxy
  (controller-runtime metrics server infrastructure).

Pod Security:
- runAsNonRoot: true
- seccompProfile: RuntimeDefault
- Capabilities: drop ALL
- No privilege escalation

Secrets:
- Redis URL Secret (Opaque) — Redis/Valkey connection URL with credentials
  Provisioned by: Helm chart or pre-existing
  Auto-Rotate: No
- TLS certs (kubernetes.io/tls) — Client certificates for mTLS to inference gateway
  Provisioned by: Manual / cert-manager
  Auto-Rotate: No

FIPS Compliance:
- Konflux build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime
- Base image: registry.redhat.io/ubi9/ubi-minimal-pqc (post-quantum crypto)
- TLS: MinVersion TLS 1.2, system + custom CA pool, optional mTLS
- InsecureSkipVerify: exists but gated behind explicit CLI flag (dev/test only)

Multi-Tenancy Considerations:
- Tenant boundary: per-attribute (userid metadata field)
- No per-tenant auth — trusts queue-level access control
- Result IDs are caller-assigned; collision causes cross-tenant result leakage
- Rate limiting via redis-quota gate is advisory, not hard isolation
