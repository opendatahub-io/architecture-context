RBAC Summary:
- No RBAC resources defined by this component
- RBAC is managed by the TrustyAI LMES operator
- Job runs as UID 65532 (non-root)

Secrets Summary:
- OPENAI_API_KEY (env) — Model endpoint auth, from EvalHub model credentials
- HF_TOKEN (env) — HuggingFace gated dataset access, optional
- AWS_SECRET_ACCESS_KEY (env) — S3 storage authentication
- REGISTRY_PASSWORD (env) — OCI registry authentication
- ANTHROPIC_API_KEY (env) — Anthropic API backend, optional
- WATSONX_API_KEY (env) — IBM WatsonX AI backend, optional
- All secrets injected via environment variables, no auto-rotation

Security Controls:
- Credential redaction: _sanitize_error_message strips API keys/tokens from error callbacks
- Path traversal protection: Job spec path resolved and constrained to /meta (CWE-22)
- Non-root execution: Container runs as UID 65532
- TLS verification: Configurable per-endpoint with custom CA bundle support
- Symlink validation: CA certificate paths checked for symlink attacks
- Air-gapped support: HF_HUB_OFFLINE=1 disables all HuggingFace network calls

FIPS Compliance:
- TLS via system OpenSSL (FIPS-capable via AIPCC/UBI base image)
- Crypto: stdlib ssl + hashlib (SHA-256 for non-security cache keys only)
- No non-FIPS crypto risks detected
