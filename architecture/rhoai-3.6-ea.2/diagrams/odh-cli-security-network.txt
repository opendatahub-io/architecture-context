RBAC Summary:
- No RBAC manifests deployed by odh-cli
- CLI operates with user's existing kubeconfig credentials
- RBAC pre-flight via SelfSubjectAccessReview before privileged operations
- Required permissions depend on subcommand:
  - lint: Read-only (list DSC, DSCI, CRDs, Deployments, Subscriptions)
  - migrate: Read/Write (patch, create, delete resources)
  - diagnose: Read-only (list resources, events, pod logs)
  - deps install: Write (create OLM Subscriptions)
  - backup: Read-only (get workload configurations)

FIPS & Crypto Configuration:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Runtime: OpenSSL via UBI9 base image (ose-cli-rhel9)
- Post-Quantum: DEFAULT:PQ crypto policy via update-crypto-policies
- TLS Minimum: tls.VersionTLS12
- Risk: InsecureSkipVerify=true on TrustYAI migration HTTP client
  (skips certificate validation for in-cluster self-signed route certs)

Secrets:
- No secrets deployed by CLI
- kubeconfig credentials: user-provided (oc login, mounted volume)
- Bearer tokens: forwarded from kubeconfig REST config to TrustYAI routes

Error Classification:
- TLS errors classified: UnknownAuthority, CertificateInvalid,
  HostnameError, RecordHeaderError → user-facing suggestions
- Kubernetes API errors: mapped to categories with exit codes
- DNS, filesystem, context cancellation → actionable messages

Build Hermeticity:
- RPM lock: rpms.lock.yaml (jq, oniguruma, crypto-policies-scripts, make)
- Go deps: go.sum
- Architectures: aarch64, ppc64le, x86_64
- No Hermeto/cachi2 prefetch on this branch
