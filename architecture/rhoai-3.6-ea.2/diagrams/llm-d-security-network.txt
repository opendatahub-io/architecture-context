RBAC Summary:
- No RBAC roles defined in this repository
- RBAC for the router and other components defined in their respective repos
- ServiceAccount: sa (automountServiceAccountToken: false)

Secrets:
- llm-d-hf-token (Opaque) - HuggingFace API token, manual provisioning, no auto-rotation

Network Policies:
- None defined in repository manifests
- Isolation depends on cluster-level NetworkPolicy and Gateway configuration

Authentication & Authorization:
- Model-server endpoints: No auth by default
- Auth enforcement delegated to Gateway implementation
- HuggingFace access: Bearer token via HF_TOKEN secret

Multi-Tenancy:
- Tenant boundary: per-namespace (one deployment per namespace)
- Shared Gateway: allowedRoutes from: All (cross-namespace routing)
- No enforced quotas in manifests (configurable per guide)

Security Gaps:
- No TLS on model-server pods (plain HTTP on port 8000)
- No TLS on NIXL KV-cache transfer (plain TCP on port 5600)
- No NetworkPolicy resources defined
- No auth on model-server endpoints
- Gateway shared across all namespaces without restriction
- TLS termination and auth enforcement depend entirely on gateway implementation
