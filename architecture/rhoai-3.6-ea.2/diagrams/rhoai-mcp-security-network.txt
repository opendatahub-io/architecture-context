Authentication & Authorization:
- /health: No auth (public health check)
- /.well-known/oauth-protected-resource: No auth (RFC 9728 metadata)
- /sse, /messages: Bearer token (OIDC JWT or OCP OAuth), fail-closed
- MCP tools: Per-user RBAC via SubjectAccessReview, governed tools filtered

Secrets:
- workflow-hmac-secret (in-memory) - HMAC key for workflow token signing,
  auto-generated at process start (or RHOAI_MCP_WORKFLOW_HMAC_SECRET env var)

Security Hardening:
- Container: runAsNonRoot, readOnlyRootFilesystem
- Capabilities: drop ALL
- Seccomp: RuntimeDefault
- OIDC: HTTPS-only issuer URLs, RS256/ES256 only (FIPS-approved)
- Headers: CWE-113 control character rejection
- Impersonation: CWE-269 header clearing before set
- JWKS: CWE-400 rate-limited refresh (30s interval)
- Workflow tokens: HMAC-SHA256 signed, step-specific validation
- RHOAI overlay: read-only mode enforced by default
