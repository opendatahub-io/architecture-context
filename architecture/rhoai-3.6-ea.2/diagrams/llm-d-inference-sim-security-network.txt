  - Self-signed option: RSA 4096-bit
- ZMQ PUB socket: No TLS support (plaintext ZMQ)

- Distroless base image: Minimal attack surface
- Non-root user 65532
- Would NOT pass Konflux check-payload FIPS validation
  (acceptable for development/testing tool)
