RBAC Summary:
- The SDK does not define any RBAC resources (no ClusterRoles, Roles, or Bindings)
- Relies entirely on the user's kubeconfig or ServiceAccount RBAC permissions
- Required permissions (user must have):
  - trainer.kubeflow.org: TrainJobs — create, get, list, watch, delete
  - kubeflow.org: Experiments — create, get, list, watch, delete
  - sparkoperator.k8s.io: SparkConnects — create, get, list, watch, delete
  - core: Pods, Events — get, list, watch (for status monitoring)

Secrets:
- HF_TOKEN (env var) — HuggingFace Hub auth for gated models, user-provided, no rotation
- AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY (env var) — S3 credentials, user or RHOAI Dashboard
- AWS_S3_ENDPOINT (env var) — Custom S3 endpoint, user-provided
- data_connection_name (K8s Secret ref) — S3 credentials mounted into training pods

Security Notes:
- Injected metrics endpoint (:28080) has NO authentication or encryption
  - Mitigated by: cluster-internal only, no sensitive data exposed
- SSL verification for S3 can be disabled (verify_cloud_storage_ssl=False)
  - Warning logged when disabled
  - Used for self-signed certificate environments
- Code injection via inspect.getsource() creates tight SDK↔pod coupling
  - Training pod code is entirely determined by SDK version
