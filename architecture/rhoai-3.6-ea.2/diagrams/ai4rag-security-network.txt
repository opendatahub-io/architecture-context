URL Trust Policy (ai4rag/utils/network.py):
- ensure_safe_url() applied to ALL external connections
- HTTPS enforced for any endpoint outside localhost or *.cluster.local
- No unverified-TLS fallback (removed in v0.21.0, commit 120e455)
- Custom CA bundles supported for every backend
- No "skip verification" escape hatch

RBAC Summary:
- No Kubernetes RBAC roles (ai4rag is a library, not an operator)
- Starter kit auth_wrapper requires a ServiceAccount token for K8s TokenReview
- Optional ALLOWED_SA_USERNAME restricts to a specific ServiceAccount

Secrets:
- MAAS_API_KEY (env var) - MaaS authentication
- MILVUS_TOKEN (env var) - Milvus server authentication
- MILVUS_CA_CERT (env var) - PEM certificate for Milvus TLS
- PGVECTOR_PASSWORD (env var) - PostgreSQL authentication
- PGVECTOR_CA_CERT (env var) - PEM certificate for PostgreSQL TLS
- NEO4J_PASSWORD (env var) - Neo4j database authentication
- AWS_SECRET_ACCESS_KEY (env var) - AWS S3 authentication
- AWS_CA_BUNDLE (env var) - CA bundle for S3 TLS
- MAAS_CA_BUNDLE (env var) - CA bundle for MaaS TLS
- K8S_REVIEWER_TOKEN (env var) - K8s TokenReview authentication (starter kit)
- AGENT_CONFIG_B64 (env var) - Base64-encoded agent config (starter kit)
- All secrets are environment variables; no auto-rotation

FIPS Compliance:
- Python stdlib ssl module delegates to system OpenSSL
- On RHEL/UBI, inherits FIPS mode from host OS
- hashlib.sha256 used for content deduplication only (non-security)
- No custom cryptographic operations

Container Security:
- Runs as non-root (UID 1001) via Containerfile.openshell
- NVIDIA base image for OpenShell sandbox
- uv for hermetic dependency installation
