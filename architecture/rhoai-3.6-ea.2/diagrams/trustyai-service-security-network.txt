Secrets:
- DATABASE_PASSWORD (env var) — MariaDB auth, provisioned by TrustyAI operator, no auto-rotate
- QUARKUS_DATASOURCE_PASSWORD (env var) — Legacy MariaDB auth (backward compat), no auto-rotate
- TLS cert/key (/etc/tls/internal/) — HTTPS endpoint TLS, provisioned by cert-manager, auto-rotated
- DATABASE_TLS_CA_CERT (/etc/tls/db/ca.crt) — MariaDB TLS CA, provisioned by platform, no auto-rotate

Authentication & Authorization:
- Port 8081 (API): Bearer token via kube-rbac-proxy → Kubernetes RBAC enforcement
- Port 4443 (HTTPS): TLS client certificates (optional), system crypto policy
- Port 8080 (health/consumer): No authentication — open to cluster network

FIPS Compliance:
- TLS: System crypto policy delegation via ssl.create_default_context() — no hardcoded ciphers
- Crypto: Python stdlib ssl module delegates to system OpenSSL (UBI 9)
- Build: AIPCC cpu-el9.8 base image inherits UBI 9 OpenSSL
- Risk: hashlib used only for Prometheus metric name derivation (non-security)

RBAC:
- No RBAC manifests in this repository — managed externally by TrustyAI operator

Multi-Tenancy:
- Tenant boundary: per-namespace (one TrustyAI Service instance per namespace)
- Health/consumer port (8080) has no authentication — relies on network policy
- No per-model access control within a namespace
