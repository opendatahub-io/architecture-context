RBAC Summary:
- No RBAC roles defined. The orchestrator runs as a standalone service
  without Kubernetes API access.

Authentication Summary:
- Inbound: Header passthrough — configured headers forwarded to downstream
  services. X-Forwarded-Access-Token rewritten to Authorization: Bearer.
  No native token validation by orchestrator.
- Outbound to detectors: Optional Bearer token
- Outbound to OpenAI: API token from environment variable
- Outbound to TGIS/Chunker: No application-level auth (gRPC)
- mTLS: Optional on inbound (guardrails port only)

Secrets:
- TLS server cert/key (kubernetes.io/tls) — server TLS for port 8033
- TLS client CA cert (Opaque) — client cert verification for mTLS
- API tokens (Opaque, env var) — downstream service auth
- Downstream TLS certs (Opaque) — client TLS for downstream connections
- No auto-rotation configured

FIPS Compliance Warning:
- TLS: rustls 0.23.36 with ring crypto provider (NOT FIPS-validated)
- OpenSSL is in the image but NOT used by the application for crypto
- Build may pass check-payload but runtime crypto is non-FIPS
- NoVerifier available: insecure mode completely bypasses cert verification

Build & Image Security:
- Base image: UBI 9 minimal PQC (post-quantum cryptography variant)
- Non-root user: orchestr8 (UID 1001)
- Hermetic build: Cargo.lock + rpms.lock.yaml + Hermeto prefetch
- Multi-arch: x86_64, aarch64, ppc64le, s390x
- Release profile: LTO enabled, symbols stripped
