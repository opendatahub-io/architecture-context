TLS Certificate Chain:
- CA: KubeRay-generated CA stored in {cluster}-ca-secret-* (Opaque)
- Client cert: SDK-generated from CA (RSA-3072, SHA-256, RFC 5280 extensions)
- Storage: ~/.local/share/codeflare/tls/{cluster}/ (0600/0700 perms)
- Rotation: No auto-rotation; certs regenerated per cluster creation

Custom CA Bundle Support:
- CF_SDK_CA_CERT_PATH env variable (user-specified)
- /etc/pki/tls/custom-certs/ca-bundle.crt (RHOAI workbench default)
- System trust store (fallback)

Secrets:
- {cluster}-ca-secret-* (Opaque) - CA cert and key, provisioned by KubeRay, no auto-rotation
- minio-secret (test infrastructure only, not production)

RBAC Note:
- All RBAC definitions in the repository are TEST INFRASTRUCTURE, not production roles.
- Production access is governed by the user's existing Kubernetes RBAC permissions.
- The SDK performs no authorization checks; it delegates entirely to the K8s API server.
