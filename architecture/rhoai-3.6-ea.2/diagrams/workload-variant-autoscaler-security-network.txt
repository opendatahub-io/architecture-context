Secrets:
- epp-metrics-token (kubernetes.io/service-account-token)
  Purpose: SA token for EPP metrics reader; mounted into controller pod
  Provisioned by: Manifest (Kubernetes auto-populates)
  Auto-Rotate: No

- controller-manager-token (kubernetes.io/service-account-token)
  Purpose: SA token for ServiceMonitor bearer auth (OpenShift overlay)
  Provisioned by: OpenShift overlay manifest
  Auto-Rotate: No

- metrics-server-cert (kubernetes.io/tls)
  Purpose: TLS serving cert for metrics endpoint (OpenShift overlay)
  Provisioned by: service-ca controller (via annotation)
  Auto-Rotate: Yes (service-ca auto-rotation)

TLS Configuration:
- Metrics endpoint: self-signed TLS by default; service-ca TLS on OpenShift
- Prometheus connection: MinVersion TLS 1.2, custom CA bundle supported,
  mTLS with client certs supported
- InsecureSkipVerify: available but gated behind explicit config,
  logged as not recommended for production
- URL credential embedding: explicitly rejected

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Base image: ubi9/ubi-minimal-pqc (post-quantum variant)
- Runtime crypto: stdlib crypto/tls via OpenSSL (FIPS mode)
