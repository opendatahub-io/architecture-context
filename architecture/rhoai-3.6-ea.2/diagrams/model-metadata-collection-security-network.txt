RBAC Summary:
  - No ClusterRoles defined
  - No RoleBindings defined
  - No ServiceAccounts created
  - Runtime container runs as non-root user 1001

Secrets:
  - HF_TOKEN (env var, .env) - HuggingFace API auth, build-time only, manual, no rotation
  - GITHUB_TOKEN (env var) - GitHub API auth, build-time only, manual/CI, no rotation
  - Docker config (~/.docker/config.json) - Registry auth, build-time only, manual/CI
  - git_auth_secret (Kubernetes Secret) - Konflux/Tekton Git auth, pipeline provisioned

FIPS Compliance:
  - Runtime image: No Go binaries, no compiled code, no crypto surface
  - Base image: UBI 9 minimal-pqc (inherits OpenSSL from base)
  - Build tools: CGO_ENABLED=0 (not FIPS-compliant but irrelevant - not in runtime image)
  - No explicit TLS version pinning in build-time tools (uses Go defaults)

Service Mesh Configuration:
  - N/A - No network endpoints, no service mesh integration required

Key Security Properties:
  - Runtime attack surface: Essentially zero (sleep infinity, no network, no ports)
  - Build-time attack surface: HTTPS egress to 4 external endpoints
  - All build-time auth tokens are optional (graceful fallback to unauthenticated)
  - Container runs as non-root (UID 1001)
  - Hermetic build pipeline with Go module prefetch
