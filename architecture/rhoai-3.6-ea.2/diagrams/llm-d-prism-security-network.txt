Authentication & Authorization Summary:
- Primary AuthN: GitHub OAuth (authorization code flow)
- Token transport: X-Prism-Github-Token header
- Identity resolution: GitHub username from OAuth token
- Permission sources (highest wins):
  1. GCS allowlist: prism-iam/github-admin-allowlist.txt → admin
  2. GCS allowlist: prism-iam/github-user-allowlist.txt → user
  3. GitHub org: llm-d org member (admin role) → admin
  4. GitHub org: llm-d org member (member role) → user
- Playground mode: RESULTS_STORE_PLAYGROUND_MODE env var bypasses all auth

Secrets:
- GITHUB_CLIENT_ID (GitHub Actions secret) - OAuth App client ID, manual provisioning
- GITHUB_CLIENT_SECRET (GitHub Actions secret) - OAuth App client secret, manual provisioning
- GOOGLE_API_KEY (GitHub Actions secret) - Google Drive/Sheets API key, manual provisioning
- GCP_WORKLOAD_IDENTITY_PROVIDER (GitHub Actions secret) - WIF provider, manual (GCP)
- GCP_SERVICE_ACCOUNT (GitHub Actions secret) - Cloud Run deploy SA, manual (GCP)

Crypto Notes:
- No explicit TLS config — relies on Cloud Run managed TLS termination
- Node.js crypto.randomUUID() and crypto.randomBytes() for server-side IDs
- System trust store for outbound HTTPS
- Dev tooling (update_arena_scores.py) disables SSL cert verification — not runtime code
- No FIPS-specific build flags or configurations
- Base image: node:26-alpine (includes OpenSSL)
