- Privilege Level: cluster-admin
- Mechanism: Inherited from must-gather framework
- Scope: Full cluster read access

xKS (documented ClusterRole):
- ClusterRole: must-gather-reader
  - API Groups: *
  - Resources: *
  - Verbs: get, list, watch

- ClusterRoleBinding: must-gather-reader-binding
  - Role: must-gather-reader (cluster-scoped)
  - ServiceAccount: must-gather-sa (namespace: must-gather)

Secrets:
- redhat-pull-secret (kubernetes.io/dockerconfigjson) - Pull image from registry.redhat.io
  Provisioned by: Cluster administrator
  Auto-rotate: No

Crypto Configuration:
- System crypto policy: DEFAULT:PQ (post-quantum key exchange enabled)
- Applied at build time via: update-crypto-policies --set DEFAULT:PQ
- Affects: oc, kubectl, helm CLI tools (all use system OpenSSL)
- TLS connections to API server use post-quantum algorithms when supported

Build Security:
- Hermetic build: Yes (Konflux pipeline, hermetic=true)
- RPM lock: rpms.lock.yaml (pins crypto-policies-scripts across 4 architectures)
- Base images: digest-pinned in Dockerfile.konflux
- Multi-arch: x86_64, aarch64, ppc64le, s390x
