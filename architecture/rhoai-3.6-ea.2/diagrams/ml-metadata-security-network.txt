Ingress:
- No ingress resources. MLMD is an internal cluster service only.
- K8s Service defined externally by the deploying operator.

RBAC Summary:
- No RBAC resources defined in this repository.
- RBAC is managed by the deploying operator (Data Science Pipelines).

Secrets:
- Database credentials (External config/flags) - MySQL/PostgreSQL authentication
  - Provisioned by: Deploying operator
  - Auto-Rotate: Unknown
- gRPC TLS certificates (External config file) - Server TLS and optional mTLS
  - Provisioned by: Deploying operator
  - Auto-Rotate: Unknown
- Database TLS certificates (External config/flags) - MySQL/PostgreSQL connection encryption
  - Provisioned by: Deploying operator
  - Auto-Rotate: Unknown

Authentication & Authorization:
- Endpoint: MetadataStoreService (gRPC) - All RPCs
- Auth: Optional mTLS (SSLConfig.client_verify)
- Enforcement: gRPC server credentials
- Policy: Configurable insecure or mutual TLS; NO application-level authorization
- Risk: Any client with gRPC access can read/write ALL metadata

FIPS Notes:
- C++ binary dynamically linked against UBI 9 PQC base image system libraries
- System-level FIPS via fips-mode-setup controls crypto module
- Default is insecure gRPC (InsecureServerCredentials) -- deployer must configure SSL
- No explicit min TLS version or cipher suite constraints in application code
