RBAC Summary:
- ClusterRole: controller-manager-role
  - Scope: Wide — DSC, DSCI, CRDs, Deployments, Secrets, ConfigMaps, etc.
  - Verbs: Full CRUD
  - Binding: opendatahub-operator-controller-manager-rolebinding → SA opendatahub-operator-controller-manager

- ClusterRole: data-science-admingroupcluster-role
  - API Groups: services.platform.opendatahub.io, datasciencecluster.opendatahub.io,
                modelregistry.opendatahub.io, feast.dev, storage.k8s.io, user.openshift.io,
                maas.opendatahub.io, loki.grafana.com
  - Resources: auths, datascienceclusters, modelregistries, featurestores, storageclasses,
               groups/users, maasmodelrefs, application
  - Verbs: get, list, watch, create, update, patch, delete (varies)

- ClusterRole: data-science-allowedgroupcluster-role
  - API Groups: services.platform.opendatahub.io
  - Resources: auths, auths/status
  - Verbs: get, list, watch (read-only)

- ClusterRole: opendatahub-operator-metrics-reader
  - Non-Resource URLs: /metrics
  - Verbs: get

- ClusterRole: argo-cluster-role
  - API Groups: argoproj.io, core
  - Resources: workflows, pods, PVCs, configmaps, secrets (resourceNames restricted)
  - Verbs: full CRUD (Argo workflow execution)

Secrets:
- opendatahub-operator-controller-webhook-cert (kubernetes.io/tls)
  - Purpose: Webhook server TLS certificate
  - Provisioned by: OpenShift service-ca operator
  - Auto-Rotate: Yes (service-ca)

- opendatahub-operator-metrics-tls (kubernetes.io/tls)
  - Purpose: Metrics server TLS certificate
  - Provisioned by: OpenShift service-ca operator
  - Auto-Rotate: Yes (service-ca)

- {kube-auth-proxy}-tls (kubernetes.io/tls) [dynamic]
  - Purpose: OIDC proxy TLS certificate
  - Provisioned by: Controller template (service-ca or cert-manager)
  - Auto-Rotate: Depends on provisioner

FIPS Compliance:
- Build flags: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- TLS: Derived from cluster APIServer TLS security profile
  - Floors TLS 1.0/1.1 to Intermediate profile
  - Custom profile support
- Crypto: stdlib crypto/tls via OpenSSL (FIPS via strictfipsruntime)
- No InsecureSkipVerify in production code

Authentication Mechanisms:
- Webhook endpoints: TLS client certificate (kube-apiserver validates service-ca cert)
- Platform dashboard: OIDC via kube-auth-proxy
- Metrics endpoint: WithAuthenticationAndAuthorization (conditional)
- Health probes: Unauthenticated by design
- Argo secrets: RBAC with resourceNames restriction (argo-workflows-agent-ca-certificates only)
