TLS Configuration:
- Dynamic: reads OpenShift cluster TLS security profile from
  apiservers.config.openshift.io/cluster at startup
- ProfileWatcher controller monitors APIServer CR for runtime changes
- Fallback: Intermediate defaults (TLS 1.2, ECDHE AEAD ciphers, ALPN h2/http1.1)
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, UBI 9 minimal-pqc base
- Python components: cryptography >=50.0.0 (FIPS via system OpenSSL)

Secrets:
- kserve-webhook-server-cert (kubernetes.io/tls) - Webhook TLS cert,
  cert-manager / OpenShift CA, auto-rotate
- kserve-webhook-server-secret (Opaque) - Webhook TLS key material,
  cert-manager, auto-rotate
- Model storage credentials (Opaque, per-namespace) - S3/GCS/Azure/HDFS
  access credentials, user-provisioned, no auto-rotation

NetworkPolicies:
- Per-namespace policies created by kserve-module via ODH overlay
- Optional: depends on ODH overlay being applied

Multi-Tenancy:
- Tenant boundary: per-namespace
- Model: multi-tenant (single controller set serves all namespaces)
- Gap: Python model servers have no built-in authentication;
  rely on platform ingress for tenant isolation
- Gap: No automatic per-tenant resource quotas
