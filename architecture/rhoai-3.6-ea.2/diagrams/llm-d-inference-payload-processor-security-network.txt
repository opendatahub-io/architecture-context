Authentication & Authorization:
- ExternalProcessor gRPC (9004): No application-level auth; transport TLS
  is configuration-dependent (--secure-serving flag)
- Health gRPC (9005): Plaintext gRPC, no authentication
- Metrics HTTP (9090): Optional controller-runtime authn/authz filter
  (--metrics-endpoint-auth flag, default: true)

TLS Configuration:
- gRPC ext-proc server TLS is optional (--secure-serving flag)
- Self-signed certificates: RSA 4096-bit, 10-year validity, generated
  at startup
- CertReloader: hot-reloads externally provisioned TLS certs via fsnotify
- Default crypto/tls config: no explicit MinVersion, MaxVersion, or
  CipherSuites set
- ⚠ Risk: Pure Go crypto (CGO_ENABLED=0); not FIPS-compliant for
  check-payload validation

Secrets:
- No Kubernetes Secrets referenced
- TLS certificates are self-signed at startup or loaded from mounted path

Multi-Tenancy:
- Tenant boundary: per-namespace
- Deployment model: single-tenant (one IPP per Gateway)
- Namespace filtering: NAMESPACE env var (when unset, watches all namespaces)
- ⚠ Risk: ClusterRole grants cluster-wide ConfigMap read; namespace
  filtering is application-level only

Known Risks:
- ⚠ Unbounded request/response body accumulation in FULL_DUPLEX_STREAMED
  mode (OOM risk under adversarial payloads) [pkg/handlers/server.go:182-183]
- ⚠ No NetworkPolicy defined in manifests
- ⚠ Self-signed cert with 10-year validity (operationally long lifetime)
