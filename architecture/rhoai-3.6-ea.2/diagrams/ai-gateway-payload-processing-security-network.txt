- Per ExternalProvider (e.g. anthropic-credentials)
  Type: Opaque
  Purpose: External LLM provider API key
  Provisioned By: User / manual
  Auto-Rotate: No

Authentication Endpoints:
- ext-proc gRPC (9004/TCP): No auth — network isolation (mesh-internal)
- Health gRPC (9005/TCP): No auth — plaintext health check
- Metrics HTTP: Optional controller-runtime authn/authz (--metrics-endpoint-auth flag)
- Inference routing: Per-provider auth (apikey / sigv4 / oauth2) injected by apikey-injection plugin

FIPS Compliance:
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime
- Base image: ubi9/ubi-minimal-pqc (post-quantum cryptography variant)
- TLS: All connections use TLS 1.2 minimum
- Crypto: stdlib crypto packages delegate to OpenSSL at runtime

Multi-Tenancy:
- Tenant boundary: per-namespace (ExternalModel/ExternalProvider are namespaced)
- Deployment: multi-tenant by default (multiNamespace=true)
- Gap: ext-proc with ClusterRole can read Secrets across namespaces
- Gap: No NetworkPolicy generated by chart
