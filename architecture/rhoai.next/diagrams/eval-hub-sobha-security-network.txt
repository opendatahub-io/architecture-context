- TLS: crypto/tls with MinVersion=TLS 1.2, MaxVersion=TLS 1.3
- No non-FIPS crypto risks detected (no MD5, RC4, custom RNG)

- S3 credentials (Opaque, file-mounted) — AWS access key/secret, manual provisioning, no auto-rotate
- MLflow token (Opaque, projected SA token) — Bearer token, kubelet rotation
- service-ca.crt (ConfigMap) — CA certificate, OpenShift service-ca operator, auto-rotated

Multi-Tenancy:
- Boundary: per-namespace (X-Tenant header → Kubernetes namespace)
- Data isolation: Application-level row filtering (WithTenant() on Storage interface)
- Compute isolation: Jobs in tenant namespaces; no explicit NetworkPolicy in this repo
- Auth isolation: SAR scoped to tenant namespace
- Gap: Empty tenant falls back to eval-hub's own namespace
