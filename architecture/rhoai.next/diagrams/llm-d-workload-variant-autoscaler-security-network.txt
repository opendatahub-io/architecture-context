Authentication & Authorization:
- /metrics (8443/TCP): Bearer Token → TokenReview → SubjectAccessReview
  Requires metrics-reader ClusterRole
- Prometheus egress: Bearer Token (SA token or PROMETHEUS_BEARER_TOKEN env/file)
- Kubernetes API: ServiceAccount Token (in-cluster mTLS)

Secrets:
- epp-metrics-token (kubernetes.io/service-account-token)
  Purpose: Bearer token for querying EPP metrics from Prometheus
  Provisioned: Manual (SA token)
  Auto-Rotate: No

- controller-manager-token (OpenShift only, kubernetes.io/service-account-token)
  Purpose: Long-lived SA token for ServiceMonitor bearer auth
  Provisioned: Manual (OpenShift component)
  Auto-Rotate: No

- metrics-server-cert (OpenShift only, kubernetes.io/tls)
  Purpose: TLS serving cert for metrics endpoint
  Provisioned: service-ca controller (auto-generated)
  Auto-Rotate: Yes

TLS Configuration:
- MinVersion: TLS 1.2
- Ciphers: Go defaults (configurable)
- CA: Configurable via PROMETHEUS_CA_CERT_PATH or system trust store
- mTLS: Optional client certs supported
- InsecureSkipVerify: Available but disabled by default in production
- Plain HTTP: Blocked by default unless PROMETHEUS_ALLOW_HTTP=true

Network Policies:
- None defined in manifests
- Relies on Kubernetes RBAC for API access control
- No network isolation between controller and managed namespaces
