  ClusterRole: metrics-auth
    - authentication.k8s.io: tokenreviews → create
    - authorization.k8s.io: subjectaccessreviews → create

Authentication & Authorization:
  - /metrics (8443/TCP):
    Auth: Bearer Token (SA token)
    Enforcement: TokenReview + SubjectAccessReview (controller-runtime)
    Required role: metrics-reader ClusterRole

  - Prometheus egress (9090/TCP):
    Auth: Bearer Token (SA token or PROMETHEUS_BEARER_TOKEN env)
    Token source: file path or environment variable

  - Kubernetes API (443/TCP):
    Auth: ServiceAccount Token (in-cluster)
    Enforcement: Kubernetes API server RBAC
    Required role: manager-role ClusterRole

Secrets:
  - epp-metrics-token (kubernetes.io/service-account-token)
    Purpose: Bearer token for querying EPP metrics from Prometheus
    Provisioned by: Manual (SA token)
    Auto-rotate: No

  - controller-manager-token (kubernetes.io/service-account-token, OpenShift only)
    Purpose: Long-lived SA token for ServiceMonitor bearer auth
    Provisioned by: Manual (OpenShift component)
    Auto-rotate: No

  - metrics-server-cert (kubernetes.io/tls, OpenShift only)
    Purpose: TLS serving cert for metrics endpoint
    Provisioned by: service-ca controller (auto-generated)
    Auto-rotate: Yes

TLS Configuration:
  - MinVersion: TLS 1.2
  - Cipher suites: Go defaults (configurable)
  - CA: System trust store or custom CA bundle (PROMETHEUS_CA_CERT_PATH)
  - mTLS: Optional client certificates for Prometheus connection
  - InsecureSkipVerify: Available but disabled by default in production
