RBAC Summary:
=============
No RBAC definitions in this component. RBAC is managed externally by:
- ODH Notebook Controller: Creates Notebook CRs and injects kube-rbac-proxy sidecar
- kube-rbac-proxy: Performs SubjectAccessReview to verify user namespace access
- OpenShift OAuth: Authenticates users at ingress level

Authentication & Authorization:
================================
| Endpoint               | Port     | Auth Mechanism      | Enforcement Point              |
|------------------------|----------|---------------------|--------------------------------|
| JupyterLab UI          | 8888/TCP | OAuth / RBAC        | kube-rbac-proxy sidecar        |
| CodeServer UI          | 8787/TCP | OAuth / RBAC        | kube-rbac-proxy sidecar        |
| RStudio UI             | 8787/TCP | OAuth / RBAC        | kube-rbac-proxy sidecar        |
| /api/kernels/ (culling)| 8787/TCP | None (internal)     | NGINX FastCGI (pod-local)      |

Secrets:
========
| Secret                      | Type   | Purpose                         | Provisioned | Rotation |
|-----------------------------|--------|----------------------------------|-------------|----------|
| RHSM credentials            | Opaque | RHEL subscription (RHEL9 builds) | Manual      | No       |
| PKI certificates            | Opaque | Container registry auth          | Manual      | No       |

Note: Both secrets are BUILD-TIME only. No runtime secrets are managed by this component.

FIPS Compliance:
================
- mongocli binary: Compiled with CGO_ENABLED=1 -tags strictfipsruntime (Data Science images)
- All other Python code: Relies on UBI9 base image system OpenSSL
- No explicit TLS configuration in workbench containers (TLS terminated at ingress)
- AIPCC gap: Python packages sourced from public PyPI, not RHEL AI PyPI
