Service Mesh Configuration:
- No Istio/service mesh sidecar injection required
- Network isolation via operator-managed Kubernetes NetworkPolicy per OGXServer CR
- NetworkPolicy can be disabled via spec.network.policy.enabled: false (webhook warns)

Secrets:
- ogx-k8s-operator-controller-manager-metrics-service-tls (kubernetes.io/tls)
  - Purpose: TLS certificate for metrics endpoint
  - Provisioned by: OpenShift service-ca operator
  - Auto-Rotate: Yes

- ogx-k8s-operator-webhook-cert (kubernetes.io/tls)
  - Purpose: TLS certificate for admission webhook
  - Provisioned by: OpenShift service-ca operator or cert-manager
  - Auto-Rotate: Yes

TLS Profile Integration:
- Reads cluster-wide TLS profile from config.openshift.io/apiserver
- Supports Intermediate, Modern, and Custom TLS profiles
- SecurityProfileWatcher triggers graceful operator restart on profile change
- Fallback: Intermediate profile on non-OpenShift clusters

FIPS Compliance:
- CGO_ENABLED=1 for dynamic linking (Konflux build)
- UBI 9-minimal-pqc base image (post-quantum crypto, includes OpenSSL)
- Application TLS via stdlib crypto/tls + OpenShift controller-runtime-common TLS integration
