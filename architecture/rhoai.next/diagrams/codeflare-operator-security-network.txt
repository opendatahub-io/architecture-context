NetworkPolicy Rules:
- Worker Pods:
  - Ingress ONLY from pods with same ray.io/cluster label (same RayCluster)
  - No external ingress allowed
- Head Pods:
  - Ingress from KubeRay operator namespace (health checks)
  - Ingress from openshift-monitoring namespace (port 8080 metrics)
  - Ingress on port 8443 (OAuth proxy)
  - Ingress on port 10001 (Ray client, mTLS required)
  - Ingress from same ray.io/cluster label (worker communication)

Secrets:
- codeflare-operator-webhook-server-cert (kubernetes.io/tls)
  - Purpose: TLS cert for webhook server (9443)
  - Provisioned By: cert-controller (open-policy-agent)
  - Auto-Rotate: Yes

- {cluster}-proxy-tls-secret (kubernetes.io/tls) [per RayCluster]
  - Purpose: TLS cert for OAuth proxy sidecar
  - Provisioned By: OpenShift serving-cert-secret annotation
  - Auto-Rotate: Yes

- {cluster}-oauth-config (Opaque) [per RayCluster]
  - Purpose: Cookie secret for OAuth proxy session
  - Provisioned By: Operator (SHA1 hash of cluster name + salt)
  - Auto-Rotate: No

- {cluster}-ca-secret (Opaque) [per RayCluster]
  - Purpose: CA private key and certificate for mTLS
  - Provisioned By: Operator (RSA 2048-bit CA)
  - Auto-Rotate: No (1 year validity)
  - Risk: No automatic rotation for long-lived clusters

FIPS Compliance:
- Build flags: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Dynamic linking with OpenSSL via ubi9/ubi-minimal
- Uses crypto/sha1 for cookie secret (non-signing, acceptable)
- Init containers use openssl CLI for cert generation
