RBAC Summary:

OpenShift Mode:
- ServiceAccount: Provided by oc adm must-gather plugin
  - Equivalent to cluster-admin (read access to all resources)
  - Automatically provisioned and cleaned up

xKS Mode:
- ClusterRole: must-gather-reader
  - API Groups: * (all)
  - Resources: * (all)
  - Verbs: get, list, watch
- ClusterRoleBinding: must-gather-reader-binding
  - Scope: cluster-wide
  - ServiceAccount: must-gather-sa (in must-gather namespace)

Secrets:
- redhat-pull-secret (xKS only)
  - Type: kubernetes.io/dockerconfigjson
  - Purpose: Pull must-gather image from registry.redhat.io
  - Provisioned By: Manual (user-created)
  - Auto-Rotate: No

Security Notes:
- NO inbound connections -- batch job only (no listening ports)
- ALL network traffic is egress-only to Kubernetes API server
- Read-only operations (GET, LIST) -- no cluster mutations
- Collected data may contain secrets from any namespace
- Pod is ephemeral -- destroyed after collection completes
- FIPS: Shell scripts only; crypto delegated to oc/kubectl (FIPS-compliant from Red Hat base images)
- helm binary FIPS compliance depends on external build (unverifiable from this repo)
