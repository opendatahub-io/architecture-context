RBAC Summary:

  OpenShift:
  - ServiceAccount: Provisioned by `oc adm must-gather` framework
  - Privileges: cluster-reader (read-only access to all cluster resources)
  - Scope: Cluster-wide

  xKS (AKS/EKS/CKS):
  - ClusterRole: must-gather-reader (user-created)
    - API Groups: * (all)
    - Resources: * (all)
    - Verbs: get, list, watch
  - ClusterRoleBinding: must-gather-reader-binding
    - ServiceAccount: must-gather-sa (cluster-wide)

Secrets:
  - redhat-pull-secret (xKS only, user-created)
    - Type: kubernetes.io/dockerconfigjson
    - Purpose: Pull must-gather image from registry.redhat.io
    - Rotation: Manual (no auto-rotate)

Crypto Policy:
  - System policy: DEFAULT:PQ (post-quantum)
  - Package: crypto-policies-scripts 20260224-1.gitea0f072.el9_8
  - Affects: OpenSSL, GnuTLS for all subprocesses (oc, kubectl, helm)
  - No direct TLS configuration in scripts

Data Sensitivity:
  - Collected data may contain:
    - Pod logs with application data
    - ConfigMap values (may include credentials)
    - Custom resource specs (may include connection strings)
    - Cluster topology and node information
  - Mitigation: Output is ephemeral; transferred directly to admin workstation
  - Recommendation: Handle collected archives as confidential
