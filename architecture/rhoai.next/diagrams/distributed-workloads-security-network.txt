  - Test framework uses InsecureSkipVerify: true for S3 connections (acceptable for tests, FIPS gap if used in prod)
  - MPI SSH runs with StrictModes disabled (acceptable within training job pod network)
  - No NetworkPolicies defined — tests rely on namespace isolation
  - RDMA/InfiniBand traffic between worker pods is unencrypted (hardware-level, by design)
  - Jupyter Notebook (port 8888) runs without TLS — relies on platform proxy for encryption
  - Ray Dashboard (port 8265) runs without TLS or auth — exposed via OpenShift Route for test monitoring only
