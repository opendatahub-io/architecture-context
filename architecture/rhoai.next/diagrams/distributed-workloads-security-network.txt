RBAC Summary:
- Dynamic RBAC: Test framework creates ephemeral Roles/ClusterRoles/Bindings per test
  - Cleaned up automatically after each test
  - No static manifests shipped
  - Tests use helper functions (support/rbac.go) to create:
    - Roles for pod log access, secret access
    - ClusterRoles for CRD operations
    - RoleBindings/ClusterRoleBindings for test ServiceAccounts

Secrets:
- SSH key pair (SSH keys) - MPI inter-node authentication
  - Provisioned by: Baked into image (benchmark) or injected by TrainJob controller
  - Auto-Rotate: No
- S3 credentials (Opaque) - Storage bucket access for training data
  - Provisioned by: Test environment variables
  - Auto-Rotate: No
- HF_TOKEN (Opaque) - HuggingFace model download authentication
  - Provisioned by: Test environment variable
  - Auto-Rotate: No

Build-Time Security:
- FIPS: OpenSSL inherited from UBI9/AIPCC base images
- Hermetic builds: 5 of 13 Konflux images use cachi2/hermeto (2 OpenMPI + 3 universal)
- Gap: 8 runtime images use public PyPI without hermetic prefetch
- ROCm 6.4 retirement: 2 AIPCC-based ROCm images need migration to ROCm 7.14

Authentication Summary:
- MPI SSH (2222/TCP): SSH key pair authentication
- JupyterLab (8888/TCP): No direct auth (platform OAuth handles upstream)
- Kubernetes API (6443/TCP): Bearer Token / ServiceAccount
- S3 Storage (443/TCP): AWS IAM credentials
- HuggingFace Hub (443/TCP): HF_TOKEN Bearer
- AIPCC PyPI (443/TCP): RHEL subscription
