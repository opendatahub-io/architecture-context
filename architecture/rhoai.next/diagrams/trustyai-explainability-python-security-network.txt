RBAC Summary:
  The library itself does not define RBAC resources.
  When using the optional [api] extra, the caller requires:
  - API Group: route.openshift.io/v1
  - Resources: routes
  - Verbs: get, list
  - Purpose: Discover TrustyAI Service and model endpoint routes

Authentication Summary:
  - TrustyAI Service API: Bearer Token (OpenShift) via Authorization header
  - Thanos Querier API: Bearer Token (OpenShift) via Authorization header
  - Model inference endpoints: Bearer Token (OpenShift) via Authorization header
  - OpenShift API: kubeconfig or in-cluster ServiceAccount token
  - Hugging Face Hub: Optional API token for private models

Secrets:
  - No secrets defined by the library
  - Bearer token passed as constructor parameter to TrustyAIMetricsService
  - Risk: Token leakage in Jupyter notebook outputs or logs

Security Concerns:
  - verify=False option in TrustyAIMetricsService allows disabling SSL verification
  - Token management is caller's responsibility (no rotation/refresh)
  - JVM within Python process increases attack surface
  - Bundled JAR uses SNAPSHOT version (999-SNAPSHOT) — not release-quality
