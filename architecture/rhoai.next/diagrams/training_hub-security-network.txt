TRUST BOUNDARIES:
1. YAML Config → importlib: _resolve_dotted_path() can load arbitrary modules
   from YAML config files (reward_fn, rollout_fn parameters). YAML configs
   are a trust boundary — they can trigger arbitrary code execution.

2. litellm Supply Chain: Versions 1.82.7-1.82.8 excluded due to TeamPCP
   credential-harvesting attack (March 2026). Pinned exclusion in pyproject.toml.

3. Subprocess Isolation: ART backend uses mp.spawn to isolate vLLM's
   non-daemon threads. Results pass via disk, not IPC. os._exit() used
   for force termination.

SECRETS:
- OPENAI_API_KEY (env var) - API auth for GEPA LLM calls
- WANDB_API_KEY (env var) - W&B experiment tracking auth
- MLFLOW_TRACKING_URI (env var) - MLflow connection (may contain credentials)
- No auto-rotation configured for any secret

RBAC:
- None. Training Hub is a library, not a Kubernetes controller.
- When deployed in Kubeflow, inherits pod's ServiceAccount RBAC.

FIPS COMPLIANCE:
- Pure Python library, no compiled binaries
- No direct crypto library usage (no ssl, cryptography, hashlib imports)
- TLS delegated to upstream HTTP clients (requests, aiohttp, litellm)
- FIPS posture inherited from consuming container image's build process
