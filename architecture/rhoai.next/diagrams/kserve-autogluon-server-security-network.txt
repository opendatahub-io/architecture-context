RBAC Summary:
- No RBAC resources defined by this component
- Runs as non-privileged container (UID 1001)
- Does not interact with Kubernetes API
- Auth enforcement delegated to kube-rbac-proxy sidecar

Authentication & Authorization:
- /v1/models/* : Bearer Token → kube-rbac-proxy (RHOAI 3.x) → Platform RBAC
- /v2/models/* : Bearer Token → kube-rbac-proxy (RHOAI 3.x) → Platform RBAC
- /v2/health/* : Unauthenticated (health probes)

Secrets:
- No secrets defined in this component
- Storage credentials injected as env vars by KServe Controller:
  - AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY (for S3)
  - AZURE_CLIENT_ID (for Azure Blob)
  - GCP service account token (for GCS)
  - HF_TOKEN (for HuggingFace Hub, optional)

FIPS Compliance:
- Pure Python application — no Go binary, no direct crypto
- FIPS inherited from AIPCC CPU base image (RHEL 9.6 + OpenSSL FIPS)
- cryptography 48.0.0 (transitive) uses system OpenSSL backend
- No non-FIPS crypto patterns detected in application code

Multi-Tenancy:
- Single-tenant per pod (one model per InferenceService)
- Tenant boundary: InferenceService name + namespace
- No cross-tenant data access within server
