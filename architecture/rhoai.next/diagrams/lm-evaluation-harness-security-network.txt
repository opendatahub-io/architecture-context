Secrets:
- HF_TOKEN (env var) — HuggingFace Hub auth for gated models/datasets — No auto-rotate
- OPENAI_API_KEY (env var) — Model inference endpoint auth — No auto-rotate
- ANTHROPIC_API_KEY (env var) — Anthropic API auth (upstream backend) — No auto-rotate
- WATSONX_API_KEY (env var) — IBM watsonx.ai API auth — No auto-rotate
- AWS_SECRET_ACCESS_KEY (env var) — S3 storage auth for asset downloads — No auto-rotate
- REGISTRY_PASSWORD (env var) — OCI registry auth for artifact persistence — No auto-rotate

RBAC Summary:
- No RBAC defined in this repository
- RBAC for the Job pod is managed by the TrustyAI operator (LMEvalJob controller)
- ServiceAccount and permissions are set at Job creation time by the operator

FIPS Compliance:
- Python inherits FIPS from UBI/AIPCC base image's system OpenSSL
- ssl.create_default_context() respects system crypto policy
- hashlib.sha256() only (FIPS-approved algorithm)
- uv and its bundled crypto explicitly removed (RHOAIENG-99284)

Network Policy:
- No NetworkPolicy defined in this repository
- No inbound connections (batch job, no listeners)
- Egress-only: all connections are outbound to external services

Build Hermeticity:
- RPM lock: rpms.lock.yaml (rpm-lockfile-prototype)
- Python lock: poetry.lock + requirements.txt
- Base images: parameterized via build args (CUDA_BASE_IMAGE, CPU_BASE_IMAGE)
- Note: Konflux build uses pyproject.toml extras, not pinned requirements.txt
