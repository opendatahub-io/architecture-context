RBAC Summary:
- No RBAC resources defined by this component.
- RBAC is managed externally by EvalHub when creating the Kubernetes Job.
- The container runs with whatever ServiceAccount EvalHub assigns.

Secrets:
- model-auth-secret (Opaque) - Model inference API key + optional HF token
  Provisioned by: EvalHub (via JobSpec model.auth.secret_ref)
  Auto-rotate: No

- oci-auth-config (kubernetes.io/dockerconfigjson) - OCI registry auth
  Provisioned by: Platform operator
  Auto-rotate: No

Authentication Summary:
- Model Inference: Bearer Token (OPENAI_API_KEY) from model-auth-secret
- EvalHub Callbacks: Bearer Token (managed by eval-hub-sdk)
- HuggingFace Hub: Bearer Token (HF_TOKEN, optional)
- OCI Registry: Docker auth config or username/password
- S3 Storage: AWS IAM credentials (access key + secret key)
- MLflow: Bearer Token

Security Controls:
- Credential redaction: _sanitize_error_message() applies 3-layer regex
  redaction before error text reaches EvalHub callbacks
- Path traversal protection (CWE-22): Job spec access restricted to /meta
- Air-gap auto-detection: Disables HuggingFace network access when
  /test_data tokenizer detected (6 HF_* env vars set)
- No model weights loaded: CPU-only, tokenizer client (device="cpu")

FIPS Compliance:
- UBI9 base image provides FIPS-compliant OpenSSL
- Python interpreter inherits FIPS mode from host OS
- SHA-256 used for caching only (not security-critical)
- No non-FIPS crypto libraries detected

Network Policy:
- No NetworkPolicy defined by this component
- Relies on cluster-level NetworkPolicy enforcement
- Job has full egress access by default
