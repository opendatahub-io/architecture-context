RBAC Summary:
  No RBAC resources defined in this component.
  The Job pod's ServiceAccount and RBAC are managed entirely by the
  TrustyAI LMEval operator. The operator grants necessary permissions
  for the Job pod to read ConfigMaps and Secrets in the target namespace.

Secrets:
  - Model auth secret (Opaque)
    Keys: api-key (OPENAI_API_KEY), hf-token (HF_TOKEN)
    Provisioned by: User / LMEval operator
    Auto-rotate: No

  - OCI registry auth (Docker config)
    Path: /tmp/.docker/config.json
    Provisioned by: LMEval operator
    Auto-rotate: No

  - S3 credentials (Opaque)
    Keys: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY
    Provisioned by: User
    Auto-rotate: No

Security Notes:
  - Error message sanitization: _sanitize_error_message() strips
    Authorization headers, key=value pairs, JSON secrets, URL userinfo,
    query parameters, and fragments before sending to EvalHub callbacks
  - Path traversal prevention: Job spec path validated against /meta root (CWE-22)
  - Credential resolution via eval-hub-sdk auth module (not direct env vars)
  - Air-gapped mode auto-detected from /test_data presence (no outbound HF calls)
  - FIPS: Relies on UBI9 base image OpenSSL; no non-FIPS crypto libraries imported
  - CONCERN: S3_VERIFY_SSL=false option can disable TLS certificate verification

Network Summary:
  - INBOUND: None (batch job, no listening ports)
  - OUTBOUND: All connections use HTTPS/443 with TLS 1.2+
  - mTLS: Not applicable (no service mesh integration documented)
  - All auth via Bearer Tokens or AWS IAM credentials
