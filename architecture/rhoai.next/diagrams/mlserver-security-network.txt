RBAC Summary:
- No RBAC definitions. MLServer is a non-privileged application container.
- All RBAC is managed by KServe at the platform level.
- Pod runs as non-root user (inherited from AIPCC base image).

Authentication Summary:
- All REST (8080) and gRPC (8081) endpoints: kube-rbac-proxy sidecar
  - Mechanism: OpenShift OAuth / ServiceAccount token validation
  - Enforcement: sidecar container injected by KServe
- Metrics endpoint (8082): No authentication
  - Risk: Information disclosure within pod network

Secrets:
- No application-level secrets defined.
- Reads namespace from: /var/run/secrets/kubernetes.io/serviceaccount/namespace
  (for CloudEvents headers only)

Crypto:
- No application-level TLS (gRPC uses add_insecure_port, REST uses plain HTTP)
- hashlib SHA-256 for file digest computation (FIPS-approved)
- OTLP exporter: insecure=True (no TLS to trace collector)
- All TLS handled by kube-rbac-proxy sidecar
- FIPS compliance: Inherited from UBI/AIPCC base image OpenSSL

Build Security:
- Trusted runtimes allowlist baked at build time (immutable in production)
- pip install with --require-hashes for dependency integrity
- AIPCC base images (UBI-based, RHEL repos)
