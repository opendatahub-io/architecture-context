RBAC Summary:
  Caikit is a Python library — no Kubernetes RBAC is defined.
  RBAC is defined by the consuming deployment (KServe, ModelMesh).

Secrets / TLS Configuration:
  - runtime.tls.server.key         TLS private key      gRPC/HTTP server TLS     Manual/cert-manager   No auto-rotate
  - runtime.tls.server.cert        TLS certificate      gRPC/HTTP server TLS     Manual/cert-manager   No auto-rotate
  - runtime.tls.client.cert        TLS CA cert          Client cert verification Manual/cert-manager   No auto-rotate
  - runtime.trace.tls.ca           TLS CA cert          OTel exporter TLS        Manual                No auto-rotate
  - runtime.trace.tls.client_key   TLS private key      OTel exporter mTLS       Manual                No auto-rotate
  - runtime.trace.tls.client_cert  TLS certificate      OTel exporter mTLS       Manual                No auto-rotate

Authentication & Authorization:
  - All HTTP/gRPC endpoints: No built-in auth
  - TLS/mTLS transport encryption: Optional, configurable via config.yml
  - Application-level auth: Delegated entirely to platform layer (KServe, kube-rbac-proxy, Istio)

FIPS Compliance:
  - Pure Python library — no compiled crypto
  - TLS via Python ssl module → system OpenSSL
  - FIPS compliance inherited from container base image (UBI + OpenSSL)
  - reversible_hasher.py is explicitly non-cryptographic (ID generation only)

Service Mesh Configuration:
  - Caikit does not configure service mesh policies
  - PeerAuthentication and AuthorizationPolicy defined by KServe/platform operator
  - Istio sidecar injection managed by namespace labels
