  - Resources: configmaps, leases, events (full CRUD)

Service Mesh Configuration:
- Istio VirtualService: Routes for model-registry, model-catalog, model-registry-ui
- AuthorizationPolicy: model-registry
  - ALLOW from: istio-ingressgateway SA
  - ALLOW from: kubeflow namespace with JWT
  - DENY: kubeflow-userid header from non-gateway sources (anti-spoofing)

Secrets:
- model-catalog-hf-api-key (Opaque) - HuggingFace API key, manual provisioning, no auto-rotate
- model-catalog-postgres (Opaque) - PostgreSQL credentials, manual provisioning, no auto-rotate
- skill-catalog-git-credentials (Opaque) - Git credentials for private repos, optional, no auto-rotate
- mysql-secret / model-registry-db-secrets (Opaque) - DB credentials, kustomize secretGenerator
- AWS_SECRET_ACCESS_KEY (env var) - S3 credentials for async-upload job

TLS Configuration:
- Proxy server: TLS 1.2 minimum, configurable cipher suites, insecure cipher rejection
- BFF: TLS 1.3 minimum when TLS enabled
- Controller: HTTP/2 disabled by default (CVE mitigation)
- FIPS: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, UBI9 minimal-pqc base

Multi-Tenancy:
- Tenant boundary: per-namespace
- Each model registry instance deployed per namespace
- BFF discovers available registries and scopes queries
- Istio AuthorizationPolicy restricts access by namespace
- Model catalog is shared (read-only) across tenants
