RBAC Summary:
- No RBAC resources defined in this repository
- RBAC is managed by the launching operator (trustyai-service-operator)
- Job runs as non-root UID 65532

Secrets:
- OPENAI_API_KEY (env var) - Model endpoint auth, from EvalHub model auth secret, no auto-rotate
- HF_TOKEN (env var) - HuggingFace Hub auth, from model auth secret, no auto-rotate
- ANTHROPIC_API_KEY (env var) - Anthropic API auth (optional), no auto-rotate
- WATSONX_API_KEY (env var) - IBM WatsonX AI auth (optional), no auto-rotate
- AWS_ACCESS_KEY_ID (env var) - S3 storage auth, no auto-rotate
- AWS_SECRET_ACCESS_KEY (env var) - S3 storage auth, no auto-rotate
- REGISTRY_USERNAME (env var) - OCI registry auth, no auto-rotate
- REGISTRY_PASSWORD (env var) - OCI registry auth, no auto-rotate

Security Controls:
- Path traversal protection: _resolve_job_spec_path_for_read restricts to /meta (CWE-22 mitigation)
- Secret redaction: _sanitize_error_message redacts Bearer tokens, API keys, passwords from error messages
- Non-root execution: Container runs as UID 65532
- TLS: Uses ssl.create_default_context() respecting system crypto policy (FIPS via UBI9 OpenSSL)
- Symlink rejection: verify_certificate parameter rejects symlink paths

Security Risks:
- S3_VERIFY_SSL env var can disable SSL verification in s3_downloader.py
- verify_certificate can be set to disable TLS for model endpoints
- 8 secrets as environment variables (no rotation, no Vault integration)
- No NetworkPolicy defined (depends on deploying operator)
- Source-compiled PyTorch/PyArrow on s390x/ppc64le (supply chain risk)
