RBAC Summary:
- This component does NOT define its own RBAC resources
- RBAC is managed by the ODH Notebook Controller:
  - Creates per-notebook ServiceAccount
  - Creates per-notebook RoleBinding
  - kube-rbac-proxy sidecar enforces namespace-scoped access

Authentication & Authorization:
- /notebook/{namespace}/{name}/*: OAuth via kube-rbac-proxy sidecar
  - Enforcement: kube-rbac-proxy (injected by notebook controller)
  - Policy: User must have access to the Notebook CR namespace
- JupyterLab API: ServerApp.token disabled (OAuth proxy handles auth)

Secrets:
- CA cert bundle (ConfigMap, ca-bundle.crt) - TLS CA certificates, controller-managed, auto-rotate
- DSPA connection (Opaque) - Pipeline endpoint + credentials, controller-mounted, no auto-rotate

Service Mesh Configuration:
- Not directly configured by this component
- kube-rbac-proxy sidecar provides mTLS at pod boundary
- All internal pod communication is localhost (no encryption needed)

Services:
- notebook (Jupyter): ClusterIP, 8888/TCP, HTTP, kube-rbac-proxy auth, Internal
- code-server (nginx): ClusterIP, 80/TCP, HTTP, kube-rbac-proxy auth, Internal
- code-server (httpd CGI): 8080/TCP, HTTP, localhost only
- code-server (IDE): 8585/TCP, HTTP, localhost only

Build-Time FIPS:
- Python-based images: N/A (interpreted)
- OpenSSL: Via UBI/RHEL 9.6 AIPCC base (system OpenSSL)
- Crypto: Delegates to system OpenSSL (FIPS-compliant)
- mongocli: Go binary built with go-toolset (datascience image only)
