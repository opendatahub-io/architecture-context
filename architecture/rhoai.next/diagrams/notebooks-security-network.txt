RBAC Summary:
- No RBAC resources defined by this component
- Auth is enforced by kube-rbac-proxy sidecar injected by Notebook Controller
- kube-rbac-proxy validates OpenShift user tokens against namespace access

Secrets Summary:
- DSPA connection secret (Opaque) - Pipeline endpoint for Elyra execution
  Provisioned by: Notebook Controller (mounted at /opt/app-root/runtimes/)
  Auto-rotate: No
- CA certificate bundle (Opaque) - Custom CA certificates for TLS verification
  Provisioned by: Notebook Controller (mounted at /etc/pki/tls/custom-certs/ca-bundle.crt)
  Auto-rotate: No

FIPS Compliance:
- mongocli: CGO_ENABLED=1, -tags strictfipsruntime (dynamic linking, FIPS-compliant)
- Python images: Interpreted, use system OpenSSL via ssl module
- compat-openssl11 installed in all images
- check-payload validates all built images for FIPS compliance

Build Hermeticity:
- OS packages: rpms.lock.yaml (rpm-lockfile-prototype)
- Python deps: pylock.*.toml + requirements.*.txt (uv pip compile)
- Go deps: go.sum (go mod)
- npm deps: package-lock.json (npm ci --offline)
- All deps prefetched via Cachi2 (Hermeto) at /cachi2/output/deps/

Multi-Tenancy:
- Tenant boundary: per-user (one workbench pod per user per namespace)
- Isolation: kube-rbac-proxy sidecar, namespace-scoped PVCs/secrets
- Risk: Jupyter kernel executes arbitrary user code with pod's service account permissions
