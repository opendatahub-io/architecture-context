Network Policies:
- Controller NetworkPolicy: allows ingress on 8443 (metrics)
- Runtime NetworkPolicy: allows ingress on 8033, 8008, 8080, 2112
  ⚠ Allows inference from any source on ports 8033 and 8008
- Webhook NetworkPolicy: allows ingress on 9443

Secrets:
- model-serving-etcd (Opaque)
  Purpose: etcd connection config (endpoints, TLS certs, credentials)
  Provisioned By: Platform operator
  Auto-Rotate: No

- storage-config (Opaque - JSON per storage backend)
  Purpose: Model storage credentials (S3 keys, GCS creds, PVC config)
  Provisioned By: User / Platform
  Auto-Rotate: No

- model-serving-proxy-tls (kubernetes.io/tls)
  Purpose: TLS cert for oauth-proxy sidecar
  Provisioned By: OpenShift service-ca (annotation-triggered)
  Auto-Rotate: Yes

- Configurable TLS secret (kubernetes.io/tls)
  Purpose: TLS cert/key for ModelMesh gRPC endpoints
  Provisioned By: Manual or cert-manager
  Auto-Rotate: Configurable

Security Risks:
- ⚠ REST proxy (8008) has no authentication enforcement
- ⚠ Runtime NetworkPolicy allows inference from any source on ports 8033 and 8008
- ⚠ InsecureSkipVerify=true in ServiceMonitor TLS config (metrics scraping only)
- ⚠ allowAnyPVC flag may expose cross-namespace PVCs
- ⚠ crypto/sha1 used for predictor spec hashing (non-security, not cryptographic)

FIPS Compliance:
- Build flags: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, -tags strictfipsruntime
- Linking: Dynamic (CGO_ENABLED=1)
- OpenSSL: Yes (via UBI 9 base image)
- TLS: stdlib crypto/tls with system defaults
- Cert handling: System trust store with optional CA bundle
