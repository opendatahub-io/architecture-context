Service Account:
- modelmesh-controller (controller namespace)
- Bound to modelmesh-controller-role (ClusterRole) via ClusterRoleBinding
- Bound to leader-election and SCC Roles via namespace-scoped RoleBindings

Secrets:
- modelmesh-webhook-server-cert (kubernetes.io/tls) - Webhook TLS cert; cert-manager provisioned; auto-rotated
- model-serving-etcd (Opaque) - etcd credentials (endpoints, cert, key, userid, password); manually provisioned; no auto-rotation
- (user-configured TLS secret) (kubernetes.io/tls) - Controller-to-ModelMesh gRPC TLS; manually provisioned; no auto-rotation

- ServiceMonitor TLS uses InsecureSkipVerify: true (TODO to fix)

- FIPS build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1 (Dockerfile.konflux)
