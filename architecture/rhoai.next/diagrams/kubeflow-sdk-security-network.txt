RBAC Summary:
  The SDK does not define RBAC resources. Required permissions depend on
  which SDK features are used. Expected minimum permissions:

  - API Group: trainer.kubeflow.org
    Resources: trainjobs, trainingruntimes, clustertrainingruntimes
    Verbs: get, list, watch, create, update, patch, delete

  - API Group: sparkoperator.k8s.io
    Resources: sparkconnects
    Verbs: get, list, watch, create, update, patch, delete

  - API Group: "" (core)
    Resources: pods, pods/log, configmaps, secrets
    Verbs: get, list, watch

Secrets:
  - HF_TOKEN (env var) - HuggingFace gated model access, user-provisioned, no auto-rotate
  - AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY (env vars) - S3 storage auth, user-provisioned
  - user_token (constructor param) - Model Registry auth, user-provisioned
  - custom_ca (constructor param) - Custom CA cert path for Model Registry TLS

Security Considerations:
  - Injected metrics server (28080/TCP) has NO authentication — pod-internal only
  - vLLM sidecar (8234/TCP) has NO authentication — localhost only
  - S3 SSL verification is opt-out (verify_cloud_storage_ssl=False)
  - All crypto operations delegated to transitive deps (cryptography, kubernetes client)
  - Code injection pattern (inspect.getsource) means injected code must be self-contained
  - FIPS compliance inherited from Python runtime and system OpenSSL
