Secrets (Consumed, not provisioned by SDK):
- kubeconfig - Kubernetes API authentication (User/Platform provisioned)
- HuggingFace access token (Opaque) - Private model/dataset downloads (User provisioned, no auto-rotate)
- S3 credentials (Opaque) - Checkpoint upload and dataset access (User/IAM provisioned)

RHAI-Specific Network Details:
- Training pods expose /metrics on 8080/TCP (HTTP, no encryption, no auth)
  - Injected by TrainingHubTrainer via code generation
  - Used for progression tracking
- Training pods annotate TrainJob CRs with trainer.opendatahub.io/progression-* annotations
  - Requires PATCH permission on trainjobs (ServiceAccount)

Code Injection Security Note:
- SDK uses inspect.getsource() to serialize Python functions into container commands
- Serialized code is embedded in shell heredocs within pod specs
- No code signing or integrity verification on injected code
- Functions must be self-contained (no closures, no module-level state)
- RHAI TransformersTrainer serializes checkpoint management and progression tracking code

Build & Supply Chain:
- No container images produced (pure pip library)
- No Konflux Dockerfiles
- FIPS compliance delegated to host/container runtime
- uv.lock for reproducible Python dependency resolution
- No RPM-level or artifact-level lock files
