  - Resources: sparkconnects

  - SDK Methods: SparkClient.connect(), get_session(), list_sessions(), delete_session()
- API Group: "" (core)
  - Resources: pods, pods/log, events, configmaps, secrets
  - Verbs: get, list
  - SDK Methods: Log streaming, status checks, version check, credential injection

Secrets:
- Data connection secret (user-specified) - Opaque - S3 credentials for checkpoint storage - User provisioned - No auto-rotate
- HuggingFace access token (user-specified) - Opaque - Auth for private HuggingFace resources - User provisioned - No auto-rotate

Authentication Mechanisms:
- Kubernetes API: Bearer Token (kubeconfig or ServiceAccount) - enforced by Kubernetes RBAC
- Model Registry: Bearer Token (user_token) or mTLS (custom_ca) - enforced by application
- HuggingFace Hub: Bearer Token (ACCESS_TOKEN env var) - enforced by HuggingFace API
- S3 Storage: AWS IAM credentials (access_key_id/secret_access_key) or IAM role (role_arn) - enforced by IAM policy

FIPS Compliance:
- Pure Python library, no compiled binaries
- Delegates TLS to kubernetes Python client and urllib3
- No direct crypto operations in SDK code
- cryptography library is a transitive dependency (via kubernetes client)

Security Considerations:
- SparkConnect gRPC (15002/TCP) has NO encryption or authentication
- RHAI metrics endpoint (28080/TCP) has NO encryption or authentication
- Model Registry supports both HTTP (insecure) and HTTPS modes
- Docker/Podman daemon access via unencrypted Unix socket
