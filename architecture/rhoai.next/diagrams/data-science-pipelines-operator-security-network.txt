NetworkPolicy Summary:
  - MariaDB: restricted to API Server + MLMD gRPC + operator
  - MLMD gRPC: restricted to v2_component + DSP pods
  - API Server proxy: open (kube-rbac-proxy handles auth)
  - ⚠ MinIO: NO NetworkPolicy (gap)

TLS Architecture:
  - Pod-to-pod TLS: ON by default (OpenShift service-CA auto-provisioned)
  - CA bundle: dsp-trusted-ca-{name} = global ODH certs + DSPA certs + service-CA certs
  - Operator watches odh-trusted-ca-bundle ConfigMap → re-reconciles on change
  - SecurityProfileWatcher: matches cluster-wide TLS profile, restarts on changes
  - FIPS: Go 1.26 native GOFIPS140=v1.0.0 (stdlib crypto, no OpenSSL)
  - ⚠ InsecureSkipVerify available for MariaDB TLS skip-verify (user opt-in)
