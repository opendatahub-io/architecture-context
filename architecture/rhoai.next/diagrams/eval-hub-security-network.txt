RBAC Summary:
  No RBAC manifests shipped in this repository.
  RBAC is managed externally by the deploying operator (TrustyAI / ODH operator).
  Expected permissions include:
  - API Groups: batch (Jobs), core (ConfigMaps, Secrets, Pods, Pod/log)
  - API Groups: infrastructure.opendatahub.io (HardwareProfile)
  - API Groups: kueue.x-k8s.io (LocalQueue)
  - Verbs: get, list, watch, create, delete

Multi-Tenancy:
  - Tenant boundary: per-namespace (X-Tenant header = namespace name)
  - Deployment: multi-tenant single instance
  - Data isolation: SQL tenant_id column on evaluations, collections, providers
  - Compute isolation: HardwareProfile CR + Kueue LocalQueue (delegated to platform)
  - Config/secret isolation: namespace-scoped Kubernetes secrets

Secrets:
  - test-data secret (Opaque) - AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_S3_ENDPOINT
  - MLflow token (kubernetes.io/serviceaccount) - SA token for MLflow auth, auto-rotated
  - Docker config secret (kubernetes.io/dockerconfigjson) - OCI registry creds
  - Service CA (Opaque) - TLS CA cert, provisioned by service-ca-operator, auto-rotated

FIPS Compliance:
  - Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1 (dynamic link to OpenSSL)
  - Runtime: /proc/sys/crypto/fips_enabled detection
  - TLS: MinVersion 1.2, MaxVersion 1.3
  - Guard: InsecureSkipVerify blocked when FIPS active
  - Base image: ubi9/ubi-minimal-pqc (post-quantum cryptography)
