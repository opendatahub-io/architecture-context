RBAC Summary:
- RBAC roles are NOT defined in this repository
- The TrustyAI Service Operator creates:
  - ServiceAccount (operator-managed)
  - Roles/RoleBindings for K8s API access
  - Permissions: Jobs (create/delete), Pods (get logs), Secrets (read),
    ConfigMaps (create), HardwareProfile CRDs (query)

Authentication Summary:
- /healthz, /openapi.yaml, /docs: Unauthenticated
- /api/v1/*: X-Tenant + X-User headers (via kube-rbac-proxy in cluster mode)
- /metrics (8081): Unauthenticated (dedicated port, Prometheus scrape)
- Sidecar → eval-hub: ServiceAccount token (projected volume)
- Sidecar → MLflow: Bearer token (file mount at /var/run/secrets/mlflow/token)
- Sidecar → OCI: Docker config.json + OCI bearer challenge
- Sidecar → Model: Bearer API key / ref-token resolution / SA token
- MCP: Optional kube-rbac-proxy headers (configurable: none or rbac-proxy)

Secrets:
- ServiceAccount token (kubernetes.io/service-account-token) - K8s API & sidecar auth, kubelet projected, auto-rotate
- MLflow token (Opaque) - Bearer token for MLflow API, Manual/Operator, no auto-rotate
- test-data S3 credentials (Opaque, /var/run/secrets/test-data/) - AWS keys, Manual, no auto-rotate
- Model credentials (Opaque, secretMountPath) - API keys/SA tokens/endpoints, Manual/Operator, no auto-rotate
- OCI registry credentials (dockerconfigjson, /etc/evalhub/.docker/config.json) - Docker auth, Manual/Operator, no auto-rotate
- TLS cert/key (kubernetes.io/tls) - HTTPS for eval-hub API, cert-manager/Operator, auto-rotate

FIPS Compliance:
- Build: CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime (all 4 binaries)
- TLS: MinVersion TLS 1.2, Go defaults (FIPS-safe via strictfipsruntime)
- Crypto: stdlib crypto/tls only (no third-party crypto)
- No weak crypto detected (no MD5, RC4, DES)
- InsecureSkipVerify defaults to false

Tenant Isolation:
- Header-based: kube-rbac-proxy injects X-Tenant, X-User after RBAC validation
- Storage-scoped: All DB queries scoped to tenant
- System resources (providers/collections) visible to all tenants
- User-created resources scoped to tenant
- Local mode: Identity enforcement bypassed
