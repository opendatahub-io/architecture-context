RBAC Summary:
  No RBAC resources defined. All detectors run as non-root user (UID 1001)
  with no Kubernetes API access. Security is delegated entirely to the
  KServe/RHOAI platform.

Authentication & Authorization:
  - Application level: None (detectors perform no authentication)
  - Platform level: Controlled by InferenceService annotations:
    - security.opendatahub.io/enable-auth: 'true'
    - sidecar.istio.io/inject: 'true'
  - RHOAI 3.x enforcement: Istio sidecar (mTLS) + kube-rbac-proxy
  - RHOAI 2.x enforcement: oauth-proxy

Service Mesh Configuration:
  - Istio sidecar injection: Enabled (per annotation)
  - mTLS: Platform-managed (STRICT expected)
  - No NetworkPolicy defined within detector manifests
  - Relies on platform-level network isolation

  - aws-connection-minio-data-connection-guardrails-guardian (Opaque)
    Purpose: S3 credentials for HF model storage
