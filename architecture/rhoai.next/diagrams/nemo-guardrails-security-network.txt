RBAC Summary:
  No Kubernetes RBAC resources defined.
  NeMo Guardrails is a standalone application service without operator privileges.
  No ClusterRoles, Roles, or RoleBindings are created.

Authentication Summary:
  - Application layer: No authentication enforced
  - /v1/chat/completions: X-Authorization header forwarded as Bearer token to LLM
  - /v1/models: Authorization header forwarded to LLM
  - All other endpoints: No auth required
  - TLS termination: Delegated to platform ingress (OpenShift Route / Istio)

FIPS Compliance:
  - Base image: AIPCC/UBI with FIPS-validated OpenSSL
  - cryptography package (v46.0.7): Binds to system OpenSSL at runtime
  - MD5 usage: Content hashing with SHA-256 fallback (FIPS-tolerant, not FIPS-first)
  - No custom TLS config: Server listens on plain HTTP; TLS delegated to platform

Multi-Tenancy:
  - Tenant boundary: per-config-id (directory name)
  - Deployment: Single instance, multi-config
  - Isolation: In-memory only; no namespace-level or RBAC enforcement per config
  - Risk: Any client can access any config_id; shared process memory
