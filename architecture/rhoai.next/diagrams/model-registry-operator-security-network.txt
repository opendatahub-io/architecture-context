RBAC Summary:
=============
ClusterRoles:
- model-registry-operator-manager-role
  - API Groups: "", apps, modelregistry.opendatahub.io, gateway.networking.k8s.io,
                route.openshift.io, rbac.authorization.k8s.io, networking.k8s.io,
                user.openshift.io, services.platform.opendatahub.io,
                migration.k8s.io, components.platform.opendatahub.io,
                authentication.k8s.io, authorization.k8s.io, events.k8s.io
  - Resources: configmaps, PVCs, secrets, serviceaccounts, services, deployments,
               modelregistries (+finalizers/status), httproutes, referencegrants,
               routes, clusterrolebindings, rolebindings, roles, networkpolicies,
               groups, auths, storageversionmigrations, tokenreviews,
               subjectaccessreviews, events, endpoints, pods, pods/log
  - Verbs: full CRUD (most), read-only (some)
- model-registry-operator-metrics-auth-role
  - tokenreviews, subjectaccessreviews: create
- model-registry-operator-metrics-reader
  - Non-Resource URLs: /metrics → get
- modelregistry-admin-role / editor-role / viewer-role
  - Graduated access to modelregistries and status

Per-Registry Roles (namespaced):
- registry-user-{registry-name} → {registry-name}-users OpenShift Group
- {registry-name}-auth-delegator → system:auth-delegator ClusterRole

Catalog Roles (namespaced):
- model-catalog → system:authenticated Group (read access)
- model-catalog-admin → {admin-group} (admin access)
- model-catalog-auth-delegator → system:auth-delegator ClusterRole

Secrets:
========
- model-catalog-kube-rbac-proxy (kubernetes.io/tls) — Catalog proxy TLS, OpenShift auto-rotate
- model-catalog-postgres (Opaque) — Catalog DB credentials, auto-generated, no rotation
- {registry-name}-kube-rbac-proxy (kubernetes.io/tls) — Registry proxy TLS, OpenShift auto-rotate
- {registry-name}-postgres-credentials (Opaque) — Registry DB credentials, auto-generated, no rotation
- controller-manager-metrics-service (kubernetes.io/tls) — Operator metrics TLS, OpenShift auto-rotate

TLS Configuration:
==================
- Operator reads cluster TLS security profile from OpenShift APIServer at startup
- SecurityProfileWatcher monitors for runtime TLS profile changes → graceful pod restart
- FIPS: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, UBI 9 ubi-minimal-pqc base
- No custom cipher suites; delegates entirely to cluster TLS profile
