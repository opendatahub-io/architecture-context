INGRESS: None
  - No persistent services exposed
  - No HTTP/gRPC endpoints
  - All components run as ephemeral KFP pipeline tasks
  - Init container communicates only via shared PVC (filesystem)

RBAC Summary:
  - No RBAC definitions in this repository
  - Pipeline ServiceAccounts require RBAC for:
    - serving.kserve.io: InferenceService, ServingRuntime (create, get, list, watch, delete)
    - training.kubeflow.org: ClusterTrainingRuntime, TrainingJob (create, get, list, watch)
    - ray.io: RayJob (create, get, list, watch, delete)
    - kueue.x-k8s.io: WorkloadPriorityClass (get, list)
    - core: pods, services, configmaps, secrets (get, list, create)
  - RBAC is configured by DSPO or cluster administrators (external to this repo)

Secrets:
  - s3-secret (Opaque) - AWS credentials (access_key, secret_key, endpoint, region)
    Provisioned: Manual | Auto-Rotate: No
  - hf-token / hf-token-secret (Opaque) - HuggingFace API token
    Provisioned: Manual | Auto-Rotate: No
  - llm-credentials (Opaque) - API key for LLM provider (SDG)
    Provisioned: Manual | Auto-Rotate: No
  - kubernetes-credentials (Opaque) - K8s API creds for multi-node training
    Provisioned: Manual | Auto-Rotate: No
  - oci-pull-secret-model-download (kubernetes.io/dockerconfigjson) - OCI registry creds
    Provisioned: Manual | Auto-Rotate: No
  - minio-secret (Opaque) - MinIO access credentials
    Provisioned: Manual | Auto-Rotate: No
  - ogx_secret_name (Opaque, user-specified) - OGX API credentials
    Provisioned: Manual | Auto-Rotate: No
  - train_data_secret_name (Opaque, user-specified) - S3 creds for AutoML data
    Provisioned: Manual | Auto-Rotate: No
  - test_data_secret_name (Opaque, user-specified) - S3 creds for AutoRAG test data
    Provisioned: Manual | Auto-Rotate: No
  - input_data_secret_name (Opaque, user-specified) - S3 creds for AutoRAG docs
    Provisioned: Manual | Auto-Rotate: No

Authentication & Authorization:
  - S3/MinIO: AWS SigV4 (access key + secret key) → IAM policy
  - HuggingFace Hub: Bearer Token (optional) → Public/gated model access
  - OGX API: API Key header → API key validation
  - Kubernetes API: ServiceAccount Token → RBAC
  - KServe InferenceService: None / Bearer → Model-level policy
  - Milvus: Token (optional) → Database-level policy

FIPS Compliance:
  - Python applications — no Go/C compiled binaries
  - TLS: Inherited from Python ssl module (OpenSSL on UBI9/AIPCC → FIPS-compatible)
  - Crypto: cryptography==49.0.0 (OpenSSL backend, FIPS-compatible on UBI9)
  - No non-FIPS crypto detected (no MD5, RC4, DES, custom ciphers)

Build-Time Network (not runtime):
  - RHEL AI PyPI (443/TCP HTTPS) - pip install during image build
  - RHAI Modelcar OCI registry (443/TCP HTTPS) - Docling model copy during build
