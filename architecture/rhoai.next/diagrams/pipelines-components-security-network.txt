Secrets:
- s3-secret / minio-secret (Opaque) - S3 credentials (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY), User/Platform provisioned, No auto-rotate
- hf-token (Opaque) - HuggingFace authentication token, User provisioned, No auto-rotate
- kubernetes-credentials (Opaque) - KUBERNETES_SERVER_URL, KUBERNETES_AUTH_TOKEN, Platform provisioned, No auto-rotate
- oci-pull-secret-model-download (kubernetes.io/dockerconfigjson) - Docker config.json for OCI model pulls, User provisioned, No auto-rotate
- ogx-secret (Opaque) - OGX_CLIENT_BASE_URL, OGX_CLIENT_API_KEY, User/Platform provisioned, No auto-rotate
- llm-credentials (Opaque) - LLM API key for SDG flows, User provisioned, No auto-rotate

Security Concerns:
1. Model Registry uses insecure HTTP (8080/TCP, no TLS, no auth) - any pod that can reach it can register models
2. S3 client has verify=False SSL fallback in AutoML data loaders - bypasses TLS verification (FIPS gap)
3. Milvus connections use plaintext gRPC (19530/TCP) - may cross namespaces without NetworkPolicy
4. Eval Hub tenant isolation relies on X-Tenant header - server-side enforcement required

Multi-Tenancy:
- Tenant boundary: per-namespace (Kubernetes namespace)
- Pipeline execution: per-namespace with pipeline ServiceAccount RBAC
- Shared services: KFP API Server, Model Registry (no tenant isolation), Milvus (app-level scoping)
