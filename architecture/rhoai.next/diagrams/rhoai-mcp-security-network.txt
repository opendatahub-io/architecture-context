NetworkPolicy (OpenShift overlay):
- Allows ingress from model-registry namespace to rhoai-mcp on port 8000/TCP

Authentication Architecture (OIDC mode):
- JWT tokens validated via JWKS endpoint (OIDC discovery)
- Opaque tokens validated via Kubernetes TokenReview API
- UserContext propagated through async context variables
- K8s operations use impersonation (Impersonate-User, Impersonate-Group headers)
- Tool visibility filtered per-user via SubjectAccessReview
- Fail-closed: validation failure → 401, missing permission → tool hidden

Workflow Token Security:
- HMAC-SHA256 signed tokens enforce multi-step tool ordering
- Embedded timestamps with configurable TTL (default 3600s)
- Timing-safe comparison prevents timing attacks
