GATEWAY ARCHITECTURE:
  data-science-gateway          Central shared gateway for all platform services
    Auth: ext_authz → kube-auth-proxy (OIDC/OAuth) → Lua token forwarding
    Consumers: Dashboard, Model Registry, Workbenches, Data Connect Hub, MLflow, MCP servers
  maas-default-gateway          Multi-tenant model consumption gateway
    Auth: Kuadrant AuthPolicy → Authorino (API key callback + TokenReview)
    Consumers: Per-tenant maas-api, KServe LLMInferenceService endpoints
  Legacy Istio Gateways         knative-ingress-gateway, knative-local-gateway, kserve-local-gateway
    Auth: Istio STRICT mTLS
    Status: Transitional (migrating to Gateway API)

TLS CONFIGURATION:
  Cluster-wide policy           OpenShift APIServer TLS profile (default: TLS 1.2 Intermediate)
  ProfileWatcher pattern        7+ controllers watch APIServer TLS profile and restart on changes
  Service-CA TLS                OpenShift service-ca operator for internal certificates
  cert-manager TLS              KServe, ai-gateway-operator, workbenches-operator, kueue-operator webhooks
  FIPS compliance               GOEXPERIMENT=strictfipsruntime + CGO_ENABLED=1 + UBI 9 PQC runtime
  Post-quantum cryptography     ubi9-minimal-pqc base images with DEFAULT:PQ crypto policy

AUTHENTICATION MECHANISMS:
  1. ext_authz/kube-auth-proxy    Gateway-level OIDC/OAuth for data-science-gateway
  2. Kuadrant AuthPolicy          Gateway-level API key + bearer for maas-default-gateway
  3. kube-rbac-proxy sidecar      Pod-level SubjectAccessReview (8+ components)
  4. Kubernetes TokenReview       Application-level token validation (KServe, workbenches)
  5. Istio mTLS                   Legacy service mesh authentication (transitional)
  6. Istio AuthorizationPolicy    Source principal validation (DS Pipelines MySQL/MinIO)
  7. CRD-configured auth          Per-provider API key/SigV4/OAuth2 (AI Gateway)
  8. Bearer token middleware      Application-level (NeMo Guardrails, agentic-starter-kits)
  9. controller-runtime authn     TokenReview + SubjectAccessReview on metrics endpoints (port 8443)
