RBAC Summary:
- This component does NOT define its own RBAC resources
- RBAC is managed by KServe operator and the platform operator
- Service accounts are configured per-InferenceService deployment

Secrets:
- minio-secret (Opaque) - S3 access credentials for model storage
  - Provisioned by: Manual (demo setup) / platform operator
  - Auto-Rotate: No
- git-auth (Opaque) - Git credentials for Konflux pipeline
  - Provisioned by: Pipelines-as-Code
  - Auto-Rotate: No

Service Mesh Configuration:
- PeerAuthentication: STRICT (namespace-scoped)
  - Exception: PERMISSIVE on port 8086 (metrics scraping)
- NetworkPolicy:
  - Allows ingress from openshift-user-workload-monitoring namespace on port 8086
- Istio sidecar injection: Enabled for all serving pods

Authentication & Authorization:
- /api/v1/task/* (HTTP):
  - Auth: Istio mTLS + PeerAuthentication
  - Enforcement: Istio sidecar proxy
  - Policy: STRICT mTLS between pods; PERMISSIVE on metrics port 8086
- gRPC services:
  - Auth: Istio mTLS + PeerAuthentication
  - Enforcement: Istio sidecar proxy
  - Policy: STRICT mTLS between pods
- Knative external endpoint:
  - Auth: Istio IngressGateway TLS passthrough
  - Enforcement: Istio IngressGateway
  - Policy: TLS termination at gateway

Multi-Tenancy:
- Tenant boundary: per-namespace (inherited from KServe)
- Deployment model: per-namespace instance (one ServingRuntime + InferenceService per model)
- Isolation: Istio mTLS per namespace, per-namespace PVC/S3 path, NetworkPolicy

FIPS Compliance:
- Python application on UBI 9 (inherits OpenSSL FIPS from base OS)
- No explicit TLS in application code (delegated to Istio sidecar)
- ML crypto (torch, transformers) is for computation, not security-sensitive communication

Supply Chain Risks:
- Base image uses floating tag (ubi9/ubi-minimal:latest) not digest-pinned
- Tekton pipeline sets hermetic: false (non-hermetic builds)
- No RPM lockfile (rpms.lock.yaml) present
- No AIPCC base images used
