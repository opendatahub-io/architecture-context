RBAC Summary:
  No Kubernetes RBAC is defined. The components use ServiceAccounts with
  default permissions and do not interact with the Kubernetes API.

  ServiceAccounts:
  - {release}-batch-gateway-apiserver
  - {release}-batch-gateway-processor
  - {release}-batch-gateway-gc

Authentication & Authorization:
  - /v1/batches, /v1/files: Delegated to Kuadrant/Authorino (external gateway)
    - Mechanisms: API key, ServiceAccount token, OpenShift user token
    - Per-tier AuthPolicy with identity extraction
  - /health, /ready, /metrics: Unauthenticated (observability ports only)
  - Inference gateway: API key (Bearer header) per-model or global
  - CRITICAL: API server has NO built-in auth — direct access bypasses
    all tenant isolation. Network restriction is mandatory.

Multi-Tenancy:
  - Model: Multi-tenant (single shared instance, all tenants)
  - Boundary: Per-user (tenant ID from X-MaaS-Username header)
  - Data isolation: Application-enforced (no DB row-level security)
    - PostgreSQL: WHERE tenant_id = ? on all queries
    - Redis: Key-prefixed by tenant ID
    - S3: SHA256-based folder paths per tenant
  - Compute isolation: None — shared worker pool and concurrency slots
  - Cross-tenant access: Returns 404 (prevents enumeration)

Secrets:
  - batch-gateway-secrets (Opaque)
    - redis-url: Redis connection URL
    - postgresql-url: PostgreSQL connection URL
    - inference-api-key: Inference gateway API key
    - s3-secret-access-key: S3 secret access key
    - Provisioned by: Manual (kubectl create secret)
    - Auto-rotate: No
    - Access: os.OpenInRoot() — path traversal safe

  - {release}-batch-gateway-apiserver-tls (kubernetes.io/tls)
    - TLS certificate and key for API server
    - Provisioned by: cert-manager (optional) or manual
    - Auto-rotate: Yes (cert-manager) / No (manual)

FIPS Compliance:
  - Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
  - Runtime: UBI 9 minimal base (OpenSSL)
  - TLS: MinVersion TLS 1.2 enforced
  - Crypto: stdlib crypto/tls (FIPS via OpenSSL with strictfipsruntime)
  - Risk: InsecureSkipVerify option available (testing only)

Ingress Configuration:
  - Optional HTTPRoute (Gateway API) via {release}-batch-gateway-apiserver
  - Parent gateway: llm-d-inference-gateway (configurable)
  - Paths: /v1/batches/*, /v1/files/*
  - Protocol: HTTP/HTTPS (inherited from parent Gateway)
