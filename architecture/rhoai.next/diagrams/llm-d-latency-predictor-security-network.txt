2. No TLS/mTLS between prediction and training servers (plaintext HTTP)
3. No NetworkPolicy to restrict access
4. No service mesh integration for mTLS
5. MD5 used for file checksums (acceptable for non-crypto use but flagged)
6. Model download lacks cryptographic integrity verification
7. Training data ingestion endpoint is unauthenticated (data poisoning risk)
8. LoadBalancer services expose endpoints externally without auth
