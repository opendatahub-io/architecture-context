SECURITY CONCERNS:
1. prediction-service (LoadBalancer) exposes prediction API externally without auth
2. training-service-external (LoadBalancer) exposes training API externally -- enables
   training data poisoning attacks that could manipulate routing decisions
3. No network policies restrict inter-service or external communication
4. No TLS on any communication path
5. /add_training_data_bulk endpoint accepts arbitrary training data without validation
   of source identity -- adversarial data injection risk
6. /flush endpoint can reset all training data/metrics without authentication
