NETWORK POLICIES
================

Namespace: redhat-ods-operator
  - Ingress: Allow from pods with label app=rhods-operator

Namespace: redhat-ods-applications
  - Ingress: Allow from labeled namespace pods (broad port range)

Namespace: redhat-ods-monitoring
  - Ingress: Allow from monitoring namespace pods
  - Ingress: Allow from openshift-monitoring namespace (federation)

SECURITY NOTES
==============

- Blackbox exporter uses insecure_skip_verify: true for internal probes
- Segment.io analytics key stored as static base64 in source control
- Prometheus /metrics endpoint allows unauthenticated access (skip-auth-regex)
- Metrics endpoints for components (8080/TCP) are unencrypted HTTP with no auth
- OAuth proxy sidecars enforce SAR-based access to monitoring UIs
