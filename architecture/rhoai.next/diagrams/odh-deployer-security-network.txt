- Alertmanager UI (10443/TCP): OpenShift OAuth Proxy, SAR check: get namespaces in redhat-ods-monitoring

Security Notes:
- Segment.io analytics key committed to repo as base64 (supply chain risk)
- Blackbox exporter uses insecure_skip_verify: true for internal probes (intentional)
- Component metrics endpoints (8080/TCP) have no authentication or encryption
- deploy.sh runs with cluster-admin privileges for ISV tile application
