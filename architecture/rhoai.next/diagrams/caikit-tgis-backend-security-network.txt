RBAC Summary:
  No RBAC — this is a library without direct Kubernetes API interactions.
  RBAC is determined by the consuming deployment's ServiceAccount.

Secrets Summary:
  ┌─────────────────────┬────────────────────────┬──────────────────────────────┐
  │ Secret              │ Type                   │ Purpose                       │
  ├─────────────────────┼────────────────────────┼──────────────────────────────┤
  │ ca_cert_file        │ TLS CA certificate     │ Verify TGIS server identity   │
  │ client_cert_file    │ TLS client certificate │ Prove client identity (mTLS)  │
  │ client_key_file     │ TLS private key        │ Private key for mTLS          │
  └─────────────────────┴────────────────────────┴──────────────────────────────┘
  Provisioning: External (cert-manager or manual, via K8s Secrets mounted as volumes)
  Auto-Rotate: No — library reads certs from file path once at connection time

FIPS Compliance:
  - Pure Python library — no compiled binaries
  - TLS delegated to grpcio C core → uses system OpenSSL
  - In FIPS-enabled container (UBI + FIPS OpenSSL): FIPS cipher suites used automatically
  - No custom crypto, no MD5/RC4/DES usage detected
  - No cipher suite or TLS version pinning — uses gRPC defaults
