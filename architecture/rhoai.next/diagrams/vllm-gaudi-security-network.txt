Build Hermeticity:
- ⚠️ Build is COMPLETELY NON-HERMETIC
- No lock files at any layer (no rpms.lock.yaml, no pip lock, no artifacts.lock.yaml)
- Tekton pipeline: hermetic: false
- Dependencies fetched from public internet (PyPI, GitHub) at build time
- Upstream vLLM and vllm-gaudi cloned from GitHub, pinned by tag (not content hash)
- Downstream release branches expected to add Hermeto prefetch and lock files

Security Risks:
1. FIPS gap — openssl-fips-provider-so stripped from production image
2. Non-hermetic builds — supply chain risk from unverified public dependencies
3. HCCL inter-HPU traffic unencrypted — lateral movement risk in multi-card setups
4. Ray coordination unencrypted (6379/TCP) — no auth on Ray cluster
5. No auth on vllm-gaudi container itself — relies entirely on sidecar proxy
6. Not using AIPCC base images — manual driver installation bypasses product security
