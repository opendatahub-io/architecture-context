RBAC Summary:
- No RBAC resources defined in this repository
- RBAC is managed by the TrustyAI Operator:
  - ServiceAccount: Created per TrustyAIService CR instance
  - ClusterRole: Managed by operator for kube-rbac-proxy authorization
  - RoleBinding: Created by operator in target namespace
- kube-rbac-proxy enforces Kubernetes RBAC via SubjectAccessReview

Security Risks:
- CORS: allow_origins=["*"] with allow_credentials=True is overly permissive
  Mitigation: kube-rbac-proxy enforces auth; HTTP listener on loopback only
  Risk: HTTPS listener on 0.0.0.0:4443 exposed if TLS certs present
- hashlib.md5: Used with usedforsecurity=False for UUID generation only (non-FIPS safe)
- LM Eval subprocess: Sandboxed via env var blocking + CLI sanitization (shlex.quote)
