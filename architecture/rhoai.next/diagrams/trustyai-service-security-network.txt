RBAC Summary:
  No RBAC resources defined in the repository.
  RBAC is managed by the trustyai-service-operator.

Authentication Summary:
  - API endpoints (port 8081): OAuth/Bearer via kube-rbac-proxy sidecar
  - HTTPS endpoints (port 4443): mTLS/Bearer (configurable, direct access)
  - Health endpoints (port 8080 GET): None (kubelet probes, by design)
  - Consumer endpoints (port 8080 POST): None (KServe agent, network-only isolation)

TLS Configuration:
  - PolicyAwareConfig: Subclasses Hypercorn Config to delegate to system crypto policy
  - Never overrides cipher suites or TLS versions
  - Applies OP_NO_COMPRESSION
  - Inherits FIPS crypto policy when deployed on FIPS-enabled cluster
  - Upstream sets DEFAULT:PQ (post-quantum) crypto policy

Secrets:
  - DATABASE_PASSWORD (env var) - MariaDB auth credential, operator-provisioned, no auto-rotation
  - QUARKUS_DATASOURCE_PASSWORD (env var) - Legacy MariaDB auth name, operator-provisioned
  - TLS certificate + key (file mount) - HTTPS termination, cert-manager/operator provisioned
  - DATABASE_TLS_CA_CERT (file mount at /etc/tls/db/ca.crt) - MariaDB TLS CA, operator/manual
