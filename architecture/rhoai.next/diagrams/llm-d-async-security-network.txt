================================================================================
  SECURITY NETWORK DIAGRAM: llm-d-async (Async Processor)
================================================================================

  No inbound ingress. The processor is a headless worker that pulls from
  message brokers and pushes to inference gateways.

================================================================================
  INTERNAL (Pod-Local Endpoints)
================================================================================

  [Health Server]
  - Port: 8081/TCP
  - Protocol: HTTP
  - Encryption: None
  - Auth: None (pod-local kubelet only)
  - Endpoints: /healthz (liveness), /readyz (readiness)

  [Metrics Server]
  - Port: 9090/TCP
  - Protocol: HTTP
  - Encryption: None
  - Auth: Optional kube-rbac-proxy (SubjectAccessReview)
  - Endpoint: /metrics (Prometheus scrape)
  - Scraped by: PodMonitor (Prometheus Operator)

================================================================================
  EGRESS (Outbound Connections)
================================================================================

  [Async Processor]
         |

         |    Protocol: HTTP/HTTPS

         |             result publishing, quota gates, cancellation
         |
         |--- Port: 443/TCP
         |    Protocol: gRPC
         |    Encryption: TLS 1.2+
         |    Auth: GCP IAM

         |    Purpose: Alternative message queue transport
         |
         |--- Port: 443/TCP
         |    Protocol: gRPC
         |    Encryption: TLS 1.2+
         |    Auth: GCP IAM
         |    Dest: GCP Cloud Monitoring

         |
         |--- Port: 9090/TCP
         |    Protocol: HTTP
         |    Encryption: None
         |    Auth: None
         |    Dest: Prometheus
         |    Purpose: Capacity metric queries for dispatch gates
         |
         |--- Port: 6443/TCP
         |    Protocol: HTTPS
         |    Encryption: TLS 1.2+
         |    Auth: ServiceAccount token

         |
         |--- Port: 4317/TCP

              Encryption: Optional TLS

================================================================================
  FIPS COMPLIANCE
================================================================================

  Build:
  - GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, dynamic linking
  - Runtime base: ubi9/ubi-minimal-pqc (post-quantum cryptography)

  Application:
  - TLS minimum: TLS 1.2 (crypto/tls MinVersion)
  - Cipher suites: Go runtime default (OpenSSL via strictfipsruntime)
  - InsecureSkipVerify: available (dev/test only, default false)
