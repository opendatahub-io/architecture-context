Cross-Namespace Secret Resolution:
- Mechanism: Gateway API ReferenceGrant
- Flow: If spec.secretRef.namespace != CR namespace, operator verifies ReferenceGrant
  permits batch.llm-d.ai/LLMBatchGateway → core/Secret
- Security: secretRef is immutable after first copy (prevents credential confusion)
- Watch filter: secretWatchFilter limits Secret informer to tracked cross-NS secrets only

Secrets:
- {user-specified via spec.secretRef} (Opaque) - Runtime credentials: postgresql-url,
  redis-url, inference-api-key, s3-secret-access-key. User-provisioned, no auto-rotate.
- {gateway-name}-credentials (Opaque) - Controller-managed copy of cross-namespace secret.
  Synced on reconcile.
- {name}-apiserver-tls (kubernetes.io/tls) - TLS cert for API server. cert-manager
  provisioned, auto-rotated.
