NetworkPolicy (config/base/networkpolicy.yaml):
- Ingress Rules:
  - Ports 8033, 8080: Only from pods with label app=model-mesh
  - Port 8033: Open to all sources (inference)
  - Port 2112: Open to all sources (metrics)
- Note: Deployer should further restrict inference access on port 8033

RBAC Summary:
- No RBAC roles defined in this repository
- RBAC is managed by the companion modelmesh-serving controller

Secrets:
- model-mesh-tls-secret (kubernetes.io/tls) - TLS key/cert for gRPC and litelinks, Manual/cert-manager, No auto-rotate
- model-mesh-icd-etcd (Opaque) - etcd connection config (JSON), Manual, No auto-rotate

FIPS Compliance:
- ⚠ FIPS EXPLICITLY DISABLED: -Dcom.redhat.fips=false in start.sh
- ⚠ security.useSystemPropertiesFile=false disables FIPS security properties
- ⚠ SunPKCS11 provider reordering modifies crypto provider chain
- ⚠ BouncyCastle 1.78 used for self-signed cert generation (non-JDK crypto)
- ⚠ Hardcoded truststore password (watson15qa) in start.sh

Authentication & Authorization:
- gRPC :8033 — mTLS optional (MM_TLS_CLIENT_AUTH setting)
- gRPC :8085 — None (localhost co-location trust)
- Thrift :8080 — TLS with client auth optional (litelinks SSL)
- HTTP :8089 — None (health probes)
- HTTPS :2112 — Server-auth TLS only (self-signed, no client auth)
