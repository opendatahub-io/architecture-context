RBAC Summary:
- kube-auth-proxy does NOT define its own RBAC resources
- When K8s token validation is enabled, requires:
  - API Group: authentication.k8s.io
  - Resources: tokenreviews
  - Verbs: create
  - Configured by: rhods-operator or odh-notebook-controller

Deployment Model:
- Sidecar container injected by platform operators
- rhods-operator: injects into RHOAI component pods
- odh-notebook-controller: injects into notebook pods
- No standalone kustomize deployment manifests

Secrets:
- kube-auth-proxy-secret (Opaque) - client-secret, cookie-secret
  - Provisioned by: Manual / Operator
  - Auto-Rotate: No
- ServiceAccount token (kubernetes.io/service-account-token)
  - Auto-detected for OpenShift OAuth provider
  - Provisioned by: Kubernetes
  - Auto-Rotate: Yes

FIPS Compliance:
- Build: CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime -tags strictfipsruntime
- Base image: UBI9 ubi-minimal (OpenSSL available)
- TLS: Configurable min TLS 1.2, max TLS 1.3, configurable cipher suites
- CI gate: check-payload validation on every PR
- Risk: InsecureSkipVerify option available (disabled by default)

Session Encryption:
- Cookie sessions: CFB cipher encryption with LZ4 compression + MessagePack serialization
- Cookie splitting: Handles >4KB sessions across multiple cookies
- Redis sessions: Data stored server-side, only session ticket in cookie
