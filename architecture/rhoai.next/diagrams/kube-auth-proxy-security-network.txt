RBAC Summary:
- No RBAC manifests shipped with kube-auth-proxy
- Required at deployment time:
  - ServiceAccount with authentication.k8s.io TokenReview create permission
  - ServiceAccount with user.openshift.io users get permission (OpenShift provider)
  - OAuth redirect annotation on ServiceAccount (OpenShift OAuth)

Secrets:
- kube-auth-proxy-secret (Opaque)
  - cookie-secret: AES key for session encryption (HMAC-SHA256 + AES-CFB)
  - client-secret: OAuth2 client secret
  - Provisioned: Manual / Platform operator
  - Auto-Rotate: No
- TLS cert/key (kubernetes.io/tls)
  - HTTPS listener certificate and private key
  - Provisioned: cert-manager / Manual
  - Auto-Rotate: Deployment-specific
- Service account token (kubernetes.io/service-account-token)
  - Auto-detected client-secret for OpenShift OAuth provider
  - Provisioned: Kubernetes (auto-mounted)
  - Auto-Rotate: Yes

Authentication Methods:
- OIDC (external provider) - browser flow with PKCE
- OpenShift OAuth - browser flow + Bearer sha256~ tokens
- Kubernetes ServiceAccount tokens - via TokenReview API
- htpasswd - basic auth (file-based)
- Session cookies - HMAC-signed, AES-CFB encrypted, 4KB auto-split

FIPS Compliance:
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, UBI9 base
- Crypto: AES-CFB (cookies), AES-GCM (Redis tickets), HMAC-SHA256, SHA-256
- No MD5/RC4/DES usage detected
- Risk: --ssl-insecure-skip-verify flag available (not default)
