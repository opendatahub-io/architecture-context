RBAC Summary:
- No ClusterRoles or RoleBindings deployed by this component
- CLI operates under the authenticated user's kubeconfig identity
- SelfSubjectAccessReview pre-flight checks before privileged operations
  (e.g., migrate, deps install, diagnose)
- Required cluster-level permissions for: deps install, diagnose
- Namespace-scoped operations where applicable

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, -tags strictfipsruntime
- Runtime: Dynamic linking to OpenSSL via ose-cli-rhel9 base image (UBI9)
- Crypto Policy: DEFAULT:PQ (Post-Quantum) set via update-crypto-policies
- Risk: InsecureSkipVerify=true on TrustYAI metrics HTTP client
  (intentional for self-signed in-cluster routes, nolint:gosec)

Secrets:
- (kubeconfig credentials) - Bearer token / client cert for Kubernetes API auth
  Provisioned by: User / oc login / service account
  Rotation: Varies by credential type

Build Hermeticity:
- rpms.lock.yaml: RPM dependencies locked (jq, oniguruma, crypto-policies)
- go.sum: Go module dependencies locked
- Tekton pipeline: hermetic=true with RPM + gomod prefetch via Hermeto
- Platforms: linux/amd64, linux/arm64, linux/ppc64le

MCP Server Security Notes:
- MCP SSE endpoint binds to 127.0.0.1 only (not externally accessible)
- No authentication on MCP endpoints (localhost trust model)
- CLI inherits kubeconfig credentials for all cluster operations
- Agent access is functionally equivalent to the CLI user's permissions
