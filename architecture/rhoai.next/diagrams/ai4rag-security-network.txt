URL Trust Policy:
  Enforcement: ensure_safe_url() at ai4rag/utils/network.py:106-136
  Rule: Every configurable external endpoint MUST use HTTPS unless:
    - Targeting localhost / 127.0.0.1
    - Targeting *.cluster.local (in-cluster services)
  Clients: MaaS, S3, Milvus, pgvector, Neo4j — all validated

RBAC Summary:
  No Kubernetes RBAC definitions. ai4rag is a Python library;
  RBAC is configured externally in the deployment environment.

Authentication Summary:
  /v1/responses (starter kit):
    - Bearer token validated via K8s TokenReview API
    - Enforced by auth_wrapper._BearerAuthMiddleware (ASGI)
    - Optional username restriction: ALLOWED_SA_USERNAME
  /health (starter kit):
    - Unprotected health check endpoint
  Library API:
    - No network endpoints; credentials passed as env vars

Secrets (Environment Variables):
  - MAAS_API_KEY           — MaaS API authentication
  - MAAS_CA_BUNDLE         — PEM CA bundle for MaaS TLS
  - MILVUS_TOKEN           — Milvus authentication token
  - MILVUS_CA_CERT         — PEM CA cert for Milvus TLS
  - PGVECTOR_PASSWORD      — PostgreSQL authentication
  - PGVECTOR_CA_CERT       — PEM CA cert for pgvector TLS
  - NEO4J_PASSWORD         — Neo4j authentication
  - AWS_ACCESS_KEY_ID      — S3 storage access key
  - AWS_SECRET_ACCESS_KEY  — S3 storage secret key
  - K8S_REVIEWER_TOKEN     — K8s SA token for TokenReview
  - AGENT_CONFIG_B64       — Base64-encoded agent config JSON
  Auto-Rotation: None — all provisioned by runtime environment

Crypto:
  - TLS: stdlib ssl, httpx, asyncpg, pymilvus, neo4j driver (all via OpenSSL)
  - Hashing: hashlib SHA-256 for chunk IDs and document fingerprinting (non-security)
  - FIPS: No non-FIPS crypto detected; SHA-256 is FIPS-compliant
