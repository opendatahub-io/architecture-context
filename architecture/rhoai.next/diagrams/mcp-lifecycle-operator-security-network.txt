EGRESS FLOWS:

  mcp-lifecycle-operator → Kubernetes API Server
  - Port: 443/TCP
  - Protocol: HTTPS
  - Encryption: TLS 1.2+
  - Auth: ServiceAccount Token (automounted)
  - Operations: CRUD on Deployments, Services, NetworkPolicies,
                ConfigMaps, Secrets, Pods, MCPServers

  mcp-lifecycle-operator → MCP Server Endpoints
  - Port: {spec.config.port}/TCP (per MCPServer CR)
  - Protocol: HTTP (Streamable HTTP / MCP Protocol)
  - Encryption: None
  - Auth: None (unauthenticated handshake; 401/403 treated as reachable)
  - Purpose: MCP initialize handshake verification
  - Retry: Exponential backoff 10s-2min, max 10 retries
