Bindings:
- manager-rolebinding (ClusterRoleBinding) → manager-role → SA: controller-manager
- leader-election-rolebinding (RoleBinding) → leader-election-role → SA: controller-manager
- metrics-auth-rolebinding (ClusterRoleBinding) → metrics-auth-role → SA: controller-manager

Secrets:
- No operator-managed secrets
- Reads user-referenced Secrets (via MCPServer spec) for config hash computation
- Metrics TLS: self-signed certificate generated by controller-runtime at startup

TLS Configuration:
- Configurable via TLS_MIN_VERSION and TLS_CIPHER_SUITES environment variables
- HTTP/2 disabled by default (mitigates CVE-2023-44487 Rapid Reset)
- FIPS: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1 (OpenSSL via UBI9)
