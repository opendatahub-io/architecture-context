TLS Configuration:
- Configurable via pkg/tls: defaults to TLS 1.2+ with ECDHE AEAD ciphers
- ProfileWatcher monitors OpenShift APIServer config.openshift.io/v1/APIServer
- Dynamically adjusts TLS settings based on cluster TLS security profile
- FIPS build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, UBI 9 pqc base

Non-FIPS Crypto Risks:
- InsecureSkipVerify in test infrastructure (pkg/testing/config.go:258) - test only
- InsecureSkipVerify in logger worker (pkg/logger/worker.go:109) - controlled by TlsSkipVerify field

Multi-Tenancy:
- Tenant boundary: per-namespace
- Isolation: RBAC, NetworkPolicy, namespace-scoped CRDs
- Shared resources: ClusterServingRuntimes (cluster-wide), LocalModelCache PVs (node-level)
- Gap: Python model servers have no auth middleware; rely on NetworkPolicy
