Special Authorization Rules:
- Hardcoded Allow: system:serviceaccount:openshift-monitoring:prometheus-k8s
  - Method: GET
  - Path: /metrics
  - Bypass: Skips SubjectAccessReview entirely
  - Purpose: OpenShift monitoring Prometheus metrics collection

RBAC Summary:
- ClusterRole: kube-rbac-proxy
  - API Group: authentication.k8s.io
  - Resources: tokenreviews
  - Verbs: create
  - API Group: authorization.k8s.io
  - Resources: subjectaccessreviews
  - Verbs: create
- ClusterRole: metrics
  - Non-Resource URLs: /metrics
  - Verbs: get

- ClusterRoleBinding: kube-rbac-proxy
  - Role: kube-rbac-proxy (ClusterRole)
  - ServiceAccount: kube-rbac-proxy (namespace: default)

Authorization Caching:
- Allow cache TTL: 5 minutes
- Deny cache TTL: 30 seconds

TLS Configuration:
- Server: TLS 1.2+ minimum, configurable cipher suites and curve preferences
- Certificate: Hot-reloaded via CertReloader (polling with atomic swap)
- Upstream: TLS 1.2+ minimum, custom CA bundle support, mTLS client certs optional
- FIPS: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, UBI 9 minimal PQC base

Secrets:
- TLS cert/key pair (kubernetes.io/tls) - Server TLS certificate, external provisioning, auto-rotate via CertReloader
