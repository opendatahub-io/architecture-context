RBAC Summary:
- No Kubernetes RBAC defined in this repository
- RBAC is managed by the platform operator (rhods-operator)
- Application-level access policy: ownership-based authorization
  - Read unowned (system) resources: all authenticated users
  - Create resources: authenticated users
  - Read/Update/Delete owned resources: owner only

Authentication:
- OAuth2 JWT (conditional, enabled when AUTH_ISSUER is set)
- JWKS endpoint: AUTH_JWKS_URI (fetched for token validation)
- Audience: AUTH_AUDIENCE (default: "ogx")
- TLS verify: AUTH_VERIFY_TLS (default: true)
- When AUTH_ISSUER is NOT set: all endpoints are unauthenticated

FIPS Compliance:
- Python application -- no Go binary compilation
- System OpenSSL inherited from AIPCC CPU base image (RHEL 9.6)
- OGX server runs --insecure (plaintext HTTP); TLS at platform ingress
- TLS verification can be disabled per-provider (VLLM_TLS_VERIFY=false, etc.)

Non-FIPS Crypto Risks:
- InsecureSkipVerify-equivalent: VLLM_TLS_VERIFY=false, AUTH_VERIFY_TLS=false
- Server runs --insecure (no TLS) by design, depends on platform TLS termination
