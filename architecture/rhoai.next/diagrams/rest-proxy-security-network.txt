RBAC Summary:
- No RBAC roles or bindings. The rest-proxy does not interact with the
  Kubernetes API server.

Secrets:
- TLS cert/key (via MM_TLS_KEY_CERT_PATH / MM_TLS_PRIVATE_KEY_PATH)
  - Type: kubernetes.io/tls
  - Purpose: TLS certificate and key for HTTPS listener
  - Provisioned by: ModelMesh Serving operator
  - Auto-rotate: Unknown
  - Shared within pod (mounted volume)

Authentication & Authorization:
- Proxy-level auth: NONE
- Auth enforcement: External to rest-proxy
  - RHOAI 3.x: kube-rbac-proxy sidecar
  - RHOAI 2.x: oauth-proxy
  - Service mesh may provide additional mTLS enforcement
- All endpoints (GET, POST) are unprotected at the proxy level
- Risk: REST listener binds to 0.0.0.0, so network access control
  depends on Kubernetes NetworkPolicy or service mesh configuration

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Base image: ubi9/ubi-minimal (provides OpenSSL for FIPS crypto)
- TLS library: stdlib crypto/tls (FIPS via OpenSSL with strictfipsruntime)
- Risks:
  - InsecureSkipVerify can be enabled via REST_PROXY_SKIP_VERIFY=true
  - No MinVersion set on tls.Config (relies on Go default TLS 1.2)
  - No cipher suite restrictions configured

Multi-Architecture:
- Platforms: x86_64, arm64, ppc64le, s390x
