RBAC Summary:
- llm-d does not define RBAC resources in this repository
- RBAC is defined by sibling components (llm-d-router Helm chart)
- Base ServiceAccount has automountServiceAccountToken: false
- Router RBAC (from llm-d-router chart): InferencePool, EndpointSlice access

Secrets:
- llm-d-hf-token (Opaque) - HuggingFace API token, manual creation, no auto-rotation

Security Gaps (for RHOAI productization):
- No NetworkPolicy manifests in guides
- No mTLS between internal services (vLLM endpoints are plain HTTP)
- No auth at model server level (delegated entirely to Gateway)
- Threat model document is a placeholder (THREAT-MODEL.md)
- No kube-rbac-proxy sidecars for internal traffic
- No FIPS build flags or UBI bases (except RDMA tools)
- No Konflux Dockerfiles for downstream hardening

Authentication Flow:
- External → Gateway: TLS + auth per Gateway controller
- Gateway → Router Proxy: Plain HTTP, no auth (cluster internal)
- Router Proxy → EPP: Plain gRPC, no auth (localhost)
- EPP → Model Server: Plain HTTP, no auth
- Model Server → HuggingFace: HTTPS + Bearer token (HF_TOKEN)
