  - Watches: InferencePool CRD (inference.networking.k8s.io)
  - Uses: Kubernetes API (in-cluster mTLS)

Secrets:
- llm-d-hf-token (Opaque) - HuggingFace Hub authentication
  - Provisioned by: Manual (kubectl create secret)
  - Auto-Rotate: No
  - Contains: HF_TOKEN for model download

Authentication & Authorization:
- vLLM API (8000/TCP): NO authentication - relies on network isolation
- Envoy proxy (8081/TCP): NO default authentication (configurable)
- EPP (9002/TCP): NO authentication - internal gRPC
- NIXL (5600/TCP): NO authentication - pod-to-pod RDMA
- Mooncake (50051/TCP): NO authentication - internal gRPC

Security Gaps Identified:
- No TLS between any internal components
- No NetworkPolicy manifests in deployment guides
- No authentication on vLLM API endpoint
- No service mesh configured by default
- RDMA traffic (NIXL, Mooncake) is unencrypted
- For RHOAI: needs kube-rbac-proxy, TLS, NetworkPolicies, AIPCC base images

FIPS Compliance:
- No FIPS-specific build flags
- CUDA image uses UBI9 (includes OpenSSL)
- CPU image uses Ubuntu 22.04
- Python stdlib ssl for TLS operations
- No Go binaries produced

Build Hermeticity:
- Partial: torch/nixl pinned via constraints, component versions pinned in docker/common-versions
- No uv.lock or pip freeze for transitive Python deps
- OS packages from UBI repos not locked
