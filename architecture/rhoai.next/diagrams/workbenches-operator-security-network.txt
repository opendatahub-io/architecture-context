- Operator bootstraps from OpenShift APIServer TLS profile (config.openshift.io/v1)

- SecurityProfileWatcher monitors TLS profile changes → triggers graceful restart
- FIPS: CGO_ENABLED=1, -tags strictfipsruntime, dynamic linking with UBI 9 OpenSSL
