NetworkPolicy Summary:
  Ingress (manifests/rhoai/networkpolicy-ingress.yaml):
  - Port 9443/TCP: Allow from Kubernetes API server (webhook admission)
  - Port 10443/TCP: Allow from training pods (status updates)
  - Port 8443/TCP: Allow from openshift-monitoring namespace (metrics scraping)

  Egress (manifests/rhoai/networkpolicy-egress.yaml):
  - Unrestricted (required for Kubernetes API access)

    - jobset.x-k8s.io/jobsets: full CRUD
    - scheduling.volcano.sh/podgroups: full CRUD
    - scheduling.x-k8s.io/podgroups: full CRUD

    - apps/deployments: full CRUD
