TLS Configuration
================================================================================

  - Webhook TLS: Self-signed certificate managed by open-policy-agent/cert-controller
  - Metrics TLS: Reads OpenShift cluster TLS security profile (config.openshift.io/v1 APIServer)
    - Supports: Intermediate (default), Modern, Old, Custom profiles
    - Fallback: Intermediate profile (TLS 1.2, strong ciphers) on non-OpenShift
  - FIPS: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, UBI9 base with OpenSSL
  - No hardcoded non-FIPS ciphers detected
