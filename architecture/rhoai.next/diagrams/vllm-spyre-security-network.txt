RBAC Summary:
  No RBAC defined — this is a container image without Kubernetes API access.
  Authentication/authorization is entirely managed by the kube-rbac-proxy
  sidecar injected by the platform operator.

  Endpoint-level auth:
  - /v1/* (HTTP) and TGIS gRPC: Bearer Token validated by kube-rbac-proxy
    against Platform RBAC policies.

Service Mesh Configuration:
  Not directly configured by this component.
  Service mesh (if enabled) is managed at the platform level.

Secrets:
  No secrets defined in this repository.
  - TLS certificates: Managed by platform operator / cert-manager
  - Model credentials: If S3-based model storage is used, credentials are
    provided via platform-managed secrets (not defined here)

Image Provenance Chain:
  registry.redhat.io/rhaiis/vllm-spyre-rhel9:3.2.2
    └── quay.io/aipcc/base-images/spyre (AIPCC IBM Spyre base)
        └── UBI 9 (Red Hat Universal Base Image)

Container Security:
  - Runs as non-root (UID 2000)
  - No privilege escalation
  - No Kubernetes API access
  - No outbound network connections (HF_HUB_OFFLINE=1)
  - FIPS: Inherits OpenSSL from UBI base; no TLS served (plaintext HTTP/gRPC)
  - TLS termination handled externally by kube-rbac-proxy sidecar
