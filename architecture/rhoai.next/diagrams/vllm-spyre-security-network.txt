- No RBAC resources defined in this repository
- This is a container image, not an operator
- RBAC for the pod is managed by the ServingRuntime/InferenceService controller
- Service account is assigned by KServe at deployment time

Authentication & Authorization:
- HTTP API (8000/TCP): No native auth; enforced by platform
  - Istio sidecar (mTLS, AuthorizationPolicy)
  - kube-rbac-proxy (optional)
  - Configured per InferenceService
- gRPC API (8033/TCP): No native auth; enforced by platform
  - Same enforcement points as HTTP API

Secrets:
- No secrets defined in this repository
- Model storage credentials injected by platform at runtime
- TLS certificates managed by Istio/cert-manager
