Security Risks:

  1. InsecureSkipVerify=true (default) for model server metrics scraping
     - Bypasses TLS certificate validation when scraping model server /metrics
     - Configurable via Helm values and plugin parameters
     - Mitigation: Set InsecureSkipVerify=false in production

  2. ext-proc gRPC has no authentication
     - Security relies on network-level isolation (namespace boundaries)
     - Gateway controls which ext-proc filters are active
     - Mitigation: NetworkPolicies, namespace isolation

  3. Latency predictor sidecars use plaintext HTTP
     - Pod-internal only (localhost), not network-exposed
     - Acceptable risk for sidecar communication

  4. No NetworkPolicy resources in Helm charts
     - Namespace isolation depends on cluster-level policies
     - Mitigation: Deploy cluster-level NetworkPolicies
