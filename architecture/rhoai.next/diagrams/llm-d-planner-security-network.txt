  - API Groups: "" (core)
  - Resources: nodes
  - Verbs: list
- ClusterRoleBinding: planner-gpu-reader
  - Namespace: planner
  - ServiceAccount: planner-backend

Authentication & Authorization:
- Most API endpoints (/api/v1/*): NO authentication middleware
- DB admin endpoints: X-Admin-Password header (hmac.compare_digest)
  - /api/v1/db/upload-benchmarks (POST)
  - /api/v1/db/reset (POST)
  - /api/v1/db/verify-admin (POST)
- CORS: allow_origins=["*"] (wide open)
- TLS: Delegated to OpenShift Routes (edge termination)
- Internal service-to-service: Plaintext HTTP (no mTLS)

Secrets:
- planner-secrets (Opaque) - HuggingFace token, Model Catalog creds,
  Vertex AI, OpenAI API key, DB admin password. Manual provisioning. No auto-rotate.
- ServiceAccount token (kubernetes.io/service-account-token) - K8s API and
  Model Catalog auth. Auto-provisioned by Kubernetes. Auto-rotated.

Security Gaps:
- No authentication on most API endpoints
- No service mesh / mTLS between internal services
- CORS allow_origins=["*"] allows any origin
- Base image: python:3.14-slim (not UBI, no FIPS)
- No Konflux integration or hermetic builds
- No NetworkPolicy restricting inbound access to backend or UI
- SSL verification for Model Catalog is configurable (can be disabled)
- Single-tenant only; no multi-tenancy isolation
