RBAC Summary:
  Not applicable — Training Hub is a Python library, not a Kubernetes workload.
  No ClusterRoles, RoleBindings, or ServiceAccounts defined.

Kubernetes Secrets:
  Not applicable — Training Hub does not define Kubernetes secrets.
  API keys are consumed via environment variables at runtime:
  - HF_TOKEN: HuggingFace Hub access
  - WANDB_API_KEY: Weights & Biases logging
  - MLFLOW_TRACKING_TOKEN: MLflow server authentication
  - LLM API keys: Provider-specific (OpenAI, Anthropic, etc.)

Service Mesh Configuration:
  Not applicable — Training Hub is a library, not a mesh-enrolled service.

FIPS Compliance:
  Not applicable — pure Python library distributed via PyPI.
  TLS is delegated to Python ssl module (system OpenSSL).
  No direct cryptographic operations in library code.
  FIPS compliance is the responsibility of the host container image.

Build Hermeticity:
  No lock files present (uv.lock, poetry.lock, rpms.lock.yaml).
  Uses pyproject.toml with version range constraints.
  Downstream consumers pin training-hub==X.Y.Z in their own lock files.

Supply Chain Notes:
  - litellm versions 1.82.7 and 1.82.8 explicitly excluded
    (supply chain attack documented in pyproject.toml comments)
  - Version constraints used as mitigation mechanism

Inter-Node Communication:
  WARNING: PyTorch torchrun (NCCL/Gloo) and Ray cluster communication
  use unencrypted TCP by default. Network-level isolation (e.g., pod
  network policies, dedicated training VLAN) is recommended for
  multi-node training scenarios.
