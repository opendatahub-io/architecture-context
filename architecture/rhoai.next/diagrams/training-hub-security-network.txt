RBAC Summary:
  None. training-hub is a Python library, not a Kubernetes operator.
  It does not create or require ClusterRoles, Roles, or RoleBindings.
  RBAC is determined by the pod/notebook ServiceAccount that runs the library.

Secrets:
  None managed by the library. Credentials are passed via:
  - WANDB_API_KEY (environment variable) — Weights & Biases logging
  - MLFLOW_TRACKING_URI (environment variable) — MLflow tracking server
  - LLM API keys (environment variable or litellm config) — GEPA evaluation
  - HF_TOKEN (environment variable) — Hugging Face model downloads
  The library does not create or manage Kubernetes Secret objects.

Service Mesh Configuration:
  Not applicable. training-hub is a library, not a deployed service.
  Service mesh (Istio/OSSM) configuration applies to the hosting pod
  (e.g., RHOAI workbench), not to the library itself.

Supply Chain Security:
  - litellm versions 1.82.7, 1.82.8 EXCLUDED (TeamPCP attack, 2026-03-24)
  - All dependencies specify minimum version floors
  - PyPI publishing uses GitHub Actions trusted publishing (id-token: write)
  - No container images built in this repository

FIPS Compliance:
  - No direct cryptographic operations in library source code
  - TLS behavior inherited from Python runtime ssl module
  - FIPS compliance determined by host container image (UBI-based)
  - No custom CA configuration
