Secrets (Environment Variables):
- OPENAI_API_KEY (env var) - LLM API authentication for GEPA and litellm routing
  Provisioned by: Runtime environment | Auto-Rotate: No
- WANDB_API_KEY (env var) - Weights & Biases experiment tracking
  Provisioned by: Runtime environment | Auto-Rotate: No
- MLFLOW_TRACKING_URI (env var) - MLflow tracking server endpoint
  Provisioned by: Runtime environment | Auto-Rotate: No
- HF_TOKEN (env var) - HuggingFace Hub authentication for gated models
  Provisioned by: Runtime environment | Auto-Rotate: No

RBAC Summary:
- No Kubernetes RBAC — runs as a user-space Python library
- When deployed in Kubeflow pipelines, isolation is provided by the
  orchestrating platform (namespace-scoped pods, RBAC, resource quotas)

Security Considerations:
- CLI dotted-path callable resolution (_resolve_callable in cli.py) imports
  arbitrary Python modules at runtime — do not expose CLI to untrusted input
- litellm versions 1.82.7 and 1.82.8 are excluded due to TeamPCP supply chain
  attack (March 2026) that harvested credentials at import time
- No lock files present — dependency pinning is managed by downstream consumers
- TLS delegated to underlying HTTP client libraries (requests, aiohttp, urllib3)
  and the Python runtime's OpenSSL linkage
- No direct cryptographic operations — FIPS compliance depends entirely on
  deployment environment's Python build and system libraries

Supply Chain:
- PyPI publishing with Sigstore signing
- Test PyPI on push, production PyPI on release
- litellm version exclusion for known-compromised versions
