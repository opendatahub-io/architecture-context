Security Design Notes:

  1. ZERO API ACCESS from workload pods: automountServiceAccountToken=false,
     ClusterRole has empty rules. All K8s API calls are made by the controller
     under the invoking admin's kubeconfig.

  2. PRIVILEGED CONTAINERS required for:
     - GPU hardware access (nvidia-smi, /dev/nvidia*)
     - RDMA device access (/dev/infiniband/*)
     - sysfs topology discovery (/sys/class/infiniband/, /sys/bus/pci/)
     Defense-in-depth: readOnlyRootFilesystem=true on check pods.

  3. EPHEMERAL resources: All Jobs, pods, and RBAC are cleaned up after validation.
     Only ConfigMaps with results persist.

  4. NO INGRESS: CLI tool connects outbound to K8s API only.
     No Services, Routes, or Ingress objects are created.

  5. UNENCRYPTED test traffic: iperf3, TCP latency, and RDMA tests use
     plaintext — these are intra-cluster performance benchmarks between
     ephemeral pods, not production data flows.
