    - kubeflow.org: workspaces, workspacekinds → create, delete, get, list, patch, update, watch
    - kubeflow.org: workspaces/status, workspacekinds/status → get, patch, update
    - kubeflow.org: workspaces/finalizers, workspacekinds/finalizers → update
    - core: configmaps, events, pods → get, list, watch
    - core: services → create, delete, get, list, patch, update, watch
    - apps: statefulsets → create, delete, get, list, patch, update, watch
    - networking.istio.io: virtualservices → create, delete, get, list, patch, update, watch

  ClusterRole: workspaces-backend
    Bound to SA: workspaces-backend (ns: kubeflow-workspaces)

    - core: namespaces, configmaps → get, list, watch
    - core: secrets → get, list, watch, create, update, delete

    - kubeflow-workspaces-view (workspaces, workspaces/status → get, list, watch)

Service Mesh Configuration:
  - Istio sidecar injection: enabled for all components
  - mTLS: enforced via Istio sidecars
  - AuthorizationPolicy: per-component, allow from istio-ingressgateway SA
  - NetworkPolicy: default-deny-ingress in kubeflow-workspaces namespace
  - Per-component NetworkPolicies allow traffic from istio-system namespace

Webhooks:
  - vworkspace.kb.io (validating): validates Workspace on create/update
  - vworkspacekind.kb.io (validating): validates WorkspaceKind on create/update/delete
  - conversion.workspacekinds.kubeflow.org (conversion): CRD version conversion
  - TLS: cert-manager provisioned certificate

Secrets:
  - workspaces-webhook-server-cert (kubernetes.io/tls)
    Purpose: TLS certificate for webhook server (port 9443)
    Provisioned By: cert-manager
    Auto-Rotate: Yes

Security Gaps / Notes:
  - DISABLE_AUTH defaults to true in code (TODO: remove before GA)

  - Secrets API in backend currently uses mock data
  - CORS allows all origins
  - Frontend hardcodes userId: "kubeflow-user", clusterAdmin: true (TODO)
  - HTTP/2 disabled by default as CVE mitigation (GHSA-qppj-fm5r-hxr3)
