Authentication & Authorization:
- All /v1/* API routes: No authentication at application layer
- Authentication delegated to external gateway (Kuadrant/Authorino)
- Tenant identity: Extracted from X-MaaS-Username HTTP header
- CRITICAL: If deployed without external gateway, all API routes are
  completely unauthenticated

Multi-Tenancy Risks:
- Data isolation: Application-enforced (row-level in PostgreSQL)
  A bug in query construction could leak cross-tenant data
- Redis queue: Shared namespace, no per-tenant isolation
- S3 storage: File IDs only, no tenant prefix in storage paths
- No per-tenant resource quotas (worker starvation possible)
- Tenant ID trusts header value — gateway bypass = impersonation

TLS Configuration:
- API Server: Optional TLS 1.2+, configurable cipher suites and ALPN
- Processor outbound: TLS 1.2+ default, custom CA and mTLS support
- InsecureSkipVerify: Available as config option (testing-only)

FIPS Compliance:
- Current: CGO_ENABLED=0, distroless/static base — NOT FIPS compliant
- Expected downstream: CGO_ENABLED=1, UBI base, GOEXPERIMENT=strictfipsruntime
