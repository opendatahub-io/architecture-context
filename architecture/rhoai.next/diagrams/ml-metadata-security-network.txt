- Database connections (libpq, libmysqlclient) DO use system OpenSSL (FIPS-compliant)
- Container built on UBI9 (FIPS-validated OpenSSL available)
- Binary is C++ (not Go), so Go FIPS flags do not apply
- Architectures: x86_64, arm64, ppc64le
