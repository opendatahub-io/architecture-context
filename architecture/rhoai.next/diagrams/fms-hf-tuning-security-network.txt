RBAC Summary:
- No RBAC definitions in this component
- RBAC is managed by the training operator that launches fms-hf-tuning containers
- Container runs with ServiceAccount assigned by the training operator Job spec

Secrets:
- S3_ACCESS_KEY_ID (Environment variable) - S3 storage authentication
  - Provisioned by: Runtime environment
  - Auto-rotate: No
- S3_SECRET_ACCESS_KEY (Environment variable) - S3 storage authentication
  - Provisioned by: Runtime environment
  - Auto-rotate: No
- SFT_TRAINER_CONFIG_JSON_ENV_VAR (Environment variable) - Base64-encoded training config
  - Provisioned by: Runtime environment
  - Auto-rotate: No
  - Note: May contain sensitive model paths

Container Security Hardening:
- Base image: UBI9 (Red Hat Universal Base Image 9)
- CUDA: 12.1 libraries installed
- Release-base stage strips: Python interpreter, dnf, yum, crypto-policies-scripts
- Effect: Reduced CVE surface; no package manager or interpreter discovery in runtime
- Risk: crypto-policies-scripts removal may affect FIPS validation

Error Handling:
- Exit code 0: Success
- Exit code 1-127: User error (bad input, missing files)
- Exit code 203: Internal error
- Errors written to /dev/termination-log (Kubernetes termination message)

Network Policy:
- No NetworkPolicy defined in this component
- Network isolation is the responsibility of the training operator / cluster admin
