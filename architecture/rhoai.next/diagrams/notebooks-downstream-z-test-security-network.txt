RBAC Summary:
- No RBAC resources defined in this repository
- Workbench images run as user workloads
- RBAC is managed by the ODH Notebook Controller at deployment time
- OAuth Proxy sidecar enforces per-user access control

Authentication & Authorization:
- JupyterLab UI (8888/TCP): OAuth Proxy sidecar, OpenShift OAuth, per-user access
- Code Server UI (8080/TCP): OAuth Proxy sidecar, OpenShift OAuth, per-user access
- Auth is NOT built into workbench images — it is injected by the Notebook Controller

FIPS Compliance:
- Base images: UBI 9 with system OpenSSL (FIPS-capable)
- mongocli binary: CGO_ENABLED=1 -tags strictfipsruntime (datascience images only)
- Workbench processes: Plain HTTP, no direct crypto — delegates to platform TLS
- CI verification: tests/containers/base_image_test.py verifies /proc/sys/crypto/fips_enabled

Secrets:
- No secrets defined in this repository
- Notebook Controller injects necessary credentials at runtime

Build Hermeticity:
- Python deps: pylock.toml with uv pip install --verify-hashes (hash-locked)
- Go deps: go.sum (hash-locked)
- OS RPM packages: NOT locked (no rpms.lock.yaml) — hermeticity gap
- Hermeto/cachi2 prefetch: NOT configured
