Authentication & Authorization:
- Feature Server: OIDC JWT or K8s ServiceAccount tokens
  - Enforcement: FastAPI inject_user_details dependency
  - Granularity: Per-resource permissions (READ_ONLINE, WRITE_ONLINE, etc.)
- Operator Metrics: Bearer token with TokenReview + SubjectAccessReview
- Inter-pod Communication: HMAC-SHA256 JWT (shared secret in ConfigMap ⚠)
- Health Probes: Unauthenticated (port 8081)

Secrets:
- feast-{project}-tls (kubernetes.io/tls) - OpenShift auto-cert, auto-rotate
- spec.authz.oidc.secretRef (Opaque) - OIDC client_id/client_secret, manual
- spec.services.*.persistence.store.secretRef (Opaque) - Store credentials, manual
- spec.openlineage.apiKeySecretRef (Opaque) - OpenLineage API key, manual

Security Notes:
- ⚠ Operator uses InsecureSkipVerify: true for registry client (cluster-internal)
- ⚠ Intra-communication token stored in ConfigMap (not Secret)
- ✅ Go operator: FIPS via GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- ✅ TLS MinVersion: tls.VersionTLS12 with X25519MLKEM768 (post-quantum hybrid)
- ✅ No ingress created by operator (external access via OpenShift Routes)
- ✅ No NetworkPolicies created (gap: requires external policy for isolation)
