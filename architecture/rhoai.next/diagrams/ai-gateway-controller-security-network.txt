- ClusterRoleBinding: ai-gateway-controller-rolebinding
  - Binds: ai-gateway-controller-role → SA ai-gateway-controller (ns: opendatahub)

Secrets Access:
- Controller reads Secrets referenced by ExternalProvider.spec.auth.secretRef
- Read via APIReader (bypasses informer cache to avoid credential caching)
- Controller cache only watches Secret metadata (not data)
- No Secrets are created or owned by this controller

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Base image: ubi9/ubi-minimal-pqc (post-quantum OpenSSL)
- TLS: stdlib crypto/tls routed through OpenSSL in FIPS mode
- Non-FIPS crypto: gowebpki/jcs (JSON canonicalization only, no crypto ops)

Backend Swap Protocol:
- Three-state CAS on MaasTenantConfig annotation:
  cleanup-complete → steady → cleanup-complete (on switch-off)
- Prevents race condition with maas-controller over shared resource names
- TOCTOU fence: live AITenant read via APIReader before SSA apply
