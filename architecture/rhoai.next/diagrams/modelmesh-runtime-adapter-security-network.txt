RBAC Summary:
- No RBAC manifests defined by this component.
- RBAC is managed entirely by the modelmesh-serving operator.
- No ServiceAccount defined; uses Pod's ServiceAccount configured by ModelMesh.

Kubernetes Services:
- None. This sidecar communicates exclusively via localhost loopback.

Secrets:
- No secrets directly defined by this component.
- Storage credentials are supplied via environment variables by the ModelMesh controller.
- Credential types by provider:
  - S3/COS: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY
  - Azure: Connection string or Azure Identity (managed identity / workload identity)
  - GCS: Service account JSON key
  - HTTP: Optional client certificate + key PEM files

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, -tags strictfipsruntime
- Base image: UBI 9 minimal with OpenSSL 3.5.8
- TLS: Go stdlib crypto/tls (FIPS-compliant via strictfipsruntime)
- No InsecureSkipVerify usage found
- No hardcoded cipher suites (Go FIPS defaults apply)

Security Notes:
- All gRPC servers use grpc.NewServer() with NO authentication interceptors
- All listeners bind to localhost only — network isolation via Pod boundary
- Outbound gRPC to runtime adapter uses insecure.NewCredentials()
- Path traversal protection via cyphar/filepath-securejoin for model paths
- Python TensorFlow dependency creates large attack surface in image
