    leaderworkerset.x-k8s.io, scheduling.k8s.io, node.k8s.io,
    flowcontrol.apiserver.k8s.io, admissionregistration.k8s.io
  - Full CRUD on kueue CRDs, workload types, pods, events
  - Read access on nodes, namespaces, limitranges, priorityclasses

- ClusterRole: kueue-metrics-auth-role
  - authentication.k8s.io/tokenreviews: create
  - authorization.k8s.io/subjectaccessreviews: create

  - Non-resource URL /metrics: get

- ClusterRole: kueue-batch-admin-role
  - Aggregates all editor roles (label: rbac.kueue.x-k8s.io/batch-admin)

- ClusterRole: kueue-batch-user-role
  - Aggregates viewer roles (label: rbac.kueue.x-k8s.io/batch-user)

- kueue-metrics-auth-rolebinding → kueue-controller-manager SA (cluster-wide)
- kueue-controller-manager-read-metrics → kueue-controller-manager-metrics-reader SA
- kueue-leader-election-rolebinding → kueue-controller-manager SA (opendatahub ns)

Secrets:
- kueue-webhook-server-cert (Opaque) - TLS cert/key, cert-controller, auto-rotate
- kueue-controller-manager-metrics-token (SA token) - Metrics auth, Kubernetes, auto-rotate
- webhook-server-cert (referenced) - Mounted into controller-manager, cert-controller, auto-rotate

Certificate Management:
- Internal: open-policy-agent cert-controller library (no cert-manager dependency)
- External option: /etc/kueue/metrics/certs when internal cert mgmt disabled
- Webhook certs: Automatically rotated by cert-controller

FIPS Compliance:
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, -tags strictfipsruntime
- Base image: UBI 9 minimal (OpenSSL included)
- Runtime: stdlib crypto/tls via OpenSSL (FIPS mode)
- No InsecureSkipVerify, no custom cipher suites, no weak hash algorithms
