RBAC Summary:
- ClusterRole: trustyai-role
  - API Groups: "" (core)
  - Resources: configmaps
  - Verbs: create, delete, get, list, patch, update, watch
- ClusterRoleBinding: trustyai-clusterrolebinding
  - Scope: cluster-wide
  - ServiceAccount: trustyai-serviceaccount
  - WARNING: Cluster-scoped ConfigMap access — potential privilege escalation
    vector if SA token is compromised in multi-tenant environment

Authentication & Authorization:
- Application layer: NO authentication (zero @RolesAllowed, no JWT, no API keys)
- Enforcement: Delegated entirely to platform layer
  - kube-rbac-proxy sidecar (deployed by trustyai-service-operator)
  - Service mesh policies (alternative)
- Risk: If sidecar is misconfigured, service is fully open with no fallback

Secrets:
- TLS certificate (kubernetes.io/tls)
  - Files: tls.crt, tls.key at /etc/tls/internal/
  - Provisioned by: trustyai-service-operator
  - Auto-Rotate: No
  - Purpose: HTTPS on port 4443

- Database credentials (Opaque)
  - Keys: QUARKUS_DATASOURCE_USERNAME, QUARKUS_DATASOURCE_PASSWORD
  - Provisioned by: Operator / manual
  - Auto-Rotate: No
  - Purpose: MariaDB/MySQL connection

- MinIO credentials (Opaque)
  - Keys: storage.minio.access-key, storage.minio.secret-key
  - Provisioned by: Operator / manual
  - Auto-Rotate: No
  - Purpose: S3-compatible storage access

FIPS Compliance:
- Java 17 on UBI9 openjdk-17-runtime base image
- JVM uses FIPS-validated crypto providers on FIPS-enabled OpenShift
- Konflux Dockerfile does NOT modify JVM security providers
- gRPC client uses usePlaintext() — no TLS on gRPC channel
  (mitigated in RHOAI by disabling explainer endpoints)

Multi-Tenancy:
- Tenant boundary: per-namespace (one TrustyAI instance per data science project)
- No NetworkPolicy in manifests — relies on operator/platform
- No ResourceQuota/LimitRange in deployment manifest
- MinIO shared bucket risk: no namespace prefix in object keys

Build Hermeticity:
- OS packages: rpms.lock.yaml (locks unzip across 4 architectures)
- Language deps: PNC (Project Newcastle) managed Maven builds
- Artifacts: artifacts.lock.yaml (sha256-locked pre-built Maven artifact)
- Hermeto (cachi2) prefetch in Konflux pipeline
