Secrets:
- rhoai-konflux-secret (Opaque) - Slack webhook URL, component failure template
  Provisioned: Manual | Auto-Rotate: No
- odh-github-secret (Opaque) - bundle-ci-token, operator-ci-token,
  commenter-token, build-metadata-token
  Provisioned: Manual | Auto-Rotate: Unknown
- konflux-test-infra (Opaque) - GitHub bot commenter token for PR interactions
  Provisioned: Manual | Auto-Rotate: Unknown
- slack-config (ConfigMap) - Slack notification templates and team handles
  Provisioned: Manual | Auto-Rotate: No

Authentication & Authorization:
- GitHub API: Bearer token (scoped per-operation from Kubernetes Secrets)
- Quay.io: Docker registry auth (.docker/config.json), some public API calls
- Git cloning: Token embedded in URL (x-access-token)
- No RBAC roles defined in this repo; tasks run under PipelineRun SA

Security Scanning (Pre-Push):
- leaktk-scanner: Runs before every git push and OCI push
  Purpose: Strip credentials, certificates, and sensitive data
- secure-push-oci: Implements retry logic (up to 5 attempts)

Build Hermeticity:
- No hermetic build required (produces YAML task definitions, not container images)
- Dependency pinning via digest-pinned Tekton bundle references
- Renovate automates bundle reference updates with automerge

FIPS Compliance:
- No compiled binaries; all shell scripts
- TLS/crypto inherited from step container images (UBI9, alpine)
- System trust store from UBI base images
- trusted-ca ConfigMap mounted for custom CA certificates

Tenant Isolation:
- Namespace boundary: rhoai-tenant (Konflux tenant)
- Per-component service accounts
- Secrets namespace-scoped but shared across tasks within tenant
- Multiple tasks share odh-github-secret with different keys
