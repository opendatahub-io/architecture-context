RBAC Summary:
- No RBAC roles defined by this component
- Requires (provisioned by eval-hub service):
  - Secrets: GET (data connection secret, model-auth secret)
  - ConfigMaps: GET (trustyai-service-operator-config, JobSpec ConfigMap)
  - Service Account Token: mounted for KFP API auth (legacy mode)
    or proxied via eval-hub sidecar (evalhub >= 0.4.4)

Secrets:
- Data Connection (Opaque) - S3 credentials
  Keys: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_S3_ENDPOINT,
        AWS_S3_BUCKET, AWS_DEFAULT_REGION
  Provisioned by: Platform admin / OpenShift AI
  Auto-rotate: No
  Injected as: Environment variables

- model-auth (Opaque) - LLM API keys
  Keys: api-key, SDG_API_KEY, JUDGE_API_KEY, ATTACKER_API_KEY, EVALUATOR_API_KEY
  Provisioned by: User / platform admin
  Auto-rotate: No
  Injected as: Volume mount at /mnt/model-auth/

TLS Configuration:
- Uses httpx with configurable TLS verification via get_http_client_with_tls()
- Supports: bool (True/False) or CA cert path
- Custom CA: via KFP_SSL_CA_CERT env var or tls_verify parameter
- WARNING: TLS verification can be disabled (verify=False) for both httpx
  and KFP client — no FIPS cipher suite enforcement

Network Policies:
- No NetworkPolicy defined by this component
- Relies on namespace-level network policies

Multi-Tenancy:
- Tenant boundary: per-job (each K8s Job runs a single scan)
- Isolation: Pod-level (Jobs run independently)
- Shared resources: S3 bucket (partitioned by S3 prefix per job),
  model-auth secret (shared across jobs in namespace)
