TLS CONFIGURATION
=================

  - TLS Verification: Enabled by default (httpx.Client(verify=tls_verify))
  - Custom CA: Supported via SSL_CA_CERT env var and KFP_SSL_CA_CERT
  - Certificate Source: System trust store via RHEL 9.6 CA bundle
  - Minimum TLS Version: 1.2 (inherited from system OpenSSL)

FIPS COMPLIANCE
===============

  - Base Image: AIPCC CPU base (RHEL 9.6, OpenSSL FIPS-capable)
  - Crypto Library: cryptography==49.0.0 (links to system OpenSSL)
  - Non-FIPS Risks: None detected (no MD5, RC4, DES, or custom RNG)
  - Python: Inherits FIPS compliance from underlying OpenSSL

SECURITY DESIGN NOTES
=====================

  - __FROM_ENV__ placeholder pattern avoids embedding real keys in config files
    that may be persisted to S3 or OCI artifacts
  - API key fallback chain: role-specific env → role-specific secret file →
    generic env → generic secret file → EvalHub SDK → "DUMMY"
  - KFP pods use kubernetes.use_secret_as_env (Data Connection) and
    kubernetes.use_secret_as_volume (model auth, optional=True)
  - No inbound network exposure: all communication is egress-only
  - Sidecar communication is loopback-only (plaintext acceptable)
