Platform Security Layer (External to caikit-nlp):
- KServe InferenceService provides Kubernetes Service, Ingress, and auth
- kube-rbac-proxy sidecar enforces authentication/authorization
- Istio/ServiceMesh provides mTLS between pods (when deployed in mesh)

RBAC Summary:
- No Kubernetes RBAC resources defined (caikit-nlp is a library/service, not an operator)
- Authentication/authorization is delegated to the platform infrastructure

Secrets:
- RUNTIME_TLS_SERVER_KEY (TLS key file) - gRPC server TLS key - Platform operator/cert-manager
- RUNTIME_TLS_SERVER_CERT (TLS cert file) - gRPC server TLS certificate - Platform operator/cert-manager
- RUNTIME_TLS_CLIENT_CERT (TLS cert file) - mTLS client certificate - Platform operator/cert-manager
- TGIS ca_cert_file (CA certificate) - TLS verification for TGIS connection - Platform operator
- TGIS client_cert_file (TLS cert) - mTLS client cert for TGIS - Platform operator
- TGIS client_key_file (TLS key) - mTLS client key for TGIS - Platform operator
- PYPI_TOKEN (API token) - PyPI publication (CI only) - GitHub Secrets

FIPS Compliance:
- Python service on UBI9 base image (FIPS-capable OpenSSL)
- Python ssl module delegates to system OpenSSL (respects host FIPS mode)
- No direct crypto library imports; no MD5/RC4 usage detected
- No custom cipher suites configured
- TLS configuration via environment variables (optional, not enforced at library level)
