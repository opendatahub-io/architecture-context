RBAC Summary:
  No RBAC — caikit-nlp is a library, not a Kubernetes controller.
  Authentication and authorization are delegated to the platform layer
  (KServe, kube-rbac-proxy sidecars, or Caikit runtime configuration).

Secrets:
  - TGIS TLS certs (kubernetes.io/tls)
    Purpose: mTLS for TGIS backend connection
    Provisioned By: Manual / cert-manager
    Auto-Rotate: No
    Config paths: ca_cert_file, client_cert_file, client_key_file

  - HuggingFace Token (Opaque)
    Purpose: Authentication for model downloads from HuggingFace Hub
    Provisioned By: Manual
    Auto-Rotate: No
    Config: HF_TOKEN environment variable

TLS Configuration:
  - Server TLS: Configurable via RUNTIME_TLS_SERVER_KEY, RUNTIME_TLS_SERVER_CERT env vars
  - TGIS Client TLS: Configurable via runtime_config.yaml (ca_cert_file, client_cert_file, client_key_file)
  - FIPS: Inherited from UBI9 base OS OpenSSL; no direct crypto imports in caikit-nlp

Build Security:
  - Base Image: registry.access.redhat.com/ubi9/ubi-minimal:latest (NOT AIPCC)
  - Hermetic Build: No (hermetic: false in Tekton pipelines)
  - Lock Files: None present on main branch
  - Supply Chain Risk: All dependency layers lack hermeticity
