RBAC Summary:
- Not applicable — caikit-nlp is a library, not a Kubernetes operator.
- No ClusterRoles, Roles, or RoleBindings are defined.
- Access control is delegated to the platform infrastructure.

Authentication & Authorization:
- HTTP/gRPC endpoints: Auth is configurable via Caikit runtime
- Enforcement point: Caikit runtime / Platform (Istio, kube-rbac-proxy)
- No auth is implemented within the caikit-nlp library itself

TLS Configuration:
- Server TLS (runtime): via RUNTIME_TLS_SERVER_KEY, RUNTIME_TLS_SERVER_CERT,
  RUNTIME_TLS_CLIENT_CERT environment variables
- Client TLS (TGIS): via ca_cert_file, client_cert_file, client_key_file
  in runtime_config.yaml
- FIPS: Delegated to UBI9 base image OpenSSL; no direct crypto in library

Secrets:
- No Kubernetes secrets are defined by this component
- TLS certificates: Provided via file paths in configuration
- HuggingFace token: Provided via environment variable (optional)

Security Controls:
- allow_downloads defaults to false (blocks external model downloads)
- Non-root container execution (UID 1001)
- UBI9-minimal base image (reduced attack surface)
- No lock files for Python dependencies (supply chain hermeticity gap)
