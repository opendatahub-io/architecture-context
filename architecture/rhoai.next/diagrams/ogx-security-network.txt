Authentication & Authorization Summary:
- OAuth2 JWT/JWKS: Validates JWT signature, audience, issuer via python-jose
- OAuth2 token introspection: RFC 7662 with external endpoint
- Custom HTTP delegation: Delegates to configurable HTTP endpoint
- ABAC: Permit/forbid rules with conditions on roles/teams/projects/namespaces
- Quota: Per-client rate limiting (separate authenticated/anonymous thresholds)
- Auth is configuration-conditional -- when disabled, all resources accessible

Secrets (Environment Variables):
- FIREWORKS_API_KEY    - Fireworks inference provider (no auto-rotate)
- TOGETHER_API_KEY     - Together AI inference provider (no auto-rotate)
- SAMBANOVA_API_KEY    - SambaNova inference provider (no auto-rotate)
- OPENAI_API_KEY       - OpenAI inference provider (no auto-rotate)
- TAVILY_SEARCH_API_KEY - Tavily web search tool (no auto-rotate)
- NVIDIA_API_KEY       - NVIDIA inference/dataset provider (no auto-rotate)
- CEREBRAS_API_KEY     - Cerebras inference provider (no auto-rotate)
- WATSONX_API_KEY      - WatsonX inference provider (no auto-rotate)

TLS Configuration:
- Server: Optional TLS via tls_certfile/tls_keyfile/tls_cafile
- Mutual TLS supported (ssl.CERT_REQUIRED when CA file provided)
- python-jose uses pure-Python ecdsa/rsa (NOT OpenSSL-backed -- FIPS risk)

Multi-Tenancy:
- Boundary: Per-user via authenticated principal attributes
- Model: Multi-tenant (single server, ABAC-enforced)
- No physical data isolation -- tenants share KV/vector stores
- Network isolation must be provided externally (K8s NetworkPolicy, Istio)
