FIPS Compliance Notes:
- NO explicit FIPS enforcement present
- Uses Python ssl module (relies on system OpenSSL linkage for TLS)
- python-jose (3.4.0) uses pure-Python ECDSA/RSA — NOT OpenSSL bindings
- Container base image: python:3.12-slim (NOT UBI) — no FIPS-compliant OpenSSL
- RHOAI productization requires: UBI base image, FIPS-approved crypto evaluation
- verify_tls flag defaults to True but can be disabled

Security Concerns:
⚠  Ollama connection (11434/TCP) has NO TLS and NO authentication
⚠  SQLite storage has NO encryption at rest
⚠  Auth is OPTIONAL — server runs without auth by default
⚠  python-jose uses pure-Python crypto, not FIPS-approved OpenSSL bindings
⚠  Containerfiles use python:3.12-slim, not UBI base images
⚠  No Kubernetes NetworkPolicy definitions (container-based deployment)
⚠  Very broad egress surface (24+ remote inference providers)
⚠  No auto-rotation for any secrets (all manual)
