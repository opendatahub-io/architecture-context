RBAC Summary:
- No RBAC resources defined — this is a container image, not a controller/operator.
- Runtime RBAC is managed by KServe and the platform operator.
- The container runs as non-root user (UID 1001).

Authentication Summary:
- Container Level: NO authentication enforced
- HTTP API (8000/TCP): No auth — delegated to KServe ingress layer
- gRPC API (8033/TCP): No auth — delegated to KServe ingress layer
- RHOAI 3.x: kube-rbac-proxy sidecar enforces auth at 8443/TCP
- RHOAI 2.x: oauth-proxy sidecar enforces auth (legacy)

Secrets (Runtime - injected via ServingRuntime/InferenceService spec):
- HF_TOKEN (env var) — HuggingFace API token for model download
- AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY — S3 model storage credentials
- No secrets defined in repository; all injected at deployment time

FIPS Compliance:
- No cryptographic operations performed by this repo's code
- TLS/crypto inherited from RHAIIS base image (registry.redhat.io/rhaiis/vllm-cuda-rhel9:3.2.2)
- Container does NOT terminate TLS — handled by KServe ingress
- FIPS assessment must target the RHAIIS base image build pipeline

Build Pipeline:
- Konflux / Tekton PipelineRuns
- hermetic: false (explicitly set)
- Architectures: amd64, arm64
- Vulnerability scanning: Clair
- Certification: Red Hat ecosystem preflight checks
- Pipeline timeout: 10 hours (large CUDA image)
