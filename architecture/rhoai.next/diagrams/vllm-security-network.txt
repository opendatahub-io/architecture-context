RBAC Summary:
  No RBAC resources defined — this is a container image, not an operator.
  Pod-level authentication is enforced by the kube-rbac-proxy sidecar
  injected by the RHOAI platform operator.

Authentication & Authorization:
  - /v1/* (HTTP):  kube-rbac-proxy → SubjectAccessReview (Kubernetes RBAC)
  - TGIS gRPC:    kube-rbac-proxy → SubjectAccessReview (Kubernetes RBAC)
  - Container itself has NO authentication mechanism

Secrets:
  No secrets defined in this repository.
  - Model storage credentials: Managed by KServe/RHOAI serving infrastructure
  - Serving certificates: Managed by KServe/RHOAI serving infrastructure

Tenant Isolation:
  - Boundary: Namespace (one pod per InferenceService)
  - Network: NetworkPolicy per namespace
  - Compute: ResourceQuota/LimitRange; GPU via NVIDIA device plugin
  - Auth: kube-rbac-proxy sidecar per pod
  - Data: Per-namespace model storage credentials

FIPS Compliance:
  - No source compilation in this Dockerfile
  - FIPS compliance delegated to RHAIIS base image (RHEL 9.6)
  - OpenSSL: Inherited from RHAIIS/AIPCC base image
  - TLS: Not terminated by container (plaintext behind proxy)

Build Hermeticity:
  - hermetic: false (explicitly set in Tekton pipeline)
  - No packages installed — only ENV/ENTRYPOINT configuration
  - Hermeticity delegated to RHAIIS base image build pipeline
