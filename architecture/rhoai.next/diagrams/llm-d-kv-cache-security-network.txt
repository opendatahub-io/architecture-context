Authentication & Authorization:
- gRPC TokenizationService: No auth -- pod-local UDS, no network exposure
- gRPC IndexerService: No auth -- embedded library API in host process
- /healthz endpoint: No auth -- unauthenticated health check

Security Concerns (⚠️):
1. ZMQ PUB/SUB transport has NO encryption -- relies entirely on network-level isolation
2. ZMQ event ingestion has NO authentication -- malicious event publisher could poison the index
3. Redis/Valkey backend shares state across all replicas WITHOUT tenant isolation
4. Cluster-wide pod watch possible when namespace is empty (over-privileged discovery)
5. hashlib.md5() used in obj_backend.py (non-cryptographic, bucket distribution only)

FIPS Compliance:
- Konflux builds Python-only UDS tokenizer (no Go binary in production image)
- Base image: AIPCC cpu:3.4 (RHEL 9 UBI with OpenSSL)
- Go library uses stdlib crypto/tls (FIPS via OpenSSL when linked with boringcrypto)
- Python: cryptography==46.0.7 (transitive via PyJWT/vLLM)
- Non-FIPS risk: hashlib.md5() in NIXL obj_backend.py (non-cryptographic use)
