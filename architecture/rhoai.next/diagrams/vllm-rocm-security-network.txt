  No RBAC defined — this is a container image without direct Kubernetes API
  interactions. All RBAC is managed by KServe and the RHOAI platform.

  - PeerAuthentication: STRICT (managed by RHOAI platform)
  - mTLS: Enforced by Istio sidecar for all pod-to-pod traffic
  - AuthorizationPolicy: Managed by KServe/RHOAI platform

  - HTTP /v1/* endpoints: No app-level auth; enforced by kube-rbac-proxy (RHOAI 3.x)
  - gRPC TGIS endpoint: No app-level auth; enforced by Istio mTLS
  - Enforcement points: kube-rbac-proxy sidecar + Istio service mesh

  - Storage secrets (S3/IAM): Mounted by KServe at deployment time
