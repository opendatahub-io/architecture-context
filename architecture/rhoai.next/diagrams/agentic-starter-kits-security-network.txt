RBAC Summary:
- ClusterRole: system:auth-delegator (built-in)
  - API Groups: authentication.k8s.io
  - Resources: tokenreviews
  - Verbs: create

- ClusterRoleBinding: <agent>-<nshash>-auth-delegator
  - Binds: <agent> ServiceAccount → system:auth-delegator
  - Created: Only when auth.enabled=true in Helm values

Security Hardening:
- All standard agents: UBI9 base, non-root (UID 1001), drop ALL capabilities
- OpenClaw: digest-pinned upstream image, non-root, drop ALL capabilities
- No NetworkPolicy manifests (relies on platform defaults)
- No explicit encryption-at-rest for Kubernetes Secrets

Secrets:
- <agent>-secret (Opaque) - API_KEY, POSTGRES_PASSWORD, MLFLOW_TRACKING_TOKEN
  - Provisioned: Helm values
  - Auto-Rotate: No
- openclaw-secrets (Opaque) - OPENCLAW_GATEWAY_TOKEN, VLLM_API_KEY
  - Provisioned: Manual (manifest)
  - Auto-Rotate: No
- Additional env vars: API_KEY, MLFLOW_TRACKING_TOKEN, K8S_REVIEWER_TOKEN,
  AGENT_TOKEN, POSTGRES_PASSWORD, EVAL_JUDGE_API_KEY
  - Provisioned: Runtime environment
  - Auto-Rotate: No

TLS Risks:
- MLFLOW_TRACKING_INSECURE_TLS=true disables certificate verification
  (pragmatic for self-signed certs, weakens trust chain in production)
- PostgreSQL connection has no encryption (plain TCP on 5432)
- Cluster-internal HTTP (Route→Agent) is unencrypted (no service mesh/mTLS)

FIPS Notes:
- Python agents inherit OpenSSL from UBI9 base image
- SHA-256 (hashlib) used for incident fingerprinting — FIPS-compliant
- No Go binaries, no explicit FIPS build flags
- No OLM FIPS annotation (not an operator)
