Authentication Mechanisms:
- kube-authkit: Auto-detection of auth method
  - OIDC tokens
  - OpenShift OAuth
  - kubeconfig file
  - In-cluster ServiceAccount
- Ray mTLS: Client-generated TLS certificates (RSA-3072/SHA-256)
  - CA from Kubernetes Secret ({cluster}-ca-secret-*)
  - Client certs stored locally with 0600 permissions

- {cluster}-ca-secret-* (Opaque) - CA cert/key, provisioned by KubeRay, no auto-rotation
- Custom CA cert path: CF_SDK_CA_CERT_PATH env or /etc/pki/tls/custom-certs/ca-bundle.crt
