TLS Configuration:
- EPP gRPC: Optional TLS, MinVersion TLS 1.2, configurable cipher suites
- Coordinator: TLS 1.2+ by default (--secure-serving=true)
- PD-Sidecar: TLS off by default (--secure-serving=false)
- Certificate provisioning: Operator-provided or self-signed generation
- Certificate rotation: fsnotify-based hot reload on all components

Security Concerns:
- Data-layer HTTP sources default InsecureSkipVerify=true (metrics, DCGM, models)
- PD-Sidecar supports per-stage InsecureSkipVerify for prefiller/encoder/decoder
- No NetworkPolicy bundled; network segmentation is operator responsibility
- Redis connection (coordinator async-broker) uses unencrypted TCP
- Rendering service connection uses unencrypted HTTP
- ZMQ subscriber (5557/TCP) uses unencrypted TCP
