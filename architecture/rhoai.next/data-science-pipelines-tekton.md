## Purpose

**Short**: Tekton-based backend for Kubeflow Pipelines, enabling ML pipeline authoring, scheduling, execution, caching, and artifact tracking on Red Hat OpenShift AI.

**Detailed**: Data Science Pipelines Tekton adapts the Kubeflow Pipelines platform to use Tekton as the workflow execution engine instead of Argo Workflows. The component provides an API server that exposes both gRPC and REST interfaces for pipeline CRUD operations, experiment management, run scheduling, and visualization; a persistence agent that synchronizes Tekton PipelineRun status back into the pipeline metadata store; a scheduled workflow controller that manages recurring pipeline runs via the ScheduledWorkflow CRD; a viewer controller that provisions visualization deployments on demand; and a cache server that acts as a mutating admission webhook to enable pipeline step caching by intercepting TaskRun pods.

The repository also contains the Tekton Catalog extensions — custom Tekton tasks for pipeline loops (`pipeline-loops`), conditional sequencing (`any-sequencer`), kubectl operations (`kubectl-wrapper`), and object store interactions — that implement higher-level Kubeflow pipeline semantics on top of Tekton's task model. A React/TypeScript frontend provides the user-facing pipeline management UI. Third-party manifests bundle MySQL (metadata storage), MinIO (artifact storage), and the ML Metadata (MLMD) gRPC service. The platform supports both single-user and multi-user modes, with multi-user mode leveraging Kubernetes TokenReview and SubjectAccessReview for per-user authorization and Istio for service-level access control.

## Architectural Analysis

Data Science Pipelines Tekton is architecturally a "Kubeflow Pipelines backend swap" — it retains the upstream KFP API surface (v1beta1), frontend, and SDK while replacing the Argo Workflows execution engine with Tekton Pipelines. This approach trades the tight Argo-KFP integration for Tekton's Kubernetes-native pipeline model, but carries significant complexity: the codebase must maintain a translation layer that maps KFP pipeline specifications into Tekton PipelineRun resources and then reconciles Tekton-specific status fields (step results, sidecar logs, loop iterations) back into the KFP data model.

The multi-service architecture introduces several inter-service dependencies that create a non-trivial failure domain. The API server depends on MySQL for metadata persistence, MinIO for artifact storage, and the Tekton API for pipeline execution. The persistence agent polls Tekton PipelineRuns and writes status back to MySQL, creating a consistency window during which the API server may return stale run status. The cache server's mutating admission webhook sits in the critical path of every TaskRun pod creation — if the webhook or its MySQL backend are unavailable, the Kubernetes API server's `failurePolicy` configuration determines whether pipeline execution is blocked or proceeds uncached.

A notable security observation is that the gRPC-to-HTTP gateway on the API server uses `grpc.WithInsecure()` for the internal localhost connection between the HTTP proxy and gRPC server (main.go:164). While this traffic stays in-process on localhost, it means the HTTP port (8888) does not enforce TLS for internal proxied requests. External TLS termination is expected to be handled by the Istio service mesh or an upstream reverse proxy. The cache server, by contrast, serves its webhook endpoint over TLS on port 8443 with certificates provisioned by the cache deployer or cert-manager.

The repository uses an older Go version (1.21) and Tekton Pipelines v0.41.0. The Dockerfile base images for downstream builds use UBI 8 (`ubi8/go-toolset:1.21`, `ubi8/ubi-minimal`), while several upstream-origin Dockerfiles still reference Alpine and community images. No Konflux build configuration is present on this branch, and no FIPS-specific build flags are set, indicating this component's FIPS compliance relies on the runtime base image's OpenSSL and the service mesh for TLS enforcement rather than compile-time crypto hardening.
