## Purpose

**Short**: Placeholder repository for tracking additional RHOAI container images that are not referenced in component manifests.

**Detailed**: rhoai-additional-images is a minimal placeholder repository in the Red Hat Data Services organization. Its sole purpose is to serve as a registry entry point for RHOAI container images that exist outside the normal manifest-driven build and deployment pipeline. These are images that are part of the RHOAI product but are not directly referenced by any component's kustomize manifests or operator deployment resources.

The repository contains no source code, no Dockerfiles, no build configuration, and no deployment manifests. It consists entirely of a README.md file describing its purpose. The actual container images it tracks are built and managed through other mechanisms outside this repository. This pattern is common in large platform distributions where certain ancillary images (tooling, debug containers, compatibility shims, or images consumed only by downstream build processes) need a repository association for tracking and governance purposes without having a traditional source-to-image build pipeline.
