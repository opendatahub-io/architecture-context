SCOPE NOTE
  The current deliverable (KEDA blueprints + benchmark test bed) adds no runtime of its own.
  The only runnable artifact is the DEPRECATED Workload-Variant-Autoscaler (WVA) controller
  in legacy/ (frozen, no CI, no Konflux build on this branch). The network surface below is
  WVA's. KEDA, Prometheus and HPA are external dependencies.

Ingress:  none
Egress (WVA):
  - Kubernetes API            6443/TCP   HTTPS  TLS 1.2+                  SA token
  - Prometheus (k-p-s)        9090/TCP   HTTPS  TLS 1.2 min, skip-verify  Bearer SA token
  - Thanos Querier (OCP)      9091/TCP   HTTPS  TLS 1.2 min, service-ca   Bearer SA token
  - EPP pods (pod IP)         EPP port   HTTP   NONE                      Bearer epp-metrics-reader

RBAC Summary:
- ClusterRole: manager-role  (bound to SA controller-manager via manager-rolebinding)
  - "": configmaps, namespaces, nodes, nodes/status, pods, resourcequotas, services
        -> get, list, watch
  - "": configmaps/status -> get
  - "": events -> create, patch
  - apps: deployments -> get, list, patch, update, watch
  - apps: deployments/scale -> get, update
  - apps: replicasets, statefulsets -> get, list, watch
  - autoscaling: horizontalpodautoscalers -> get, list, patch, update, watch
  - inference.networking.k8s.io, inference.networking.x-k8s.io: inferencepools
        -> get, list, watch
  - keda.sh: scaledobjects -> get, list, patch, update, watch
  - leaderworkerset.x-k8s.io: leaderworkersets -> get, list, patch, update, watch
  - leaderworkerset.x-k8s.io: leaderworkersets/scale -> get, update
  - monitoring.coreos.com: servicemonitors -> get, list, watch
- ClusterRole: metrics-auth-role (controller-manager)
  - authentication.k8s.io: tokenreviews -> create
  - authorization.k8s.io: subjectaccessreviews -> create
- ClusterRole: metrics-reader (nonResourceURL /metrics -> get)
  - Bound to kube-prometheus-stack-prometheus (workload-variant-autoscaler-monitoring);
    patched to controller-manager on OpenShift
- ClusterRole: epp-metrics-reader-role (nonResourceURL /metrics -> get)
  - Bound to SA epp-metrics-reader
- Role: leader-election-role (wva-system, controller-manager)
  - coordination.k8s.io: leases -> create, delete, get, list, patch, update, watch
  - "": events -> create, patch
- ClusterRole: cluster-monitoring-view (OpenShift, pre-existing)
  - Bound to controller-manager and prometheus-user-workload
    (openshift-user-workload-monitoring)
- NOTE: namespace-scoped overlay (--watch-namespace) still uses
  ClusterRole/ClusterRoleBinding, so permissions remain cluster-wide.

Service Mesh Configuration:
- None. No PeerAuthentication, AuthorizationPolicy or NetworkPolicy defined.

Admission Control:
- None. Webhook server scaffolded; no admission webhooks registered.
- Opt-in by annotation (llm-d.ai/managed: "true", llm-d.ai/model-id,
  llm-d.ai/variant-cost) on HPA / ScaledObject; anyone who can annotate an HPA in a
  watched namespace places that workload under WVA control.

Secrets:
- epp-metrics-token (kubernetes.io/service-account-token) - long-lived epp-metrics-reader
  token at /var/run/secrets/epp-metrics/token; no auto-rotation
- controller-manager-token (kubernetes.io/service-account-token, OpenShift) - ServiceMonitor
  bearer token for scraping WVA /metrics; no auto-rotation
- metrics-server-cert (kubernetes.io/tls, OpenShift) - metrics serving cert from service-ca;
  auto-rotated, reloaded by certwatcher
- Projected SA token - Prometheus/Thanos bearer token; rotated by kubelet but read once
  at startup

Security Observations (severity tags are a diagram-time assessment, not from the source doc):
- [HIGH]  EPP scrape sends bearer token over plaintext HTTP (pod_scraping_source.go:60,283-287)
- [MED]   PROMETHEUS_TLS_INSECURE_SKIP_VERIFY "true" and ServiceMonitor insecureSkipVerify
          in base manifests (fixed only by OpenShift component)
- [MED]   Metrics server falls back to self-signed cert when no cert path configured
- [MED]   Long-lived SA token secrets (epp-metrics-token, controller-manager-token)
- [MED]   Cluster-wide RBAC even in namespace-scoped mode; patch/update on deployments,
          HPAs, ScaledObjects, LeaderWorkerSets
- [INFO]  FIPS: CGO_ENABLED=0 static build on distroless; would fail check-payload
- [INFO]  No Konflux / Hermeto / RPM lock on this branch; base images digest-pinned
