llm-d-async (Async Processor) - Security Network Diagram
Source: architecture/rhoai-3.7-ea.1/llm-d-async.md (commit cbce4a0, chart/appVersion 0.7.0)

NOTE: This component is PULL-BASED. It has no request API, no Kubernetes Service,
no Route/Ingress and no NetworkPolicy. Nearly all of its traffic is OUTBOUND. Anyone
who can write to the broker queues can effectively submit inference work.

Retry / Deadline Path:
- 429 / 5xx / dropped-reason / transient transport error from gateway
  -> re-enqueue to broker with exponential backoff while deadline not passed
  -> write DEADLINE_EXCEEDED error result once the deadline has passed
- Queue gates: Refuse (nack to broker) | Drop (error result)
- Pool gates:  additionally Wait (park worker up to --gate-wait-timeout, default 5m)

RBAC Summary:
- ServiceAccount: {{fullname}} (chart-created, optional imagePullSecrets)
- ClusterRoles / Roles: NONE shipped
- RoleBindings: NONE shipped
- If --metrics-endpoint-auth=true, grant outside the chart:
  - API Groups: authentication.k8s.io   Resources: tokenreviews          Verbs: create
  - API Groups: authorization.k8s.io    Resources: subjectaccessreviews  Verbs: create

Service Mesh Configuration:
- None defined by this component (no PeerAuthentication / AuthorizationPolicy)
- No NetworkPolicy shipped: 8081 and 9090 are reachable by anything on the pod network

Secrets:
- {{fullname}} connection secret (Opaque, key `url`) - Redis/Valkey or Postgres URL
  with credentials, injected as REDIS_URL / SQL_URL. Chart-created or existing Secret.
  No auto-rotation. WARNING: an inline `url` in transportConfig ends up in pod args
  (visible via `kubectl get pod`).
- ap.tls.secretName (user-defined PEM) - CA bundle + client cert/key for TLS/mTLS
  to the inference gateway, mounted at /etc/tls. Manual or cert-manager.
  Read once at startup (no hot reload).
- GCP credentials (ADC: env / workload identity) - Pub/Sub auth. Platform-managed.

Multi-Tenancy:
- Tenant boundary is logical only (message attribute, default `userid`)
- Tenant identity is written by the producer and NOT verified by the processor
- All tenants on a release share broker credentials; isolation relies on queue
  naming, broker ACLs, quota gates, and gateway (EPP) fair-share flow control

Security Risks / Observations:
1. /metrics served unauthenticated over plain HTTP in Helm default.
2. OTLP trace export is plaintext gRPC by default (ap.otel.insecure: true).
3. --tls-insecure-skip-verify disables gateway certificate validation (dev/test).
4. Broker write access = ability to drive inference requests to configured gateways
   (gateway URLs come from operator-controlled transport config, not from messages,
   which limits SSRF; gcs_uri_multipart passes signed URLs through without fetching).
5. Upstream image: CGO_ENABLED=0 static on distroless/static, so it would fail the
   Konflux check-payload FIPS gate. The downstream RHOAI build needs its own Dockerfile.
6. Postgres schema migrations run automatically at startup with SQL_URL credentials
   (the role needs DDL rights).
