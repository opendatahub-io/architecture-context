Services:
- ogx-k8s-operator-controller-manager-metrics-service  ClusterIP 8443/TCP -> 8443  HTTPS  Bearer -> TokenReview/SAR
- ogx-k8s-operator-webhook-service                     ClusterIP 443/TCP  -> 9443  HTTPS  Kubernetes admission
- opendatahub-ogx-metrics-service                      ClusterIP 8443/TCP -> 8443  HTTPS  None
- <ogxserver>-service (per CR)                         ClusterIP 8321/TCP -> 8321  HTTP   Header auth (Praxis) / distribution-defined

Admission Webhook:
- vogxserver.kb.io (Validating), /validate-ogx-io-v1beta1-ogxserver, 443->9443/TCP
  - failurePolicy: Fail; ogx.io/v1beta1 ogxservers; CREATE, UPDATE
  - CA injected via service.beta.openshift.io/inject-cabundle
  - Rejects unknown distributions, duplicate provider IDs, disallowed volume types,
    external access without hostname + TLS secret; Praxis-mode warnings only

RBAC Summary:
- ClusterRole: ogx-k8s-operator-manager-role  (SA ogx-k8s-operator-controller-manager)
  - ogx.io ogxservers (+status, finalizers): full CRUD
  - apps deployments, autoscaling HPAs, batch jobs, policy PDBs,
    networking.k8s.io ingresses/networkpolicies, monitoring.coreos.com: full CRUD
  - core services/serviceaccounts: full CRUD; configmaps/PVCs: create/get/list/patch/update/watch
  - core secrets: get, list, watch (CLUSTER-WIDE; label filter is cache-only, not an RBAC boundary)
  - rbac rolebindings: full CRUD; clusterrolebindings: delete/get/list; clusterroles: get/list/watch
  - CRDs, config.openshift.io apiservers: get/list/watch; SCC: use
- ClusterRole: ogx-k8s-operator-proxy-role / metrics-auth: tokenreviews, subjectaccessreviews create
- ClusterRole: ogx-k8s-operator-tls-profile: config.openshift.io apiservers (cluster) get/list/watch
- Role: ogx-k8s-operator-leader-election-role: configmaps, leases CRUD; events create/patch
- ClusterRole: opendatahub-ogx manager-cluster-role  (SA opendatahub-ogx-operator)
  - rbac clusterroles/clusterrolebindings/roles/rolebindings: full CRUD   <-- privilege concentration
  - admissionregistration validatingwebhookconfigurations: full CRUD
  - apiextensions customresourcedefinitions: full CRUD
  - components.platform.opendatahub.io ogxs (+status, finalizers): full CRUD
  - plus all workload/core/ogx.io/monitoring/SCC grants of the root operator
- Role: opendatahub-ogx manager-role (module NS): core, apps, autoscaling, networking, policy, rbac roles
- ClusterRole: system:openshift:scc:nonroot-v2 bound per OGXServer ServiceAccount (RoleBinding in CR NS)

Network Policies:
- Per-OGXServer NetworkPolicy
  - Praxis mode (spec.praxisMode.enabled: true): admit Praxis gateway pods + operator namespace only
  - Legacy mode: admit all pods in namespace + OpenShift router
- No service mesh / PeerAuthentication configured by this operator

TLS:
- Webhook + metrics servers use crypto/tls options from the OpenShift APIServer TLS profile
  (min version, ciphers, adherence); Intermediate fallback off-OpenShift; restart on profile change
- No InsecureSkipVerify. Plain-HTTP paths: operator -> OGX status polling; registry HTTP fallback

Secrets:
- ogx-k8s-operator-webhook-cert (kubernetes.io/tls) - webhook serving cert, OpenShift service-ca, auto-rotate
- ogx-k8s-operator-controller-manager-metrics-service-tls (kubernetes.io/tls) - operator metrics cert, service-ca, auto-rotate
- opendatahub-ogx-metrics-server-cert (kubernetes.io/tls) - module metrics cert, service-ca, auto-rotate
- User provider/storage Secrets (Opaque) - env vars in OGX pods; must be labeled ogx.io/watch: "true"; rollout on change
- spec.network.tls.secretName (kubernetes.io/tls) - existence check only, not mounted
- spec.network.externalAccess.tls.secretName (kubernetes.io/tls) - Ingress edge TLS
- spec.praxisMode.migrationJob.targetConnectionString (Opaque) - Praxis migration target DB
- spec.tls.identity.key (Opaque) - client identity key reference

Security Notes:
- ogx-module /metrics on 8443 is unauthenticated (no FilterProvider)
- Praxis header auth trusts any client that can reach 8321; relies on NetworkPolicy
- OCI registry fetch silently downgrades HTTPS -> HTTP
- ogx-module SA is cluster-admin-adjacent (cluster RBAC, CRDs, webhook configurations)
