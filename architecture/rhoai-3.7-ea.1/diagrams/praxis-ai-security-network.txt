- 9901/TCP  /healthy /ready /metrics  GET              admin, unauthenticated

RBAC Summary:
- Kubernetes RBAC: NONE. No ClusterRole/Role/Binding/ServiceAccount in repo;
  praxis-ai does not call the Kubernetes API.
- Application authZ:
  - Provider-route chains: peer_identity_trust (mandatory first filter),
    downstream mTLS + SPIFFE ID; startup rejects optional/plaintext cert modes.
  - /v1/responses, /v1/conversations: state_owner + identity_header_guard;
    store queries scoped by tenant_id + owner_issuer + owner_subject.
  - Upstream credentials bound to the validated target origin.

Trust Boundary Risk:
- Identity is header-asserted. If untrusted clients can reach 8080 directly
  (bypassing the authenticator), tenant/user identity can be forged.
  NetworkPolicy is left to the deployer.

Secrets (none defined in-repo; all consumer-supplied):
- Upstream provider credentials  - mounted file, watched and hot-reloaded
- Listener TLS cert/key (PEM)    - reloaded via config hot reload
- PostgreSQL client cert / DATABASE_URL / PGPASSWORD - no rotation determined
- GCP key file (GOOGLE_APPLICATION_CREDENTIALS) / Azure client secret
                                 - tokens cached and refreshed
- TOKEN_RATE_LIMIT_VALKEY_URL / TOKEN_RATE_LIMIT_SENTINEL_* (env)
- Handling: secrecy / zeroize wrappers

Crypto / FIPS:
- TLS: rustls with a single OpenSSL-backed provider (praxis_tls::provider::install);
  TLS 1.2 (EMS required) to TLS 1.3; ChaCha20 absent in FIPS mode.
- Dynamic link to system libcrypto.so.3 / libssl.so.3 (openssl crate, not vendored).
- FIPS image: UBI9 ubi-minimal + openssl-fips-provider-so, digest-pinned bases,
  features limited to aws-sigv4-filter by default, cargo auditable SBOM,
  check-payload scan (make fips-scan).
- PRAXIS_REQUIRE_FIPS=1: fail closed unless provider, kernel and crypto policy
  all report FIPS; the standard build refuses the variable outright.
- Standard image (Alpine OpenSSL) is NOT FIPS; policy engine pulls aws-lc-rs,
  SQLx uses sha2/md-5 (SCRAM).

Service Mesh:
- None in repo. mTLS is provided by Praxis listener TLS + SPIFFE peer identity.

Supply Chain:
- SQLx pinned to temporary fork praxis-proxy/sqlx@637e7025.
- No Konflux Dockerfile, RPM lockfile or Hermeto config on this branch.
- Cargo.lock present; FIPS build uses --locked.
