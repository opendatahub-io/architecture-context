----------------------------------------------------------------------------------------
Service Mesh Configuration
----------------------------------------------------------------------------------------
- None. No PeerAuthentication / AuthorizationPolicy. Istio VirtualServices disabled (USE_ISTIO=false).
- Transport security relies on service-ca TLS (webhook, metrics, kube-rbac-proxy) and Gateway TLS.

----------------------------------------------------------------------------------------
Secrets
----------------------------------------------------------------------------------------
- odh-notebook-controller-webhook-cert (kubernetes.io/tls) - webhook serving cert, service-ca, auto-rotate
- odh-notebook-controller-metrics-tls  (kubernetes.io/tls) - ODH metrics cert, service-ca, auto-rotate
- kf-notebook-controller-metrics-tls   (kubernetes.io/tls) - KF metrics cert, service-ca, auto-rotate
- <nb>-kube-rbac-proxy-tls             (kubernetes.io/tls) - per-notebook proxy cert, service-ca, auto-rotate
- ds-pipeline-config (Opaque, per ns)  - Elyra runtime config incl. S3 access/secret keys COPIED from the
                                         DSPA credentials Secret; owner = DSPA; resynced on reconcile, no rotation
- Controller cache strips Secret `data` and non-own ConfigMap `data`; reads bypass cache.

----------------------------------------------------------------------------------------
Admission Webhooks (failurePolicy: Fail)
----------------------------------------------------------------------------------------
- Mutating notebooks.opendatahub.io (kubeflow.org/v1 Notebook CREATE/UPDATE):
  reconciliation lock, ImageStream image resolution, CA bundle / pipeline-runtime-images /
  ds-pipeline-config / Feast mounts, MLflow env, cluster proxy env, kube-rbac-proxy sidecar
  injection with cluster TLS flags, probe timeouts, holds back updates to running notebooks
- Validating notebooks-validation.opendatahub.io (CREATE/UPDATE):
  denies hostNetwork/hostPID/hostIPC, hostPath, serviceAccountName != notebook name,
  unsafe security contexts; denies removing opendatahub.io/mlflow-instance on running notebooks
- Conversion: scaffold only, inactive (strategy None)

----------------------------------------------------------------------------------------
Crypto / FIPS
----------------------------------------------------------------------------------------
- Build: CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime -tags strictfipsruntime; dynamic linking
- Runtime base: registry.redhat.io/ubi9/ubi-minimal-pqc (OpenSSL); UID 1001
- TLS: cluster APIServer tlsSecurityProfile applied to webhook + metrics; fallback TLS 1.2 + Intermediate
- Old profile legacy ciphers (CBC/3DES) honored if admin selects Old profile
- Hermetic Konflux build (Hermeto gomod prefetch); x86_64, ppc64le, s390x, arm64; digest-pinned bases

----------------------------------------------------------------------------------------
Security Observations
----------------------------------------------------------------------------------------
1. Culler uses plaintext, unauthenticated HTTP to notebooks (80->8888); requires -ctrl-np to open 8888
   to the whole shared controller namespace (code acknowledges over-broad peer).
2. Auth is opt-in (notebooks.opendatahub.io/inject-auth); without it the notebook backend is unauthenticated
   and HTTPRoute points directly at 8888.
3. kube-rbac-proxy 8443 open to any source by NetworkPolicy; notebook egress allow-all.
4. ODH controller can create/delete ClusterRoleBindings and bind the MLflow ClusterRole cluster-wide;
   also holds cluster-wide Secret create/update.
5. S3 credentials duplicated from DSPA secret into ds-pipeline-config in the same namespace.
6. Single replica, no leader election, maxUnavailable 100% + fail-closed webhooks => brief Notebook
   admission outage on every rollout.
7. Upstream RBAC still grants networking.istio.io virtualservices * though unused.
