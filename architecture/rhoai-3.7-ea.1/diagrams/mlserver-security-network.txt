Exposed Endpoints (all on the MLServer container, no in-app auth):
- 8080/TCP HTTP
  - GET  /v2/health/live, /v2/health/ready
  - GET  /v2, /v2/runtimes (RHOAI: runtime security mode + allowed implementations)
  - GET  /v2/models/{name}[/versions/{v}], .../ready
  - POST /v2/models/{name}[/versions/{v}]/infer, infer_stream, generate, generate_stream
  - GET  /v2/docs, /v2/docs/dataplane.json, per-model /docs
  - POST /v2/repository/index
  - POST /v2/repository/models/{name}/load    (state-changing; allowlist-checked)
  - POST /v2/repository/models/{name}/unload  (state-changing)
- 8081/TCP gRPC (plaintext)
  - inference.GRPCInferenceService: ServerLive, ServerReady, ModelReady,
    ServerMetadata, RuntimeSecurity (RHOAI), ModelMetadata, ModelInfer,
    ModelStreamInfer, RepositoryIndex, RepositoryModelLoad, RepositoryModelUnload
  - inference.model_repository.ModelRepositoryService: RepositoryIndex,
    RepositoryModelLoad, RepositoryModelUnload
- 8082/TCP HTTP
  - GET /metrics

Unauthenticated / High-Attention Surfaces:
- Model load/unload (REST + two gRPC services) is unauthenticated in-app. Any client
  past the platform auth layer, or reaching the pod directly, can change server state.
- All listeners bind 0.0.0.0 in plaintext. Protection depends on kube-rbac-proxy,
  NetworkPolicy and Gateway/mesh TLS configured by the platform.
- Trace export and Kafka cannot use TLS without code changes.

Authentication & Authorization:
- REST /v2/* and gRPC (8080/8081): kube-rbac-proxy sidecar (platform-delegated);
  TokenReview + SubjectAccessReview. None in application code.
- /metrics (8082): none; network-level only.
- Model implementation loading: trusted runtime allowlist
  (mlserver/settings.py _assert_trusted_runtime_import_path). PRODUCTION mode in
  Konflux images blocks arbitrary import paths (closes upstream RCE path).
- CORS: opt-in CORSMiddleware; wildcard origins and regex rejected in PRODUCTION mode.

RBAC Summary:
- ClusterRoles: none
- Roles / RoleBindings: none
- ServiceAccounts: none defined (predictor pod SA is KServe-managed)
- MLServer does not call the Kubernetes API.

Service Mesh Configuration:
- None defined in this repository. Any mTLS / PeerAuthentication / AuthorizationPolicy
  is platform-provided.

Secrets:
- None read by MLServer. Model storage credentials are consumed by the KServe
  storage-initializer.

Crypto / FIPS:
- TLS: none anywhere (gRPC add_insecure_port, uvicorn no SSL, OTLP insecure=True)
- Crypto libraries: stdlib hashlib only (SHA-256 for env tarball cache key)
- grpcio bundles BoringSSL (unused unless TLS enabled via custom settings)
- OpenSSL from RHEL 9.8 AIPCC base image; no OLM FIPS annotation (no CSV in repo)

Supply Chain:
- Konflux builds hermetic: true, Hermeto pip prefetch
- pip install --no-deps --require-hashes from RHEL AI index (rhoai/3.6 channel)
- Base images digest-pinned: cpu-el9.8:3.6, cuda-12.9-el9.8:3.6
- No RPM lockfile (no RPMs installed); no artifacts lockfile
- Architectures: CPU x86_64/arm64/ppc64le; CUDA x86_64/arm64

Multi-Tenancy:
- Tenant boundary: per-namespace (inherited from InferenceService)
- Deployment: one MLServer process per predictor pod (single-tenant)
- Gap: multiple models in one server share the process and worker pool
