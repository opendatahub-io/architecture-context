NOTE: This repo runs no long-lived service. It ships a one-shot init container
(odh-pipelines-components) and task runtime images (odh-automl, odh-autorag,
odh-autorag-inference). Network traffic originates from pipeline task pods that
run these components inside the Data Science Pipelines (KFP/Argo) stack.
No Kubernetes Services, Ingress, RBAC, or CRDs are defined in this repo.

Network Policy:
- None defined. Egress to MaaS / S3 / Hugging Face is unrestricted unless
  the platform applies NetworkPolicy.

RBAC Summary:
- No ClusterRoles, Roles, or bindings are defined in this repo.
- Task pods act as the DSP pipeline runner ServiceAccount or as the identity
  of a user-supplied kubernetes-credentials token. Required (granted outside
  this repo, namespace-scoped):
  - serving.kserve.io: inferenceservices, servingruntimes (create/patch/get)
  - infrastructure.opendatahub.io: hardwareprofiles (read)
  - Kubeflow Trainer resources (job submission)
  - ray.io resources (Ray data processing pipelines)
- Risk: a user-supplied KUBERNETES_AUTH_TOKEN may carry broader-than-
  namespace privileges.
- Starter kit: needs a reviewer token allowed to create TokenReviews.

Authentication & Authorization:
- Starter-kit /v1/responses  POST  K8s TokenReview  auth_wrapper.py (ASGI); startup
                                   fails if K8S_API_URL / K8S_REVIEWER_TOKEN missing
- Starter-kit /health        GET   None
- Starter-kit main:app       All   None (no auth middleware)
- Task → K8s API             All   Bearer token; kube-apiserver namespace RBAC

Secrets (all Opaque → env, none auto-rotated):
- kubernetes-credentials (KUBERNETES_SERVER_URL, KUBERNETES_AUTH_TOKEN) - user
- S3 connection secrets (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY,
  AWS_S3_ENDPOINT; INPUT_DATA_* / TEST_DATA_* prefixes; S3_SECRET_KEY)
  - user / RHOAI Connections
- HF token secret (HF_TOKEN) - user
- llm-credentials / MaaS secret (LLM_API_KEY, MAAS_API_KEY) - user
- OCI_PULL_SECRET_MODEL_DOWNLOAD - user
- MLFLOW_TRACKING_TOKEN - platform / user
- K8S_REVIEWER_TOKEN (starter kit) - user

Crypto / FIPS:
- No Go binaries; Python ssl (OpenSSL) via UBI 9 / RHEL 9.8 bases;
  cryptography 50.0.2 (transitive).
- TLS: library defaults, no custom ciphers or minimum versions.
- No MD5/SHA1/custom crypto; SHA-256 used only for cache filenames.
- No OLM FIPS annotation (no CSV in repo).

Supply Chain / Build:
- Hermetic Konflux builds (Hermeto pip prefetch), multi-arch
  (x86_64, arm64, ppc64le, s390x); no RPM or artifact lock files.
- Requirements point at AIPCC STAGING index (cpu-torch2.13-el9.8-test).
- Default runtime image refs are mutable tags (odh-automl:odh-stable,
  odh-autorag:odh-stable) when RELATED_IMAGE_* is not set.
- Some component base images unpinned (e.g. ubi9/python-311:latest).
- odh-autorag patches docling_core in place with sed at build time.
