RBAC Summary:
- ClusterRole <fullname>-manager  (bound to <modelservice SA>, cluster-wide)
  - core: configmaps, serviceaccounts — create, delete, get, list, patch, update, watch
  - core: pods — get, list, watch
  - core: services — create, delete, list, patch, update, watch
  - apps: deployments — create, delete, get, list, patch, update, watch
  - apps: deployments/scale — patch, update
  - discovery.k8s.io: endpointslices — get, list, watch
  - gateway.networking.k8s.io: httproutes — create, delete, get, list, patch, update, watch
  - inference.networking.x-k8s.io: inferencemodels, inferencepools — full CRUD + watch
  - llm-d.ai: modelservices — full CRUD + watch; /finalizers update; /status get, patch, update
  - rbac.authorization.k8s.io: rolebindings — create, delete, get, list, patch, update, watch
  !! Privilege-escalation path: can create SAs + RoleBindings in any namespace
- ClusterRole <fullname>-endpoint-picker  (bound to modelservice SA, and per-model EPP SA via RoleBinding)
  - inference.networking.x-k8s.io: inferencepools, inferencemodels — get, watch, list
  - core/discovery.k8s.io: pods, endpointslices — get, watch, list
  - tokenreviews, subjectaccessreviews — create
- ClusterRole <fullname>-metrics-auth — tokenreviews, subjectaccessreviews: create
- ClusterRole <fullname>-epp-metrics-scrape  (bound to <SA>-epp-metrics-scrape, <model>-epp-sa)
  - pods: get, watch, list; TokenReview/SAR create; nonResourceURL /metrics: get
- Role <fullname>-leader-election (release ns): services, events, leases
- User-facing ClusterRoles: <fullname>-admin (*), -editor (CRUD), -viewer (read) on modelservices
- Grafana quickstart (grafana-sa, grafana-sa-token): ClusterRoleBindings to view,
  cluster-monitoring-view, openshift-cluster-monitoring-view, grafana-prometheus-reader

Service Mesh / Gateway Configuration:
- Istio DestinationRule (sample app) → EPP: tls.mode SIMPLE, insecureSkipVerify: true
- No PeerAuthentication / AuthorizationPolicy defined
- kgateway GatewayParameters: Envoy + SDS read-only root FS; proxy UID from
  openshift.io/sa.scc.uid-range + 1 (installer)
- No NetworkPolicy anywhere (Redis NetworkPolicy explicitly disabled)

Secrets:
- llm-d-hf-token (Opaque, key HF_TOKEN) — HF token for vLLM, EPP, download Job;
  created by llmd-installer.sh from $HF_TOKEN; no rotation
- <SA>-epp-metrics-scrape-token (kubernetes.io/service-account-token) — legacy
  long-lived token for EPP ServiceMonitor; no rotation
- llm-d-redis (Opaque, key redis-password) — only if redis.auth.enabled (default off)
- grafana-sa-token (kubernetes.io/service-account-token) — Grafana → Thanos; legacy long-lived
- ingress.tls.secretName (kubernetes.io/tls) — optional manual Ingress TLS

Key Security Findings (quickstart defaults):
1. Inference endpoint is plain HTTP :80 with no authentication.
2. Envoy → EPP TLS without certificate verification.
3. Redis KV index unauthenticated, unencrypted, no NetworkPolicy; EPP Service is NodePort.
4. NIXL/UCX KV transfer between prefill and decode is unencrypted.
5. global.security.allowInsecureImages: true; community images with mutable tags,
   imagePullPolicy Always, curl/curl:latest test image.
6. Grafana admin/admin hardcoded; Thanos datasource tlsSkipVerify: true.
7. Controller ClusterRole can create rolebindings/serviceaccounts cluster-wide.
8. No FIPS signals; repo builds no images; no Konflux / hermetic build.
