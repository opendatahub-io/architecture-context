odh-gitops - Security Network Diagram (RHOAI 3.7-ea.1)
Source: architecture/rhoai-3.7-ea.1/odh-gitops.md (commit 81e4e96, charts v3.6.0)

odh-gitops is a configuration repository. It builds no images. The topology below
covers the workloads and network paths that its charts and Kustomize layers
render directly. Items marked [!] are risks called out in the source document.

RBAC Summary:
- ClusterRole: rhai-operator-role (XKS) → SA redhat-ods-operator/rhai-operator-controller-manager
  - rbac.authorization.k8s.io: roles, clusterroles, rolebindings, clusterrolebindings
    Verbs: *   [!] privilege-escalation capable
  - apiGroups "*": deployments, services, statefulsets
    Verbs: create, delete, get, list, patch, update, watch
  - "*", apps, extensions: replicasets - get, list, watch
  - ~45 API groups, 95 rules total
- ClusterRole: rhai-operator-metrics-reader - nonResourceURL /metrics: get
- ClusterRole: rhai-{aws,azure,coreweave}-cloud-manager-role (23 rules)
  → SA rhai-cloudmanager-system/<cloud>-cloud-manager-operator
  + leader-election Role (leases, events) in rhai-cloudmanager-system
- ClusterRole: cert-manager-operator-controller-manager-clusterrole (vendored, 17 groups, 23 rules)
- ClusterRole: rhai-post-install-hook (9 rules, create/get/patch) → SA <release-ns>/rhai-post-install-hook
  + rhai-post-install-hook-cert binding in redhat-ods-applications
- ClusterRole: rhai-pre-delete-hook - kserves, *kubernetesengines, platforms(default): get, list, watch, delete
- ClusterRole: rhai-pre-upgrade-delete-crs - CRDs: get; aigateways: get, list, watch, delete
- ClusterRole: rhai-pre-upgrade-migrate-certmanager - namespaces, serviceaccounts, deployments,
  leases(cert-manager-operator-lock), *kubernetesengines, certmanagers: get, list, watch, patch
- ClusterRole: xks-gateway-config - gatewayconfigs lifecycle apply/delete
- ClusterRole: usage-logs-infrastructure-writer / -reader (loki.grafana.com infrastructure: create / get)
  → SA ai-grid-o11y/usage-logs-{writer,reader}
- Role: <release>-grid-enrollment-ca-bootstrap - Secret create + name-scoped get/update/patch
  [!] persists after uninstall; hub-site Role can create any Secret in operator namespace
- ClusterRole: <release>-grid-bootstrap-membership-<hash> (ACM / core)
- Role: praxis-gateway role-mount-reconciliation (optional) → SA grid-operator

Authentication & Authorization:
- grid-provider-gateway :8080      mTLS, named Grid-CA client cert, path allowlist (Praxis listener)
- grid-gateway :8443               no inbound auth; Authorization removed; NetworkPolicy ingress group
                                   [!] caller identity does not propagate cross-site
- grid-gateway :9443 metrics       TLS only; NetworkPolicy (redhat-ods-monitoring,
                                   openshift-user-workload-monitoring)
- MaaS / KServe Gateways           Kuadrant AuthPolicy via Authorino (configured by operator)
- XKS default-gateway              OIDC cookie session via kube-auth-proxy
- XKS operator metrics :8080       none
- ACM ScrapeConfig → :8890         none (HTTP); NetworkPolicy allow-acm-rhai-metrics

Service Mesh Configuration:
- OpenShift: no PeerAuthentication/AuthorizationPolicy defined in this repo; Gateways use
  openshift.io/gateway-controller/v1 and maas-gateway-class.
- XKS: Sail operator (OSSM 3.4.2) provides GatewayClass `istio`; mesh policies are not defined here.

Secrets:
- grid-model-client-token (kubernetes.io/service-account-token) - grid gateways → KServe Bearer; Helm; NO rotation [!]
- grid-site-identity (kubernetes.io/tls), grid-ca (Opaque) - site mTLS identity / CA bundle; cert-manager + ACM Policy; site cert rotates
- grid-ca-key / grid-root-ca (kubernetes.io/tls) - Grid root CA ECDSA P-256; self-signed Issuer or bootstrap Job; NO rotation (rotationPolicy: Never) [!]
- grid-gateway-listener-tls, grid-gateway-metrics-tls (kubernetes.io/tls) - service-ca; rotates
- maas-gw-service-tls (kubernetes.io/tls) - MaaS reencrypt Route backend cert; service-ca; rotates
- authorino-server-cert (kubernetes.io/tls) - Authorino listener; service-ca via prepare-authorino-tls.sh; rotates
- hub-usage-logs-auth (Opaque, redhat-ods-monitoring) - spoke → hub OTLP token; ACM Policy or --set-file; NO rotation
- usage-logs-object-storage (Opaque) - LokiStack S3 credentials; OBC / admin; NO rotation
- rhai-pull-secret (kubernetes.io/dockerconfigjson) - registry pulls (XKS); Helm; NO rotation
- rhai-operator-controller-webhook-cert (kubernetes.io/tls) - webhook serving cert; cert-manager; rotates
- rhai-ca (kubernetes.io/tls, ns cert-manager) - platform CA for rhai-ca-issuer; cert-manager policy
- inference-gateway-cert-secret (kubernetes.io/tls) - XKS inference gateway TLS; cert-manager; rotates
- oidc-client-secret (Opaque, rh-ai-gateway) - kube-auth-proxy OIDC client; Helm values or BYO;
  [!] stored in Helm release Secret if set via values; NO rotation

Crypto / FIPS:
- No images built in repo; FIPS posture inherited from referenced images.
- ghcr.io/praxis-proxy/grid-gateway is a non-Red Hat image with unknown FIPS posture.
- No cipher suites or minimum TLS versions configured anywhere in the repo.
- Grid CA uses ECDSA P-256 (FIPS-approved algorithm).
