Source: architecture/rhoai-3.7-ea.1/ai4rag.md
Deployment type: Python LIBRARY (in-process). No Services, Ingress, listeners, CRDs or RBAC.

Egress Summary:
| Dest                    | Port      | Protocol  | Encryption                         | Auth            |
|-------------------------|-----------|-----------|------------------------------------|-----------------|
| MaaS / OpenAI-compat    | 443/TCP   | HTTPS     | TLS verified; HTTP local/cluster   | Bearer API key  |
| S3-compatible storage   | 443/TCP   | HTTPS     | TLS verified; HTTP local/cluster   | AWS SigV4       |
| Milvus / Zilliz         | 19530/TCP | gRPC      | TLS if https://                    | Token           |
| PostgreSQL + pgvector   | 5432/TCP  | PG wire   | verify-full non-local              | user/password   |
| Neo4j                   | 7687/TCP  | Bolt      | TLS CA-verified; +ssc rejected     | user/password   |
| Hugging Face Hub        | 443/TCP   | HTTPS     | TLS                                | None            |

RBAC Summary:
- None. ai4rag defines no ClusterRoles, Roles, RoleBindings or ServiceAccounts
  and makes no Kubernetes API calls. Pod identity and RBAC are owned by the
  consuming pipelines-components / Data Science Pipelines run.

Service Mesh Configuration:
- None defined by ai4rag. Plaintext to *.cluster.local endpoints is permitted
  by the library; any mTLS must come from the platform.

Secrets (consumed as env vars / arguments; provisioned by consuming pipeline; no auto-rotation):
- AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY / AWS_S3_ENDPOINT - S3 credentials (data connection)
- MaaS api_key (function argument)                              - Bearer token
- MILVUS_TOKEN                                                  - Milvus auth
- PGVECTOR_USER / PGVECTOR_PASSWORD                             - PostgreSQL auth
- NEO4J_USERNAME / NEO4J_PASSWORD                               - Neo4j auth
- MAAS_CA_BUNDLE, AWS_CA_BUNDLE, MILVUS_CA_CERT,
  PGVECTOR_CA_CERT, NEO4J_CA_CERT (path or inline PEM)          - Private CA trust
  * Inline PEMs written to /tmp temp files for process lifetime, removed by atexit hook

Multi-Tenancy / Isolation Notes:
- Collections/tables forced to "ai4rag" prefix + secrets-based random suffix (<=63 chars).
  This is an application-level guard, NOT access control: tenants sharing a DB
  account can read each other's collections. Isolation = scope of injected creds.
- MaaS isolation per API key (gateway auth / rate limiting).

FIPS:
- No FIPS signals in repo (pure Python wheel). TLS via stdlib ssl (OpenSSL) for MaaS,
  Milvus, pgvector; no cipher/version pinning. Posture depends on consuming image.
- grpcio bundles BoringSSL: Milvus gRPC TLS may not use system OpenSSL.
- Non-security SHA-256 for doc/chunk IDs; secrets.choice for suffixes.
