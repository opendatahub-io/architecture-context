SERVICE MESH / GATEWAY CONFIGURATION:
- Mesh-wide mTLS:     NOT a platform model. No PeerAuthentication STRICT
                      inventory observed (unresolved, not a negative finding)
- Gateway → backend:  per-hop TLS via DestinationRules + service-ca; commonly
                      insecureSkipVerify (rhods-operator data-science-tls-rule
                      host "*", maas-api, payload-processing, llm-d-router
                      istio provider, kserve sidecar without cert rotation)
- EnvoyFilter producers (5): rhods-operator, odh-model-controller,
                      ai-gateway-controller, models-as-a-service, praxis-extproc
- ext_proc:           9004/TCP, BUFFERED or FULL_DUPLEX_STREAMED, 300s timeout
- InferencePool EPP:  one llm-d EPP per InferencePool, ext_proc 9002/TCP
- ReferenceGrants:    kubeflow notebook-httproute-access, workbenches, kuberay,
                      llm-d-batch-gateway-operator (Secret copy)
- Certificates:       service-ca dominant; cert-manager for webhooks (kserve,
                      trainer), Ray, AI Grid root CA
                      (rotationPolicy: Never), xKS
