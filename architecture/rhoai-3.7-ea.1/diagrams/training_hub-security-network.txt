Source: architecture/rhoai-3.7-ea.1/training_hub.md (v0.11.2, commit 1eb3d9b)
Deployment type: Python library + `thub` CLI running INSIDE training pods.
                 No Services, no Ingress, no listeners, no CRDs, no RBAC.

RBAC Summary:
- ClusterRoles / Roles / Bindings: NONE. training_hub makes no Kubernetes API calls.
- Effective identity: the training pod ServiceAccount set by Kubeflow Trainer,
  KFTO or the workbench (owned by those components).

Service Mesh Configuration:
- None defined. torchrun / NCCL / Gloo collectives between pods are
  unauthenticated and unencrypted unless the platform adds NetworkPolicy or mesh.

Secrets (environment variables, provisioned by runtime / user, no auto-rotation):
- OPENAI_API_KEY        - GEPA LLM endpoint; defaults to "dummy" when api_base set
                          (gepa.py:65-71); gepa() overwrites OPENAI_API_BASE/KEY
                          process-wide and restores afterwards (not thread-safe)
- WANDB_API_KEY         - W&B auth; presence also disables the wandb stub in ART
                          GRPO (lora_grpo.py:89)
- AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY (or credential chain)
                        - S3 checkpoint storage (e.g., data connection Secret)
- MLflow / HF tokens    - tracking server and Hub access (read by SDKs)

TLS / Crypto / FIPS:
- No TLS config in training_hub code; no ssl/SSLContext use; no verify=False.
- No direct crypto imports; upload change detection uses size/mtime fingerprint.
- FIPS posture fully inherited from the universal training image / AIPCC base.

Code-execution trust boundaries:
- exec() of serialized callback source in every torchrun rank (adapters/serialize.py:92)
- importlib.import_module for callable params named in CLI YAML (cli.py:391-410, 702)
- YAML parsed with yaml.safe_load (cli.py:450)
- trust_remote_code defaults to False (memory_estimator.py:83, lora.py:370)

Operational risks:
- SFT/OSFT full checkpoint upload happens inside the pod termination grace period;
  the default 120 s is too short for multi-GB checkpoints.
- Shared PVC / bucket prefixes between jobs are not detected.

Supply chain:
- No lockfile, Dockerfile or Konflux config; lower-bound dependency ranges only.
- litellm compromised versions excluded (1.82.7, 1.82.8, 1.107.0).
- GitHub Actions SHA-pinned; PyPI trusted publishing (OIDC); harden-runner in audit mode.
