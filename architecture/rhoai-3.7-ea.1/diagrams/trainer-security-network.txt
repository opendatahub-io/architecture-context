TLS:
- Both managers resolve the OpenShift APIServer TLSSecurityProfile at startup
  (Intermediate fallback → TLS 1.2 min) and restart when it changes.
- trainer-operator writes minVersion + cipher suites into operand Configuration.tls.
- Max TLS version: unconstrained. HTTP/2 NextProtos configurable (enableHTTP2).

Admission Webhooks (kubeflow-trainer-controller-manager, failurePolicy Fail):
- Mutating   TrainJob (CREATE, UPDATE): stamps spec.runtimePatches[].time
- Validating TrainJob (CREATE, UPDATE): delegates to runtime plugins
- Validating TrainingRuntime / ClusterTrainingRuntime (CREATE, UPDATE)
    BYPASS: objectSelector skips objects labelled
            trainer.kubeflow.org/webhook-validation=disabled
- Validating OptimizationJob (CREATE)

Service Mesh Configuration:
- None. No Istio/PeerAuthentication/AuthorizationPolicy in the RHOAI overlay.
  Isolation relies on Kubernetes NetworkPolicy and RBAC.

Secrets:
- kubeflow-trainer-webhook-cert (Opaque: tls.crt/tls.key/ca.crt) - webhook, metrics and
  status-server serving cert; created empty by kustomize, populated by cert-controller;
  auto-rotated (cert-controller). CA also trusted by ServiceMonitor.
- trainer-operator-metrics-tls (kubernetes.io/tls) - operator metrics cert; OpenShift
  service-ca; auto-rotated.
- <trainjob>-mpi-ssh-auth (kubernetes.io/ssh-auth) - MPI launcher↔worker SSH, ECDSA P-521
  from crypto/rand; job lifetime, no rotation.
- <trainjob>-flux-curve (Opaque) - Flux ZeroMQ CURVE cert; secret key = sha256(TrainJob.UID),
  X25519 (non-FIPS, predictable). Flux runtime not shipped in RHOAI curated runtimes.
- Projected SA tokens (training pods) - audience-bound, kubelet-rotated (gated TrainJobStatus).

Security Findings:
1. Cluster-wide Secret get/list/watch for operand SA.
2. Deterministic Flux CURVE key from TrainJob UID; X25519 not FIPS-approved.
3. Runtime webhook validation bypassable by label; only CRD CEL rules remain.
4. Plaintext, unauthenticated HTTP progression polling (NetworkPolicy-mitigated).
5. Operator metrics NetworkPolicy admits any pod in operator namespace (authn/authz still enforced).
6. Insecure gRPC to Optuna suggestion service (gated, off in RHOAI).
7. InsecureSkipVerify only on status-server local liveness dial (no data exchanged).

FIPS:
- Both images: CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime, dynamic link,
  OpenSSL from ubi9/ubi-minimal-pqc (digest-pinned). Hermetic gomod prefetch builds.
