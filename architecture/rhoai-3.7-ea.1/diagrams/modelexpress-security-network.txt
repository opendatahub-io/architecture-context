        configmaps                                            CRUD
  - networking.k8s.io: networkpolicies                        CRUD
  - rbac.authorization.k8s.io: roles, rolebindings            CRUD
  - rbac.authorization.k8s.io: clusterrolebindings            CRUD  (!)
  - authentication.k8s.io: tokenreviews                       create
  - authorization.k8s.io: subjectaccessreviews                create
  - modelexpress.nvidia.com: modelmetadatas, modelcacheentries CRUD
                             (+status get/update/patch, finalizers update)
- ClusterRole: modelexpress-operator-openshift  (bound to SA modelexpress-operator)
  - config.openshift.io: apiservers                           get, list, watch
  - monitoring.coreos.com: servicemonitors                    get, create, patch, update
- Role: <cr>-metadata  (operator-generated, CR namespace; bound to <cr>-server)
  - modelexpress.nvidia.com: modelmetadatas, modelcacheentries CRUD
                             (+status, finalizers)
  - "": configmaps (ALL in namespace)                         CRUD
- ClusterRoleBinding: modelexpress-<ns>-<cr>-auth-delegator-<digest>
  - enforce mode only; binds <cr>-server to system:auth-delegator
    (tokenreviews, subjectaccessreviews create); finalizer-managed cleanup
  (!) RBAC escalation prevention requires the operator to hold every
      permission it grants, hence cluster-wide CRB/Role/ConfigMap CRUD.

Service Mesh Configuration:
- No Istio PeerAuthentication / AuthorizationPolicy defined.
- Server NetworkPolicy allows HBONE port 15008 (ambient mesh compatible).
- Transport security relies on optional application-level TLS.

Authentication Summary:
- Server gRPC 8001 (Model, P2P, Refit, RefitCollective, Api):
    Tower AuthLayer, Bearer SA token → TokenReview (audience check) +
    ns:sa / ns:* allowlist. OFF by default (spec.security.mode: enforce).
    Decisions cached in moka with zeroized token keys, TTL configurable.
    Errors: UNAUTHENTICATED / PERMISSION_DENIED / UNAVAILABLE.
- Server P2P + cache tenancy: tenantIsolation: enforce scopes sources and
    cache to the caller's verified namespace (requires mode enforce).
- Server health gRPC: always unauthenticated (kubelet gRPC probes).
- Server /metrics 9401: unauthenticated, protected only by NetworkPolicy
    when allowFrom is set.
- Operator /metrics 8443: TokenReview + SAR (metrics_auth.rs).
- Operator /metrics 8080 (xKS): unauthenticated, NetworkPolicy only.

TLS / Crypto:
- Server gRPC: OpenSSL SslAcceptor, min TLS1.2 clamp, configurable
  ciphers/groups. On OpenShift, defaults follow the cluster APIServer TLS
  profile when tlsAdherence=StrictAllComponents, otherwise Intermediate.
- FIPS build: --no-default-features --features openssl; ci/check-fips-crypto.sh
  rejects ring/rustls/aws-lc symbols. Dynamically linked to RHEL OpenSSL.
  Runtime base ubi-minimal-pqc:9.8 (digest-pinned).

Secrets:
- modelexpress-operator-metrics-tls (kubernetes.io/tls) - operator metrics
    TLS on 8443, OpenShift service-ca, auto-rotated
- spec.tls.secretName (kubernetes.io/tls, e.g. modelexpress-tls-serving-cert)
    - server gRPC TLS, service-ca (auto-rotated) or user/cert-manager
- spec.metadataBackend.redis.urlSecret (Opaque) - Redis URL with embedded
    credentials, user-provisioned, no rotation
- spec.credentials.hfTokenSecret (Opaque) - HF_TOKEN, user-provisioned,
    no rotation
- spec.credentials.ngcApiKeySecret (Opaque) - NGC_API_KEY, user-provisioned,
    no rotation

Key Risks:
- gRPC API unauthenticated and plaintext by default.
- Server NetworkPolicy ingress open to all sources unless allowFrom is set.
- Server /metrics 9401 unauthenticated plaintext.
- Operator holds cluster-wide clusterrolebindings CRUD.
- Server Role grants CRUD on all ConfigMaps in its namespace; use a
  dedicated namespace on shared clusters.
- Shared Redis has no inherent tenant key namespacing.
- NIXL RDMA weight transfer is unencrypted and unauthenticated at MX layer.
