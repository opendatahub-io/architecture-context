Unauthenticated Surfaces / Key Risks:
- API Service 8000/TCP has no in-app auth. Any in-cluster pod that can reach it
  can act as any tenant by setting X-MaaS-Username (no NetworkPolicy shipped).
- Missing tenant header silently maps to shared tenant "default".
- Observability ports 8081/9090/9091 are plaintext and unauthenticated;
  pprof is available if enablePprof=true (default false).
- End-user bearer tokens are persisted at rest in PostgreSQL job tags; jobs
  may fail mid-run when stored tokens expire.
- OTel export defaults to insecure (plaintext gRPC).

RBAC Summary:
- No ClusterRoles. API server and processor ServiceAccounts have no RBAC.
- Role: {gc-fullname}-pod-watcher (namespaced, gated by gc.config.reconciler.enabled)
  - API Groups: "" -> pods         Verbs: get, list, watch
  - API Groups: apps -> statefulsets Verbs: get, list, watch
- RoleBinding: {gc-fullname}-pod-watcher -> SA {gc serviceAccountName}
  (release namespace)

Authentication & Authorization:
- /v1/files*, /v1/batches*: none in app; external Gateway (Kuadrant AuthPolicy)
  verifies Kubernetes token + RateLimitPolicy; app enforces tenant equality
  on reads (404 on mismatch) and tenant_id filters on lists.
- Observability endpoints: none; not routed by HTTPRoute; reachable in-cluster.
- Processor -> inference gateway: forwarded user bearer; SAR on inferencepools
  at internal gateway (batch-llm-route).
- GC -> Kubernetes API: in-cluster SA token; namespaced Role.

Service Mesh Configuration:
- None shipped in this repo. No PeerAuthentication / AuthorizationPolicy /
  NetworkPolicy. Gateway/AuthPolicy wiring comes from the platform operator
  and deployment guides.

Secrets:
- batch-gateway-secrets (Opaque, global.secretName) - keys postgresql-url,
  redis-url, inference-api-key, s3-secret-access-key; mounted read-only at
  /etc/.secrets in all three components; manual; no rotation.
- {apiserver-fullname}-tls (kubernetes.io/tls) - API server HTTPS cert/key;
  cert-manager Certificate (optional) or manual; auto-rotates with
  cert-manager (pod reload not observed).
- Processor TLS CA / client cert files (mounted) - tlsCaCertFile,
  tlsClientCertFile, tlsClientKeyFile for inference gateway; manual.
- global.imagePullSecrets (kubernetes.io/dockerconfigjson) - image pulls.

Multi-Tenancy:
- Tenant boundary: per-user application-level tenant ID (X-MaaS-Username).
- Shared PostgreSQL (row-level tenant_id), shared bucket/PVC (t-<sha256> prefix),
  Redis queues per model/pool (not per tenant). No per-tenant concurrency quota.

FIPS / Build:
- CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, dynamic linking,
  ubi-minimal-pqc runtime (OpenSSL), hermetic Konflux build (gomod prefetch),
  multi-arch (x86_64, arm64, ppc64le, s390x).
- Containers: non-root (UID 1001), all capabilities dropped, read-only root FS,
  RuntimeDefault seccomp.
