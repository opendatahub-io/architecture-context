Service Mesh / Gateway Configuration:
- EnvoyFilter data-science-authn-filter: ext_authz → kube-auth-proxy /oauth2/auth + Lua
  bearer-token injection, cookie strip
- DestinationRule data-science-tls-rule: TLS to kube-auth-proxy 8443/443,
  insecureSkipVerify: true (gateway_controller_actions.go:687)
- HTTPRoute oauth-callback-route: PathPrefix /oauth2 → kube-auth-proxy 8443
- AdditionalIngresses: extra Gateways/Routes with ownership and conflict checks

Network Policies:
- DSCI default NetworkPolicy (redhat-ods-applications): ingress from ODH namespaces,
  router, host network, monitoring; excludes app=dashboard-redirect
- kube-auth-proxy: ingress from gateway pods on 8443; egress allow-all
- dashboard-redirect: allow router
- No per-user-namespace policies created by this operator

Secrets:
- redhat-ods-operator-controller-webhook-cert (kubernetes.io/tls) - webhook cert, service-ca, auto-rotate
- rhods-operator-metrics-tls (kubernetes.io/tls) - metrics cert, service-ca, auto-rotate
- data-science-gatewayconfig-tls (kubernetes.io/tls) - gateway listener cert; copied from default
  ingress (follows source), self-signed RSA-2048 1y (no rotation), user-provided, or cert-manager (XKS)
- data-science-gateway-service-tls (kubernetes.io/tls) - gateway ClusterIP cert, service-ca, auto-rotate
- kube-auth-proxy-tls (kubernetes.io/tls) - proxy HTTPS, service-ca, auto-rotate
- kube-auth-proxy-creds (Opaque) - OAUTH2_PROXY_CLIENT_ID / CLIENT_SECRET / COOKIE_SECRET,
  operator-generated (crypto/rand), NO rotation

FIPS / Crypto Notes:
- manager: CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime -tags rhoai, ubi9 ubi-minimal-pqc (OpenSSL)
- cloudmanager: CGO_ENABLED=${CGO_ENABLED} (undeclared ARG), -tags strictfipsruntime, no GOEXPERIMENT
- CSV: features.operators.openshift.io/fips-compliant: "false"
- Fallback cipher list includes CHACHA20-POLY1305 (not FIPS-approved)

Key Risks:
1. Envoy → kube-auth-proxy TLS not verified (bearer tokens exposed to endpoint spoofing)
2. kube-auth-proxy egress unrestricted
3. Operator SA effectively cluster-admin; cluster-wide secrets read/write
4. cloudmanager metrics unauthenticated plain HTTP (XKS)
5. dashboard-redirect plaintext hop router → nginx (8080)
6. Gateway authenticates but does not authorize per route
