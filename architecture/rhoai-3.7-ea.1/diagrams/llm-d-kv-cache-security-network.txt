RBAC Summary:
- ClusterRoles / Roles: none defined by shipped components
- Bindings: none
- ServiceAccount llm-d-kv-cache-pvc-evictor: automountServiceAccountToken=false,
  no bindings, no Kubernetes API calls
- UDS tokenizer sidecar: runs under the EPP scheduler pod's SA (set by KServe)
- Not shipped: examples/kv_events/pod_reconciler (demo Pod watcher);
  deploy/ stub referencing SA operator-controller-manager and missing rbac files

Service Mesh Configuration:
- None defined. No PeerAuthentication, AuthorizationPolicy or NetworkPolicy.
- All in-cluster channels (ZMQ, OTLP, Redis without rediss://, /healthz)
  are plaintext and unauthenticated.

Authentication & Authorization:
- TokenizationService (UDS): none; enforcement = socket dir 0700 inside
  pod-shared emptyDir. Any same-pod container with matching UID can call
  InitializeTokenizer (remote download + trust_remote_code).
- :8082/healthz: none; reachable cluster-wide unless NetworkPolicy restricts.
- Evictor ZMQ PUB (optional): none; any subscriber reaching the port receives.

Secrets:
- HF_TOKEN (env, optional) - Hugging Face auth for gated tokenizer repos;
  provisioned by deployer / KServe pod spec; no rotation
- Redis/Valkey password (in Address URL, optional) - index backend auth;
  scheduler configuration; no rotation
- No TLS certificates mounted; no cert-manager usage

Crypto / FIPS:
- Go evictor: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime,
  base ubi9/ubi-minimal-pqc:9.8
- Tokenizer: system OpenSSL from AIPCC cpu:3.5 (UBI9)
- FNV-32a / FNV-64a used for sharding and block keys (non-security use)
- No InsecureSkipVerify, custom ciphers or MinVersion settings found
