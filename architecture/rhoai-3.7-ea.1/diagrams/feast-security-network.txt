  plaintext/TLS port pairs; TLS is the OpenShift default.

Service Mesh Configuration:
- None. No PeerAuthentication or AuthorizationPolicy. Transport security is
  service-CA TLS per service, and access control is NetworkPolicy + Feast authz.

Secrets:
- controller-manager-metrics-tls (kubernetes.io/tls) - operator metrics cert, service CA, auto-rotate
- feast-{name}-{type}-tls (kubernetes.io/tls) - Feast service certs, service CA (auto) or user-supplied (no rotation)
- {name}-data-registry-tls (kubernetes.io/tls) - kube-rbac-proxy cert, service CA, auto-rotate
- CR-referenced store secrets (Opaque) - DB/S3/Snowflake creds; inlined into
  FEATURE_STORE_YAML_BASE64 pod env ⚠
- CR-referenced OIDC secret (Opaque) - client_id, client_secret, auth_discovery_url
- Git token secret (Opaque) - feature repo clone
- Intra-communication token - stored in a ConfigMap, NOT a Secret; not rotated ⚠
- Env tokens: AWS_SECRET_ACCESS_KEY, MLFLOW_TRACKING_TOKEN, FEAST_RAY_AUTH_TOKEN,
  FEAST_OPENLINEAGE_API_KEY, FEAST_OIDC_TOKEN

FIPS:
- Operator: strictfipsruntime + CGO, dynamic link, UBI OpenSSL (ubi-minimal-pqc).
  No OLM fips-compliant annotation.
- Python images: AIPCC cpu-el9.8 base (RHEL OpenSSL), no explicit FIPS opt-in.
  Python servers set no explicit TLS minimum version or cipher list.
- Non-FIPS crypto: hashlib.md5 for Bigtable row keys (non-security use);
  ssl.CERT_NONE when OIDC verify_ssl: false.

Security Findings (⚠):
1. Feast UI has no auth middleware and is exposed externally through a Route.
2. Workbench NetworkPolicy admits labeled pods from ANY namespace.
3. CR-referenced secrets are inlined into Deployment env. Anyone who can read the
   Deployment spec can see them.
4. The static intra-communication token lives in a ConfigMap and is not rotated.
5. The operator has broad privileges: cluster-wide secrets read, pods/exec,
   ClusterRole bind/CRUD, namespace create.
6. Feast metrics on 8000/TCP use plaintext HTTP with no auth.
7. noAuth is an explicit opt-out with no platform guard.
8. params.env defaults to upstream quay.io/feastdev images. The platform must
   inject the downstream images.
