Sensitive Unauthenticated Endpoints (backend 8000/TCP, exposed via Route):
- POST   /api/v1/deploy-bundle-to-cluster  arbitrary YAML + caller-chosen namespace
                                           → kubectl create namespace / apply -f -
                                           (confused-deputy risk under backend identity)
- DELETE /api/v1/deployments/{id}          deletes InferenceService
- PUT    /api/v1/deployment-mode           global simulator/production toggle
- PUT    /api/v1/quality/auto-update       global setting
- POST   /api/v1/db/upload-benchmarks, /db/reset
                                           X-Admin-Password (hmac.compare_digest), only
                                           enforced if DB_ADMIN_PASSWORD non-empty
                                           (shipped Secret: "")

RBAC Summary:
- ClusterRole: planner-gpu-reader
  - API Groups: "" (core)
  - Resources: nodes
  - Verbs: list
- ClusterRoleBinding: planner-gpu-reader → SA planner/planner-backend
- ui and ollama use the namespace "default" SA (no extra RBAC)
- NOT granted: namespaces create, inferenceservices apply/get/delete, pods get/list

Service Mesh Configuration:
- None. No PeerAuthentication / AuthorizationPolicy. All in-namespace traffic is plaintext HTTP.

Network Policies:
- planner namespace: none
- rhoai-model-registries: ingress allow from planner backend pods → 8443/TCP
  (deploy/kubernetes/networkpolicy-model-catalog.yaml)

Secrets:
- planner-secrets (Opaque), manual empty template, no rotation:
  hf-token, model-catalog-token, vertex-project-id, vertex-region,
  gcp-credentials-json, openai-api-key, openai-base-url, db-admin-password
- planner-backend projected SA token (kubelet-managed rotation): Model Catalog
  Bearer fallback; Kubernetes API
- planner-service-ca (ConfigMap, service.beta.openshift.io/inject-cabundle):
  /etc/pki/service-ca/service-ca.crt, rotated by service-ca operator
- GCP credentials JSON written to mkstemp temp file for ADC (deleted at exit)

TLS / Crypto:
- No in-pod server TLS; TLS terminated at Route edge
- Client TLS: httpx/requests defaults, no min version or cipher config
- MODEL_CATALOG_VERIFY_SSL=false disables Model Catalog cert verification
- Base image python:3.14-slim (Debian OpenSSL), not FIPS-validated; no FIPS signals
