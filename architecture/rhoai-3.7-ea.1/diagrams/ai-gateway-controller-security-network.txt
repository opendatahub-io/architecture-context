NOTE: The controller itself serves no request traffic. Its only listeners are
metrics (8443) and health (8081). It affects the data path solely through
Kubernetes API writes (EnvoyFilters, DestinationRules, ExtProc Deployments,
HTTPRoutes, AuthPolicies, Secrets).

RBAC Summary:
- ClusterRole: ai-gateway-controller-role
  (bound by ClusterRoleBinding ai-gateway-controller-rolebinding to
   opendatahub/ai-gateway-controller)
  - maas.opendatahub.io: maastenantconfigs (get,list,watch,update,patch);
      aitenants, maassubscriptions, maasmodelrefs, externalmodels (get,list,watch)
  - inference.opendatahub.io: externalmodels, externalproviders
      (get,list,watch,create,update,patch); /status (get,update,patch); /finalizers (update)
  - aigateway.opendatahub.io: aiguardrails (get,list,watch); /status (get,patch)
  - core: services, serviceaccounts, configmaps (full CRUD)
  - core: secrets (get,list,watch,create,patch,delete)   ** CLUSTER-WIDE **
  - core: pods (get,list); pods/log (get); namespaces (get,list,watch)
  - apps: deployments (CRUD); replicasets (get,list)
  - autoscaling: horizontalpodautoscalers (CRUD)
  - networking.k8s.io: networkpolicies (CRUD)
  - networking.istio.io: envoyfilters, destinationrules, serviceentries (CRUD)
  - rbac.authorization.k8s.io: clusterrolebindings (CRUD);
      clusterroles (get,list,watch,create,update,patch);
      roles, rolebindings (get,list,create,update,patch,delete)
  - gateway.networking.k8s.io: httproutes, referencegrants (CRUD); gateways (read)
  - kuadrant.io: authpolicies (CRUD)
  - monitoring.coreos.com: servicemonitors (CRUD)
  - route.openshift.io: routes (get,list)
  - trustyai.opendatahub.io: nemoguardrails (read)
  - dscinitialization.opendatahub.io: dscinitializations (read)
  - authentication.k8s.io tokenreviews / authorization.k8s.io subjectaccessreviews (create)
  - coordination.k8s.io: leases (CRUD); events (create,patch)
  - nonResourceURL /metrics (get)
- Managed: payload-processing-metrics-auth (tokenreviews/SAR create)
    → openshift-ingress/payload-processing
- Managed: payload-processing-metrics-reader (/metrics get)
    → redhat-ods-monitoring/prometheus-k8s

  Risk: Ownership labels and field-manager checks (pkg/tenant/ownership.go)
  are the safety boundary, NOT RBAC. A compromised controller SA gains
  cluster-wide Secret read/write and Gateway filter-chain control.

Service Mesh / Gateway Configuration:
- EnvoyFilters (payload-processing, payload-processing-external-model-filters,
  maas-consumer-portal-extproc-bypass): workloadSelector
  gateway.networking.k8s.io/gateway-name=<gateway>; priority 10 after Kuadrant;
  fail-closed ExtProc; per-route ExtProcPerRoute overrides
- DestinationRules: ExtProc TLS SIMPLE; provider TLS SIMPLE with SNI;
  portal re-encrypt to auth proxy and maas-portal
- ServiceEntries for external provider hosts
- Cross-namespace providers require Gateway API ReferenceGrant
  (missing/unpermitted both → RefNotPermitted, no existence disclosure)

NetworkPolicies:
- Controller: metrics 8443 only from redhat-ods-monitoring, openshift-monitoring;
  8081 probe port open
- ExtProc: ingress only from Istio gateway pods (openshift-ingress) + monitoring;
  egress DNS 53/5353, 443/6443, NeMo (per callout; widens to whole NeMo ns if
  Service selector unreadable)
- Auth proxy: ingress from Gateway + Authorino only
- --skip-network-policy removes controller-managed ExtProc NetworkPolicies

Secrets:
- ai-gateway-controller-metrics-tls (kubernetes.io/tls) - metrics cert, service-ca, auto-rotate (loaded at startup)
- payload-processing-tls / payload-pre-processing-tls (kubernetes.io/tls) - ExtProc gRPC TLS, service-ca
- maas-consumer-portal-auth-proxy-tls (kubernetes.io/tls) - auth proxy cert, service-ca
- maas-consumer-portal-auth-proxy-creds (Opaque) - OIDC client id/secret (copied from AITenant), 32-byte crypto/rand cookie secret; created by controller
- <provider auth secret> (Opaque, key api-key) - user-provided provider credential, no rotation
- agc-cred-<hash12> (Opaque) - controller copy of out-of-namespace credential into tenant ns ("exposure, not isolation")
- <tls.credentialName> (+ -cacert) (Opaque) - private CA for provider TLS in Gateway ns, Istio SDS

Crypto / FIPS:
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, ubi9 ubi-minimal-pqc (digest-pinned)
- Go stdlib crypto only (sha256 identifiers, crypto/rand, x509 PEM validation); no InsecureSkipVerify
- Metrics TLS uses Go crypto/tls defaults (no explicit MinVersion/ciphers)
