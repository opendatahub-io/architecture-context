- helm v4.1.4 vendored via Git LFS - unknown provenance/linking (check-payload risk)
- update-crypto-policies --set DEFAULT:PQ (hybrid post-quantum, not FIPS)
- OpenSSL present via RHEL 9 base

Supply Chain / Build Hermeticity:
- Konflux: hermetic: true, Hermeto RPM prefetch, rpms.lock.yaml (crypto-policies-scripts,
  4 arches), digest-pinned base images, multi-arch (x86_64/arm64/ppc64le/s390x), source image

  curl without checksum verification, amd64 only

Multi-Tenancy:

- Single support archive mixes data from every user/project namespace
- No resource limits in README Job; parallel fan-out can load the API server
