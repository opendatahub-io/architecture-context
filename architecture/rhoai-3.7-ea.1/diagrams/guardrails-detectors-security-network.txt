RBAC Summary:
- Detectors call no Kubernetes APIs; no Roles/ClusterRoles defined.
- Sample only: RoleBinding user-one-view
  - ServiceAccount: user-one
  - Role: view (ClusterRole) — get, list, watch on namespace resources
- Product access control: Kubernetes RBAC on the InferenceService, enforced
  by the platform auth proxy/Gateway (outside this repo).

Service Mesh Configuration:
- No PeerAuthentication / AuthorizationPolicy in this repo.
- Sample InferenceServices set sidecar.istio.io/inject: 'true' and
  RawDeployment mode; mesh mTLS applies only when a sidecar is injected.

TLS / Crypto:
- No server TLS in shipped entrypoints (uvicorn invoked directly).
- Unused common main() helper supports ssl_* config (CERT_REQUIRED w/ CA).
- Crypto: Python stdlib ssl → RHEL 9.8 system OpenSSL; uv (bundled crypto)
  uninstalled from image (RHOAIENG-97373). No explicit FIPS opt-in.

Secrets:
- <S3 data connection> (Opaque, opendatahub.io/connection-type: s3)
  - Model storage credentials, consumed by KServe storage-initializer
- aws-connection-minio-data-connection-guardrails-guardian (Opaque) — SAMPLE
  - Placeholder keys THEACCESSKEY/THESECRETKEY, endpoint
    http://minio-guardrails-guardian:9000; manual, no rotation
- Application itself reads no secrets.

Build / Supply Chain:
- Konflux hermetic build, Hermeto pip prefetch of hash-pinned requirements
- Multi-arch: x86_64, aarch64 (CUDA 13.0 base), ppc64le, s390x (CPU base)
- Digest-pinned AIPCC base images (torch 2.13, EL 9.8)
- pip install ".[huggingface]" without --require-hashes (relies on hermetic set)
- Requirements compiled against legacy rhoai/3.6 RHAI index (drift risk)
