RBAC Summary:
- ClusterRoles / Roles / Bindings: NONE defined in this repository
- ServiceAccount: supplied by the launcher (trustyai-service-operator / EvalHub)
- The component does not call the Kubernetes API

Service Mesh Configuration:
- None defined (no PeerAuthentication / AuthorizationPolicy / NetworkPolicy)
- Egress is unrestricted unless the platform applies NetworkPolicy

Authentication & Authorization:
- Inbound: none (nothing listens)
- Outbound model endpoint: POST, Bearer token, enforced by remote inference server / gateway
- Outbound EvalHub callback: POST, eval-hub-sdk managed, enforced by EvalHub service

Secrets (all user/launcher provisioned, no auto-rotation):
- HF_TOKEN (env or hf-token key in model auth secret) - gated HF datasets/models
- OPENAI_API_KEY (env, via resolve_model_credentials) - Bearer token for model endpoint
- ANTHROPIC_API_KEY, WATSONX_API_KEY (env) - third-party API backends
- AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY (env) - S3-compatible downloads
- REGISTRY_USERNAME / REGISTRY_PASSWORD, OCI_USERNAME / OCI_PASSWORD,
  /tmp/.docker/config.json - OCI registry push

Application Hardening (EvalHub adapter, main.py):
- Job spec must resolve under /meta (CWE-22 guard, main.py:95-116)
- HF_ALLOW_CODE_EVAL forced to 0 except humaneval, humaneval_instruct, mbpp
- trust_remote_code allow-list: ethics_cm
- num_concurrent capped at 128
- Error messages scrubbed of bearer tokens, key=value / JSON secrets,
  URL userinfo and query strings before callbacks (main.py:440-485)

TLS / Crypto:
- Python stdlib ssl (system OpenSSL from AIPCC RHEL 9.8 base); certifi trust store
- Custom CA bundle via ssl.create_default_context(cafile=...); symlinks rejected
- No minimum TLS version or cipher settings configured
- SHA-256 used only for cache keys / doc IDs (non-security)
- uv binary (bundled crypto) removed from image (RHOAIENG-99284)

Risks:
- CLI path keeps upstream behaviour: trust_remote_code=True possible
  (lm_eval/__main__.py:396); HF_TOKEN passed into hf_hub_log_args (:307-308)
- TLS verification can be disabled: verify_certificate=False, S3_VERIFY_SSL=false,
  skopeo --tls-verify=false, evalhub_insecure, oci_insecure
- Secrets exposed as env vars to the whole process
- Arbitrary egress to model URL / HF Hub unless NetworkPolicy is applied
