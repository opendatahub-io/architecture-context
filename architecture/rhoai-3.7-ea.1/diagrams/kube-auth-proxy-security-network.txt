RBAC Summary (none shipped in repo; inferred from code):
- Deployer-provided ClusterRole bound to the proxy ServiceAccount
  - API Group: authentication.k8s.io
  - Resources: tokenreviews
  - Verbs: create
- Performed with the logged-in user's token (not the SA):
  - user.openshift.io / users (~): get
  - oauth.openshift.io / oauthaccesstokens: delete (on sign-out)
- Example binding: SA kube-auth-proxy in namespace default with OAuth redirect
  annotations (no RoleBinding in repo)
- Authorization: NOT implemented. No RBAC/SubjectAccessReview checks; downstream
  components (kube-rbac-proxy / apps) must authorize.

Authentication Mechanisms (kube-auth-proxy session chain):
- Encrypted session cookie _oauth2_proxy (OIDC or OpenShift OAuth); checks for
  email domain / authenticated emails / allowed groups
- Bearer token via Kubernetes TokenReview (--enable-k8s-token-validation);
  optional audiences; 10s cache keyed by SHA-256(token); 30s review timeout;
  synthetic email <username>@cluster.local; 30s session expiry
- Bearer JWT (skip-jwt-bearer-tokens), verified via go-oidc issuer/audience
- Basic auth (htpasswd) only if --htpasswd-file set; supports legacy SHA-1 {SHA}
- skip-auth-routes / skip-auth-regex: explicit unauthenticated allow-list

Service Mesh / Network Policy:
- No NetworkPolicy, PeerAuthentication or AuthorizationPolicy shipped in repo
- ext_authz EnvoyFilter and Gateway configuration owned by rhods-operator

Secrets:
- kube-auth-proxy-secret (Opaque, example) - cookie-secret for cookie
  encryption/HMAC; manual / deploying operator; no auto-rotation
- Client secret file (--client-secret-file) - OAuth/OIDC client secret, or the
  mounted SA token for SA OAuth clients; SA token auto-rotated (projected)
- TLS cert/key (--tls-cert-file/--tls-key-file, kubernetes.io/tls) - HTTPS
  listener; service-ca / cert-manager / operator; rotation depends on provisioner
- /etc/ssl/private/jwt_signing_key.pem - empty placeholder created at image build

Cryptography / FIPS:
- Build: CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime -tags strictfipsruntime,
  dynamic OpenSSL via ubi9/ubi-minimal-pqc (digest-pinned); check-payload in CI
- Session cookie / CSRF cookie: AES-CFB + HMAC-SHA256 signature
- Redis tickets: AES-GCM
- Token cache keys and PKCE: SHA-256
- Risks (opt-in): --ssl-insecure-skip-verify, --ssl-upstream-insecure-skip-verify,
  Redis InsecureSkipTLSVerify, insecure cipher names accepted, SHA-1 htpasswd,
  AES-CFB unauthenticated on its own (mitigated by HMAC)

Build Hermeticity:
- go.sum present; Hermeto gomod prefetch with Tekton hermetic: true
- No rpms.lock.yaml (runtime installs no RPMs; base images digest-pinned)
- Konflux multi-arch: x86_64, ppc64le, s390x, arm64
