    destinationrules                              : get, list, watch, create, update, delete
- ClusterRoleBinding: <release>-externalmodels-reader
  → SA payload-processing-<release> (release / Gateway namespace)
- Note: upstream chart rbac.yaml adds base IPP permissions; tokenreviews /
  subjectaccessreviews create (needed by metrics auth filter) is not granted
  in this repo's chart.

Service Mesh Configuration:
- EnvoyFilter payload-processing on maas-default-gateway: ext_proc inserted
  after Kuadrant Wasm; failure_mode_allow: false
- DestinationRule payload-processing.<ns>.svc.cluster.local:9004
  TLS SIMPLE, insecureSkipVerify: true  (encrypted, NOT authenticated)
- Per ExternalProvider: ServiceEntry (MESH_EXTERNAL, DNS) +
  DestinationRule (TLS SIMPLE; DISABLE only if inference.opendatahub.io/tls=false
  and no auth — effectively never)
- No PeerAuthentication / AuthorizationPolicy shipped

Secrets:
- User-defined provider Secrets (Opaque, label inference.llm-d.ai/ipp-managed=true)
  - keys: api-key | aws-access-key-id, aws-secret-access-key, aws-session-token |
          GCP service-account JSON
  - Provisioned manually; no auto-rotation (picked up live by informer)
  - GCP access tokens cached in memory, refreshed before expiry
- ext-proc TLS cert: in-memory only, self-generated RSA-4096, 10y validity,
  regenerated on every restart

Security Observations:
- Manager default cache has no Secret label selector; provider reconciler's
  validateSecretRef r.Get likely starts a cluster-wide unfiltered Secret
  informer (multiNamespace: true default), defeating the label-filtered
  injection cache.
- validateSecretRef checks existence only (not label / api-key field):
  provider may report Ready while injection fails at runtime.
- Model store keyed only by modelName (global, last-writer-wins): cross-
  namespace model name collisions can shadow each other.
- Gateway → IPP TLS unverified; ext-proc has no client authentication.
- pprof enabled by default on metrics server (behind authn/authz filter).
- Metering client does not enforce HTTPS.
- No leader election configured; >1 replica causes controller churn.

FIPS:
- CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, UBI9 minimal PQC base
  (OpenSSL), digest-pinned; no non-FIPS crypto detected in repo code.
