Remaining plaintext hops:
- kube-rbac-proxy → method-gate → prom-label-proxy (pod loopback, HTTP)
- prom-label-proxy → Thanos Querier :10902 (HTTP, NetworkPolicy-restricted)
- Default DCGM scrape over HTTP :9400

RBAC Summary:
- ClusterRole: <fullname>-manager (bound to SA <fullname>)
  - services.platform.opendatahub.io: monitorings (+status, finalizers) - full
  - monitoring.rhobs: monitoringstacks, thanosqueriers, monitors, rules - full CRUD
  - monitoring.coreos.com: podmonitors, servicemonitors - *
  - tempo.grafana.com, opentelemetry.io, loki.grafana.com, perses.dev,
    observability.openshift.io: operand CRs - full CRUD
  - admissionregistration.k8s.io: validatingadmissionpolicies(+bindings) - full CRUD
  - rbac.authorization.k8s.io: get, list, watch, create;
    update/patch/delete only on named resources
  - core: configmaps, secrets, services, serviceaccounts - full CRUD (cluster-wide)
  - apps/batch, networkpolicies, routes, leases - full CRUD
  - authentication/authorization: tokenreviews, subjectaccessreviews - create
  - read: pods, namespaces, nodes(/metrics), CRDs, apiservers, OLM objects,
    serving.kserve.io inferenceservices/llminferenceservices
  - mlflow.kubeflow.org experiments - update
  - nonResourceURLs /metrics, /api(/*), /apis(/*) - get
- ClusterRole: <fullname>-metrics-reader → data-science-monitoringstack-prometheus
- odh-observability-opentelemetry-cert-manager (cert-manager.io full CRUD)
  → opentelemetry-operator-controller-manager

- Collector SA → generate-processors-role, tempo-trace-export, mlflow-trace-export

Admission Control:
- MutatingWebhook podmonitor-injector.opendatahub.io / servicemonitor-injector
  .opendatahub.io (monitoring.coreos.com/v1, monitoring.rhobs/v1; CREATE, UPDATE)
  Adds monitoring.opendatahub.io/scrape=true when namespace opted in and
  default-monitoring exists. failurePolicy Fail.
- AdmissionProbe: canary PodMonitor every 5 min →
  webhook_admission_probe_* metrics, MonitoringWebhookAdmissionPathDown alert.
- ValidatingAdmissionPolicy rendered by the controller.

Secrets:
- <fullname>-webhook-cert (kubernetes.io/tls) - cert-manager, auto-rotate
- <fullname>-metrics-tls (kubernetes.io/tls) - service-ca, auto-rotate
- data-science-*-proxy(-service)-tls (kubernetes.io/tls) - service-ca, auto-rotate
- prometheus-operated-tls (kubernetes.io/tls) - Prometheus web TLS / cluster-proxy client cert
- data-science-collector(-monitoring)-tls, *-collector-headless-tls - service-ca
- Korrel8r -tls (kubernetes.io/tls) - service-ca
- TargetAllocator CA / serving / client certs - cert-manager via OTel operator
- data-science-prometheus-cluster-proxy-kube-rbac-proxy (Opaque) - proxy config
- traces.storage.secret (Opaque) - S3/GCS creds for TempoStack, user, no rotation
- LokiStorageConfig.secretName (Opaque) - S3 creds (static/token/token-cco)
- usageLogs.credentialSecret (Opaque) - remote exporter token, user, no rotation

FIPS / Build:
- CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime -tags strictfipsruntime (Konflux)
- Runtime base: ubi9/ubi-minimal-pqc (digest-pinned); hermetic gomod prefetch
- No InsecureSkipVerify in non-test code; SHA-256 used only for config checksums

Security Observations:
- Webhook failurePolicy Fail: operator downtime blocks monitor create/update in
  opted-in namespaces.
- Webhook ipBlock CIDRs default to OpenShift/ROSA install values; non-default
  machine CIDR clusters must override them.
- Operator SA holds cluster-wide Secret CRUD and * on monitors.
- Any user able to label a namespace monitoring.opendatahub.io/scrape=true opts it
  into cluster-wide scraping.
- Tempo/trace queries have no per-namespace proxy equivalent; storage is shared.
- TargetAllocator does not discover monitoring.rhobs/v1 monitors, though the
  webhook labels them.
- Test-only (not shipped): lgtm / oauth-proxy from tests/e2e/prerequisites.
