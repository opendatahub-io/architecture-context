No external ingress: the operator creates no Routes/HTTPRoutes. It only passes
gatewayDomain/ingresses into operand manifests as the `gateway-url` parameter.

Admission Webhooks (served by this operator, kubeflow.org/v1 Notebook CREATE/UPDATE):
- connection-notebook.opendatahub.io        /workbenches-connection-notebook
  failurePolicy Fail, timeout 5s, sideEffects None
  annotation opendatahub.io/connections (≤4096 bytes); SAR per Secret for requesting user
- hardwareprofile-notebook-injector.opendatahub.io  /workbenches-hardware-profile
  failurePolicy Fail, timeout 5s, sideEffects NoneOnDryRun
  annotations opendatahub.io/hardware-profile-name / -namespace
(The notebooks.kubeflow.org /convert conversion webhook is served by the operand
 notebook controller, not by this operator.)

Service Mesh Configuration:
- None. No Istio sidecar / PeerAuthentication / AuthorizationPolicy in operator manifests.

Secrets:
- workbenches-operator-controller-webhook-cert (kubernetes.io/tls) - webhook serving cert,
  mounted at /tmp/k8s-webhook-server/serving-certs; provisioned by service-CA or cert-manager;
  auto-rotated; reloaded by controller-runtime certwatcher
- User connection Secrets (Opaque, any namespace) - read-only existence/access check before
  envFrom injection; provisioned by users / dashboard

TLS / FIPS:
- crypto/tls driven by OpenShift APIServer TLS profile (min version + Go-negotiable ciphers,
  RC4 excluded); refuses to start on unusable profile or unreadable adherence policy
- Non-OpenShift fallback: TLS 1.2 min, Mozilla Intermediate ECDHE + AES-GCM/ChaCha20-Poly1305
  (ChaCha20 not FIPS-approved; path irrelevant on OpenShift)
- Build: CGO_ENABLED=1, -tags strictfipsruntime, dynamic link to UBI 9 OpenSSL
- No InsecureSkipVerify, MD5, SHA1 or JWT usage detected

Notable Risks:
- Single replica + failurePolicy Fail: operator outage blocks Notebook CREATE/UPDATE for all tenants
- Operator SA can read all Secrets cluster-wide; connection isolation relies on the SAR check
- Webhook port 9443 and probe port 8081 open to any peer; egress allow-all
- HardwareProfile namespace taken from user annotation (cross-namespace profile reference)
- RHOAI operand manifests pinned to rhoai-3.6 refs on this 3.7-ea.1 branch
