RBAC Summary:
- None. The orchestrator does not call the Kubernetes API, and the repo defines no
  ClusterRoles, Roles, RoleBindings, or ServiceAccounts.

Authentication & Authorization:
- 8033 all routes : optional TLS / mTLS (rustls WebPkiClientVerifier, src/server/tls.rs:30-63).
                    mTLS only when a client CA is configured; otherwise no caller auth.
- /api/v1/*, /api/v2/* : passthrough_headers allow-list (empty by default) copied downstream.
- /api/v1/*, /api/v2/* : X-Forwarded-Access-Token -> Authorization: Bearer
                    (rewrite_forwarded_access_header: true; expects upstream auth proxy).
- /health, /info  : no auth, plain HTTP on 8034.
- Outbound HTTP   : static Bearer api_token (config value = env var name, src/clients/http.rs:151-160).
                    Shared by all callers of the instance.

Service Mesh Configuration:
- None defined in repo (no PeerAuthentication, AuthorizationPolicy, or NetworkPolicy).

Secrets (all mounted/provided by the deployer; none auto-rotate, restart required):
- Server TLS cert/key (TLS_CERT_PATH, TLS_KEY_PATH) - kubernetes.io/tls mounted files
  (e.g. OpenShift service-serving certs / cert-manager); encrypted keys unsupported.
- Server client CA (TLS_CLIENT_CA_CERT_PATH) - Opaque/ConfigMap mounted file, enables mTLS.
- Downstream client TLS (tls.<name>.cert_path / key_path / client_ca_cert_path) - mounted files.
  NOTE: client_ca_cert_path means "CA to verify the server" in the gRPC client path,
  but the server CLI flag of the same name means "CA to verify clients".
- Downstream API tokens (api_token: <ENV_VAR_NAME>) - env var, typically sourced from a Secret.

Crypto / FIPS:
- Data-plane TLS: rustls 0.23 with ring 0.17 (NOT FIPS validated), TLS 1.2 + 1.3, default suites.
- System OpenSSL linked dynamically only through reqwest native-tls (OTLP HTTP exporter).
- No-TLS HTTP client path also builds the connector with NoVerifier (src/clients.rs:237-238).
- FIPS posture: NOT established; likely non-compliant for data-plane TLS.

Build / Supply chain:
- Konflux hermetic build (Hermeto cargo + rpm prefetch), rpms.lock.yaml, Cargo.lock.
- protoc built from source (protobuf-src); git crates: ginepro (runtime), mocktail (dev).
- Tekton PR pipeline labels are stale (rhoai-v3-6 / 3.6.0).
