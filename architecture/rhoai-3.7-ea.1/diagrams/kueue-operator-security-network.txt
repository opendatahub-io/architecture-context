NetworkPolicies (operator-managed):
- kueue-deny-all                     operator+operand  Ingress+Egress  default deny
- kueue-allow-egress-kube-apiserver  operator+operand  Egress          TCP 6443 to any destination
- kueue-allow-egress-cluster-dns     operator+operand  Egress          openshift-dns dns/dns-tcp
- kueue-allow-ingress-metrics        operator+operand  Ingress         port "metrics" from ANY source
- kueue-allow-ingress-webhook        operand           Ingress         9443 from openshift-kube-apiserver only
- kueue-allow-ingress-visibility     operand           Ingress         port "visibility" from ANY source (no listener)

RBAC Summary:
- ClusterRole: openshift-kueue-operator  (bound to SA openshift-kueue-operator)
  - rbac.authorization.k8s.io: clusterroles, clusterrolebindings, roles, rolebindings
      Verbs: bind, escalate, create, delete, deletecollection, get, list, patch, update, watch
  - core: configmaps, events, pods, secrets, serviceaccounts, services  (full CRUD, cluster-wide)
  - apps: deployments, replicasets (full CRUD)
  - apiextensions.k8s.io: customresourcedefinitions (full CRUD)
  - admissionregistration.k8s.io: mutating/validatingwebhookconfigurations (full CRUD)
  - cert-manager.io: certificates, issuers (full CRUD)
  - monitoring.coreos.com: servicemonitors
  - kueue.openshift.io: kueues, kueues/finalizers, kueues/status
  - coordination.k8s.io: leases
  - config.openshift.io: apiservers, infrastructures (get, list, watch)
- Role: openshift-kueue-operator-networking (ns openshift-kueue-operator): networkpolicies CRUD
- ClusterRole: kueue-manager-role  (bound to SA kueue-controller-manager)
  - core secrets: get, list, update, watch (cluster-wide)
  - core pods: delete, get, list, patch, update, watch; podtemplates CRUD
  - admissionregistration webhook configs: get, list, update, watch
  - batch/jobset/kubeflow.org/ray.io/workload.codeflare.dev jobs: get, list, patch, update, watch
  - kueue.x-k8s.io: clusterqueues, localqueues, workloads, cohorts, admissionchecks (CRUD)
  - autoscaling.x-k8s.io provisioningrequests (CRUD)
- ClusterRoles: kueue-metrics-auth-role / kueue-proxy-role (tokenreviews, subjectaccessreviews create)
- ClusterRole: kueue-metrics-reader (/metrics get)
- RoleBinding: kueue-visibility-server-auth-reader (kube-system, extension-apiserver-authentication-reader)
- RoleBinding: prometheus-k8s (ns openshift-kueue-operator) → openshift-monitoring/prometheus-k8s
- Editor/viewer ClusterRoles for Kueue + job CRDs; kueue-batch-admin/user aggregation roles (bundle)

Secrets:
- kueue-webhook-server-cert (kubernetes.io/tls) - webhook serving cert for kueue-webhook-service.<ns>.svc,
  cert-manager Certificate webhook-cert from self-signed Issuer, auto-renewed, CA injected into webhooks
- metrics-server-cert (kubernetes.io/tls) - metrics serving cert, also CA + client cert for ServiceMonitor,
  cert-manager Certificate metrics-certs, auto-renewed
- MultiKueueCluster kubeconfig Secrets (Opaque) - remote cluster credentials, admin-provisioned, no rotation

Admission Control:
- MutatingWebhookConfiguration / ValidatingWebhookConfiguration, failurePolicy: Fail
- namespaceSelector: kueue.openshift.io/managed=true AND NotIn [kube-system, openshift-kueue-operator]
- Filtered to frameworks in Kueue.spec.config.integrations.frameworks
- RISK (inferred, not runtime-verified): Kueue-native webhooks (ClusterQueue, Workload, ResourceFlavor,
  Cohort) likely always filtered out → no admission defaulting/validation for these kinds
- RISK: getFrameworkForValidatingWebhook panics on unregistered webhook name

Security Notes:
- Operator SA holds bind/escalate on RBAC: compromise is cluster-significant
- Operand SA can update Secrets cluster-wide and patch every supported job kind
- Bundled apiservice.yaml sets insecureSkipTLSVerify: true (NOT applied; visibility API disabled)
- CSV tls-profiles: "false" - cluster TLS security profile not honored
- FIPS: -tags strictfipsruntime, openshift-golang-builder, CSV fips-compliant: "true"
- Opt-in label kueue.openshift.io/managed differs from kueue.x-k8s.io/managed referenced in overlay 0007
