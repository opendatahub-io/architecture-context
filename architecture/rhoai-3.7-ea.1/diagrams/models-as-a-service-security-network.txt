KEY SECURITY OBSERVATIONS
- Trusted-header model: maas-api trusts Authorino-injected X-MaaS-* headers.
  Protection depends on AuthPolicy header denial + RejectTrustedIdentityHeaders
  + NetworkPolicy, all staying in place.
- /internal/v1/api-keys/validate and /internal/v1/subscriptions/select have NO
  caller authentication. They rely only on NetworkPolicy. The validate endpoint
  is a hash-lookup oracle if the NetworkPolicy is not enforced.
- Gateway -> maas-api and Gateway -> payload-processing use DestinationRule
  tls SIMPLE + insecureSkipVerify: true (RHOAIENG-61070; BackendTLSPolicy needs
  OpenShift 4.22+).
- Base maas-api-cleanup CronJob uses http://maas-api:8080. Only the TLS overlay
  (applied by TenantReconciler) switches it to HTTPS 8443.
- maas-api egress is allow-all by default despite policy name
  maas-api-egress-restrict.
- ext_proc ipp-pre is fail-open (pre-auth). ipp is fail-closed (post-auth).
- Webhooks are failurePolicy Fail. A down controller blocks CR creation.
- Tenant data isolation in PostgreSQL is application-level only (TENANT_NAME
  query scoping, one shared DB credential, no RLS/schema isolation).

SERVICE MESH / GATEWAY CONFIGURATION
- Gateway: maas-default-gateway (openshift-ingress, openshift-default class)
- DestinationRule (maas-api): tls.mode SIMPLE, insecureSkipVerify: true
- DestinationRule (payload-processing): tls.mode SIMPLE, insecureSkipVerify: true
- EnvoyFilter (payload-processing): ipp-pre (fail-open) / ipp (fail-closed)
  around the Kuadrant wasm plugin
- ServiceEntry: external model providers (443/TCP)
- TokenRateLimitPolicy gateway-default-deny: zero limit by default
- Telemetry / TelemetryPolicy: usage telemetry

SECRETS
- maas-db-config (Opaque) - DB_CONNECTION_URL (+ optional DB_READ_CONNECTION_URL);
  manual, cluster admin, no rotation
- maas-api-serving-cert (kubernetes.io/tls) - maas-api HTTPS; service-ca
  (cert-manager on xKS); auto-rotate
- maas-api-metrics-tls (kubernetes.io/tls) - maas-api metrics; service-ca; auto-rotate
- maas-controller-webhook-cert (kubernetes.io/tls) - webhook serving; service-ca; auto-rotate
- maas-controller-metrics-tls (kubernetes.io/tls) - controller metrics; service-ca; auto-rotate
- maas-discovery-tls (kubernetes.io/tls) - discovery HTTPS; service-ca; auto-rotate
- usage-logs Loki token secret (Opaque) - LOKI_READ_TOKEN; maas-controller; no rotation
- ExternalModel credential Secrets (Opaque) - provider API keys; user; no rotation
- Gateway cert ${CERT_NAME} (kubernetes.io/tls) - gateway listener; platform/admin

CRYPTO / FIPS
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, dynamic linking,
  UBI ubi-minimal-pqc runtime with OpenSSL
- TLS: Go stdlib crypto/tls, min TLS 1.2 (flag allows 1.3), follows OpenShift
  APIServer TLS profile; maas-api restarts on profile change
- API keys: 256-bit crypto/rand secrets, stored as SHA-256(keyID||0x00||secret)
- Log redaction: HMAC-SHA256 with random key
