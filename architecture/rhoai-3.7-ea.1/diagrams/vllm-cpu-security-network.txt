Endpoint Auth Summary (port 8000/TCP):
- Bearer (opt-in):  /v1/chat/completions[/batch|/render|/derender], /v1/completions[...],
                    /v1/responses[/{id}[/cancel]], /v1/messages[/count_tokens], /v1/models,
                    /v1/embeddings, /v1/score, /v1/rerank, /v1/audio/*, /v1/realtime (WS),
                    /v1/load_lora_adapter, /v1/unload_lora_adapter, /v2/embed, /v2/rerank,
                    /inference/v1/generate
- Never guarded:    /abort_requests, /tokenize, /detokenize, /tokenizer_info, /pooling,
                    /classify, /score, /rerank, /generative_scoring, /invocations, /ping,
                    /scale_elastic_ep, /is_scaling_elastic_ep, /start_profile, /stop_profile,
                    /health, /load, /version, /metrics, /docs
- Middleware: SHA-256 digest + secrets.compare_digest (constant time); OPTIONS exempt

RBAC Summary:
- No ClusterRoles, Roles or bindings defined in this repository.
- The engine makes no Kubernetes API calls; pod identity comes from KServe.

Secrets (environment variables; no Kubernetes Secret objects in repo):
- VLLM_API_KEY                         - Bearer API key (overridden by --api-key); ServingRuntime/ISVC env; no rotation
- HF_TOKEN                             - Hugging Face gated model access; deployer; no rotation
- S3_ACCESS_KEY_ID / S3_SECRET_ACCESS_KEY - tensorizer S3 loading; deployer; no rotation
- MODELSCOPE_API_TOKEN                 - ModelScope download; deployer; no rotation
- EXA_API_KEY                          - MCP/demo web-search tool; deployer; no rotation
- OPENAI_API_KEY, GH_TOKEN/GITHUB_TOKEN - benchmark/build tooling only

Crypto / FIPS:
- OpenSSL from UBI 9 minimal PQC base; Python ssl/hashlib/secrets use system OpenSSL
- No explicit FIPS opt-in in vLLM or Dockerfile
- MD5 config hashing falls back to SHA-256 under FIPS (vllm/utils/hashing.py)
- hf3fs_connector.py:1012 uses hashlib.md5 without usedforsecurity=False (optional connector)

Build Hermeticity:
- RPM lock: none | Python lock: none (ranges) | Artifacts: git clone / curl | Hermeto: not used
- Not AIPCC-based; migration target aipcc-cpu-torch2.11-el9.8-app (overlay 0017)

Key Risks:
1. UV_EXTRA_INDEX_URL (IBM DevPI) + UV_INDEX_STRATEGY=unsafe-best-match persisted in RUNTIME
   image env (Dockerfile.konflux.cpu:85-86) - dependency-confusion risk for in-pod installs.
2. Non-hermetic build from multiple third-party indexes and GitHub sources.
3. vLLM auth is opt-in and path-scoped; compute and operational root routes (/score, /pooling,
   /scale_elastic_ep, /start_profile) are unauthenticated - platform layer must enforce.
4. Plain HTTP on 8000 by default; permissive CORS (*).
5. Unauthenticated /metrics.
