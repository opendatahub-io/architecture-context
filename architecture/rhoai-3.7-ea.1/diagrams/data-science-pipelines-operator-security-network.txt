RBAC Summary:
- ClusterRole: manager-role (bound to controller-manager via manager-rolebinding)
  - core: configmaps, PVs, PVCs, pods, pods/exec, pods/log, secrets,
          serviceaccounts, services — full CRUD (cluster-wide)
  - rbac.authorization.k8s.io: roles, rolebindings, clusterroles,
          clusterrolebindings — full CRUD (privilege-escalation surface)
  - apps: deployments, replicasets — full CRUD; batch: jobs — full CRUD
  - admissionregistration.k8s.io: webhook configurations (resourceNames
          pipelineversions.pipelines.kubeflow.org)
  - apiextensions.k8s.io: customresourcedefinitions (named Argo CRDs)
  - argoproj.io, kubeflow.org, pipelines.kubeflow.org,
          datasciencepipelinesapplications.opendatahub.io — full CRUD
  - route.openshift.io routes, networking.k8s.io networkpolicies — full CRUD
  - ray.io, serving.kserve.io, workload.codeflare.dev — CRUD (passed through
          to pipeline-runner SA)
  - monitoring.coreos.com / monitoring.rhobs: servicemonitors, prometheusrules
  - authentication/authorization: tokenreviews, subjectaccessreviews — create
  - config.openshift.io apiservers — get/list/watch
  - components.platform.opendatahub.io: aipipelines; delete
          default-datasciencepipelines
- ClusterRole: manager-argo-role (Argo controller permission set to delegate)
- ClusterRole: argo-cluster-role → SA argo (secrets restricted to
          argo-workflows-agent-ca-certificates via resourceNames)
- ClusterRoles: aggregate-dspa-admin-edit / aggregate-dspa-admin-view
          (DSPA + /api, pipelines, pipelineversions; aggregated to
          admin/edit/view — this is how users get DSPA API access)
- ClusterRoles: argo-aggregate-to-admin / -edit / -view
- Per DSPA (runtime): ClusterRoleBinding ds-pipeline-ui-auth-delegator-<ns>-<dspa>
          → system:auth-delegator (no owner reference); RoleBindings for
          ds-pipeline-<dspa>, pipeline-runner-<dspa>, persistence agent,
          scheduled workflow, workflow controller
- ClusterRoleBinding data-science-pipelines-operator-rhoai-prometheus
          → metrics-reader for data-science-monitoringstack-prometheus

Network Policies:
- Operator (OpenShift overlay): ingress 8081 any; 8443 monitoring namespaces;
  9443 opened (no handlers)
- Per DSPA ds-pipelines-<dspa>: 8888/8887 only from persistence agent,
  scheduled workflow, v2_component=true pods; 8443 from all sources (router
  may use host networking); egress to DB, S3, MLMD, MLflow, proxy ports.
  External DB/S3 egress allowed by port only.

Secrets:
- data-science-pipelines-operator-metrics-tls (kubernetes.io/tls) - operator metrics cert, service-ca, auto-rotate
- ds-pipelines-proxy-tls-<dspa> (kubernetes.io/tls) - API server kube-rbac-proxy cert, service-ca, auto-rotate
- ds-pipelines-envoy-proxy-tls-<dspa> (kubernetes.io/tls) - MLMD Envoy proxy cert, service-ca, auto-rotate
- ds-pipeline-metadata-grpc-tls-certs-<dspa> (kubernetes.io/tls) - MLMD gRPC cert, service-ca, auto-rotate
- ds-pipelines-mariadb-tls-<dspa> (kubernetes.io/tls) - MariaDB TLS, service-ca, auto-rotate
- ds-pipeline-webhook-tls (kubernetes.io/tls) - admission webhook cert, service-ca, auto-rotate
- ds-pipeline-db-<dspa> or user-specified (Opaque) - DB password, crypto/rand generated, no rotation
- Object storage credentials (Opaque) - S3 access/secret key, generated (MinIO) or user, no rotation
- ds-pipeline-metadata-grpc-tls-config-secret-<dspa> (Opaque) - MLMD config.proto with MySQL settings
- argo-workflows-agent-ca-certificates (Opaque) - Argo agent CA, rotation unknown

Crypto / FIPS:
- Build: CGO_ENABLED=0 GOFIPS140=v1.0.0 -tags no_openssl (static; Go native
  FIPS 140-3 module); runtime ubi9/ubi-minimal-pqc. Does not match classic
  check-payload (dynamic CGO + OpenSSL) pattern; acceptance unverified.
- TLS: crypto/tls; min version from cluster profile (Intermediate = TLS 1.2
  fallback); max unconstrained; SecurityProfileWatcher restarts on change.
- Weak spots: MySQL health check default no TLS; skip-verify/preferred →
  InsecureSkipVerify; MinIO 9000 plaintext; raw API/MLMD ports unauthenticated.
