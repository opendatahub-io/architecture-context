RBAC Summary:
- No ClusterRole, Role, RoleBinding, or ServiceAccount is shipped.
- Tooling runs as the invoking user's kubeconfig identity. Required
  (namespace-scoped) permissions:
  - core:  pods                     get, list
  - core:  pods/exec                create
  - core:  pods/ephemeralcontainers patch          (--debug-image only)
  - core:  pods/log                 get
  - core:  configmaps               create, delete (preflight skill)
  - apps:  deployments              patch, update  (preflight skill)
- RoCE benchmark pods set serviceAccountName: default explicitly.

Service Mesh / Network Policy Configuration:
- No PeerAuthentication, AuthorizationPolicy, or NetworkPolicy defined.
- No Ingress, Route, Gateway, or HTTPRoute defined.
- All in-pod listeners rely on platform-default pod networking.

Secrets:
- nccl_test_key (file in $HOME/.ssh of pod 1, not a K8s Secret)
  - RSA-2048, no passphrase, generated per run by run-tests-nccl-rccl.py
  - Public key appended to authorized_keys on every pod (incl. /root/.ssh)
    and never removed. No rotation.
- GHCR_TOKEN (GitHub Actions secret) - push release image to ghcr.io/llm-d.
- Indirect exposure: preflight /info returns every env var of the vLLM
  container, which may include HF tokens, S3 credentials, or other
  secret-sourced env vars.

Crypto / FIPS:
- No TLS anywhere in repo code (preflight http.server, etcd, ZMQ plaintext).
- Only crypto use: Python secrets (CSPRNG) for benchmark agent IDs.
- Runtime ssh-keygen RSA-2048 (FIPS-allowed minimum).
- Benchmark image on Ubuntu/NVIDIA CUDA base with Ubuntu OpenSSL:
  not FIPS-validated, would not pass check-payload.
- Build not hermetic: no lock files, unpinned pip, gdrcopy from master.

Key Security Observations (ordered by significance, per source analysis):
 [1] Preflight /info exposes all container env vars over unauthenticated
     plaintext HTTP bound to all interfaces (llm-d-preflight-checks.py
     55-58, 117-139, 155). Any pod that can reach pod-IP:8000 can read
     secrets and call /exit while paused.
 [2] --install-deps mutates running inference pods: unverified source
     downloads/builds, root SSH authorized_keys, sshd on 22 with
     StrictHostKeyChecking=no, plaintext etcd on 2379/2380.
     Restart test pods before serving production traffic.
 [3] NodePort 30002 exposes the unauthenticated ZMQ benchmark port on
     every node IP.
 [4] Port auto-increment: if 8000 is busy, probes may hit a different
     listener than the preflight gate.
 [5] Benchmark image is non-Red Hat, non-digest-pinned, published to
     ghcr.io (not a shipped RHOAI image).
