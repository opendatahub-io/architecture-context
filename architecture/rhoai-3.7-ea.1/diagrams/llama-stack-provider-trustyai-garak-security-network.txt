RBAC Summary:
- No ClusterRoles, Roles, RoleBindings or ServiceAccounts are defined in this repo.
- Job ServiceAccount (provisioned by eval-hub / operator) needs, at runtime:
  - API Group: core   Resources: secrets      Verbs: get   (job namespace, Data Connection)
  - API Group: core   Resources: configmaps   Verbs: get   (redhat-ods-applications / opendatahub)
  - KFP / DSP runs: create, get (KFP_NAMESPACE; enforced by DSP namespace RBAC)
- If the ConfigMap read is denied, the KFP pipeline silently falls back to a hard-coded
  upstream quay.io/trustyai image digest (supply-chain / disconnected-install risk).

Service Mesh Configuration:
- None. No PeerAuthentication, AuthorizationPolicy, or NetworkPolicy defined in the repo.

Credential Resolution (fallback chains, failures logged at debug level):
- KFP token:  KFP_AUTH_TOKEN → SA token file → unset (sidecar injects)
- S3 creds:   in-cluster read_namespaced_secret → KFP_AUTH_TOKEN vs KUBERNETES_SERVICE_HOST
              → sidecar http://localhost:8080/api/v1/... → S3 keys in model-auth secret
              → local kubeconfig
- Model keys: 13-step chain per role (core/pipeline_steps.py:resolve_api_key) ending in "DUMMY"

Secrets:
- Data Connection secret (KFP_S3_SECRET_NAME / kfp_config.s3_secret_name) (Opaque)
  - AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_S3_ENDPOINT, AWS_S3_BUCKET, AWS_DEFAULT_REGION
  - Provisioned by user (OpenShift AI Data Connection); no auto-rotation
- model-auth secret (model_auth_secret_name, default "model-auth") (Opaque)
  - Mounted at /mnt/model-auth, optional=True
  - API_KEY, {ROLE}_API_KEY, api-key, kfp_url, kfp_sa_token, k8s_url, k8s_sa_token
  - Provisioned by user / eval-hub (model.auth.secret_ref); no auto-rotation
- KFP_AUTH_TOKEN (env var) - KFP and K8s API bearer token, legacy path; no auto-rotation
- OPENAICOMPATIBLE_API_KEY, API_KEY, {ROLE}_API_KEY (env vars) - model API keys
- Projected SA token (/var/run/secrets/kubernetes.io/serviceaccount/token) - auto-rotated
- Hygiene: intents configs force api_key=__FROM_ENV__; config.json redacted before OCI/S3 export

Crypto / FIPS:
- Pure Python; no custom TLS min-version or cipher configuration
- OpenSSL from AIPCC RHEL 9.8 base; transitive cryptography==50.0.1 (OpenSSL-backed)
- uv removed from image (bundled Rust crypto, RHOAIENG-97373)
- User-configurable TLS disable: KFP_VERIFY_SSL=false, tls_verify=false
