RBAC Summary:
- None. The gateway does not call the Kubernetes API and ships no
  ClusterRole, Role, RoleBinding or ServiceAccount.

Authentication & Authorization:
- /{route}/v1/chat/completions (POST): no in-gateway auth; Authorization
  header passed through. Enforcement: fronting proxy and/or orchestrator.
  Route-level detector policy fixed by config; clients cannot override.
  Routes are NOT tied to caller identity - any caller reaching 8090 can
  use every route (including /passthrough with no detectors).
- Gateway -> orchestrator (POST): optional mTLS client cert + forwarded
  bearer. Enforcement: orchestrator TLS listener.

Service Mesh / Network Policy:
- None defined in repo. NetworkPolicy, Service, and exposure are left to
  the deployer.

Secrets / Mounted Credentials:
- /etc/tls/private/tls.{crt,key} (kubernetes.io/tls, expected) - mTLS
  client identity to orchestrator; provisioned by deploying operator /
  OpenShift service-ca (inferred); read once at startup, rotation only on
  restart.
- /etc/tls/ca/service-ca.crt (CA bundle, expected) - extra trust root;
  OpenShift service-ca injection (inferred); read once at startup.
  NOTE: CA alone does NOT enable HTTPS (scheme stays http).

Cryptography / FIPS:
- TLS library: native-tls (OpenSSL backend) + openssl crate; no rustls/ring.
- Min/Max TLS version, ciphers: unset (system / crypto-policy defaults).
- Linking: dynamic against system OpenSSL (openssl-libs in runtime image).
- Server-side TLS: none.
- JWT: none; bearer tokens forwarded opaquely.

Key Security Risks:
1. Tracing hard-coded to DEBUG: full Authorization bearer tokens, request
   payloads (prompts) and orchestrator responses (completions) are logged.
2. Plain HTTP listener with no in-process auth; relies on external proxy.
3. Silent plaintext fallback to orchestrator when cert files are missing.
4. Hostname verification disabled for "localhost" orchestrator host.
5. Streaming output guardrails are best-effort (pre-detection chunks
   already delivered).
6. Panics on unexpected orchestrator JSON (request task abort); no rate
   limiting or request size limits.
