Source: architecture/rhoai-3.7-ea.1/eval-hub-contrib.md
Scope: productized images odh-eval-hub-lighteval-rhel9 and odh-eval-hub-inspectai-rhel9.
       Both are one-shot batch Job containers with NO inbound listener
       (io.openshift.expose-services=""). eval-hub owns all control-plane concerns.

RBAC Summary:
- Productized adapters: NO ClusterRoles, Roles or bindings defined. Adapters
  do not call the Kubernetes API. Job SA and RBAC are owned by eval-hub.
- EXAMPLE ONLY (adapters/swebench/rbac.yaml, applied by hand per namespace):
  - Role: swebench-eval
    - batch/jobs: create, get, list, delete
    - core/pods, pods/log: get, list
  - RoleBinding: swebench-eval -> SA evalhub-evalhub-opendatahub-job
  - ClusterRoleBinding: swebench-eval-anyuid-NAMESPACE
    -> ClusterRole system:openshift:scc:anyuid -> SA evalhub-evalhub-opendatahub-job
  - RISK: the SA is shared by every adapter Job in the namespace, so this grants
    anyuid SCC and child-Job creation to all evaluation workloads there.

Service Mesh Configuration:
- None. No PeerAuthentication, AuthorizationPolicy or mesh sidecar defined.
- Sidecar <-> adapter traffic is plaintext over pod loopback.

Secrets (consumed, none defined in repo):
- Model-auth secret (Opaque, projected at /var/run/secrets/model)
  - Keys: api-key, hf-token, judge_api-key, judge_url
  - Provisioned by eval-hub from user model.auth.secret_ref; no auto-rotation
  - Inspect ignores sidecar placeholder tokens when resolving HF_TOKEN
- OPENAI_JUDGE_API_KEY (Secret-backed env via provider runtime.k8s.env)
  - Provisioned by user; no auto-rotation
- redhat-appstudio-staginguser-pull-secret (dockerconfigjson) - Konflux build only

Credential Handling Observations:
- Raw keys may enter subprocess env: OPENAI_API_KEY, ANTHROPIC_API_KEY,
  OPENAI_JUDGE_API_KEY.
- Job params api_key / anthropic_api_key are accepted as fallbacks, so
  credentials can persist in the JobSpec ConfigMap.
- "api_key" is redacted from logged command strings (_API_KEY_RE,
  adapters/inspect/_execution.py:47).

TLS / Crypto:
- No custom TLS config; library defaults (requests/httpx/aiohttp/urllib).
- No verify=False / CERT_NONE found in adapter code.
- CA trust from certifi bundle: cluster custom CAs need SSL_CERT_FILE /
  REQUESTS_CA_BUNDLE overrides.
- OpenSSL from RHEL 9.8 AIPCC base; no explicit FIPS opt-in.
- SHA-256 used only for non-security cache naming (_preflight.py:405).

Hardening / Disconnected Notes:
- /tmp chmod 777 and group-writable site-packages: a compromised evaluation
  could modify installed packages for the pod's lifetime (bounded: short-lived Job).
- Inspect fail-fast network pre-flight (INSPECT_PREFLIGHT=fail) probes HF/GitHub.
- RHOAI Inspect image ships WITHOUT NLTK data (NLTK_AIRGAP=true, licensing);
  makemesay needs egress or a volume mount.
- INSPECT_NO_TELEMETRY=1.

Supply Chain:
- Hermetic Konflux builds, Hermeto pip prefetch, 4 arches
  (x86_64, aarch64, ppc64le, s390x), digest-pinned AIPCC CPU bases.
- Inspect lock is fully hash-pinned; LightEval lock pins versions but has no hashes
  (installed --no-deps).
