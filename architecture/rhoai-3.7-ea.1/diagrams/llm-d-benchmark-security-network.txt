Secrets:
- {{ huggingface.secretName }} (Opaque) - HF token; created at standup from
  HF_TOKEN / LLMDBENCH_HF_TOKEN / HUGGING_FACE_HUB_TOKEN; no rotation;
  may be rendered as plaintext stringData in workspace manifests
- inference-gateway-sa-metrics-reader-secret (SA token) - EPP /metrics Bearer;
  provisioned by GAIE / router chart; consumed only
- vllmCommon.pullSecret (kubernetes.io/dockerconfigjson) - user-provided
- KEDA TriggerAuthentication secrets (Opaque/token) - Prometheus auth for KEDA
- LLMDBENCH_TELEMETRY_TOKEN (env) - short-lived Google OIDC ID token
- LLMDBENCH_BASE64_CONTEXT_CONTENTS (env) - base64 kubeconfig injected into the
  harness container

TLS / Crypto Posture:
- Python ssl / urllib3 / requests defaults; no min-version or cipher config
- Verification disabled: verify_ssl=False, --insecure-skip-tls-verify=true,
  curl -k / -sk, ssl.CERT_NONE fallback
- SHA-256 used only for naming/IDs (non-security)

FIPS / Supply Chain:
- Harness image base: docker.io/library/python:3.13.5-slim-bookworm (Debian
  OpenSSL, not FIPS-validated); s390x variant on ubi9/ubi-minimal:9.6
- No Konflux Dockerfile, no .tekton pipelines, no hermetic lock files
- Images published to ghcr.io/llm-d by GitHub Actions
- Build-time downloads (oc, gcloud plugin, AWS CLI, git clones, CPU torch)
  without checksum verification

Multi-Tenancy:
- Tenant boundary: per-namespace (model ns + harness ns per stack);
  single-tenant, per-user ephemeral; teardown removes resources
- Gaps: unauthenticated rsync results exposure, no NetworkPolicies, PSA
  audit/warn privileged, cluster-admin needed for shared infra standup,
  shared GCS/Prism credentials with path-prefix isolation only
