RBAC Summary:
- None. OVMS does not call the Kubernetes API; the repository ships no
  ClusterRoles, Roles or RoleBindings.
- Deployment and Service creation is performed by the KServe controller
  (its own RBAC, not part of this component).

Service Mesh Configuration:
- None defined by this component. No PeerAuthentication or
  AuthorizationPolicy. Encryption and auth come from the platform
  (KServe RawDeployment, ODH Model Controller Route/Gateway, optional
  kube-rbac-proxy / Authorino).
- No NetworkPolicy in repo; relies on platform NetworkPolicy.

Secrets:
- API_KEY / --api_key_file (env var / mounted file) - static Bearer token
  for /v3 endpoints; user-provisioned; read once at startup, no rotation
- AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_SESSION_TOKEN (env) - S3
  model storage; KServe / data connection Secret; no rotation
- GOOGLE_APPLICATION_CREDENTIALS (env → mounted file) - GCS; user; no rotation
- HF_TOKEN (env) - Hugging Face pull; user; no rotation
- OPENAI_API_KEY, GITHUB_TOKEN - demo / tooling scripts only, not the server

FIPS / Crypto:
- No compilation in Konflux; server is a prebuilt, dynamically linked RPM
- OpenSSL from RHEL 9.8 AIPCC base (cpu-el9.8:3.6.0, digest-pinned)
- RISK: legacy OpenSSL MD5() for config change detection
  (src/filesystem/filesystem.hpp:263-280); may fail under a FIPS provider
  in --config_path multi-model mode
- RISK: API key compared with plain == (not constant-time)

Build Hermeticity:
- hermetic: true; Hermeto prefetch of rpm + pip
- rpms.lock.yaml: 22 RPMs from cdn.redhat.com rhelai-3.6 (x86_64)
- requirements.txt: hash-pinned, --require-hashes --only-binary --no-index
- Single architecture: linux/amd64, CPU only (Intel GPU via OpenVINO plugin
  only if RPMs provide it; NVIDIA/CUDA unsupported)

Key Security Findings:
1. No native TLS on either listener; all in-pod traffic is plaintext.
2. KServe v2, TFS v1, gRPC, /metrics and /v1/config/reload are
   unauthenticated; anything that can reach the pod can call them.
3. CORS is permissive (*) by default.
4. Overlay 0014 still says "not hermetic"; it is stale for this release.
5. ENTRYPOINT /ovms/bin/ovms vs sanity check /usr/bin/ovms; verify the
   RPM provides both paths.
