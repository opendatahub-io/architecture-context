RBAC Summary:
- No ClusterRoles, Roles, RoleBindings or ServiceAccounts in this repo.
- The server makes no Kubernetes API calls.

Authentication & Authorization:
- MetadataStoreService/* on 8080: no authentication by default.
- Optional mTLS: GRPC_SSL_REQUEST_AND_REQUIRE_CLIENT_CERTIFICATE_AND_VERIFY
  when ssl_config.client_verify is set (metadata_store_server_main.cc:45-61).
- No per-RPC authorization; isolation relies on network placement and any
  fronting proxy (DSP Envoy / kube-rbac-proxy, inferred).

Service Mesh Configuration:
- None defined in repo.

TLS / Crypto:
- gRPC SslServerCredentials with library defaults (no min TLS version, no cipher list).
- MySQL cipher list user-supplied (--mysql_config_sslcipher, arbitrary strings allowed).
- BoringSSL statically linked into gRPC and MariaDB Connector/C; bypasses the RHEL
  OpenSSL FIPS provider (system OpenSSL in base image is unused).
- PostgreSQL TLS flags exposed but non-functional (HAVE_LIBSSL/USE_OPENSSL undefined).

Secrets (no Kubernetes Secrets referenced; all provisioned by deployer, inferred):
- DB password (--mysql_config_password / --postgres_config_password) - CLI flag,
  visible in process args, no rotation
- gRPC TLS key/cert/CA - inline PEM in MetadataStoreServerConfig.ssl_config textproto,
  read once at startup, no rotation
- DB client TLS cert/key (--mysql_config_ssl* / --postgres_config_ssl*) - file paths,
  no rotation

Multi-Tenancy:
- Single-tenant instance (inferred one per DSPA/namespace); no tenant fields, no
  namespace/user filtering on RPCs; shared DB has no row-level separation.

Build Hermeticity:
- Non-hermetic (Tekton hermetic: "false"); COPR repo + Bazel 6.3.2 binary fetched
  via curl without checksum; Bazel http_archives sha256-pinned.
