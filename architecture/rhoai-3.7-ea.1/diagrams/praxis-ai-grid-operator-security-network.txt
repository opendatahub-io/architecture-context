Admission Policies (ValidatingAdmissionPolicy, CEL, failurePolicy: Fail):
- grid-operator-endpointslice-cleanup: operator SA may DELETE only
  controller-managed EndpointSlices of grid-operator-signals / grid-operator-swim
- grid-operator-protect-config: operator SA may never UPDATE grid-operator-config

Service Mesh Configuration:
- None. No Istio/PeerAuthentication. Transport security is application-level:
  mTLS with Grid CA + fingerprint pins (signals, gateway-to-gateway),
  AES-256-GCM shared key (SWIM).

Secrets:
- grid-operator-metrics-tls (kubernetes.io/tls) - metrics TLS, OpenShift
  service-ca, auto-rotated (listener hot reload)
- grid-site-identity (Opaque/TLS) - site P-256 cert+key: metrics TLS (base),
  peer mTLS, gossip signing; enrollment / operator; rotated via /v1alpha1/rotations
- grid-swim-key (Opaque) - shared AES-256-GCM mesh key; deployment owner; no rotation
- Provider credential Secrets (Opaque) - backend API keys; referenced only
  (name/namespace/key), never copied into overlays; no rotation
- Enrollment CA / TLS (kubernetes.io/tls) - Grid CA signing material + serving
  cert; bootstrap Job; CA rotation requires ENROLLMENT_CONFIRM_CA_ROTATION
- Invite Secrets (Opaque) - SiteInvite material; enrollment

Key Security Risks:
1. Shipped Konflux images are NOT built with the fips feature (operator: rustls+ring;
   enrollment: sar,bootstrap; gateway: aws-lc default, fails check-payload).
2. Shared SWIM mesh key: any key holder can inject state; per-site origin pins
   not fully wired (praxis-proxy/grid#75).
3. 9090 metrics/health has no application auth (NetworkPolicy-only on OpenShift);
   plaintext fallback if TLS is unconfigured.
4. SWIM/signals LB ports open to any source that can reach the internal LB.
5. Cluster-scoped CRDs; no tenant isolation (explicitly out of scope).
6. Optional enrollment Postgres may be shared with MaaS.
