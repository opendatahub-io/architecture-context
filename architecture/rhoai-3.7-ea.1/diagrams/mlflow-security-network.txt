RBAC Summary:
- No RBAC manifests in this repository; all defined by the MLflow Operator.
- MLflow server ServiceAccount (operator-defined):
  - authorization.k8s.io selfsubjectaccessreviews: create
  - core namespaces: list, watch
  - mlflow.kubeflow.org mlflowconfigs: get/read
- User-facing roles (operator-defined) on mlflow.kubeflow.org
  pseudo-resources (not real CRDs), bound per namespace via RoleBindings.
  Every request is checked with SSAR using the caller's own token.

Multi-Tenancy:
- Tenant boundary: Kubernetes namespace = MLflow workspace
- Tenant identifier: X-MLFLOW-WORKSPACE header, validated against workspace store
- Data isolation: application-level only (shared DB, shared artifact root)
- Network isolation: none at tenant level; NetworkPolicy (if any) operator-owned
- Compute: shared pods/workers; no per-tenant quotas or rate limits

Service Mesh Configuration:
- None defined by this component (TLS is terminated in the pod).

Secrets:
- Server TLS cert/key (kubernetes.io/tls, mounted) - uvicorn TLS, provisioned by
  MLflow Operator (service-CA / platform), rotation platform-dependent
- Backend store URI credentials (env / Secret) - PostgreSQL, no rotation
- AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY / AWS_SESSION_TOKEN (env) - S3, no rotation
- MLFLOW_CRYPTO_KEK_PASSPHRASE (env) - KEK for gateway secret store (AES-GCM,
  PBKDF2 600k); FALLS BACK TO HARDCODED DEFAULT (mlflow/utils/crypto.py:30)
- MLFLOW_WEBHOOK_SECRET_ENCRYPTION_KEY (env) - Fernet key; RANDOM PER PROCESS
  IF UNSET (secrets undecryptable after restart, differ across workers)
- MLFLOW_FLASK_SERVER_SECRET_KEY (env) - Flask session/CSRF key
- LLM provider keys (OPENAI_API_KEY, ANTHROPIC_API_KEY, ...) - AI Gateway only (disabled)

Security Notes:
- Operator must set --allowed-hosts correctly for the gateway hostname.
- New upstream routes require the plugin's route-authorization audit
  (66 registry + 147 native route/method pairs) or may lack authorization.
- Every API call depends on the Kubernetes API server (SSAR); plugin caching unknown.
