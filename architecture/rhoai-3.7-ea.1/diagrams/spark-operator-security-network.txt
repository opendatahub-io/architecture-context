Key Security Observations:
1. Module controller SA is effectively cluster-admin-equivalent.
2. /metrics (8080) is HTTPS but unauthenticated; protected only by NetworkPolicy.
3. Webhook cert is self-signed with 10-year validity (not service-ca / cert-manager).
4. Admission scope (jobNamespaces) is narrower than controller scope (all namespaces).
5. Operator pods have allow-all egress; spark-submit fetches arbitrary user URLs in a
   shared multi-tenant process.
6. SparkConnect gRPC 15002 and Spark RPC 7078/7079 are plaintext with no app-level auth.
