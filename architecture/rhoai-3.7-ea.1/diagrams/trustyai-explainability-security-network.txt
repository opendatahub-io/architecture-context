Services:
- trustyai-service (in-repo manifest)  ClusterIP 80/TCP → 8080  HTTP, no auth
- <instance>-tls (operator, reference)  ClusterIP 443/TCP → 8443 (kube-rbac-proxy)
                                        HTTPS, service-serving cert, Bearer (SAR)
- <instance> internal (operator, ref.)  ClusterIP 443/TCP → 4443 (internal-tls-proxy)
                                        HTTPS, Bearer except ignored paths

RBAC Summary (legacy in-repo manifest):
- ClusterRole: trustyai-role
  - API Groups: "" (core)
  - Resources: configmaps
  - Verbs: create, delete, get, list, patch, update, watch   (CLUSTER-WIDE)
- ClusterRoleBinding: trustyai-clusterrolebinding → SA trustyai-serviceaccount
- Only consumer: ose-cli init container (Java service has no K8s client)

Service Mesh Configuration:
- None. No PeerAuthentication / AuthorizationPolicy / NetworkPolicy shipped.

Secrets:
- Internal TLS (kubernetes.io/tls) at /etc/tls/internal - Quarkus HTTPS 4443;
  operator / OpenShift service-ca; auto-rotated
- DB configuration secret (Opaque, via env) - kind, user, password, host, port, name;
  user/operator (spec.storage.databaseConfigurations); no rotation
- DB CA (Opaque/TLS) at /etc/tls/db - JDBC verify-ca; user-provided; no rotation
- MinIO credentials (env) - access/secret key; user-provided; no rotation

Security Observations:
1. Unauthenticated ingestion: any in-cluster client that can reach 4443 (or 8080)
   can inject inference data and skew fairness/drift metrics. No NetworkPolicy.
2. Outbound explainer gRPC is plaintext, with a new channel per request.
3. Legacy Route is plaintext (tls: null); legacy ServiceMonitor scrapes over HTTP.
4. Legacy ClusterRole grants cluster-wide ConfigMap CRUD.
5. DB credentials default to quarkus/quarkus; Hibernate schema mode "update".
6. CloudEvent decompression capped at 100 MB (gzip-bomb guard).
7. FIPS: no explicit opt-in; relies on RHEL OpenJDK 17 following host FIPS mode.
8. Build: hermetic Konflux image (RPM + artifact locks, digest-pinned bases), but
   Java bytecode comes from a prebuilt PNC jar; the PNC trigger only fires for
   rhoai-2.1[6-9]+ branches, so the 3.x artifact may be stale.
