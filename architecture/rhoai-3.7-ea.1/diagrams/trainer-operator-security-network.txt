Egress (operator): Kubernetes API server only (6443/TCP, HTTPS, TLS 1.2+,
SA token). Manifests are baked into the image; nothing is fetched at runtime.
Egress (operand): unrestricted by NetworkPolicy.

RBAC Summary:
- ClusterRole: trainer-operator-manager-role
  (bound by ClusterRoleBinding trainer-operator-manager-rolebinding to
   SA trainer-operator-system/trainer-operator-controller-manager)
  - core: configmaps, secrets, services — full CRUD (cluster-wide)
  - core: namespaces — create, get, list, patch, update, watch
  - core: serviceaccounts — create, list, watch; delete/get/patch/update only
    on kubeflow-trainer-controller-manager, kubeflow-trainer-cache-initializer
  - core: pods (get, list); limitranges (get, list, watch); events
  - admissionregistration.k8s.io: mutating/validatingwebhookconfigurations — full CRUD
  - apiextensions.k8s.io: customresourcedefinitions — create, get, list, patch, update, watch
  - apps: deployments — full CRUD
  - rbac.authorization.k8s.io: clusterroles, clusterrolebindings, roles,
    rolebindings — create, list, watch; delete/get/patch/update restricted by
    resourceNames (training-*, kubeflow-trainer-*, trainer-metrics-reader,
    trainer-tls-profile, kubeflow-trainer-public)
  - trainer.kubeflow.org: clustertrainingruntimes, trainingruntimes, trainjobs — full CRUD;
    optimizationjobs, */status, */finalizers
  - jobset.x-k8s.io: jobsets — full CRUD
  - scheduling.volcano.sh / scheduling.x-k8s.io: podgroups
  - networking.k8s.io: networkpolicies; monitoring.coreos.com: servicemonitors,
    podmonitors, prometheusrules; image.openshift.io: imagestreams
  - components.platform.opendatahub.io: trainers, trainers/status, trainers/finalizers
  - config.openshift.io: apiservers, clusterversions (read)
  - operator.openshift.io: jobsetoperators (read); OLM operatorconditions /
    clusterextensions (list); coordination.k8s.io: leases
  - authentication/authorization: tokenreviews, subjectaccessreviews (create)
  - nonResourceURL /metrics (get)
  NOTE: Broad by design (RBAC escalation prevention requires holding every
  permission the upstream Trainer ClusterRoles grant). `create` on RBAC cannot
  be restricted by resourceNames. The operator SA is a high-value credential.
- ClusterRole trainer-operator-metrics-reader: get /metrics
- ClusterRoles trainer-operator-trainer-admin-role / -viewer-role: Trainer CR access
- Operand: trainer-tls-profile (get/list/watch apiservers "cluster") →
  SA kubeflow-trainer-controller-manager; trainer-metrics-reader → SA
  openshift-monitoring/prometheus-k8s; training-edit / training-admin /
  training-view (aggregate-to-view) for tenant use

Service Mesh Configuration:
- None. No Istio sidecars, PeerAuthentication or AuthorizationPolicy.
  Transport security is TLS at each listener.

Secrets:
- trainer-operator-metrics-tls (kubernetes.io/tls) - operator metrics serving
  cert; issued by OpenShift service-ca; auto-rotated; key pair reloaded on
  every handshake (GetCertificate)
- kubeflow-trainer-webhook-cert (Opaque, generated empty) - operand webhook +
  metrics TLS and ServiceMonitor CA; populated and rotated by Trainer's
  internal cert management (certManagement.enable: true)

TLS / Crypto:
- Operator: crypto/tls configured from OpenShift APIServer TLS profile when
  adherence requires it, else hardened Intermediate (TLS 1.2+); HTTP/2 NextProtos.
- Operand: profile translated into Configuration.tls (minVersion, ciphers,
  curves); TLS 1.3 suite IDs and RC4 dropped; fails closed on unsupported curves.
  Config SHA-256 hash on pod template forces rollout.
- Profile change → SecurityProfileWatcher cancels manager context → pod restart.
- FIPS build: CGO_ENABLED=1 GOEXPERIMENT=strictfipsruntime, dynamic linking,
  OpenSSL from ubi-minimal-pqc. No InsecureSkipVerify in Go code.
- Hermetic build: Hermeto gomod prefetch, hermetic: true; x86_64 + arm64.

Security Observations:
1. Operand NetworkPolicy allows 9443 (webhooks) from any source.
2. Operand status server 10443 trusts pod label training.kubeflow.org/job-name
   from any namespace; tenants can set that label on their own pods.
3. Operand egress is unrestricted.
4. Operator SA holds cluster-wide CRUD on Secrets, ConfigMaps, webhooks and
   CRDs; compromise crosses all tenants.
5. Operand ServiceMonitor may keep placeholder serverName
   kubeflow-trainer-controller-manager..svc if the kustomize replacement fails.
6. config/prometheus/monitor.yaml uses insecureSkipVerify: true (not deployed
   by default).
7. Informer cache falls back to all namespaces if APPLICATIONS_NAMESPACE is unset.
8. Single replica, no leader election (no HA).
