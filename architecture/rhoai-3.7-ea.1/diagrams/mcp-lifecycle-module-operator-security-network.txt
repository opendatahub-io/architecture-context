Egress (module):
- Kubernetes API server 6443/TCP HTTPS TLS 1.2+, SA token
  (reconciliation, SSA, discovery, dynamic informers)

RBAC Summary:
- ClusterRole: mcp-lifecycle-module-operator-manager-role
  (bound to SA mcp-lifecycle-module-operator-controller-manager)
  - rbac.authorization.k8s.io clusterroles, clusterrolebindings, roles,
    rolebindings: create, delete, get, list, patch, update, watch
  - apiextensions.k8s.io customresourcedefinitions: full CRUD
  - admissionregistration.k8s.io validatingwebhookconfigurations: full CRUD
  - core configmaps, namespaces, serviceaccounts, services: full CRUD
  - core pods, secrets: get, list, watch (cluster-wide)
  - apps deployments: full CRUD; daemonsets, statefulsets: get, list, watch
  - mcp.x-k8s.io mcpservers, mcpgatewaybindings (+status/finalizers):
    full CRUD + deletecollection
  - gateway.networking.k8s.io httproutes: full CRUD; gateways: read
  - mcp.kuadrant.io mcpserverregistrations: full CRUD;
    mcpgatewayextensions: read
  - networking.k8s.io networkpolicies, cert-manager.io certificates/issuers,
    monitoring.coreos.com servicemonitors, coordination.k8s.io leases:
    full CRUD
  - components.platform.opendatahub.io mcplifecycleoperators
    (+status/finalizers): full CRUD
  - config.openshift.io apiservers: get, list, watch
  - migration.k8s.io storageversionmigrations: create, delete, get
  - tokenreviews, subjectaccessreviews: create; events: create, patch
  - nonResourceURL /metrics: get
  RISK: superset of operand permissions (RBAC escalation prevention);
  compromise of module SA ≈ cluster-admin via RBAC creation.

- ClusterRole: mcp-lifecycle-operator-manager-role (operand SA)
  - core configmaps, namespaces, pods, secrets: get, list, watch
  - core services: create, delete, get, list, update, watch
  - apps deployments: create, get, list, update, watch
  - networking.k8s.io networkpolicies: create, get, list, update, watch
  - httproutes, mcpserverregistrations: create, delete, get, list,
    update, watch
  - mcpservers: get, list, patch, update, watch;
    mcpgatewaybindings: full CRUD
- ClusterRole: mcp-lifecycle-operator-metrics-auth-role (operand SA)
  - tokenreviews, subjectaccessreviews: create
- Role: mcp-lifecycle-operator-leader-election-role (SYSTEM_NAMESPACE)
  - configmaps, leases: full CRUD; events: create, patch
- Aggregated: mcpserver-admin-role (→admin), mcpserver-editor-role (→edit),
  mcpserver-viewer-role (→view), metrics-reader (/metrics get)

Service Mesh Configuration:
- None. No Istio/service mesh; TLS is application-level.

Admission Webhooks (served by operand, deployed by module):
- Conversion: MCPServer v1alpha1 ↔ v1beta1, /convert, svc 443→9443
- Validating: mcp.x-k8s.io/v1alpha1 mcpservers CREATE/UPDATE,
  failurePolicy Fail, sideEffects None (fail-closed if operand down)

Secrets:
- mcplo-webhook-server-cert (kubernetes.io/tls) - operand webhook serving
  cert; cert-manager Certificate mcp-lifecycle-operator-serving-cert,
  self-signed Issuer; auto-renewed by cert-manager
- mcplo-metrics-server-cert (kubernetes.io/tls) - operand metrics TLS,
  ca.crt used by ServiceMonitor; cert-manager Certificate
  mcp-lifecycle-operator-metrics-certs; auto-renewed by cert-manager
- Module: no secrets mounted (controller-runtime self-generated metrics cert)

TLS / FIPS:
- Module and operand TLS follow OpenShift APIServer TLS profile (when
  adherence policy allows), else hardened Intermediate profile
- Profile change → module restarts its process; operand rolls out
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, dynamic OpenSSL
  (ubi9-minimal), crypto-policy DEFAULT:PQ
