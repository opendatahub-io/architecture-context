RBAC Summary:
- No ClusterRoles or RoleBindings installed by SDK
- SDK operates with the authenticated user's existing permissions
- Required API groups: ray.io, kueue.x-k8s.io, gateway.networking.k8s.io,
  route.openshift.io, services.platform.opendatahub.io, core (secrets, namespaces)
- All API calls are namespace-scoped (except HTTPRoute cluster-wide search
  with fallback to namespace-scoped on permission error)

Secrets:
- {cluster-name}-ca-secret-{uid} (Opaque) — KubeRay CA cert for mTLS
  - Provisioned by: KubeRay Operator
  - Auto-Rotate: No
- {job-name}-files (Opaque) — Local Python files for RayJob submission
  - Provisioned by: CodeFlare SDK
  - Auto-Rotate: No
  - Cleanup: ownerRef to RayJob CR (garbage collected)
  - Size limit: 1MB

Certificate Management:
- Algorithm: RSA 3072-bit with SHA-256 signatures (FIPS-approved)
- Extensions: BasicConstraints, KeyUsage, ExtendedKeyUsage (serverAuth + clientAuth)
- SANs: Ray head service DNS names
- Storage: ~/.local/share/codeflare/tls/{cluster}-{namespace}/
- Permissions: 0600 (user-private)
- Cleanup: Best-effort on cluster.down(); stale certs may persist
- Custom CA: CF_SDK_CA_CERT_PATH env var supported
- ODH CA bundle: /etc/pki/tls/certs/odh-trusted-ca-bundle.crt (mounted in Ray pods)

Multi-Tenancy:
- Tenant boundary: per-namespace (Kubernetes namespace RBAC)
- Kueue LocalQueue labels enforce resource quotas
- No quota enforcement if Kueue queue not found
