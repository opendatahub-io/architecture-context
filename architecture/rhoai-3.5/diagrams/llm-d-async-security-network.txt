  (enabled via --metrics-endpoint-auth flag)

Secrets:
- {release}-redis or user-provided (Opaque)
  - Key: url
  - Purpose: Redis/Valkey connection URL
  - Provisioned by: Helm chart or manual
  - Auto-rotate: No

- TLS secret (user-provided via ap.tls.secretName) (kubernetes.io/tls)
  - Keys: ca.crt, tls.crt, tls.key
  - Purpose: mTLS to inference gateway
  - Provisioned by: Manual / cert-manager
  - Auto-rotate: No

Security Hardening:
- Runs as non-root (UID 1001)
- Read-only root filesystem
- Dropped capabilities
- FIPS-compliant build (GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1)
- TLS minimum version: 1.2
- Redis credentials via Kubernetes Secrets (never in Helm values for production)
- --redis.url redacted in startup logs

Gaps:
- No NetworkPolicy included in Helm chart (network isolation must be configured externally)
- No per-tenant authentication (queue-level access delegated to Redis ACLs / GCP IAM)
- InsecureSkipVerify option exists (gated behind --tls-insecure-skip-verify, dev/test only)

Monitoring & Alerting:
- PrometheusRule with 4 alert rules:
  - Retry rate
  - Deadline exceeded
  - Success rate
  - Shed rate
- PodMonitor for Prometheus scraping of async processor metrics
- PodMonitor for vLLM model server metrics with inference_pool label relabeling
- Grafana dashboard JSON via ConfigMap
