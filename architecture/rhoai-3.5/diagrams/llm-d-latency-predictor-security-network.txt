⚠️  SECURITY GAPS:
1. No authentication on any endpoint (training data injection, model download, flush)
2. All inter-service communication is plaintext HTTP (no TLS/mTLS)
3. No NetworkPolicies defined -- relies on external network controls
4. /flush endpoint can wipe all training data without credentials
5. training-service-external LoadBalancer exposes sensitive endpoints externally
6. MD5 used for file checksums (hashlib.md5) -- not for security, only cache invalidation
7. Single-tenant design with no data isolation
