RBAC Summary:
- No RBAC resources defined by LMEval
- RBAC for the Job pod is managed by the TrustyAI operator
- Job pod runs with ServiceAccount provided by operator

Secrets:
- Model auth secret (Opaque) — Contains:
  - api-key: Model endpoint authentication (→ OPENAI_API_KEY env var)
  - hf-token: HuggingFace gated dataset access (→ HF_TOKEN env var)
  - Provisioned by: User / TrustyAI operator
  - Auto-rotate: No

Security Controls:
- Path traversal mitigation (CWE-22): _resolve_job_spec_path_for_read()
  validates job spec path stays under /meta
- Credential redaction: _sanitize_error_message() strips Bearer tokens,
  API keys, and URL credentials from error callbacks to EvalHub
- TLS verification: Configurable per model endpoint via verify_certificate
  parameter (default: True, uses system trust store)
- Offline mode: Auto-detects /test_data layout and prevents outbound
  HuggingFace Hub calls (sets HF_HUB_OFFLINE=1, TRANSFORMERS_OFFLINE=1)

FIPS Compliance:
- Pure Python application on UBI 9 — FIPS inherited from base image OpenSSL
- Uses hashlib.sha256 for cache keys (FIPS-approved algorithm)
- No non-FIPS algorithms (MD5, RC4, DES) detected
- TLS via Python ssl module → system OpenSSL FIPS policy

Network Policy:
- No NetworkPolicy defined by LMEval
- Depends on namespace-level NetworkPolicy from platform operator
- All egress is outbound only — no inbound services exposed
