NAMESPACE SUMMARY:
- redhat-ods-operator:       Platform operator, CRDs, webhooks
- redhat-ods-applications:   Platform services, controllers, Gateway stack
- redhat-ods-monitoring:     Prometheus, AlertManager, Perses dashboards
- istio-system:              Service mesh control plane (when mesh enabled)
- redhat-ai-gateway-infra:   AI Gateway shared infrastructure
- User namespaces:           Per-project workloads (DSPA, notebooks, models)

AUTHENTICATION LAYERS:
Layer 1 - Gateway ext_authz:    kube-auth-proxy (OAuth2/OIDC) for all
                                Gateway-routed services
Layer 2 - Kuadrant AuthPolicy:  Per-HTTPRoute Authorino-backed authorization
                                (anonymous, user-defined, API key modes)
Layer 3 - kube-rbac-proxy:      Per-component SubjectAccessReview RBAC checks
                                (TLS termination on port 8443)
Layer 4 - Istio mTLS:           Pod-to-pod mutual TLS within service mesh
Layer 5 - Application auth:     Bearer tokens (MaaS API keys), SA token
                                pass-through, BFF auth modes

TLS CONFIGURATION:
- External ingress:    TLS 1.3 (OpenShift Router / Gateway)
- kube-rbac-proxy:     TLS (serving certs via service-ca or cert-manager)
- Istio mesh:          mTLS (sidecar-to-sidecar, cert rotation by Istiod)
- Service-ca certs:    Auto-generated, auto-rotated by OpenShift service-ca
- FIPS compliance:     Go native FIPS module (GOFIPS140=v1.0.0) or
                       GOEXPERIMENT=strictfipsruntime; TLS profiles from
                       OpenShift APIServer configuration

DISCONNECTED (AIR-GAPPED) SUPPORT:
- RELATED_IMAGE_* env vars (OLM-injected, digest-pinned)
- ImageContentSourcePolicy / ImageDigestMirrorSet for registry mirroring
- All 162 images use SHA256 digest references (no tags)
- NVIDIA NIM explicit airGapped mode (disables NGC API calls)
- CA bundle aggregation: platform + user-provided + service-ca certificates
