- CORS: allow_origins=["*"] (wide open)

Secrets:
- planner-secrets (Opaque) - PostgreSQL password, HF token, Model Catalog token,
    Vertex AI credentials, OpenAI API key, DB admin password
    Provisioned: Manual (deploy-all.sh injects from env vars)
    Auto-Rotate: No
- planner-service-ca (ConfigMap, injected) - OpenShift service-serving CA bundle
    for Model Catalog TLS
    Provisioned: OpenShift service-ca operator
    Auto-Rotate: Yes (automatic injection)

NetworkPolicy:
- networkpolicy-model-catalog: Cross-namespace ingress from planner backend
  to Model Catalog (rhoai-model-registries namespace)
- NO NetworkPolicy restricting access to backend or UI within the namespace

Security Risks:
- trust_remote_code=True in HuggingFace AutoConfig.from_pretrained()
  executes arbitrary remote Python code from model repos
- CORS allow_origins=["*"] in production
- No authentication on API endpoints that can deploy to Kubernetes clusters
- DB admin password is optional (operations proceed without auth if unset)
- kubectl subprocess calls for deployment (less structured error handling)
- Model Catalog sync is destructive (DELETE + INSERT, brief data gap)

Container Security Context:
- runAsNonRoot: true
- Drop ALL capabilities
- seccompProfile: RuntimeDefault
