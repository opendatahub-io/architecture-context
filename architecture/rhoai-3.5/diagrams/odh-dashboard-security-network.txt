- Ingress: Allows OpenShift ingress controller + same-namespace pods on all module ports

- Egress: K8s API (6443/TCP), HTTPS (443/TCP), HTTP (80/TCP)
- Note: BFF modules in sidecar mode share the same pod; intra-pod traffic is unrestricted

Secrets:
- proxy-tls (kubernetes.io/tls) - TLS cert for kube-rbac-proxy, Service Serving Certificate, auto-rotate
- odh-dashboard-modules-token (SA token) - BFF module SA token, 3607s TTL, auto-rotate
- pgvector password (Opaque) - PostgreSQL auth for gen-ai vector DB, manual, no auto-rotate

Authentication Chain:
  Browser → OAuth (OpenShift) → Gateway → kube-rbac-proxy (Bearer validation + RBAC)
  → Backend (x-forwarded-access-token) → BFF modules (user_token or SA impersonation)

FIPS Compliance:
- All Go BFF binaries: CGO_ENABLED=1, -tags strictfipsruntime, dynamic linking
- Node.js dashboard: OpenSSL from UBI9 nodejs-22 base
- TLS 1.3 minimum enforced in all BFF Go servers
- esbuild Go binaries explicitly removed from Node.js image as safety net
