NetworkPolicy (Helm chart, disabled by default):
  Ingress:
    - Port: 5000/TCP
    - From: All namespaces (when enabled)

  Egress:
    - DNS: 53/UDP, 53/TCP, 5353/UDP
    - Kubernetes API: 6443/TCP
    - PostgreSQL: 5432/TCP
    - MySQL: 3306/TCP
    - S3/MinIO: 443/TCP, 9000/TCP
    - HTTPS (LLM providers): 443/TCP

RBAC Summary (Optional - configured via Helm values):
  - No default RBAC rules created
  - namespace_rbac.extraRules: User-defined Role rules
  - cluster_rbac.extraRules: User-defined ClusterRole rules
  - Binds MLflow ServiceAccount to chart-created Role/ClusterRole

Secrets:
  - mlflow-tls (kubernetes.io/tls) - TLS cert for HTTPS server, cert-manager/manual, no auto-rotate
  - backendStoreUri (Opaque) - Database connection URI, manual/platform operator, no auto-rotate
  - MLFLOW_CRYPTO_KEK_PASSPHRASE (env var) - KEK for gateway secret envelope encryption, manual (admin)
  - MLFLOW_FLASK_SERVER_SECRET_KEY (env var) - CSRF protection for basic-auth plugin, manual (admin)
  ⚠️  Default KEK passphrase exists ("mlflow-default-kek-passphrase-for-development-only")
     Installations must set MLFLOW_CRYPTO_KEK_PASSPHRASE to a unique value

Multi-Tenancy:
  - Tenant boundary: per-workspace (Kubernetes namespace)
  - Isolation: Column-based (workspace column in all tracking tables)
  - Enforcement: Application-level SQLAlchemy query filters (no DB-level row isolation)
  - Workspace header: X-MLFLOW-WORKSPACE (client-asserted, trusted after auth)
  ⚠️  Cross-workspace isolation is application-level only
  ⚠️  NetworkPolicy disabled by default; when enabled, ingress open to all namespaces
