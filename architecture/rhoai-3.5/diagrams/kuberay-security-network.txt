RBAC Summary:
- ClusterRole: kuberay-operator
  - Core API: pods (full CRUD + deletecollection), services, configmaps, events, serviceaccounts, secrets
  - apps: deployments (get, list, watch, patch, update)
  - batch: jobs (full CRUD)
  - ray.io: rayclusters, rayjobs, rayservices, raycronjobs (full CRUD + finalizers + status)
  - cert-manager.io: certificates, issuers (full CRUD)
  - gateway.networking.k8s.io: gateways (get, list, watch, create, update), httproutes, referencegrants (full CRUD)
  - networking.k8s.io: networkpolicies, ingresses (full CRUD), ingressclasses (read-only)
  - rbac.authorization.k8s.io: clusterroles, clusterrolebindings (read-only), roles, rolebindings (full CRUD)
  - route.openshift.io: routes (full CRUD)
  - config.openshift.io: apiservers (get), authentications/oauths (read-only)
  - authentication.k8s.io: tokenreviews (create)
  - authorization.k8s.io: subjectaccessreviews (create)
  - coordination.k8s.io: leases (get, list, create, update)

Role Bindings:
- kuberay-operator (cluster-scoped) → ClusterRole/kuberay-operator → SA: kuberay-operator
- leader-election-rolebinding (operator namespace) → Role/leader-election-role → SA: kuberay-operator

Secrets:
- kuberay-webhook-server-cert (kubernetes.io/tls) - Webhook TLS, OpenShift service-serving-cert-signer, auto-rotate
- {cluster}-ca-secret-{uid} (Opaque) - CA cert for mTLS, cert-manager, 10yr duration / 30d renewal
- ray-head-secret-{cluster} (kubernetes.io/tls) - Head node mTLS cert, cert-manager, 90d duration / 15d renewal
- ray-worker-secret-{cluster} (kubernetes.io/tls) - Worker node mTLS cert, cert-manager, 90d duration / 15d renewal

TLS Configuration:
- Operator aligns with OpenShift cluster-wide TLS security profile (Intermediate/Modern/Old/Custom)
- Default: Intermediate (TLS 1.2+, modern cipher suites)
- ALPN: h2, http/1.1
- FIPS: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, dynamic linking with OpenSSL via UBI9

NetworkPolicy (annotation-gated, opt-in):
- Head policy: allows intra-cluster + namespace + operator access
- Worker policy: allows intra-cluster only
- WARNING: NetworkPolicy is NOT enabled by default — without annotation, all namespace pods can reach Ray ports
