FIPS Compliance:
  - EPP: CGO_ENABLED=1, NO strictfipsruntime tag → may NOT pass check-payload
  - PD-Sidecar: CGO_ENABLED=1 + -tags strictfipsruntime → FIPS compliant
  - Coordinator: CGO_ENABLED=0 (static) → would FAIL check-payload (upstream only)

Security Gaps:
  - EPP data source clients default to InsecureSkipVerify=true for model server TLS
  - No NetworkPolicy defined for any component
  - Self-signed TLS certificates with 10-year expiry (should use cert-manager in production)
  - EPP ext-proc relies on network topology for auth (no per-request authentication)
  - Coordinator assumes reverse proxy handles authentication (no auth on 8080/TCP)
