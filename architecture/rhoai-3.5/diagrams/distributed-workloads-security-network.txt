RBAC Summary:
- No persistent RBAC resources deployed by this repository
- Tests create temporary Roles/RoleBindings per test namespace via tests/common/support/rbac.go
- Temporary RBAC cleaned up via t.Cleanup() at test completion

Authentication & Authorization:
- Kubernetes API:   Bearer Token (ServiceAccount)     → RBAC enforcement
- HuggingFace Hub:  Bearer Token (HF_TOKEN, optional) → Per-model access control
- S3 Storage:       AWS IAM credentials               → Bucket policy
- Prometheus:       Bearer Token                      → kube-rbac-proxy + cluster-monitoring-view role

Secrets:
- No Kubernetes Secrets deployed by this repository
- Credentials provided via environment variables at test runtime:
  - HF_TOKEN: HuggingFace Hub access
  - AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY: S3 storage
  - SSH keys: Generated at runtime for MPI inter-node communication

FIPS Compliance:
- No Go binaries shipped (test-only Go code)
- Container images inherit OpenSSL from UBI9/AIPCC base images
- Python/PyTorch uses system OpenSSL for HTTPS (no custom TLS config)
- No non-FIPS crypto risks detected in shipped artifacts

Build Hermeticity:
- Universal images: Full hermeticity (AIPCC bases + cachi2 prefetch)
- OpenMPI runtime images: Partial hermeticity (AIPCC bases, no cachi2)
- Standard runtime images (8 of 10): No hermeticity — install from vendor repos
- Go dependencies: go.sum lockfile present
- Python dependencies: Pipfile.lock (runtime) / requirements.txt (universal)

Network Security Gaps:
- NCCL/RCCL gradient sync: No encryption (intra-cluster TCP+RDMA)
- Ray Head-Worker communication: No encryption (intra-cluster gRPC)
- Ray Dashboard: HTTP only, no authentication (port 8265)
- No NetworkPolicies deployed in test namespaces
