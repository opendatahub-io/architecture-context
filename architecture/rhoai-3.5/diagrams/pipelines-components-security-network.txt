Multi-Tenancy:
- Tenant boundary: per-namespace
- Deployment model: multi-tenant (shared KFP control plane, per-namespace runs)
- Tenant identifier: namespace name
- Network isolation: Delegated to platform operator (no NetworkPolicy in component)
- Data isolation: Per-namespace PVC mounts; S3 credentials scoped per pipeline
- Risk: Shared S3 buckets could leak data across tenants
- Risk: Components creating cluster-scoped CRs could affect other namespaces

FIPS Compliance:
- Python application — no Go binaries, no custom TLS config
- Crypto: cryptography==49.0.0 (OpenSSL backend, FIPS-capable)
- Certificate handling: System trust store (UBI9/AIPCC base)
- Non-FIPS crypto risks: None detected

Build Hermeticity:
- All 3 Konflux builds use hermetic: true with pip prefetch
- Requirements files include --generate-hashes for integrity
- RHAI PyPI index used exclusively (no public PyPI)
- Gap: No rpms.lock.yaml for OS package locking
