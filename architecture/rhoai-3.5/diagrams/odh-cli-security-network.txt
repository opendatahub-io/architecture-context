RBAC Summary:
- No static ClusterRoles or RoleBindings defined
- CLI operates with user's kubeconfig identity permissions
- SelfSubjectAccessReview preflight checks before operations
- Graceful degradation on permission denial (no hard failures)
- Migration creates temporary RBAC resources:
  - ServiceAccount (per migration action, owner-referenced)
  - Role (scoped to target namespace)
  - RoleBinding (links temp SA to temp Role)
  - All temporary resources have owner references for automatic cleanup

Security Controls:
- Catalog source validation: Allowlist-based (CWE-829 prevention)
- System namespace rejection: Blocks system namespace targeting (CWE-269)
- Terminal escape sanitization: Events output sanitized (CWE-150)
- Directory traversal prevention: MCP backup tool rejects path traversal
- Exit code differentiation: Codes 0-5 for CI/CD integration

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Linking: Dynamic (links to OpenSSL via UBI9 base)
- TLS: crypto/tls stdlib (FIPS via OpenSSL at runtime)
- Risk: InsecureSkipVerify=true on TrustyAI route (in-cluster only)
- No non-FIPS crypto: No MD5, RC4, or DES usage

Build Hermeticity:
- RPM lock: rpms.lock.yaml (make package, multi-arch)
- Go modules: go.sum (full checksums)
- Tekton: hermetic=true, prefetch for rpm + gomod
- Container: quay.io/rhoai/rhai-cli-rhel9 (UBI9 base)

Secrets:
- No secrets created or managed by CLI
- Backup command may export namespace Secrets to local files (security warning)
- Bearer tokens read from kubeconfig or BearerTokenFile
