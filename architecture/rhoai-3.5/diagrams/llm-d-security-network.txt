RBAC Summary:
- No RBAC resources defined in this repository
- RBAC is defined in component repositories:
  - llm-d-inference-scheduler (EPP RBAC)
  - llm-d-kv-cache (KV cache indexer RBAC)
  - Gateway API Inference Extension Helm charts

Multi-Tenancy:
- Tenant boundary: per-namespace (via InferencePool CRD)
- Deployment model: Single model server pool per InferencePool; multiple pools per cluster
- Isolation: Namespace-scoped InferencePool; NetworkPolicy NOT defined by default
- Gap: No NetworkPolicy in guide manifests — relies on cluster-level defaults

Secrets:
- hf-token (Opaque) — HuggingFace Hub authentication for model downloads
  - Provisioned by: Manual (user-provided)
  - Auto-rotate: No
  - Referenced in guide manifests, not defined in this repository

Security Notes:
- Model servers expose PLAINTEXT HTTP on port 8000 — NO TLS at pod level
- All authentication and authorization is DELEGATED to the Gateway/proxy layer
- If Gateway is misconfigured, model server endpoints are exposed without auth
- Model server runs as non-root (UID 2000, GID 0), compatible with OpenShift restricted SCC
- NIXL KV-cache transfers are unencrypted (RDMA/TCP)
- No FIPS-validated crypto in model server (plaintext HTTP, no TLS)
- UBI9-based images (CUDA, ROCm) inherit FIPS-capable OpenSSL from RHEL base
- Ubuntu-based images (CPU, XPU) do NOT have FIPS-validated OpenSSL

Build Hermeticity:
- No comprehensive lock file (uv.lock) present
- Partial pinning via constraints.txt (torch, nixl)
- Component versions centralized in docker/common-versions
- No Konflux build infrastructure in upstream repo
- No rpms.lock.yaml, no Hermeto/cachi2 prefetch
