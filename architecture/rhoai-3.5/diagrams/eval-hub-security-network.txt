Authentication & Authorization:
- /healthz: Unauthenticated (kubelet probe)
- /api/v1/*: X-Tenant + X-User headers required (injected by kube-rbac-proxy)
- /openapi.yaml, /docs: Unauthenticated (public documentation)
- /metrics: Unauthenticated (local mode only; kube-rbac-proxy fronts in cluster)
- MCP /mcp, /sse: X-User + X-Tenant when auth-type=rbac-proxy

Multi-Tenancy:
- Tenant boundary: per-namespace (X-Tenant header)
- Data isolation: Row-level filtering by tenant column in shared database
- Compute isolation: Jobs created in tenant's namespace, bounded by ResourceQuota
- Risk: Header-based auth; if kube-rbac-proxy bypassed, headers could be spoofed
- Risk: No NetworkPolicy defined by eval-hub; relies on platform operator

Secrets:
- model-ref-secret (Opaque, ephemeral) - Model API credentials; created per-job, deleted after
- test-data-s3-secret (Opaque) - AWS credentials for S3; user-provisioned, no auto-rotate
- OCI docker-config (kubernetes.io/dockerconfigjson) - Docker registry credentials; user-provisioned
- service-ca.crt (ConfigMap, projected) - CA bundle; OpenShift service-ca operator, auto-rotated
- ServiceAccount token (projected) - K8s SA token; 1h expiry for ROSA/STS, auto-rotated

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1 (dynamic linking)
- TLS: MinVersion TLS 1.2, MaxVersion TLS 1.3
- Crypto: stdlib crypto/tls via OpenSSL (FIPS mode)
- No non-FIPS crypto (md5/rc4/des) detected
- InsecureSkipVerify blocked when FIPS enabled
