## Purpose

**Short**: TrustyAI Service is a Python FastAPI application that provides AI model fairness metrics, drift detection, explainability, and inference data management for models served via KServe and ModelMesh on RHOAI.

**Detailed**: trustyai-service (v1.0.0rc0) is a FastAPI-based Python service that ingests inference payloads from KServe v2 and ModelMesh-served models, reconciles input/output pairs into persistent storage (PVC via h5py or MariaDB), and exposes HTTP APIs for computing fairness metrics (SPD, DIR), drift detection (KS test, Jensen-Shannon, Fourier MMD, compare means, mean shift), batch statistics, model explainability (LIME, SHAP, counterfactual, TSSaliency -- currently stubbed as NOT_IMPLEMENTED), and metadata/schema management. Metrics results are published to Prometheus. The service requires Python >=3.12, <3.15 and runs under Uvicorn or Hypercorn ASGI servers. No authentication middleware is registered at the application level; all 87 HTTP endpoints are unprotected by the service itself.

## Data Flows

- **Inference ingestion:** KServe v2 inference requests and responses arrive via `POST /` (cloud events with `ce-id` header) or `POST /consumer/kserve/v2` (ModelMesh partial payloads). The consumer endpoint reconciles matched input/output pairs and persists them to the storage interface (PVC via h5py or MariaDB). <!-- Source: src/endpoints/consumer/consumer_endpoint.py:66-190,443-544 -->
- **Data upload:** Paired request/response payloads can be directly uploaded via `POST /data/upload`, which delegates to the consumer reconciliation flow. <!-- Source: src/endpoints/data/data_upload.py:44-117 -->
- **Metrics computation:** Fairness (SPD, DIR), drift (KS, Jensen-Shannon, Fourier MMD, compare means, mean shift), batch mean, and identity metrics are computed on-demand or via scheduled Prometheus publishing. Results are exposed at `/q/metrics`. <!-- Analyzer-seeded: src/endpoints/metrics/ -->
- **Metadata management:** The `/info` endpoint aggregates model metadata, observation counts, schema information, and scheduled metric summaries from the shared DataSource and PrometheusScheduler. <!-- Source: src/endpoints/metadata.py:80-218 -->
- **Security context:** No authentication middleware is registered. 2 secret references (DATABASE_PASSWORD, QUARKUS_DATASOURCE_PASSWORD) provide database credential inputs for the MariaDB storage backend. <!-- Analyzer-seeded: src/main.py:189; src/service/data/storage/__init__.py:77 -->
