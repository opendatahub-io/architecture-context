## Purpose

**Short**: vllm-cpu is a CPU-optimized fork of the vLLM inference engine providing OpenAI-compatible, Anthropic-compatible, and native API surfaces for high-throughput LLM serving in RHOAI.

**Detailed**: vllm-cpu packages the vLLM high-throughput and memory-efficient inference and serving engine for CPU-based deployments within RHOAI. The component exposes 47 HTTP endpoints and 1 WebSocket endpoint across multiple API compatibility layers — OpenAI (chat completions, completions, embeddings, responses), Anthropic (messages), SageMaker, and native vLLM APIs — plus operational surfaces for health checks, profiling, LoRA adapter management, and disaggregated serving. Authentication is enforced via bearer token through ASGI middleware controlled by the VLLM_API_KEY environment variable. The component includes optional MCP tool integrations (web browsing via Exa API and code interpretation via Docker-based gpt_oss) and a plugin system for LoRA resolver extensions. This description is derived from analyzer-extracted facts enriched with bounded source evidence from 8 files.
