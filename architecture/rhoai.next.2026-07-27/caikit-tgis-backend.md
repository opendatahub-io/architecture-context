## Purpose

**Short**: Caikit module backend providing a gRPC interface for text generation models served by TGIS, with client-side DNS-based load balancing.

**Detailed**: caikit-tgis-backend is a Python gRPC service that implements the FMaaS (Foundation Model as a Service) GenerationService interface for text generation, tokenization, and model info queries. It acts as a Caikit module backend that delegates inference to TGIS (Text Generation Inference Server) via gRPC, with HTTP health checks. The GRPCLoadBalancerProxy component provides DNS-polling client-side load balancing for TGIS connections, supporting both secure (TLS with credentials) and insecure gRPC channels. In RHOAI deployments, this component runs as a co-located container within ModelMesh serving pods, with external authentication delegated to the ModelMesh TLS/auth boundary.
