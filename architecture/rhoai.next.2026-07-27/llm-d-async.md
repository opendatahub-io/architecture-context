## Purpose

**Short**: Async inference request processing framework for LLM serving with flow-control gating, multi-backend message queuing (Redis/Valkey, Google Cloud Pub/Sub), and Prometheus-driven dispatch decisions.

**Detailed**: llm-d-async is an asynchronous inference processing system that forms part of the llm-d project ecosystem. It provides a pipeline-based architecture for managing asynchronous LLM inference requests with pluggable message queue backends (Redis/Valkey sorted sets and Google Cloud Pub/Sub), metric-driven flow control gates that query Prometheus or Google Managed Prometheus (GMP) to make dispatch decisions based on inference pool queue depth, and a health server for Kubernetes liveness/readiness probes. The repository is structured as a Go multi-module monorepo with three local sub-modules (api, pipeline, producer) providing the core API types, pipeline processing framework, and message producer implementations respectively. It integrates with the Gateway API Inference Extension for inference pool metrics and uses OpenTelemetry for distributed tracing. The vLLM model server deployment patch demonstrates the intended companion deployment pattern with GPU-accelerated inference serving.
