## Purpose

**Short**: Data repository containing ML model benchmark results (performance, evaluations, security) packaged as a container init image for the RHOAI model-catalog deployment, with a Python API client for upstream data ingestion.

**Detailed**: models-perf-benchmark-data is a data-only component that stores ML model performance benchmarks, accuracy evaluations, security evaluations, and validation records in NDJSON/JSON format organized by model ID. The repository includes a Python API client (`api-client/`) that fetches benchmark data from an external REST API, serializes and deduplicates it, and writes it to the local data directory. The data is packaged as a container image and deployed as an init container in the `model-catalog` deployment within the `odh-model-registries` namespace. The `model-registry-operator` in the `opendatahub` namespace manages the deployment lifecycle.

## Data Flows

- The `api-client` CLI tool connects to an external benchmark REST API (configured via `API_BASE_URL` environment variable) over HTTPS with configurable TLS verification.
- It fetches paginated data from 7 REST endpoints: `/api/v1/providers`, `/api/v1/models`, `/api/v1/evaluations`, `/api/v1/performances`, `/api/v1/validations`, `/api/v1/variant-groups`, `/api/v1/security`.
- Fetched data is serialized (timestamps converted to epoch-ms, fields normalized), deduplicated by record ID, and post-processed (overall accuracy computation, hardware configuration strings, vLLM runtime commands, modelcar image sizes).
- Output is written as NDJSON files per model (evaluations, performance, security-evaluations) and JSON files (metadata, provider info), with a generated `manifest.json` summarizing the dataset.
- The data directory is packaged as a container image, which is deployed as an init container in the `model-catalog` deployment in the `odh-model-registries` namespace.
