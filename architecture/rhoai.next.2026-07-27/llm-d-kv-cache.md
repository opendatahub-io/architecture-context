## Purpose

**Short**: KV cache indexing and scoring service for LLM inference optimization, providing prefix-aware pod scoring via gRPC and HTTP APIs, with a vLLM filesystem backend connector for KV cache offloading.

**Detailed**: llm-d-kv-cache is a multi-component system for managing and indexing KV (key-value) caches generated by LLM inference engines. It provides a KV Cache Indexer that scores inference pods based on cached prefix overlap, exposing this functionality through both gRPC (IndexerService on port 50051) and HTTP (/score_completions, /score_chat_completions on port 8080) endpoints. A TokenizationService gRPC interface handles tokenization and chat template rendering for prompt processing, supporting multimodal content. The system ingests KV cache events from vLLM engines via ZMQ pub/sub messaging and stores KV block metadata in Redis/Valkey. A PodReconciler controller watches Kubernetes Pods to dynamically discover and subscribe to ZMQ endpoints on inference engine pods. The Python component (llmd_fs_backend) provides a vLLM-integrated filesystem backend connector for KV cache offloading with Prometheus metrics. The architecture exposes 6 runtime components, 10 API identities (3 HTTP endpoints, 7 gRPC services), and 6 integration points including 1 internal platform dependency on the vLLM Serving Runtime.
