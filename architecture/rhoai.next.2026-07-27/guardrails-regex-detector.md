## Purpose

**Short**: Regex-based text content detection service for AI guardrails, exposing a single POST endpoint for content scanning and a health endpoint on a configurable HTTP port.

**Detailed**: guardrails-regex-detector is a lightweight Rust service built on the Axum web framework with Tokio async runtime. It provides regex-based text content detection as part of the AI guardrails system. The service exposes two HTTP endpoints on a single listener: a POST endpoint at `/api/v1/text/contents` for text content scanning (handled by the `detectors` module), and a GET `/health` endpoint returning a static health status. The server binds to a configurable host (default `0.0.0.0`, `HOST` env var) and port (default `8080`, `HTTP_PORT` env var). Request tracing is enabled via `tower-http` TraceLayer middleware. No TLS termination or authentication middleware is configured at the application level; these are expected to be handled by the deployment infrastructure.
