## Purpose

**Short**: Container image build repository producing the `odh-vllm-rocm-rhel9` image for GPU-accelerated LLM inference on AMD ROCm hardware, exposing OpenAI-compatible HTTP and TGIS gRPC serving endpoints via the vllm-tgis-adapter.

**Detailed**: vllm-rocm is a thin downstream packaging repository that builds a container image from the RHAIIS `vllm-rocm-rhel9` base image (version 3.2.1). The repository contains no application source code; the runtime is inherited entirely from the base image, which bundles vLLM (a high-performance LLM inference engine using PagedAttention) compiled for AMD ROCm GPUs together with the `vllm_tgis_adapter` Python module. The adapter provides an OpenAI-compatible HTTP API on port 8000 and a TGIS-compatible gRPC API on port 8033. The image runs as non-root user 2000 and is built via Konflux CI/CD pipelines synchronized from the `konflux-central` repository.
