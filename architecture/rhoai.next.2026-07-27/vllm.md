## Purpose

**Short**: Container image build repository that packages vLLM with the TGIS gRPC adapter for GPU-accelerated LLM inference serving in RHOAI, exposing an OpenAI-compatible HTTP API on port 8000 and TGIS gRPC on port 8033.

**Detailed**: This repository produces the `odh-vllm-cuda-rhel9` container image for Red Hat OpenShift AI. It layers the vllm-tgis-adapter entrypoint on top of the upstream RHAIIS vLLM CUDA base image (`registry.redhat.io/rhaiis/vllm-cuda-rhel9:3.2.2`). The resulting container serves LLM inference requests via an OpenAI-compatible REST API (port 8000, uvicorn) and a TGIS-compatible gRPC interface (port 8033). The repository contains no application source code; the runtime is inherited entirely from the base image. Build and CI are managed through Konflux pipelines referencing `red-hat-data-services/konflux-central`.
