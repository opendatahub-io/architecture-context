## Purpose

**Short**: ODH/RHOAI platform module operator that deploys and manages the upstream Feast operator for feature store lifecycle management.

**Detailed**: feast-module-operator is an ODH/RHOAI platform component operator that manages the lifecycle of the upstream Feast operator. It is a Cobra CLI application with two subcommands: `operator` (runs the controller-manager reconciling `FeastOperator` CRs) and `chartgen` (generates Helm charts). The operator implements the `common.PlatformObject` interface from opendatahub-operator, bridging the ODH/RHOAI platform component model with the upstream Feast `FeatureStore` CRD. The `FeastOperator` CR is a cluster-scoped singleton (name must be `default-feastoperator`) that configures OIDC issuer settings and tracks component release status. The operator creates and reconciles Deployments, Services, ConfigMaps, RBAC resources, ServiceMonitors, CronJobs, PersistentVolumeClaims, HorizontalPodAutoscalers, PodDisruptionBudgets, and OpenShift Routes on behalf of the managed Feast operator.
