## Purpose

**Short**: ModelMesh runtime adapter providing gRPC sidecar adapters for Triton, MLServer, and TorchServe model serving runtimes, plus a model-serving puller for object storage downloads.

**Detailed**: modelmesh-runtime-adapter is a Go application (module `github.com/kserve/modelmesh-runtime-adapter`, Go 1.23.6) that implements the ModelMesh `mmesh.ModelRuntime` sidecar gRPC interface and adapts it to backend-specific inference protocols. It contains four adapter sub-components: the Triton adapter (NVIDIA Triton Inference Server), the MLServer adapter (Seldon MLServer), the TorchServe adapter (PyTorch TorchServe), and the model-serving puller. Each adapter translates the ModelMesh `loadModel`/`unloadModel`/`runtimeStatus` contract into the backend's native gRPC API. The puller component (`pullman`) downloads model artifacts from Azure Blob Storage, Google Cloud Storage, or IBM Cloud Object Storage (S3-compatible) before the runtime loads them. The repository defines 6 distinct gRPC service interfaces across 7 proto files spanning KFServing V2 inference, MLServer dataplane, ModelMesh control plane, ModelRuntime sidecar, TorchServe inference/management, and Triton inference protocols. No HTTP endpoints are exposed. No application-level authentication interceptors are configured; all gRPC services rely on external platform-level enforcement (e.g., Istio service mesh). The `controller-runtime` dependency is used only for logging (go.mod comment), not as an operator framework. Python dependencies (requirements.txt) support a TensorFlow protobuf generation utility script (tf_pb.py), not runtime components.
