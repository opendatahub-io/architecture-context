## Purpose

**Short**: Caikit NLP module library providing text generation, token classification, and tokenization capabilities for the Caikit AI runtime, with local HuggingFace Transformers inference and remote TGIS gRPC backend support.

**Detailed**: caikit-nlp is a Python module library within the Caikit AI framework that implements NLP tasks including text generation (local and TGIS-backed), token classification (filtered span classification), and tokenization (regex sentence splitting). It does not run as a standalone service; instead, it registers modules with the Caikit runtime which exposes them via a gRPC server (default port 8085) and an optional REST gateway (default port 8080). For text generation, it supports both local inference using HuggingFace Transformers models and remote inference via gRPC to a TGIS (Text Generation Inference Server) backend. TLS and mTLS are configurable via environment variables.
