## Purpose

**Short**: Python client library providing explainability, fairness metrics, and model-trust tooling that bridges to the TrustyAI Java library via JPype JVM and communicates with TrustyAI Service over HTTP.

**Detailed**: trustyai-explainability-python is a Python SDK that wraps the TrustyAI Java explainability library via a JPype JVM bridge. It provides explainers (LIME, SHAP, PDP, Counterfactual), fairness and distance metrics, language toxicity detection, and visualization utilities. The `TrustyAIMetricsService` client class connects to the TrustyAI Service and Thanos Querier endpoints on an RHOAI/ODH cluster, using OpenShift Bearer-token authentication and OpenShift Route discovery via the Kubernetes Python client. The library does not expose its own HTTP or gRPC endpoints; it is consumed as a pip-installable package within notebooks or user workloads. Version 0.6.1.

- **Runtime inventory:** The library is consumed as a Python package inside user workloads (notebooks, scripts). It initializes a JVM via JPype and loads the TrustyAI Java explainability JAR to perform local explainability computations (LIME, SHAP, PDP, Counterfactual).
- **Outbound HTTP interactions:** `TrustyAIMetricsService` makes authenticated HTTPS calls to three categories of endpoints discovered via OpenShift Routes:
  1. **TrustyAI Service** (`trustyai-service` route): `POST /data/upload`, `GET /info`, `POST /info/names`, `POST /metrics/{metric}`, `POST /metrics/{metric}/request`.

## Architectural Analysis

- **Deployment shape:** Client library (Python package), not a standalone service. Consumed via `pip install trustyai` within notebooks or user workloads on RHOAI/ODH clusters. Version 0.6.1.
- **JVM bridge pattern:** The library embeds a Java Virtual Machine via JPype to access the TrustyAI Java explainability engine. The initializer loads `explainability-arrow-999-SNAPSHOT.jar` and configures JVM args including `--add-opens=java.base/java.nio=ALL-UNNAMED` for Arrow compatibility.
- **Service discovery:** Uses the Kubernetes Python dynamic client to discover OpenShift Routes by name and namespace, constructing HTTPS URLs from `spec.host`. Falls back from in-cluster config to local kubeconfig.
- **Authentication model:** Delegates authentication to the caller. The `TrustyAIMetricsService` constructor accepts an OpenShift OAuth Bearer token and passes it via `Authorization` header to all outbound HTTP requests. No inbound authentication surface exists.
- **Evidence boundary:** Analyzer coverage is partial for agent_baseline, platform_semantics, python, and webhooks_source. No HTTP endpoints or gRPC services are exposed by this library. Dynamic behavior outside the extracted literal and manifest evidence is not asserted.
