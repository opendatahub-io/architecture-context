## Purpose

**Short**: Pluggable Envoy external processing (ExtProc) gRPC service and Kubernetes controller for intelligent LLM inference request routing, scheduling, and flow control within inference pools.

**Detailed**: llm-d-inference-scheduler (internally named llm-d-router) implements the Endpoint Picker (EPP), an Envoy External Processing gRPC service that intercepts inference requests and routes them to optimal model-serving endpoints using a configurable plugin framework. The EPP supports multiple request protocol parsers (OpenAI, Anthropic, vLLM gRPC/HTTP, Vertex AI, passthrough), a scheduling framework with filters, scorers, pickers, and profile handlers (single, disaggregated/prefill-decode, data-parallel), a request control layer with admission control and data producers, and an experimental flow control layer with priority bands, fairness policies, and ordering policies. Four Kubernetes controllers reconcile InferenceModelRewrite, InferenceObjective, InferencePool, and Pod resources to maintain the routing datastore. The system is configured via the EndpointPickerConfig CRD and supports both Kubernetes-based and file-based endpoint discovery modes. Its documented interface surface contains 7 API identities, including 3 HTTP endpoints, 2 gRPC services, and 3 custom resource identities. The extracted dependency view records 5 internal platform dependencies and 12 integration points.
