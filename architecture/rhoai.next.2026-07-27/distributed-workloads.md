## Purpose

**Short**: Distributed training workloads, runtime container images, and benchmarks for RHOAI, orchestrated via Kubeflow TrainJob, KubeRay, and Kueue on OpenShift.

**Detailed**: distributed-workloads provides pre-built container images and example workloads for distributed machine learning training on Red Hat OpenShift AI. The repository contains runtime images for multiple accelerator backends (NVIDIA CUDA 13.0, AMD ROCm 6.4, CPU), universal training images, and benchmarks demonstrating MPI+DDP supervised fine-tuning via Kubeflow TrainJob. Its Go test harness integrates with Kubeflow Trainer v2, the legacy Kubeflow Training Operator, KubeRay, Kueue for job queueing, and OpenShift APIs. Supporting infrastructure includes MinIO for S3-compatible object storage used in examples and hyperparameter optimization workflows. The Python runtime images bundle the RHOAI-specific Kubeflow SDK, MLflow, Model Registry, InstructLab Training, and Training Hub libraries for end-to-end training pipelines.
