## Purpose

**Short**: Kubernetes operator that manages the lifecycle of the Kubeflow Trainer component within RHOAI, deploying and reconciling training infrastructure including CRDs, RBAC, webhooks, and runtimes.

**Detailed**: trainer-operator is a platform-level Kubernetes operator that manages the Kubeflow Trainer component for Red Hat OpenShift AI. It reconciles a singleton `Trainer` custom resource (which must be named `default-trainer`) to deploy and manage the upstream Kubeflow Trainer controller manager, its CRDs (`TrainJob`, `TrainingRuntime`, `ClusterTrainingRuntime`), validating webhooks, RBAC roles, and associated runtimes. The operator uses embedded manifest templates from `/opt/manifests-template`, `/opt/runtimes-template`, and `/opt/imagestreams-template`, rendering them into a work directory at `/opt/manifests-work`. It implements the `common.PlatformObject` interface from odh-platform-utilities, integrating with the ODH/RHOAI platform's condition-based health reporting and release tracking. The controller uses label-scoped caches filtered by `platform.opendatahub.io/part-of: trainer` to limit memory consumption, and supports namespace-scoped caching via the `APPLICATIONS_NAMESPACE` environment variable injected by the platform operator.
