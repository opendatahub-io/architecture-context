## Purpose

**Short**: Source-backed analysis represents pipelines-components as a KFP component library with 4 functional domains, 0 inbound API identities, and 8 integration points.

**Detailed**: pipelines-components is a collection of reusable Kubeflow Pipelines (KFP) components and pipelines for Red Hat OpenShift AI. The package (kfp-components v1.11.0) provides `@dsl.component`-decorated Python functions organized into four functional domains: data processing, deployment, evaluation, and training. Data processing components handle dataset download (HuggingFace, S3, HTTP, PVC), PDF parsing and chunking (via Ray + Docling), synthetic data generation (via SDG Hub), AutoML tabular data loading, and vector database ingestion. Deployment components manage model serving via KServe and Model Registry. Evaluation components provide inference evaluation via KServe and language model evaluation. Training components support LoRA/SFT/OSFT fine-tuning, AutoML (AutoGluon), and AutoRAG optimization. Components run as pipeline steps within Kubeflow Pipelines and do not expose standalone HTTP or gRPC services. All external authentication is credential-based via Kubernetes Secrets and environment variables.
