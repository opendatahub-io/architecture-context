## Purpose

**Short**: CLI-driven language model evaluation framework with pluggable model backends (Anthropic, OpenAI, Watsonx, HuggingFace) and S3 asset management, used in RHOAI for automated LLM benchmarking.

**Detailed**: lm-evaluation-harness is a fork of the EleutherAI lm-evaluation-harness (v0.4.8) customized for Red Hat OpenShift AI. It provides a CLI tool (`lm-eval`) that evaluates language models against configurable benchmark tasks. The framework supports multiple model backends registered through a plugin architecture: HuggingFace Transformers (default), Anthropic (completions and chat), IBM Watsonx AI, and OpenAI (completions and chat). It integrates with the eval-hub-sdk adapter for RHOAI platform evaluation orchestration. An S3 downloader utility enables pre-fetching evaluation assets from S3-compatible storage. The harness outputs evaluation metrics as JSON, supports result push to HuggingFace Hub and Weights & Biases, and operates as a batch CLI process without exposing HTTP or gRPC services.
