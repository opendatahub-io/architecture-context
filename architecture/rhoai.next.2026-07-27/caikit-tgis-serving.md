## Purpose

**Short**: Caikit-TGIS serving runtime packaging for deploying text generation models via KServe InferenceService on RHOAI.

**Detailed**: caikit-tgis-serving packages the Caikit AI runtime with the TGIS (Text Generation Inference Service) gRPC backend for serving text generation models on Red Hat OpenShift AI. It provides KServe InferenceService and ServingRuntime definitions for both HTTP and gRPC inference protocols, a model conversion utility for transforming HuggingFace models to Caikit format, and demo manifests for Knative Serving with Istio gateway configuration. The component integrates with MinIO/S3-compatible storage for model artifacts and exposes Prometheus-compatible metrics.
