## Purpose

**Short**: Kubernetes operator managing AppWrapper custom resources and RayCluster lifecycle with admission webhooks, Kueue quota integration, and multi-framework distributed workload orchestration on RHOAI.

**Detailed**: codeflare-operator is a Kubernetes operator / controller that manages the AppWrapper custom resource (workload.codeflare.dev/v1beta2) and orchestrates RayCluster lifecycle for distributed computing workloads. It provides mutating and validating admission webhooks for both AppWrapper and RayCluster resources. The operator integrates with Kueue for quota management via AppWrapper PodSetInfos (injecting labels, annotations, nodeSelectors, tolerations, and schedulingGates), manages PodGroups for gang scheduling through both scheduling.sigs.k8s.io and scheduling.x-k8s.io API groups, and supports multi-framework workloads including KubeRay RayClusters/RayJobs, Kubeflow PyTorchJobs, and Kubernetes JobSets. The RayClusterReconciler owns Services, ServiceAccounts, Ingresses, NetworkPolicies, and Routes for each RayCluster, and watches ClusterRoleBindings. The operator reads DSCInitialization CRs to obtain RHOAI platform initialization state and uses the opendatahub-operator Go library for runtime integration.
