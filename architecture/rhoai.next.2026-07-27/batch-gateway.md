## Purpose

**Short**: Batch inference gateway providing an OpenAI-compatible API for asynchronous batch job submission, processing, and lifecycle management with S3 storage, PostgreSQL persistence, and Redis queue coordination.

**Detailed**: batch-gateway is a multi-binary Go service comprising three independently deployable components: an API server that accepts batch inference requests via an OpenAI-compatible REST API, a processor that dequeues jobs from Redis and dispatches them to model gateways (supporting async, global, and per-model dispatch modes), and a garbage collector that periodically removes expired batch jobs and files with optional orphan reconciliation. All binaries are built as static Go binaries (CGO_ENABLED=0) and run as non-root user 65532 on distroless base images. The system integrates with PostgreSQL for persistent state, Redis/Valkey for queue coordination, S3-compatible storage for batch input/output files, and llm-d inference gateways for model serving. Authentication is not enforced within the service; the architecture delegates authentication to an external Envoy ext_authz sidecar that injects identity headers.
