## Purpose

**Short**: Kubeflow Trainer controller manager for distributed ML training job lifecycle management on OpenShift, providing TrainJob orchestration via JobSet with gang scheduling support.

**Detailed**: trainer is a Kubernetes Operator / Controller that manages the lifecycle of distributed machine learning training jobs through the TrainJob CRD. The controller manager (`kubeflow-trainer-controller-manager`) reconciles TrainJob resources by resolving them against TrainingRuntime or ClusterTrainingRuntime templates, then creating downstream JobSet workloads for distributed execution. The operator integrates with gang scheduling systems (Kubernetes Scheduler Plugins CoScheduling and Volcano) for coordinated pod scheduling, manages MPI-based distributed training via ConfigMap and Secret watches, and enforces admission validation through three validating webhooks. The controller resolves the OpenShift cluster TLS profile for webhook and metrics server encryption, and uses OPA cert-controller for automated webhook certificate management. Its documented interface surface contains 9 API identities, including 5 HTTP endpoints and 4 custom resource definitions. The extracted dependency view records 4 internal platform dependencies and 14 integration points.
