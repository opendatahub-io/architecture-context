## Purpose

**Short**: ai4rag is a Python library for automatic and optimized RAG (Retrieval-Augmented Generation) pattern generation, with S3-based document ingestion, Docling-powered text extraction, OGX and Chroma vector stores, and scikit-learn/pyGAM-based optimization.

**Detailed**: ai4rag provides a modular pipeline for constructing RAG patterns over enterprise document corpora. The library handles document discovery and download from S3-compatible storage (via boto3), text extraction and conversion through the Docling document processing framework (supporting PDF, DOCX, PPTX, HTML, Markdown, and plain text), text chunking via LangChain text splitters, vector storage through OGX and Chroma backends, embedding generation via OGX, and RAG template optimization using scikit-learn and pyGAM. It uses multiprocess-based parallelism for extraction workloads and Pydantic for data validation. The library ships as a Python package (Python >=3.12, <3.14) with no inbound HTTP or gRPC service surfaces; it is consumed as a library dependency. Source evidence: `pyproject.toml:6-48`, `ai4rag/components/data/text_extraction.py:1-587`.
