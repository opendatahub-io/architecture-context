## Purpose

**Short**: Algorithm-focused Python library providing a pluggable backend architecture for common language model training, continual learning, and reinforcement learning techniques.

**Detailed**: training_hub is a Python library (not a deployed service) that provides a unified API for language model fine-tuning and optimization. It implements a three-layer architecture: user-facing convenience functions (`sft()`, `osft()`, `lora_sft()`, `lora_grpo()`, `gepa()`), an algorithm layer defining training strategies (SFT, OSFT, LoRA, GRPO, GEPA), and a pluggable backend layer that delegates to external training frameworks (instructlab-training, rhai-innovation-mini-trainer, unsloth, openpipe-art, verl). The `AlgorithmRegistry` provides runtime discovery and selection of algorithm-backend combinations. Auxiliary modules include GPU memory profiling/estimation, ITS Hub rollout integration for GRPO training, reward functions for tool-call verification, and loss visualization. Source: `src/training_hub/__init__.py:1-48`, `src/training_hub/algorithms/__init__.py:1-97`, `docs/api/backends/README.md:1-275`.
