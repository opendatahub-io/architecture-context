RBAC Summary:
- No ClusterRoles defined
- No RoleBindings defined
- No ServiceAccounts defined
- Component runs as a CLI batch process, not a Kubernetes controller

Service Mesh Configuration:
- Not applicable — CLI batch process with no inbound service endpoints
- No PeerAuthentication, no AuthorizationPolicy

Secrets / Credentials:
- HF_TOKEN (environment variable) — HuggingFace Hub authentication
  - Provisioned by: runtime environment
  - Auto-Rotate: Unknown
- ANTHROPIC_API_KEY (environment variable) — Anthropic API authentication
  - Provisioned by: runtime environment
  - Auto-Rotate: Unknown
- WATSONX_API_KEY (environment variable) — IBM Watsonx AI authentication
  - Provisioned by: runtime environment
  - Auto-Rotate: Unknown
- OPENAI_API_KEY (environment variable) — OpenAI API authentication
  - Provisioned by: runtime environment
  - Auto-Rotate: Unknown
- AWS_SECRET_ACCESS_KEY (environment variable) — S3-compatible storage access
  - Provisioned by: runtime environment
  - Auto-Rotate: Unknown

Note: All credentials are injected via environment variables. No Kubernetes
Secrets or cert-manager certificates are used. All authentication is
outbound client-side credential injection.

Offline Mode:
- When HF_EVALUATE_OFFLINE=1 is set, metrics are loaded from local path
  (LMEVAL_METRICS_PREFIX) instead of downloading from HuggingFace Hub.
- This eliminates the HuggingFace Hub egress dependency for metrics.
