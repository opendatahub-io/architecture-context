Custom Resource Definitions:
- InferencePool (inference.networking.k8s.io/v1) - Namespaced
  - Groups model-serving Pods by label selector
  - References EPP via Spec.EndpointPickerRef
  - FailOpen/FailClose failure behavior (default FailClose)
- EndpointPickerConfig (inference.networking.x-k8s.io/v1alpha1) - Namespaced
  - Configuration-only CRD (no controller)
  - Defines plugin pipeline: SchedulingProfiles, DataLayer, SaturationDetector,
    FlowControl, Parser
- InferenceModelRewrite (inference.networking.x-k8s.io/v1alpha2) - Namespaced
  - Model name rewriting with weighted traffic distribution
  - References parent InferencePool via poolRef
- InferenceObjective (inference.networking.x-k8s.io/v1alpha2) - Namespaced
  - Per-workload priority levels for flow control
  - References parent InferencePool via poolRef
- InferencePoolImport (inference.networking.x-k8s.io/v1alpha1) - Namespaced
  - Cross-cluster pool federation (status-only CRD)

RBAC Summary:
- No RBAC rules included in component manifests
- RBAC expected to be provisioned by deployment mechanism
- CRD validation uses CEL expressions

Security Notes:
- No application-level authentication on gRPC services
- Transport TLS is optional and configuration-dependent
- No Secret resources referenced by component
- Kubernetes API access via standard ServiceAccount authentication
- 18 HTTPRoute ingress identities (conformance test fixtures, not production)
