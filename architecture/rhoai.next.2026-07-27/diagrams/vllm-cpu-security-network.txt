RBAC Summary:
- No Kubernetes RBAC roles defined (Application Service, not an Operator)
- Access control is application-level via bearer token middleware

Authentication & Authorization:
- Mechanism: Bearer token via ASGI AuthenticationMiddleware
- Token Source: VLLM_API_KEY environment variable
- Scope: All HTTP endpoints on production OpenAI-compatible server
- Warning: Demo API server (vllm/entrypoints/api_server.py) does NOT
  include authentication middleware - not for production use

Secrets / Environment Variables:
- VLLM_API_KEY (runtime) - Bearer token for API authentication
- S3_SECRET_ACCESS_KEY (runtime) - S3 model storage access
- EXA_API_KEY (runtime) - Exa search API for MCP tool
- MODELSCOPE_API_TOKEN (runtime) - ModelScope model downloads
- OPENAI_API_KEY (benchmark-only) - Used in benchmark scripts
- VLLM_BENCH_MAX_TOKENS (benchmark-only) - Benchmark configuration
- GH_TOKEN (build-time) - GitHub access for CI/builds
- GITHUB_TOKEN (build-time) - GitHub access for CI/builds
- VLLM_USE_FASTOKENS (configuration) - Not secret material
- VLLM_MAX_TOKENS_PER_EXPERT_FP4_MOE (configuration) - Not secret material
- VLLM_SHARED_EXPERTS_STREAM_TOKEN_THRESHOLD (configuration) - Not secret
- VLLM_MULTI_STREAM_GEMM_TOKEN_THRESHOLD (configuration) - Not secret

SSL/TLS Configuration:
- Optional TLS via CLI arguments:
  --ssl-keyfile: Path to SSL key file
  --ssl-certfile: Path to SSL certificate file
  --ssl-ca-certs: Path to CA certificates
  --enable-ssl-refresh: Enable automatic certificate refresh
- When not configured, server runs plaintext HTTP on port 8000
