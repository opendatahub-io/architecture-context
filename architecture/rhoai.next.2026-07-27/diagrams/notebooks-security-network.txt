RBAC Summary:
- No RBAC roles defined in this repository
- RBAC is managed by the RHOAI Notebook Controller and Dashboard
- Notebook pods use per-notebook ServiceAccounts created by the controller

Secrets:
- RENOVATE_TOKEN (environment variable) - CI only, not in runtime images
- JIRA_API_TOKEN (environment variable) - CI only, not in runtime images
- JIRA_TOKEN (environment variable) - CI only, not in runtime images
- JIRA_OAUTH_CLIENT_SECRET (environment variable) - CI only, not in runtime images
Note: All 4 secrets are CI/build-time only. Runtime notebook images use
ServiceAccount tokens (auto-mounted) and user-provided credentials for
platform service access.

Authentication Flow:
- Inbound: OpenShift OAuth via OAuth Proxy sidecar (platform-delegated)
- JupyterLab itself has NO authentication middleware
- Outbound to K8s API: ServiceAccount token (auto-mounted by kubelet)
- Outbound to platform services: ServiceAccount token or user-configured credentials
- Outbound to external storage: User-provided credentials (S3 keys, etc.)

Network Policy:
- No NetworkPolicy defined in this repository
- Network isolation managed by RHOAI platform-level policies
