Protocol Translation Summary:
  Inbound:  HTTP/JSON (KServe Predict V2 REST API)
  Outbound: gRPC (GRPCInferenceService protobuf)
  Direction: Bidirectional (request + response translation)

Tensor Data Types Handled:
  - BOOL, INT8, INT16, INT32, INT64
  - UINT8, UINT16, UINT32, UINT64
  - FP32, FP64 (FP16 NOT supported)
  - BYTES (base64 encoded)
  - Raw binary output contents (little-endian)
  - Multi-dimensional arrays (nested JSON ↔ flat tensors)

TLS Configuration:
  - Inbound TLS: Optional, controlled by REST_PROXY_USE_TLS
    - Certificate: MM_TLS_KEY_CERT_PATH
    - Private Key: MM_TLS_PRIVATE_KEY_PATH
  - Outbound TLS: Optional, same REST_PROXY_USE_TLS flag
    - Skip verification: REST_PROXY_SKIP_VERIFY
  - When TLS disabled: Plaintext HTTP inbound, plaintext gRPC outbound

RBAC Summary:
  - No Kubernetes RBAC roles or bindings defined
  - No CRDs defined or watched
  - No Kubernetes API interactions
  - Component operates purely as a network proxy

Authentication:
  - No application-level authentication middleware
  - Transport-level TLS only (mutual authentication not configured)
  - Relies on pod-level network policies and service mesh for access control

Container Security:
  - Runs as non-root user (UID 2000)
  - Statically compiled binary (no dynamic library dependencies)
  - Minimal base image (ubi9/ubi-micro:9.5)
  - No shell or package manager in runtime image
