RBAC Summary:
- No ClusterRoles or RoleBindings defined by kubeflow-sdk itself.
- RBAC permissions depend on the kubeconfig or ServiceAccount used at runtime.
- Required permissions (delegated to user's identity):
  - API Groups: trainer.kubeflow.org, katib.kubeflow.org, sparkoperator.k8s.io
  - Resources: trainjobs, experiments, sparkconnects
  - Verbs: get, list, watch, create, update, patch, delete

Secrets:
- No secrets provisioned by kubeflow-sdk.
- Runtime secrets are user-managed:
  - kubeconfig file (client certs or bearer tokens for K8s API access)
  - AWS credentials (for S3 storage access via fsspec/s3fs)
  - Model Registry credentials (depends on deployment)

Authentication Model:
- Delegated entirely to kubernetes Python client
- KubernetesBackendConfig supports:
  - config_file: path to kubeconfig
  - context: kubeconfig context name
  - client.Configuration: explicit client config
  - In-cluster: automatic SA token mounting

Network Posture:
- INBOUND: None (pure client library, no listening ports)
- OUTBOUND: Kubernetes API (6443/TCP), S3 (443/TCP), Model Registry (varies)
- No service mesh participation (not a deployed workload)
- No ingress/egress policies defined (not a Kubernetes resource)
