  - batch.llm-d.ai: llmbatchgateways/status (get, patch, update)

  - gateway.networking.k8s.io: referencegrants (get, list, watch)
  - monitoring.coreos.com: podmonitors, prometheusrules, servicemonitors (full CRUD + watch)

Aggregate Roles:
  - llm-d-batch-gateway-admin: full CRUD on llmbatchgateways + status read
  - llm-d-batch-gateway-view: read-only on llmbatchgateways + status
  - admin (aggregate): full CRUD on llmbatchgateways + status read
  - view (aggregate): read-only on llmbatchgateways + status

Leader Election:
  - Role: llm-d-batch-gateway-leader-election-role
  - Namespace: redhat-ods-applications
  - Resources: coordination.k8s.io/leases (full CRUD), events (create, patch)

Cross-Namespace Secret Access:
  - Mechanism: ReferenceGrant authorization check before cross-ns Secret copy
  - Source: spec.secretRef.namespace (remote namespace)
  - Target: <gateway-name>-credentials in CR namespace
  - Enforcement: gateway.networking.k8s.io/v1beta1/ReferenceGrant

CRD Validation:
  - CEL rule: tlsInsecureSkipVerify is disallowed
  - Async mode: spec.processor.asyncConfig required when dispatchMode=async

Authentication & Authorization:
  - :8081/healthz  → No auth (Kubernetes health probe by design)
  - :8081/readyz   → No auth (Kubernetes readiness probe by design)
  - Kubernetes API → ServiceAccount token (in-cluster), RBAC enforced
  - Managed workloads → Credentials from spec.secretRef Secret
