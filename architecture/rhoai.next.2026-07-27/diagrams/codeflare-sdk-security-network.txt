TLS Certificate Resolution:
- Priority 1: Explicit CA cert path (constructor parameter)
- Priority 2: CF_SDK_CA_CERT_PATH environment variable
- Priority 3: OpenShift workbench default: /etc/pki/tls/custom-certs/ca-bundle.crt
- skip_tls option: Disables TLS verification (development only)
  - Suppresses urllib3 InsecureRequestWarning

RBAC Summary:
- No ClusterRoles defined (client library, not an operator)
- No RoleBindings defined
- SDK relies on the calling user's RBAC permissions
- Authentication delegated to Kubernetes API server

Secrets:
- minio-secret (Opaque) - TEST ONLY, not shipped
  - Contains: MinIO access credentials
  - Provisioned by: e2e test manifest
  - Auto-Rotate: Unknown

Inbound Attack Surface:
- NONE - codeflare-sdk is a pure client library
- No listening ports, no HTTP/gRPC servers
- No webhooks, no CRD controllers
- Runs entirely client-side within user notebooks/workbenches

Outbound Connections:
- Kubernetes API Server (6443/TCP, HTTPS, Bearer/kubeconfig/SA token)
- Ray Cluster Dashboard (8265/TCP, HTTP/HTTPS, configurable headers/cookies)

OpenShift Integration:
- SDK references route.openshift.io API group for cluster endpoint discovery
- Uses OpenShift Routes to determine Ray cluster dashboard URLs
