RBAC Summary:
- No RBAC roles defined. The component does not interact with the Kubernetes API.

Multi-Tenancy:
- Tenant boundary: Per-request HTTP header (configurable, default X-MaaS-Username)
- Model: Multi-tenant (single instance serves all tenants)
- Isolation: Application-level query filtering by tenant_id
- Storage isolation: SHA256(tenant_id) as filesystem/S3 prefix
- Gap: No per-tenant NetworkPolicy, resource limits, or auth within application
- Gap: Tenant header spoofable without upstream auth proxy

Secrets:
- batch-gateway-secrets (Opaque)
  - redis-url: Redis/Valkey connection URL
  - postgresql-url: PostgreSQL connection URL
  - inference-api-key: Inference gateway API key
  - s3-secret-access-key: S3 credentials
  - Provisioned by: Manual (kubectl create secret generic)
  - Auto-Rotate: No

- {release}-batch-gateway-apiserver-tls (kubernetes.io/tls)
  - TLS certificate and key for API server HTTPS
  - Provisioned by: cert-manager (when tls.certManager.enabled) or manual
  - Auto-Rotate: Yes (cert-manager) / No (manual)

FIPS Compliance:
- Current: CGO_ENABLED=0, distroless/static base → FAILS check-payload
- Required for RHOAI: UBI base, CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime
- TLS: crypto/tls MinVersion TLS 1.2, stdlib only
- Non-critical crypto: SHA256 for tenant ID hashing

Authentication Flow:
- No application-level authentication
- Tenant ID extracted from HTTP header (X-MaaS-Username)
- Authentication expected at upstream proxy (Envoy ext_authz)
- Authorization pass-through headers: [Authorization]
