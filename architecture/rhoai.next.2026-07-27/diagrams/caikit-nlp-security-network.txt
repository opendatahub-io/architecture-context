RBAC Summary:
- No Kubernetes RBAC roles defined (caikit-nlp is a Python library, not a K8s operator)
- Authentication and authorization are delegated to:
  - Caikit Runtime (transport-level TLS/mTLS)
  - Platform infrastructure (OpenShift Service Mesh, Istio, etc.)

Service Mesh Configuration:
- Not directly configured by caikit-nlp
- TLS/mTLS transport security is configurable via environment variables
- Platform-level service mesh (e.g., Istio sidecar) provides additional mTLS enforcement

Secrets:
- TLS certificates: Configured via environment variables (paths to cert/key files)
- HuggingFace API token: Optional, for accessing private model repositories
- TGIS connection credentials: Configured via environment variables for mTLS to TGIS backend

Environment Variables (Security-Relevant):
- TLS/mTLS configuration for gRPC server and TGIS client connections
- Model storage paths and credentials
- HuggingFace Hub token for private model access
