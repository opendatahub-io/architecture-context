Authentication Summary:
- /healthz, /readyz: Unauthenticated (health probes by design)
- Kubernetes API access: ServiceAccount token (in-cluster), RBAC enforced
- Webhook endpoints: Kubernetes admission (API server authenticates)
- security_proxy: Token-based auth (HTTP path-prefix + gRPC Authorization header)
- kuberay-apiserver: APIServerInterceptor (semantics not fully resolved)

Secrets:
- No explicitly declared secrets in architecture
- TLS certificates managed via cert-manager CRDs
- ServiceAccount tokens managed by Kubernetes

Unresolved Security Items:
- APIServerInterceptor authentication semantics not fully resolved from source
- security_proxy token validation logic details not fully resolved
- gRPC services (ClusterService, ComputeTemplateService, etc.) have unresolved
  interceptors/credentials
