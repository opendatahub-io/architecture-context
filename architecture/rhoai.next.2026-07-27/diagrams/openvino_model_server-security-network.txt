Security Posture Summary:
- OVMS has NO built-in authentication or authorization
- All security is delegated to KServe/Istio service mesh layer
- Container hardening:
  - runAsNonRoot: true
  - runAsUser: 5000
  - Capabilities: ALL dropped
  - allowPrivilegeEscalation: false
- Optional NGINX mTLS sidecar for certificate-based mutual authentication

RBAC Summary:
- No cluster roles or role bindings defined by OVMS itself
- OVMS runs as a serving container within KServe-managed pods
- RBAC is managed by KServe operator

Secrets:
- No secrets directly managed by OVMS
- Model storage credentials managed by KServe storage initializer
- Optional: TLS certificates for NGINX mTLS sidecar pattern

Supported Model Formats:
- OpenVINO IR (opset13)
- ONNX
- TensorFlow 1/2
- PaddlePaddle 2
- PyTorch 2
- Hugging Face generative models
- vLLM (non-autoSelect)
