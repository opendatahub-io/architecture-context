Network Policies:
- No NetworkPolicy defined — no network-level isolation between TGIS instances

Security Risks:
- FIPS: Rust router uses rustls (pure-Rust TLS, not OpenSSL-backed)
  May not use FIPS-validated crypto provider at runtime
  Python server communicates over local UDS only (no TLS)
- No per-request authorization — any client with valid cert can access all endpoints
- No NetworkPolicy — all pods in namespace can reach TGIS
- TRUST_REMOTE_CODE env var — if enabled, allows arbitrary code execution during model load

Container Security:
- Optional readOnlyRootFilesystem (via patch)
- emptyDir mounts for /home/tgis and /tmp when read-only enabled
- 1Gi emptyDir for /dev/shm (NCCL shared memory)
- Model weights mounted read-only from PVC

- Cargo.lock: Present (Rust dependency lock)
- poetry.lock: Present (Python dependency lock)
- rpms.lock.yaml: Absent (no OS-level lock)
- Hermeto/cachi2: Not used (no hermetic prefetch)
- Build installs from public PyPI and NVIDIA repos at build time
