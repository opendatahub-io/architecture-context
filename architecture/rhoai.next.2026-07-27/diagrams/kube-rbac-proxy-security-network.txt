TLS Configuration:
- Minimum TLS Version: Configurable (supports both "TLS1.2" and "VersionTLS12" formats)
- Cipher Suites: Configurable via CLI flags
- HTTP/2: Supported with ALPN negotiation
- Client Auth Mode: RequestClientCert (requests but does not require)
- Certificate Rotation: Hot-reload via pkg/tls.CertReloader
- Upstream TLS: Optional custom CA bundle and client certificates

Secrets:
- No explicit secret references in manifests
- ServiceAccount tokens used for in-cluster Kubernetes API authentication
- TLS certificates managed externally (cert-manager or manual provisioning)
