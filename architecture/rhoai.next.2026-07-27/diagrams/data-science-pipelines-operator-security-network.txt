RBAC Summary (Key Roles):

1. data-science-pipelines-operator-manager-role (ClusterRole)
   - Bound to SA: data-science-pipelines-operator-controller-manager
   - Scope: Cluster-wide
   - Key permissions:
     * Core: configmaps, secrets, serviceaccounts, services, PVs, PVCs, pods (full CRUD)
     * Apps: deployments, replicasets (full CRUD)
     * Admission: mutating/validating webhook configurations
     * Argo: workflows, workflowartifactgctasks (full CRUD)
     * DSPA: datasciencepipelinesapplications + /finalizers + /status
     * Pipelines: pipelines, pipelineversions + /finalizers + /status
     * Auth: tokenreviews, subjectaccessreviews (create)
     * Networking: networkpolicies, ingresses
     * RBAC: clusterroles, clusterrolebindings, roles, rolebindings
     * External CRDs: KServe, Seldon, Ray, CodeFlare, MLflow

2. data-science-pipelines-operator-manager-argo-role (ClusterRole)
   - Bound to SA: data-science-pipelines-operator-controller-manager
   - Scope: Argo workflow management
   - Key permissions:
     * Argo CRDs: workflows, cronworkflows, workflowtasksets (full CRUD)
     * Core: pods, pods/exec (full CRUD), PVCs, configmaps, secrets, leases

3. argo-cluster-role (ClusterRole)
   - Bound to SA: argo (namespace: argo)
   - Scope: Argo workflow execution
   - Key permissions:
     * Core: pods, pods/exec, PVCs (full CRUD)
     * Argo CRDs: workflows, workflowtasksets, cronworkflows
     * Secrets: GET restricted to resourceNames: [argo-workflows-agent-ca-certificates]

4. argo-aggregate-to-{admin,edit,view} (ClusterRoles)
   - Aggregation labels for Kubernetes built-in role aggregation
   - admin: full CRUD on all Argo resources
   - edit: full CRUD excluding WorkflowTaskSets
   - view: read-only

Leader Election:
- data-science-pipelines-operator-leader-election-role (Role, namespace: opendatahub)
  * Resources: configmaps, leases, events
  * SA: data-science-pipelines-operator-controller-manager

Authentication & Authorization:
- :8081/healthz - GET - No Auth - Kubernetes health probe (unauthenticated by design)
- :8081/readyz - GET - No Auth - Kubernetes readiness probe (unauthenticated by design)
- :8080 metrics - Auth: Unknown (not fully resolved from source)
- :9443 webhook - Auth: Unknown (not fully resolved from source)
- Argo agent secrets restricted via resourceNames to argo-workflows-agent-ca-certificates only

Secrets:
- No secrets explicitly declared in architecture document
- Operator manages secrets as owned resources (ConfigMaps, Secrets via DSPAReconciler)

Network Policies:
- Operator creates NetworkPolicy resources in target namespaces (networking.k8s.io/v1)
- Operator owns NetworkPolicy lifecycle via DSPAReconciler watch
