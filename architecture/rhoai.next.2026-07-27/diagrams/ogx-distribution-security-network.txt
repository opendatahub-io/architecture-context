Secret Resolution (entrypoint.sh):
- Mechanism: _FILE environment variable suffix pattern
- 18 secret variables resolved from Kubernetes-mounted files
- Avoids /proc exposure by reading file contents → exporting as env vars
- Examples: POSTGRES_PASSWORD_FILE → POSTGRES_PASSWORD
            AWS_SECRET_ACCESS_KEY_FILE → AWS_SECRET_ACCESS_KEY

RBAC Summary:
- No CRDs, ClusterRoles, or RoleBindings defined
- This component is a container image, not a Kubernetes operator
- Deployment and lifecycle managed externally by RHOAI platform operator
- No RBAC roles are created or required by this component

Authentication Summary:
- OAuth2/JWKS token validation (optional, disabled by default)
- Owner-based access control model:
  * Unauthenticated: READ unowned resources
  * Authenticated: CREATE resources (become owner)
  * Owner: UPDATE/DELETE owned resources
- JWKS endpoint configurable via environment variable

Provider Activation:
- Providers use ${env.VAR:+id} pattern — activated only when trigger env var is set
- Providers without this pattern are always active
- This allows selective enablement at deployment time
