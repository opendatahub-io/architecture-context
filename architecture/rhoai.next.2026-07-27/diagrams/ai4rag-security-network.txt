RBAC Summary:

Secrets / Credentials:
- AWS_ACCESS_KEY_ID (environment variable) - S3 access, runtime environment, Unknown rotation
- AWS_SECRET_ACCESS_KEY (environment variable) - S3 access, runtime environment, Unknown rotation
- AWS_SESSION_TOKEN (environment variable, optional) - S3 session token, runtime environment
- DOCLING_ARTIFACTS_PATH (environment variable) - Docling model artifacts path

Security Considerations:
1. SSL Error Retry with verify=False (text_extraction.py:316-319)
   - On SSL/TLS error during S3 download, the library retries with certificate
     verification disabled. This exposes the connection to MITM attacks.
   - Recommendation: Log a warning; consider making this behavior configurable
     or removing it in production contexts.

2. Credential Handling
   - S3 credentials are resolved via explicit parameters with environment variable
     fallback. Missing required credentials raise ValueError (fail-closed).

3. Path-Traversal Protection
   - S3 object keys are validated before download to prevent path-traversal
     attacks (text_extraction.py:298-307).
