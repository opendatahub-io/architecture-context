Network Summary:
- Direction: Egress-only (CLI → Kubernetes API)
- No ingress surfaces (CLI is not a server)
- No services exposed, no cluster-resident workload
- Single egress target: Kubernetes API Server (6443/TCP)

Authentication & Authorization:
- Endpoint: Kubernetes API (6443/TCP)
- Auth Mechanism: kubeconfig credential chain
  - Bearer token
  - Client certificate (mTLS)
  - OIDC token
- Enforcement Point: kube-apiserver
- Pre-flight: SelfSubjectAccessReview before privileged operations
  - Source: pkg/util/kube/rbac/check.go:36-61

RBAC Summary:
- No ClusterRoles defined by the CLI itself
- No RoleBindings defined by the CLI itself
- CLI operates with the user's existing RBAC permissions
- Pre-flight checks ensure sufficient permissions before operations

Secrets:
- No secrets managed or stored by odh-cli
- Credentials delegated entirely to kubeconfig credential chain
