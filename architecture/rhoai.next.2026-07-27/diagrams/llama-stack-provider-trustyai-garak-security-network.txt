Secrets / Credentials:
- API_KEY (env var) - Generic API key, runtime environment, rotation unknown
- KFP_AUTH_TOKEN (env var) - Kubeflow Pipelines auth, runtime environment, rotation unknown
- OPENAICOMPATIBLE_API_KEY (env var) - OpenAI-compatible endpoint key, runtime environment, rotation unknown
- AWS_SECRET_ACCESS_KEY (env var) - S3 access credentials, runtime environment (Data Connection), rotation unknown
- Role-specific keys (env vars / secret files) - Per-role API keys for TARGET, SDG, JUDGE, ATTACKER, EVALUATOR, TRANSLATION
- SA token - Kubernetes Service Account token for KFP auth (disabled in sidecar proxy mode)

Security Controls:
- API Key Redaction: All keys replaced with *** before persistence to S3 or OCI
- Role-Based Resolution: 6 roles with independent credential chains
- Sidecar Proxy Model: eval-hub >= 0.4.4 disables SA token auto-mounting
- No Inbound Surfaces: Component exposes no HTTP/gRPC endpoints (library adapter)
- Pod-Scoped Execution: All operations run within eval-hub K8s Job pod boundary

RBAC Summary:
- No ClusterRoles or RoleBindings defined by this component
- Relies on eval-hub platform RBAC for K8s API access

Service Mesh:
- No service mesh configuration (library adapter, no exposed services)
- Network policies inherited from eval-hub platform
