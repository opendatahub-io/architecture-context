INBOUND SURFACES:
  Port 8081/TCP (HTTP):
    - /healthz (GET) - Health probe, unauthenticated
    - /readyz (GET) - Readiness probe, unauthenticated
  Port 9443/TCP (HTTPS, TLS from OpenShift cluster profile):
    - /workbenches-hardware-profile (POST) - Mutating webhook, K8s admission auth
    - /workbenches-connection-notebook (POST) - Mutating webhook, K8s admission auth
    - /convert (POST) - Conversion webhook, K8s admission auth

OUTBOUND CONNECTIONS:
  Kubernetes API (6443/TCP, HTTPS/WSS, TLS 1.2+, ServiceAccount token):
    - Workbenches CR CRUD
    - Notebook CR CRUD
    - HardwareProfile CR read
    - ConfigMap, Secret read
    - Deployment, Service, ServiceAccount CRUD
    - Namespace CRUD
    - ImageStream CRUD
    - RBAC resource CRUD
    - CRD, WebhookConfiguration CRUD
    - SubjectAccessReview create
    - Lease operations (leader election)

RBAC Summary:
  ClusterRole: manager-role
    - core: configmaps, secrets, serviceaccounts, services, namespaces, events
    - admissionregistration.k8s.io: mutatingwebhookconfigurations, validatingwebhookconfigurations
    - apiextensions.k8s.io: customresourcedefinitions
    - apps: deployments
    - authorization.k8s.io: subjectaccessreviews
    - components.platform.opendatahub.io: workbenches, workbenches/finalizers, workbenches/status
    - config.openshift.io: apiservers (get, list, watch)
    - image.openshift.io: imagestreams
    - infrastructure.opendatahub.io: hardwareprofiles (get)
    - kubeflow.org: notebooks
    - rbac.authorization.k8s.io: clusterrolebindings, clusterroles, rolebindings, roles
    Verbs: get, list, watch, create, update, patch, delete (varies per resource)

  ClusterRole: manager-rbac-escalate-role
    - rbac.authorization.k8s.io: clusterroles (bind, escalate)
    - Scoped to 9 named upstream notebook-controller ClusterRoles

  Role: leader-election-role (namespace-scoped)
    - core: configmaps, events
    - coordination.k8s.io: leases

Role Bindings:
  - manager-rolebinding → manager-role → SA: controller-manager
  - manager-rbac-escalate-rolebinding → manager-rbac-escalate-role → SA: controller-manager
  - leader-election-rolebinding → leader-election-role → SA: controller-manager

TLS Configuration:
  - Webhook and metrics endpoints derive TLS settings from OpenShift cluster TLS
    security profile (bootstrapped at startup from config.openshift.io/apiservers)
  - TLS SecurityProfileWatcher triggers graceful shutdown on TLS profile changes
  - Metrics serving disabled by default (metrics-bind-address=0)

Secrets:
  - No operator-owned secrets defined
  - Reads Secrets from user namespaces for connection notebook mutation
