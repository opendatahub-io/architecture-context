- PagerDuty service key secret (Opaque) - External alerting credential
- Dead Man's Snitch URL/key secret (Opaque) - Watchdog credential

- Anaconda CE access (from partners/anaconda/anaconda-ce-access.yaml)

Notes:
- odh-deployer is a one-shot script, NOT a long-running controller
- No persistent network listeners or services are created by the script itself
- The Prometheus/Alertmanager stack is the only long-running workload directly deployed
- All RHOAI component workloads are managed via KfDef CRs by the KubeFlow Operator
