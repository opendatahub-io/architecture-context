Authentication Configuration:
- Per-provider (required): ExternalProvider.spec.auth
  - Types: apikey, sigv4, oauth2, none
  - Credentials: same-namespace Secret with "api-key" data key
- Per-model (optional override): ExternalModel.spec.externalProviderRefs[].auth
  - Overrides provider-level auth on a per-reference basis

Secrets:
- anthropic-credentials (Opaque) - Anthropic API key, manifest-provisioned
- azure-credentials (Opaque) - Azure OpenAI credentials, manifest-provisioned
- openai-credentials (Opaque) - OpenAI API key, manifest-provisioned
- vertex-credentials (Opaque) - Google Vertex AI credentials, manifest-provisioned

RBAC Summary:
- Defined in deploy/payload-processing/templates/rbac.yaml (templated, not fully parseable)
- Expected permissions: watch/CRUD on ExternalModel, ExternalProvider, HTTPRoute, Service, Secret

Traffic Splitting:
- ExternalModel supports up to 64 provider refs
- Weight range: 0-100 (default: 1, weight=0 disables provider ref)
- Routing decision made per-request via ext_proc plugin
