INBOUND SURFACE:
- NONE — This is a client library with no listening sockets, HTTP servers,
  or gRPC services. All network activity is outbound-only.

RBAC Summary:
- No ClusterRoles or RoleBindings defined by this library.
- RBAC permissions depend on the ServiceAccount of the hosting workload
  (notebook or script). The workload SA needs:
  - routes.route.openshift.io: get, list (for Route discovery)
  - Access to TrustyAI Service, Thanos Querier, and Model Routes

Authentication Model:
- Caller-delegated: TrustyAIMetricsService constructor accepts an
  OpenShift OAuth Bearer token as a parameter.
- All outbound HTTPS requests include: Authorization: Bearer {token}
- Kubernetes API auth: in-cluster SA token or kubeconfig credentials.

Secrets:
- No secrets are defined or provisioned by this library.
- Bearer token is passed at runtime by the caller.
- Kubernetes credentials come from in-cluster SA mount or kubeconfig.

Service Mesh:
- Not applicable — client library runs within the caller's pod.
- If the hosting pod is in a service mesh, outbound traffic follows
  the pod's sidecar proxy configuration.
