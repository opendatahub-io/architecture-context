Secrets:
  - (user-provided HF_TOKEN) - Opaque - HuggingFace auth token for hf:// URIs - User provisioned - No auto-rotation
  - (optional metrics TLS cert) - kubernetes.io/tls - Metrics endpoint TLS - cert-manager - Yes (certwatcher)
  - (optional webhook TLS cert) - kubernetes.io/tls - Webhook server TLS - cert-manager - Yes (certwatcher)

TLS Configuration:
  - HTTP/2 disabled: CVE-2023-44487 (HTTP/2 Rapid Reset), CVE-2023-39325 (HTTP/2 Stream Cancellation)
  - NextProtos: ["http/1.1"]
  - Optional external certs via --metrics-cert-path / --webhook-cert-path with certwatcher rotation
  - Self-signed certs generated by controller-runtime when no external cert provided

FIPS Notes:
  - Upstream: CGO_ENABLED=0 (static, pure-Go crypto) - NOT FIPS-validated
  - Downstream: Needs CGO_ENABLED=1 with FIPS-compatible flags for check-payload
  - No Konflux Dockerfile in upstream repo

Multi-Tenancy Risks:
  - Controller has cluster-wide write access across all namespaces
  - BaseConfig ConfigMap supports cross-namespace reads (baseConfigMapRef.namespace)
  - No NetworkPolicies for child resources by default
  - No ResourceQuota or LimitRange enforcement by controller
