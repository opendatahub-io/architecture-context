RBAC Summary:
- No ClusterRoles or RoleBindings defined by this repository.
- RBAC is managed by the RHOAI Notebook Controller at deployment time.
- Per-user ServiceAccounts are created for each workbench pod.

Authentication Architecture:
- Authentication is NOT embedded in the container images.
- OAuth proxy sidecar is injected by the RHOAI Notebook Controller.
- The OAuth proxy validates OpenShift OAuth tokens before forwarding
  requests to the IDE server on localhost.
- IDE servers (Jupyter, code-server, RStudio) listen on localhost only
  and trust the OAuth proxy for authentication.

Cryptographic Libraries (bundled for user-space operations, NOT transport):
- cryptography==43.0.3
- bcrypt==4.3.0
- pynacl==1.5.0
- pycryptodome==3.23.0

Secrets:
- No secrets are defined by this repository.
- Data connection credentials are user-configured at runtime
  through RHOAI Data Connection resources.

GPU Acceleration:
- NVIDIA CUDA 12.6: torch==2.6.0+cu126 (PyTorch + Jupyter variants)
- AMD ROCm: tensorflow-rocm==2.14.0.600, pytorch-triton-rocm==3.2.0
- GPU device access requires appropriate node labels and tolerations
  configured by the Notebook Controller.
