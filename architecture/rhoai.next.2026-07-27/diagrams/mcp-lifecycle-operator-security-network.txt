- :8443 metrics: TokenReview + SubjectAccessReview via controller-runtime filter
- Kubernetes API: ServiceAccount token (in-cluster), RBAC-enforced
- MCPServer CR access: RBAC aggregation into admin/edit/view ClusterRoles

Security Mitigations:
- HTTP/2 disabled (CVE GHSA-qppj-fm5r-hxr3, GHSA-4374-p667-p6c8)
- Leader election prevents split-brain (lease: bed7462b.x-k8s.io)
- Resource ownership: rejects updates to foreign-owned resources
- Orphaned resource adoption with same-name matching only

Secrets:
- No operator-specific secrets defined
- Metrics TLS: controller-runtime generated self-signed certificate
- Optional: PROPAGATE_TLS_ENV_VARS=true propagates platform TLS settings to managed containers

No Ingress Routes:
- No external ingress defined
- Metrics service is ClusterIP-only (internal access)
