================================================================================
  SECURITY NOTES
================================================================================

  - HTTP/2 is disabled by default in cmd/llmisvc to mitigate:
    - CVE-2023-44487 (HTTP/2 Rapid Reset)
    - CVE-2023-39325 (Go net/http2 resource consumption)
    Source: cmd/llmisvc/main.go:155-168

  - Core manager metrics are protected by kube-rbac-proxy sidecar
    (TokenReview + SubjectAccessReview)

  - LLMInferenceService controller metrics are protected by
    controller-runtime authn/authz filters

  - All webhook endpoints use TLS with Fail policy
    (reject on webhook unavailability)

  - Health/readiness probes (8081/TCP) are unauthenticated by design
