NETWORK SURFACE SUMMARY:
=========================

Inbound:
  - NONE (ephemeral pod, no Services, no Ingress, no Routes)

Outbound:
  - Kubernetes API Server: 6443/TCP, HTTPS, TLS 1.2+, SA Token Auth
  - No other external egress

RBAC Summary:
=============
  - No explicit ClusterRoles documented
  - Requires read access to:
    - Namespaces across all RHOAI-managed components
    - Custom Resources: DSCI, DSC, InferenceServices, etc.
    - Pod logs across collected namespaces
    - ConfigMaps, Secrets (metadata), Services
    - Webhook configurations, Gateway classes
    - Istio and Gateway API resources
  - Service Account: Auto-provisioned by oc adm must-gather

SECRETS HANDLING:
=================
  - No secrets created or stored by must-gather
  - Reads secret metadata for Helm release values
  - Service Account token mounted by Kubernetes (auto-provisioned)

SECURITY POSTURE:
=================
  - Ephemeral: Pod destroyed after collection completes
  - Read-only: No write operations to cluster resources
  - No inbound attack surface: No listening ports, no services
  - No persistent storage: Output rsync'd to user workstation
  - Scoped access: SA token limits API access to granted RBAC
  - Multi-distribution: Falls back to kubectl on non-OpenShift
