- Transport security is OPTIONAL TLS with optional mTLS
- NO application-level authentication or authorization in the server
- Access control is delegated to network-level policies and platform deployment
- Server runs as non-root user (65534:65534)
- Container built from UBI9 base with pinned image digests

RBAC Summary:
- No Kubernetes RBAC roles defined by this component
- Component operates as a standalone gRPC server, not a Kubernetes operator
- Network access should be restricted via NetworkPolicy

- TLS certificates (optional): --ssl_cert, --ssl_key, --ssl_ca flags
