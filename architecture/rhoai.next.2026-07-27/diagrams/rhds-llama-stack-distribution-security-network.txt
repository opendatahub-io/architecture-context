Security Notes:
- The server does NOT configure endpoint authentication at the application layer
- Authentication and authorization are expected to be enforced by the platform layer
  (e.g., OpenShift Routes, Istio, Service Mesh)
- Remote provider credentials are passed as environment variables
- Provider activation is environment-variable-driven and conditionally enabled
- Container image is RHEL 9-based (CPU only) for x86_64 and aarch64

RBAC Summary:
- No application-level RBAC defined in this component
- RBAC enforcement is delegated to the platform (RHOAI/OpenShift)

Secrets (Environment Variable-based):
- Inference provider API keys/credentials (env vars per provider)
- PostgreSQL connection credentials (env vars)
- Vector store connection credentials (env vars)
- All secrets are injected via environment variables, not Kubernetes Secret objects
  managed by this component

Configuration:
- Single config.yaml with environment variable interpolation
- ${env.VAR:=default} for defaults
- ${env.VAR:+provider_id} for conditional provider activation
- No TLS termination at application level (platform responsibility)
