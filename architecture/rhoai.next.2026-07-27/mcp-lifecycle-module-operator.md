## Purpose

**Short**: Kubernetes operator that manages the lifecycle of an MCP (Model Context Protocol) lifecycle operator operand, deploying and reconciling its resources via kustomize-rendered manifests with Server-Side Apply.

**Detailed**: mcp-lifecycle-module-operator is a controller-runtime-based Kubernetes operator that manages the deployment and lifecycle of an MCP lifecycle operator operand. The operator watches a cluster-scoped `MCPLifecycleOperator` custom resource (singleton named `default`) whose `spec.managementState` field controls whether the operand is actively deployed (`Managed`) or removed (`Removed`). During reconciliation, the operator fetches TLS configuration from the OpenShift APIServer resource, renders operand manifests via a kustomize-based provider, applies them using Server-Side Apply (SSA) through the odh-platform-utilities Deployer, garbage-collects stale resources using label-based ownership, and monitors operand deployment readiness. The operator manages MCPServer resources (`mcp.x-k8s.io` API group) as part of the operand surface. Status conditions (`MCPLifecycleOperatorAvailable`, `Ready`, `ProvisioningSucceeded`, `Degraded`) and component release metadata are maintained on the CR status. The operator supports leader election for HA deployments and uses namespace-scoped caching with label-filtered cluster-scoped resource watches.

All managed resource watches use a label predicate (PlatformPartOf label) to filter to owned resources, and an `EnqueueRequestsFromMapFunc` to always reconcile the singleton CR instance.
