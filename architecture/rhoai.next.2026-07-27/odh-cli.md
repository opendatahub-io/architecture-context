## Purpose

**Short**: kubectl plugin for ODH/RHOAI cluster inspection, linting, migration, and operator lifecycle management with 12 subcommands and MCP server capability.

**Detailed**: odh-cli is a Cobra-based kubectl plugin (`kubectl-odh`) for managing and inspecting OpenDataHub and Red Hat OpenShift AI deployments. The CLI provides 12 subcommands: `api`, `version`, `lint`, `get`, `deps`, `components`, `status`, `logs`, `completion`, `mcp`, `migrate`, and `events`. It connects to the Kubernetes API using standard kubeconfig credentials and interacts with OLM (Operator Lifecycle Manager) for operator installation and lifecycle operations. The events subsystem uses the opendatahub-operator clusterhealth library for event aggregation and watch-based streaming. The tool performs RBAC pre-flight checks via SelfSubjectAccessReview before privileged operations. Source: `cmd/main.go:29-51` (subcommand registration), `pkg/util/kube/rbac/check.go:36-61` (RBAC pre-flight), `pkg/events/filter.go:39-46` (clusterhealth integration).
