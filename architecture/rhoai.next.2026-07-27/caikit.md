## Purpose

**Short**: Source-backed analysis represents caikit as Application Service with 1 runtime component, 16+ API identities, and 2 integration points.

**Detailed**: caikit is an AI toolkit that enables AI users to consume stable task-specific model APIs and enables AI developers to build algorithms and models in a modular/composable framework. It provides both gRPC and HTTP runtime servers for model inference and training. The gRPC server (`RuntimeGRPCServer`) registers dynamically generated inference and training services alongside ModelMesh sidecar APIs (`mmesh.ModelRuntime`, `mmesh.ModelMesh`) and a training workflow API (`processproto.Process`). The `ModelManager` handles model lifecycle operations including loading (from directories, zip archives, or byte streams), training delegation, and singleton caching. The server supports configurable TLS and mutual TLS for secure communication, and communicates with ModelMesh via unix domain sockets when co-located in serving pods.
