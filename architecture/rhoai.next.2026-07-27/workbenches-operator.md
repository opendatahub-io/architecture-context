## Purpose

**Short**: Kubernetes operator that manages the lifecycle of Workbenches (Jupyter notebook environments) within the OpenShift AI platform, deploying and reconciling Kubeflow Notebook controllers, admission webhooks, and supporting resources.

**Detailed**: workbenches-operator is a controller-runtime-based Kubernetes operator that reconciles the cluster-scoped `Workbenches` custom resource (`components.platform.opendatahub.io/v1alpha1`). It manages the full lifecycle of workbench infrastructure: deploying Kubeflow Notebook controller manifests from `/opt/manifests`, registering mutating admission webhooks for hardware profile injection and connection notebook mutation, managing RBAC resources, and monitoring OpenShift TLS security profile changes. The operator supports both OpenDataHub and SelfManagedRhoai platform modes, uses leader election for high availability, and applies the cluster's TLS profile to all serving endpoints. Its documented interface surface contains 6 API identities, including 5 HTTP endpoints and 1 custom resource identity. The extracted dependency view records 3 internal platform dependencies and 14 integration points.
