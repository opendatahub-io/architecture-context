## Purpose

**Short**: Guardrails content-safety detection services providing built-in regex/file-type detectors and LLM-as-Judge evaluation, deployed with MinIO model storage on Kubernetes.

**Detailed**: guardrails-detectors provides content-safety detection for the RHOAI Guardrails subsystem through two independent FastAPI applications and a supporting model-storage deployment. The **built-in detector** (`detectors/built_in/app.py`) hosts regex, file-type, and custom detector registries for content analysis. The **LLM Judge detector** (`detectors/llm_judge/app.py`) evaluates content and generations against configurable metrics (safety, toxicity, accuracy, helpfulness, etc.) using an LLM-as-Judge pattern. A **MinIO deployment** (`guardrails-container-deployment-guardian`) provides S3-compatible model storage, with an init container that downloads models (e.g., `ibm-granite/granite-guardian-3.0-2b`) from HuggingFace Hub. The interface surface includes 5 HTTP endpoints across the two detector applications. Neither application registers authentication middleware; access control is expected to be enforced externally.
