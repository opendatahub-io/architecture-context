Authentication Model (ADR 0002 — Relay-Only):
- Auth proxy (oauth2-proxy) owns login, sessions, OIDC flows
- BFF extracts token from x-forwarded-access-token header (fallback: Authorization header)
- BFF forwards token as Bearer to OpenShell gateway
- Gateway validates JWT and enforces RBAC
- BFF NEVER validates tokens, runs OIDC, or makes authz decisions
- Dev mode (AUTH_DISABLED=true): injects synthetic identity, ignores tokens

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1 (UBI 9 go-toolset)
- Crypto: stdlib crypto/tls + crypto/x509 (FIPS via OpenSSL with strictfipsruntime)
- No non-FIPS crypto detected (no InsecureSkipVerify, no MD5, no RC4)
