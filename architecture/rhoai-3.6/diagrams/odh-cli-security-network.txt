RBAC Summary:
- No RBAC manifests shipped. odh-cli runs with caller's kubeconfig credentials.
- RBAC pre-flight via SelfSubjectAccessReview (pkg/util/kube/rbac/check.go:60)
  before privileged operations (backup, migrate, deps install).
- All operations constrained by authenticated user's Kubernetes RBAC permissions.

FIPS Compliance:
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, -tags strictfipsruntime
- Crypto: stdlib crypto/tls + crypto/x509 via OpenSSL (strictfipsruntime)
- Crypto Policy: DEFAULT:PQ (Post-Quantum) set via update-crypto-policies
- Base Image: ose-cli-rhel9 (UBI 9 with OpenSSL)
- Risk: InsecureSkipVerify: true for TrustyAI in-cluster routes

Secrets:
- No secrets provisioned by odh-cli.
- Tool reads credentials from kubeconfig (bearer tokens, client certificates).
- `backup` command can export Kubernetes Secrets from cluster.

Security Observations:
- ⚠️ TrustyAI migration uses InsecureSkipVerify: true (pkg/migrate/actions/trustyai/metrics/http.go:60-63)
  Documented as matching original `curl -sk` behavior for self-signed in-cluster certificates.
- ⚠️ MCP SSE transport (8080/TCP) has no authentication or TLS.
  Intended for local/development use only.
