FIPS Configuration:
- Build: GOFIPS140=v1.0.0, CGO_ENABLED=0, -tags no_openssl (static binary)
- Runtime: godebug fips140=on (Go 1.26 native FIPS 140-3 module)
- Base Image: UBI 9 minimal-pqc (post-quantum cryptography)
- No OpenSSL dependency — uses Go's NIST-certified FIPS module

Security Notes:
- InsecureSkipVerify=true on gRPC-gateway loopback (localhost only, self-signed cert)
- InsecureSkipVerify user-configurable on CLI and SSO client connections (not default)
- Agent executor HTTP transport uses InsecureSkipVerify=true
- Metrics endpoints (9090, 6060) are unauthenticated
- argo-server not deployed in RHOAI (DSP provides API layer)
