RBAC Summary:
- No RBAC roles defined in component manifests
- Components rely on KFP task pod service account permissions
- SA needs: create/patch KServe CRs, read pods, read HardwareProfile CRs
- Permissions are granted by KFP/DSPO at pipeline run time

Secrets:
- HF_TOKEN (env var) - HuggingFace Hub auth, user-provided, no auto-rotate
- AWS_SECRET_ACCESS_KEY (env var) - S3/MinIO auth, user-provided, no auto-rotate
- S3_SECRET_KEY (env var) - S3 storage auth, user-provided, no auto-rotate
- LLM_API_KEY (env var) - LLM service auth for SDG, user-provided, no auto-rotate
- KUBERNETES_AUTH_TOKEN (env var) - K8s API bearer token, secret mount, no auto-rotate
- OCI_PULL_SECRET_MODEL_DOWNLOAD (env var) - OCI registry auth, user-provided, no auto-rotate
- evalhub_auth_token (KFP parameter) - Eval Hub API bearer token, user/SA provided, no auto-rotate

Security Warnings:
- ⚠ Eval Hub API: verify_tls defaults to False (self-signed cert accommodation)
- ⚠ AutoML S3 data loaders: SSL error fallback retries with verify=False
- ⚠ Model Registry: HTTP/8080 unencrypted, unauthenticated
- ⚠ KServe InferenceService: HTTP/8080 unencrypted for evaluation inference
- ⚠ No NetworkPolicy defined; relies on platform-level network isolation

FIPS / Crypto:
- pipelines-components image: DEFAULT:PQ (post-quantum) crypto policy
- AIPCC-based images: inherit crypto posture from AIPCC base image
- cryptography==50.0.1 (FIPS-capable via OpenSSL)
- In-cluster TLS uses CA from service account mount
