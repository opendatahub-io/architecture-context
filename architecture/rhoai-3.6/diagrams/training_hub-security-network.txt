Secrets (Environment Variables):
- OPENAI_API_KEY — LLM API authentication for GEPA prompt optimization
- WANDB_API_KEY — Weights & Biases experiment tracking authentication
- AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY — S3 checkpoint storage auth
- HF_TOKEN — HuggingFace Hub model/dataset access

Security Notes:
- No Kubernetes RBAC defined (library, not operator)
- No CRDs, no Services, no Ingress
- Trust boundary: YAML config files — _resolve_dotted_path imports arbitrary
  modules from config (src/training_hub/cli.py:386-433)
- API keys in environment are accessible to any process in same namespace
- Secrets visible in /proc/environ if running in shared pods
- Supply chain defense: litellm 1.82.7-1.82.8 excluded (TeamPCP compromise)
- No direct TLS/crypto — delegates to requests, aiohttp, litellm, urllib3
- FIPS compliance depends on consuming container's base image

FIPS / Crypto:
- Pure Python package — no compiled extensions shipped
- No ssl, hashlib, hmac, or cryptography imports in shipped source
- TLS delegated to HTTP client libraries (system OpenSSL)
- No container image built from this repository

Build Hermeticity:
- No lock files present (version ranges in pyproject.toml)
- No Dockerfiles in repository
- Distributed as PyPI package, not container image
