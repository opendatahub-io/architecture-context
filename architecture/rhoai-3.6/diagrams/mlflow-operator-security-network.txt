- Ingress restricted to metrics port (8443) from monitoring namespaces only
- Per-CR NetworkPolicies rendered via Helm chart for MLflow pods

Secrets:
- controller-manager-metrics-tls (kubernetes.io/tls) - Metrics TLS cert,
  provisioned by OpenShift service-ca-operator, auto-rotated
- mlflow-artifact-connection (Opaque) - Artifact storage credentials (S3, etc.),
  user-provisioned, not auto-rotated

TLS Configuration:
- Metrics endpoint: Uses cluster TLS profile from apiservers.config.openshift.io
- Cipher suites: Profile-driven (Intermediate fallback)
- SecurityProfileWatcher restarts operator on profile change
- MLflow pods: Uvicorn SSL ciphers set to PROFILE=SYSTEM

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Runtime: stdlib crypto/tls with OpenSSL via strictfipsruntime
- TLS ciphers: Cluster-profile-driven, no non-FIPS crypto risks detected
