RBAC Summary:
- No RBAC defined by this component
- All RBAC managed by LMEval Operator (trustyai-service-operator)
- Job runs under namespace-scoped ServiceAccount configured by operator

Secrets:
- HF_TOKEN (env var) - HuggingFace Hub auth, from model auth secret, no auto-rotate
- OPENAI_API_KEY (env var) - Model endpoint auth, from model auth secret, no auto-rotate
- ANTHROPIC_API_KEY (env var) - Anthropic API auth, runtime environment, no auto-rotate
- WATSONX_API_KEY (env var) - WatsonX API auth, runtime environment, no auto-rotate
- AWS_SECRET_ACCESS_KEY (env var) - S3 auth, runtime environment, no auto-rotate
- REGISTRY_USERNAME (env var) - OCI registry auth, runtime environment, no auto-rotate
- REGISTRY_PASSWORD (env var) - OCI registry auth, runtime environment, no auto-rotate

TLS Configuration:
- Uses ssl.create_default_context() with optional custom CA bundle
- Symlink traversal blocked on certificate paths
- aiohttp TCPConnector with SSL configuration
- S3 downloader supports custom CA bundle (S3_VERIFY_SSL default: true)

FIPS Compliance:
- Python ssl module delegates to system OpenSSL (FIPS via UBI base image)
- hashlib.sha256() used for non-cryptographic cache keys only
- uv removed from base image to eliminate bundled crypto (RHOAIENG-99284)
- No MD5, RC4, or weak ciphers detected

Container Security:
- Runs as non-root (UID 65532)
- Path traversal protection (CWE-22) on file operations
- Error message sanitization prevents credential leakage
- Code execution gated by explicit benchmark allowlist
