TLS Configuration:
- Cluster TLS profile read from apiservers.config.openshift.io/cluster
- Resolved via openshift/controller-runtime-common
- Propagated to operator metrics and kube-rbac-proxy sidecars
- Manager restarts on TLS profile change (restart-on-change strategy)
- TLS minimum version: 1.2 (default); cluster profile may override
- FIPS mode: X25519 and X25519MLKEM768 curves excluded
- Cipher suites: OpenSSL→IANA mapped via library-go

FIPS Compliance:
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, UBI 9-minimal-pqc
- Dynamic linking for OpenSSL FIPS module
- Crypto: stdlib crypto/tls via OpenSSL strictfipsruntime
- Non-FIPS risk: lmes-job Python container uses pip without FIPS validation

NetworkPolicy:
- Operator adds identity labels to managed Deployments
- Platform-level NetworkPolicies in redhat-ods-applications handle traffic filtering
- EvalHub metrics port 8081 aligned with platform NetworkPolicy allowlist
- No per-tenant NetworkPolicies created by operator
