RBAC Summary (Required by Caller):
- Required Role: trainer.kubeflow.org
  - Resources: trainjobs, trainingruntimes, clustertrainingruntimes
  - Verbs: get, list, watch, create, delete, patch

- Required Role: kubeflow.org
  - Resources: experiments, trials
  - Verbs: get, list, watch, create, delete

- Required Role: sparkoperator.k8s.io
  - Resources: sparkconnects
  - Verbs: get, list, watch, create, delete

- Required Role: core ("")
  - Resources: pods, configmaps, events
  - Verbs: get, list, watch

Secrets:
- HF_TOKEN (env var) - HuggingFace Hub auth for gated models - User-provisioned, no auto-rotate
- ACCESS_TOKEN (env var) - Dataset/model initializer access token - User-provisioned
- AWS_SECRET_ACCESS_KEY (env var) - S3 checkpoint storage credentials - User/IAM role
- KUBEFLOW_TRAINER_SERVER_TOKEN (projected SA token) - In-pod Trainer server auth - Auto-rotate (5 min cache TTL)

Security Notes:
- In-pod metrics server (28080/TCP) binds 0.0.0.0 with NO authentication
  → Security relies on Kubernetes network isolation at pod/namespace level
- vLLM sidecar (8234/TCP) is localhost-only within the pod
- trust_remote_code=False hardcoded in SpeculativeDecodingTrainer (security-correct)
- SDK is a client library — no container image, no FIPS build pipeline
- All crypto delegated to underlying libraries (kubernetes, requests → cryptography/OpenSSL)
