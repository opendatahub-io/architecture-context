URL Trust Policy (ai4rag.utils.network.ensure_safe_url):
- Plaintext HTTP only allowed for: localhost, 127.0.0.1, *.cluster.local
- All other endpoints: HTTPS required with certificate verification
- No unverified-TLS fallback (removed in commit 120e455)
- Custom CA certificates supported for all backends

RBAC Summary:
- No Kubernetes RBAC roles or bindings (library/application, not operator)
- Auth enforcement via application-level ASGI middleware only

Secrets (all environment variables, no auto-rotation):
- MAAS_API_KEY              - MaaS API key for model access
- MAAS_CA_BUNDLE            - CA bundle path for MaaS TLS verification
- MILVUS_TOKEN              - Milvus authentication token (user:password)
- MILVUS_CA_CERT            - PEM-encoded CA cert for Milvus TLS
- PGVECTOR_PASSWORD          - PostgreSQL password for pgvector backend
- PGVECTOR_CA_CERT           - PEM-encoded CA cert for PostgreSQL TLS
- NEO4J_PASSWORD             - Neo4j database password
- AWS_ACCESS_KEY_ID          - AWS/S3 access key
- AWS_SECRET_ACCESS_KEY      - AWS/S3 secret key
- K8S_REVIEWER_TOKEN         - K8s ServiceAccount token for TokenReview
- K8S_CA_PATH                - K8s API CA certificate path

FIPS Compliance:
- Python library: delegates to system OpenSSL (inherited from base image)
- hashlib.sha256 used for content deduplication only (not security-critical)
- No custom cipher suite configuration
- Containerfile.openshell inherits OpenSSL from OpenShell base image

Build Hermeticity:
- uv.lock present (4822 lines) for Python dependency pinning
- No Konflux Dockerfiles or RPM lock files
- No Hermeto/cachi2 prefetch (expected for library component)
