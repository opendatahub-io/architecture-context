  → Mitigated: pod-local access only via kubectl exec/port-forward

  → Risk: Any cluster node can reach the benchmark service
- All inter-pod test traffic (RDMA, iperf3, ZMQ, UCX) is unencrypted
  → Acceptable: Performance testing requires raw throughput measurement
- RoCE deployments request IPC_LOCK capability and SYS_RESOURCE
  → Required for RDMA memory registration (ibv_reg_mr)
- No FIPS compliance — upstream NVIDIA CUDA base image, not UBI
