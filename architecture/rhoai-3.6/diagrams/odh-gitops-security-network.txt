Authentication & Authorization:
- Inference Gateway (HTTPS):
  Auth: TLS termination + Authorino AuthPolicy
  Enforcement: Gateway API + RHCL (Kuadrant/Authorino)
  Policy: Per-namespace AuthorizationPolicy
- MaaS Gateway (HTTPS):
  Auth: TLS termination + Authorino AuthPolicy
  Enforcement: Gateway API + RHCL (Kuadrant/Authorino)
  Policy: Configured via MaaS API
- Webhook endpoint (9443):
  Auth: mTLS (cert-manager certificate)
  Enforcement: Kubernetes API server
  Policy: Admission control

Multi-Tenancy:
- Tenant boundary: per-namespace
- Deployment model: single-tenant cluster-scoped config
- Shared CA (rhai-ca) across all namespaces
- Authorino operates clusterWide with per-namespace AuthPolicy isolation
- Gateway allowedRoutes namespace selectors for route visibility
