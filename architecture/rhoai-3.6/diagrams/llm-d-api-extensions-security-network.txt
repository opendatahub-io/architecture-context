Security Summary:

  RBAC:
  - Not applicable — this is a Python library, not a Kubernetes-deployed
    component. No ClusterRoles, Roles, or RoleBindings defined.

  Secrets:
  - No secrets defined by this library.
  - CAUTION: kv_connector_extra_config in the /config endpoint may contain
    operator-supplied credentials (e.g., for KV transfer connectors).
    Values are redacted by default. Set LLM_D_INTROSPECTION_EXPOSE_KV_EXTRA_CONFIG=1
    to expose them.

  Authentication & Authorization:
  - All plugin endpoints are unauthenticated at the plugin level.
  - Authentication is the responsibility of the vLLM deployment configuration.
  - All endpoints are read-only (GET only).

  Cryptography:
  - No cryptographic code in this library.
  - TLS, if any, is inherited from the vLLM server configuration.
  - FIPS compliance is inherited from the host vLLM container image
    (typically UBI with OpenSSL).

  Graceful Degradation:
  - Missing worker extensions → 503 with specific error detail
  - Absent engine clients → 503 with specific error detail
  - Pre-#48121 vLLM builds → 503 with specific error detail
  - CPU-only platforms → _safe wrapper handles NotImplementedError

  Environment Variables (security-relevant):
  - VLLM_PLUGINS: Controls which plugins are loaded (opt-in)
  - LLM_D_INTROSPECTION_EXPOSE_KV_EXTRA_CONFIG: When set to "1",
    exposes potentially sensitive kv_connector_extra_config values
