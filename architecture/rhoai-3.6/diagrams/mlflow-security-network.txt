RBAC Summary:
- RBAC provisioned by MLflow Operator (not this repository)
- kubernetes-auth plugin requires:
  - SelfSubjectAccessReview permission
  - Namespace list/watch permission
  - MLflowConfig CRD read (mlflow.kubeflow.org)
- Authorization model: K8s-native RBAC via mlflow.kubeflow.org API group
  - Resources: experiments, runs, models (per workspace/namespace)
  - Verbs: get, list, create, update, delete (depending on role)

Multi-Tenancy:
- Tenant boundary: Kubernetes namespace = MLflow workspace
- Deployment model: Single shared service (all namespaces)
- Workspace context: X-MLFLOW-WORKSPACE header
- Data isolation: Workspace-scoped SQLAlchemy queries
- Auth isolation: SelfSubjectAccessReview per workspace per request

Secrets:
- MLFLOW_BACKEND_STORE_URI (env var) - PostgreSQL connection string
- MLFLOW_ARTIFACTS_DESTINATION (env var) - Artifact storage config
- AWS_SECRET_ACCESS_KEY (env var) - S3 credentials
- AWS_SESSION_TOKEN (env var) - AWS temporary credentials
- OPENAI_API_KEY (env var) - OpenAI access (gateway, disabled by default)
- ANTHROPIC_API_KEY (env var) - Anthropic access (gateway, disabled by default)
- mlflow-tls (kubernetes.io/tls) - TLS cert for in-pod termination

Network Policy:
- Optional NetworkPolicy in Helm chart (not enabled by default)
- No per-tenant network isolation
- All tenants share the same pod network path

FIPS Notes:
- Base image: ubi9/ubi-minimal-pqc (post-quantum cryptography variant)
- cryptography >= 43.0.0 (FIPS-capable via OpenSSL backend)
- MD5 used for data fingerprinting only (not security-critical)
- No explicit cipher suite or TLS protocol version selection
