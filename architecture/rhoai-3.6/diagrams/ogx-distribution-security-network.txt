RBAC Summary:
- No RBAC defined in this component — managed by ogx-operator
- ServiceAccount: managed by ogx-operator

Application-Level Access Policy:
- Read system resources: All users (authenticated or not)
- Create resources: Authenticated users only
- Read/Update/Delete owned resources: Resource owner only
- Auth disabled entirely when AUTH_ISSUER is unset

Secrets:
- Provider API keys (18 variables): Opaque env vars or file mounts, manual provisioning, no auto-rotation
  - Supports _FILE suffix pattern (e.g., OPENAI_API_KEY_FILE) for file-mounted secrets
- POSTGRES_PASSWORD: Opaque, manual provisioning, no auto-rotation
- AUTH_JWKS_URI: Public JWKS endpoint, keys rotate via OIDC provider

Multi-Tenancy:
- Tenant boundary: per-user ownership model
- Identity: OAuth2 token or Praxis headers (x-user-id, x-tenant-id)
- Data isolation: Shared PostgreSQL with per-user row ownership (application-level query filter)
- Compute isolation: None — single server process shared by all tenants
- Credential isolation: None — provider API keys shared across all tenants

Build Supply Chain:
- Base image: AIPCC cpu-el9.8:3.6.0-ea.2 (RHEL 9 UBI, Python 3.12)
- Dependencies: Hermeto (cachi2) prefetch with hashed pins (requirements-lock-konflux.txt)
- Model artifacts: modelcar OCI image (ProdSec-scanned, no runtime downloads)
- Architectures: x86_64, arm64, ppc64le
