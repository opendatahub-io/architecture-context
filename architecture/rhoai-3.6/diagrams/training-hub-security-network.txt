Secrets / Credentials:
- OPENAI_API_KEY (env var) — API key for GEPA prompt optimization via litellm
- WANDB_API_KEY (env var) — Weights & Biases experiment tracking (optional)
- AWS_ENDPOINT_URL_S3 (env var) — Custom S3 endpoint for checkpoint storage
- AWS_* credentials (env vars) — S3 authentication for checkpoint mirroring
- HF_TOKEN (env var) — HuggingFace Hub access for gated models (optional)

RBAC:
- Not applicable. Training Hub is a Python library with no Kubernetes RBAC manifests.
- All RBAC and namespace isolation is the responsibility of the consuming component
  that packages Training Hub into a container image.

Service Mesh Configuration:
- Not applicable. Training Hub does not deploy any Kubernetes services.
- Network policies and service mesh configuration are managed by the consuming
  component's deployment manifests.

FIPS Compliance:
- No direct cryptographic operations in Training Hub source code.
- All TLS handled by transitive dependencies (urllib3, aiohttp, s3fs) using
  system OpenSSL configuration.
- FIPS compliance at runtime is the responsibility of the container image.

Supply Chain Notes:
- litellm versions 1.82.7 and 1.82.8 explicitly excluded due to TeamPCP
  supply chain attack (pyproject.toml).
- PyPI publishing uses Sigstore package signing via Trusted Publisher (OIDC).
