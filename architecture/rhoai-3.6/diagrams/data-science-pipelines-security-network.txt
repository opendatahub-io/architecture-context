  - gRPC/REST APIs: Bearer token → TokenReview + SubjectAccessReview (multi-user)
  - Standalone mode: No auth (all users share everything)
  - Webhook endpoints: Kubernetes admission
  - MySQL: Istio AuthorizationPolicy (source principal)
  - Prometheus /metrics: Unauthenticated

  - mysql-secret (Opaque) — DB credentials for API server, cache, MLMD — DSPO-provisioned, no auto-rotate
  - mlpipeline-minio-artifact (Opaque) — S3 credentials — DSPO-provisioned, no auto-rotate
  - kfp-api-webhook-cert (kubernetes.io/tls) — Webhook TLS cert — cert-manager, auto-rotate
  - webhook-server-tls (referenced) — Cache server webhook TLS — cert-manager, auto-rotate
  - kfp-mlflow-credentials (Opaque) — MLflow credentials (optional) — manual, no auto-rotate
