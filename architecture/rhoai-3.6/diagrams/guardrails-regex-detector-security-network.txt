RBAC Summary:
- No RBAC roles or bindings. The service does not interact with the
  Kubernetes API.

Service Mesh Configuration:
- No application-level service mesh configuration.
- If Istio sidecar is injected, mTLS is handled transparently.
- AuthorizationPolicy should be configured at the platform level to
  restrict access to only the FMS Guardrails Orchestrator.

Secrets:
- None. The service has no authentication, database connections,
  or external service credentials.

Authentication & Authorization:
- POST /api/v1/text/contents: Unauthenticated at application level.
  Relies on network-level isolation and orchestrator-level auth.
- GET /health: Unauthenticated health check.

FIPS Compliance:
- Application performs NO cryptographic operations (no TLS, hashing,
  signing, or certificate handling).
- No crypto libraries in dependency tree (no openssl, rustls, ring).
- TLS termination delegated entirely to platform infrastructure.
- Build uses Debian rust:1.84.0 builder (not UBI) — may not pass
  check-payload FIPS validation.

Risk Notes:
- User-supplied regex patterns compiled per request without caching or
  complexity limits. Pathological patterns could cause CPU exhaustion
  (ReDoS). Rust regex crate mitigates via default size/nesting limits.
- No application-level rate limiting or request size limits.
