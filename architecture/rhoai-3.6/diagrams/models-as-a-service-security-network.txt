Authentication & Authorization:
- Gateway-level: Kuadrant/Authorino AuthPolicy
  - API key validation (via /internal/v1/api-keys/validate callback)
  - Kubernetes TokenReview
  - Optional OIDC JWT
  - Authorization header stripped before forwarding (prevents credential exfiltration)
- Application-level:
  - /v1/tenants: TokenReview + SubjectAccessReview
  - /internal/v1/api-keys/cleanup: Cleanup SA token → TokenReview
  - /internal/v1/api-keys/validate: None (NetworkPolicy-restricted to Authorino)
- Webhook: ValidatingWebhookConfiguration (failurePolicy: Fail)
  - Validates: AITenant, MaaSAuthPolicy, MaaSModelRef, MaaSSubscription

- maas-api-metrics-tls (kubernetes.io/tls) — TLS for metrics, OpenShift service-ca, auto-rotate
- maas-db-config (Opaque) — PostgreSQL connection URL, manual provisioning, no auto-rotate
