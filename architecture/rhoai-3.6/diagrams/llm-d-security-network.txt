RBAC Summary:
- No ClusterRoles defined in this repository
- RBAC delegated to llm-d-router Helm chart and per-deployment configuration
- ServiceAccount: automountServiceAccountToken: false

Secrets:
- llm-d-hf-token (Opaque) - Hugging Face API token, manual provisioning, no auto-rotation

Multi-Tenancy:
- Tenant boundary: per-namespace (InferencePool namespace-scoped)
- Isolation: Kubernetes namespace + optional NetworkPolicy/AuthorizationPolicy
- Flow control: Workload prioritization and fairness within shared InferencePool
- Gaps: No default NetworkPolicy shipped; no built-in auth in model server

Security Notes:
- No TLS between internal components (model server, proxy, EPP)
- TLS termination expected at Gateway or Istio layer
- RDMA fabric has no software-level encryption (hardware-level only)
- No FIPS-compliant builds on this branch (upstream base images)
- No Konflux Dockerfiles — upstream build model
- Threat model documented as placeholder (THREAT-MODEL.md)
