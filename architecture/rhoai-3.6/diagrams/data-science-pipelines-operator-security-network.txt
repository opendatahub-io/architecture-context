               KServe, Ray, AppWrapper, RBAC resources, webhooks
  - Verbs: Full CRUD (get, list, watch, create, update, patch, delete)
  - Note: 39 rules — broad blast radius if SA is compromised

- ClusterRole: manager-argo-role
  - API Groups: argoproj.io, core
  - Resources: Argo workflow resources, pods, configmaps, PVCs, leases, events
  - Verbs: Full CRUD for Argo workflow lifecycle

- ClusterRole: argo-cluster-role
  - Resources: workflows, pods, PVCs, configmaps, secrets
  - Restriction: Secret access limited to argo-workflows-agent-ca-certificates only
  - Verbs: Runtime permissions for Argo workflow execution

- Aggregate ClusterRoles:
  - argo-aggregate-to-admin/edit: Full CRUD on Argo CRDs
  - argo-aggregate-to-view: Read-only on Argo CRDs
  - aggregate-dspa-admin-edit: Full CRUD on DSPA, Pipeline, PipelineVersion
  - aggregate-dspa-admin-view: Read-only on DSPA, Pipeline, PipelineVersion
