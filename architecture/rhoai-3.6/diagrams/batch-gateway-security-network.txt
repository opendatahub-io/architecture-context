Multi-Tenancy Security:
- Tenant identity: X-MaaS-Username header injected by external gateway
- Spoofing defense: LastHeaderValue() takes last header value
  (ext_authz appends after client values)
- Data isolation: Application-enforced, all DB queries scoped by tenant_id
- Risk: No in-process auth — direct pod access bypasses all authentication
- Risk: Application-level isolation, not database row-level security
- Risk: No per-tenant compute quotas or fairness enforcement
