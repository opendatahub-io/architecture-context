RBAC Summary:
- No RBAC manifests shipped; RBAC must be configured per-deployment
- Required permission when K8s token validation is enabled:
  - API Group: authentication.k8s.io
  - Resource: tokenreviews
  - Verbs: create

Secrets:
- kube-auth-proxy-secret (Opaque) - Cookie secret, client secret, sensitive config
  - Provisioned By: Manual / Operator
  - Auto-Rotate: No

FIPS Compliance:
- Build: CGO_ENABLED=1, GOEXPERIMENT=strictfipsruntime, -tags strictfipsruntime
- Base Image: ubi9/ubi-minimal-pqc (post-quantum cryptography variant)
- TLS: Minimum TLS 1.2 (default), configurable to TLS 1.3
- Crypto: stdlib crypto/tls, crypto/sha256, crypto/x509 (FIPS-validated via Go runtime)
- Risk: InsecureSkipVerify available via --ssl-insecure-skip-verify (opt-in, not default)

Session Security:
- Cookie-based sessions by default (encrypted, signed)
- Optional Redis/Valkey for multi-replica session sharing
- CSRF protection on OAuth flows
- PKCE for OIDC authorization code flow
- OAuthAccessToken deletion on sign-out (OpenShift provider)

Authentication Methods (cascade order):
1. Kubernetes ServiceAccount Token → TokenReview API (singleflight + cache)
2. JWT/OAuth Bearer Token → Local verification or provider validation
3. Basic Auth → htpasswd file
4. Stored Session → Cookie or Redis lookup
5. Deny → MLflow JSON error (if mlflow-python-client UA) or HTML redirect
