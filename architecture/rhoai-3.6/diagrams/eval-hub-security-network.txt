FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Runtime base: ubi9/ubi-minimal-pqc (post-quantum crypto)
- TLS: MinVersion 1.2, MaxVersion 1.3 on all servers
- FIPS check: /proc/sys/crypto/fips_enabled at startup
- InsecureSkipVerify blocked in FIPS mode
- Crypto: stdlib crypto/tls (FIPS via OpenSSL)

Secrets:
- test-data (Opaque) - S3/Git/HF credentials for init container, User/Operator provisioned, no auto-rotate
- service-ca.crt (kubernetes.io/tls) - CA cert for sidecar TLS verification, OpenShift service CA, auto-rotated
- SA token (kubernetes.io/service-account-token) - Auth to eval-hub API and MLflow, Kubernetes provisioned, auto-rotated

Authentication & Authorization:
- /api/v1/evaluations/*: kube-rbac-proxy enforces Bearer token authn + RBAC authz; injects X-User, X-Tenant
- /api/v1/health: Unauthenticated (probe-friendly)
- /docs, /openapi.yaml: Unauthenticated (documentation)
- /metrics (port 8081): Unauthenticated (separate port avoids proxy auth)
- Kubernetes API: ServiceAccount credential chain

Multi-Tenancy:
- Tenant boundary: per-namespace (X-Tenant header)
- Deployment model: multi-tenant (single API instance)
- Data isolation: Row-level tenant column in SQL (application-enforced)
- Network isolation: Per-Job NetworkPolicy denying peer-Pod ingress
- Risk: Direct access to API port 8080 bypasses auth; local mode bypasses tenant enforcement
