FIPS Compliance Notes:
- Base image: ubi9/ubi-minimal-pqc (OpenSSL available)
- Default multimodal hasher: blake3 (NOT FIPS 140-3 compliant)
  - Set VLLM_MM_HASHER_ALGORITHM=sha256 or sha512 for FIPS compliance
- hashlib.sha256 usage throughout: FIPS-safe (delegates to OpenSSL on UBI)
- MD5 used in hf3fs KV transfer connector: NOT FIPS-compliant
- No mTLS enforcement at application level (delegated to platform/Istio)
- gRPC port (50051) is INSECURE — no TLS support

RBAC Summary:
- No Kubernetes RBAC — vllm-cpu is a stateless application server
- No CRDs — not an operator
- No ServiceAccount API access requirements

Secrets:
- VLLM_API_KEY (env var) — API authentication token, no auto-rotation
- HF_TOKEN (env var) — HuggingFace Hub auth, no auto-rotation
- S3_ACCESS_KEY_ID (env var) — S3 access key, no auto-rotation
- S3_SECRET_ACCESS_KEY (env var) — S3 secret key, no auto-rotation
- OPENAI_API_KEY (env var) — benchmark tooling only, no auto-rotation
- MODELSCOPE_API_TOKEN (env var) — ModelScope downloads, no auto-rotation
