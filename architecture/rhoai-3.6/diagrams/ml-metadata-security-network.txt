Ingress:
- No ingress routes defined in this repository
- Ingress is managed by the deploying operator (Data Science Pipelines Operator)

RBAC Summary:
- No RBAC resources defined in this repository
- RBAC is managed by the deploying operator

Secrets:
- Database credentials are passed via command-line flags or config file
- Secret management is delegated to the deploying operator
- No kubernetes Secret resources defined in this component

Multi-Tenancy:
- Single-tenant service (one server instance per database)
- No application-level data isolation or access control
- No API scoping — full database access per connection
- Tenant isolation depends on namespace-scoped deployment by operator

FIPS Compliance:
- C++ binary delegates crypto to gRPC/OpenSSL
- Base image: ubi9/ubi-minimal-pqc (PQC-ready)
- OpenSSL operates in FIPS mode when system FIPS policy enabled
- No hardcoded ciphers or weak algorithms detected
- TLS configuration delegated to gRPC/OpenSSL defaults

Build Hermeticity:
- Bazel manages C++ deps with pinned SHA256 hashes
- No rpms.lock.yaml or artifacts.lock.yaml
- Tekton pipeline: hermetic=false
- Python deps in setup.py with version ranges (no lock file)
