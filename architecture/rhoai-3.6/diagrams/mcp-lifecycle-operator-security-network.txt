- ClusterRole: mcp-lifecycle-operator-manager-role
  - (core): configmaps, namespaces, pods, secrets → get, list, watch
  - (core): services → create, get, list, update, watch
  - (core), events.k8s.io: events → create, patch
  - apps: deployments → create, get, list, update, watch
  - gateway.networking.k8s.io: gateways → get, list, watch
  - gateway.networking.k8s.io: httproutes → create, delete, get, list, update, watch
  - mcp.kuadrant.io: mcpgatewayextensions → get, list, watch
  - mcp.kuadrant.io: mcpserverregistrations → create, delete, get, list, update, watch
  - mcp.x-k8s.io: mcpgatewaybindings → create, delete, get, list, update, watch
  - mcp.x-k8s.io: mcpgatewaybindings/finalizers, mcpservers/finalizers → update
  - mcp.x-k8s.io: mcpgatewaybindings/status, mcpservers/status → get, patch, update
  - mcp.x-k8s.io: mcpservers → get, list, patch, update, watch
  - networking.k8s.io: networkpolicies → create, get, list, update, watch
- ClusterRole: mcp-lifecycle-operator-metrics-auth-role
  - authentication.k8s.io: tokenreviews → create
  - authorization.k8s.io: subjectaccessreviews → create
- ClusterRole: mcp-lifecycle-operator-metrics-reader
  - Non-Resource URL: /metrics → get
- Aggregate Roles:
  - admin → mcpservers CRUD + deletecollection
  - edit  → mcpservers CRUD
  - view  → mcpservers get, list, watch

Service Accounts:
- mcp-lifecycle-operator-controller-manager
  - Bound to: manager-role (Cluster), metrics-auth-role (Cluster), leader-election-role (NS)

Secrets:
- mcplo-webhook-server-cert (kubernetes.io/tls) - Webhook + conversion TLS cert, cert-manager, auto-rotate

TLS Configuration:
- Configurable via environment: TLS_MIN_VERSION, TLS_CIPHER_SUITES, TLS_GROUPS
- Supported TLS 1.3 groups: X25519, CurveP256, CurveP384, CurveP521, X25519MLKEM768 (post-quantum)
- HTTP/2 disabled by default (CVE-2023-44487 Rapid Reset, CVE-2023-39325 Stream Cancel)
- FIPS: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, DEFAULT:PQ crypto policy

Network Policy (operand):
- Default posture: open (all ingress allowed)
- Restricted posture: auto-injects operator + gateway ingress peers
- ODH overlay: pins metrics scraping to openshift-monitoring, adds allow-all egress stopgap
