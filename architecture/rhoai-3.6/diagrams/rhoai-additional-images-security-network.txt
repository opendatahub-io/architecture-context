Security Notes:
- All image references are digest-pinned (@sha256:...) providing cryptographic
  integrity verification during mirroring.
- Image security (FIPS, CVE scanning, signing) is the responsibility of each
  image's source repository (notebooks, trainer, Ray, etc.).
- The YAML manifest itself has no authentication or authorization requirements.
- Image lifecycle: Current (in component manifests) → N-1 (here) → Deprecated (here) → Removed.
