RBAC Summary:
- ClusterRole: odh-dashboard-operator-role
  - 30+ API groups spanning core K8s, OpenShift, KServe, Kubeflow,
    Gateway API, Feast, MLflow, TrustyAI, NIM, agents, MCP, observability
  - Key verbs: get, list, watch, create, update, patch, delete
  - Impersonation: users, groups, serviceaccounts
  - TokenReview: create
  - SubjectAccessReview: create

- Binding: odh-dashboard-operator-rolebinding
  - Namespace: system
  - ServiceAccount: odh-dashboard-operator

TLS Configuration:
- Cluster-wide TLS profile: Reads from apiservers.config.openshift.io/cluster
- Supported profiles: Intermediate (default), Modern, Old, Custom
- Default ciphers: 6 ECDHE-only GCM/ChaCha20 (Mozilla Intermediate)
- Post-quantum: X25519MLKEM768 curve supported
- Crypto policy: DEFAULT:PQ (post-quantum readiness)
- FIPS: CGO_ENABLED=1, -tags strictfipsruntime

Secrets:
- dashboard-proxy-tls (kubernetes.io/tls) - kube-rbac-proxy and core-bff TLS cert
  - Provisioned by: OpenShift serving-cert-secret annotation
  - Auto-Rotate: Yes
- dashboard-operator-metrics-tls - Operator metrics TLS cert
  - Provisioned by: cert-manager / platform
  - Auto-Rotate: Yes
- dashboard-operator-webhook-tls - Operator webhook TLS cert
  - Provisioned by: cert-manager / platform
  - Auto-Rotate: Yes
- {n-i-m-secret-name} (Opaque) - NVIDIA NIM API credentials
  - Provisioned by: User-provided
  - Auto-Rotate: No

Admission Webhooks:
- Dashboard CR (ValidatingWebhook, failurePolicy: Fail)
- Workspace CR (Validating, CREATE/UPDATE)
- WorkspaceKind CR (Validating, CREATE/UPDATE/DELETE)
- WorkspaceKind CRD (Conversion webhook for version upgrades)

Multi-Tenancy:
- Tenant boundary: per-namespace (OpenShift projects)
- Model: Single shared instance, per-user scoping via token impersonation
- Network isolation: Per-module NetworkPolicy (operator-managed)
