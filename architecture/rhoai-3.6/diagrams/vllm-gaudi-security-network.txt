RBAC Summary:
- No RBAC definitions. This component runs as a container within pods
  managed by the serving runtime (KServe / ModelMesh).
- Container runs as non-root user (UID 2000).

Service Mesh Configuration:
- No service mesh configuration defined by this component.
- Serving runtime (KServe) provides Istio sidecar injection and mTLS.

Secrets:
- No secrets directly consumed by this component.
- Model storage credentials and HuggingFace tokens are injected by the
  serving runtime via environment variables or mounted volumes.

FIPS Compliance:
- ⚠️  FIPS OpenSSL provider explicitly removed (rpm -e --nodeps openssl-fips-provider-so)
- Reason: Habana SynapseAI drivers are incompatible with FIPS-mode OpenSSL
- Impact: Container image cannot pass FIPS validation via check-payload
- Mitigation: Component does not perform cryptographic operations itself;
  TLS/auth delegated to KServe/Istio serving runtime infrastructure

Build Hermeticity:
- ⚠️  No hermetic build configuration (no lock files, no cachi2 prefetch)
- Dockerfile performs live git clones and pip installs from public repos
- Supply-chain gap for reproducible builds in Konflux
