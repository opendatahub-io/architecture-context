Service Mesh Configuration:
- EnvoyFilter: per-tenant ExtProc filter chain (pre-auth and post-auth)
  - Priority 10 (ordered relative to Kuadrant WasmPlugin)
  - TLS mode: ACCEPT_UNTRUSTED for ExtProc upstream clusters
- DestinationRule: per-provider TLS SIMPLE mode with SNI
- ServiceEntry: per-provider FQDN DNS resolution

Secrets:
- Per-provider API key Secrets (Opaque) - Provider auth credentials
  - Referenced by ExternalProvider.spec.auth.secretRef
  - Read via APIReader (bypassing informer cache)
  - Provisioned by: User / platform admin
  - Auto-Rotate: No

Multi-Tenancy:
- Tenant boundary: per-MaasTenantConfig
- Per-tenant resources: Deployment, Service, EnvoyFilter, DestinationRule,
  NetworkPolicy, RBAC (ClusterRoleBinding)
- Isolation: Kubernetes namespace, NetworkPolicy, label-gated Gateway resources
- Compute limits: 256Mi memory / 500m CPU per ExtProc container
