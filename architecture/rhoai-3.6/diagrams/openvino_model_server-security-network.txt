RBAC Summary:
  OVMS does not define Kubernetes RBAC resources.
  RBAC is managed by KServe and the RHOAI platform.

Service Mesh Configuration:
  - TLS termination delegated to Istio service mesh
  - gRPC uses InsecureServerCredentials (no built-in TLS)
  - REST (Drogon) runs without TLS
  - Optional nginx-mtls-auth sidecar for application-level mTLS

Secrets:
  - Cloud storage credentials via environment variables or mounted files
    (configured through KServe InferenceService specs)
  - API_KEY (env) or --api_key_file (flag) for OpenAI endpoint auth
  - HF_TOKEN (env) for HuggingFace Hub access

Crypto Notes:
  - BoringSSL (vendored via Bazel) for gRPC and S3/GCS filesystem backends
  - System OpenSSL via curl/libgit2 for outbound HTTPS
  - OpenSSL MD5 used for filesystem checksums (non-cryptographic)
  - Base image: ubi9/ubi-minimal-pqc (post-quantum crypto variant)
  - SDL flags: relro, noexecstack, PIE, stack-protector, fortify-source

Build Hermeticity:
  - Non-hermetic build: C++ dependencies fetched from git during Docker build
  - No rpms.lock.yaml or cachi2/Hermeto prefetch configured
  - Bazel WORKSPACE pins versions but no lock files
