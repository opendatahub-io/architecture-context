TLS Configuration:
  - OpenShift: Reads cluster TLS security profile from apiservers.config.openshift.io/cluster
  - Fallback: Intermediate defaults (TLS 1.2, ECDHE AEAD ciphers)
  - ProfileWatcher: Watches APIServer CR for TLS profile changes
  - ALPN: h2, http/1.1
  - FIPS: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1

Authentication Mechanisms:
  - /healthz, /readyz: Unauthenticated (health probes)
  - /metrics: kube-rbac-proxy (TokenReview + SubjectAccessReview)
  - Webhook endpoints: Kubernetes admission (TLS cert validation)
  - Inference router: Kubernetes TokenReview (Bearer tokens)
  - Kubernetes API: ServiceAccount tokens
  - Python model servers: No built-in auth (external enforcement required)
