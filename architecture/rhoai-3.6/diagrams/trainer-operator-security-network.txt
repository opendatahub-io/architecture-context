Network Policy Summary:
- allow-metrics-traffic (trainer-operator-system, Ingress):
  Restricts 8443/TCP to same-namespace pods and openshift-monitoring,
  openshift-user-workload-monitoring, redhat-ods-monitoring namespaces

- kubeflow-trainer-controller-manager (applications NS, Ingress):
  Restricts 9443/TCP (webhook), 10443/TCP (progression), 8443/TCP (metrics)

- kubeflow-trainer-controller-manager-egress (applications NS, Egress):
  Unrestricted egress for upstream trainer (Kubernetes API access)

- trainer-operator-metrics-tls (kubernetes.io/tls) — TLS cert for operator metrics endpoint; provisioned by OpenShift service-ca operator; auto-rotated
- kubeflow-trainer-webhook-cert (Opaque) — TLS cert for upstream trainer admission webhooks; bootstrap generated; no auto-rotation
