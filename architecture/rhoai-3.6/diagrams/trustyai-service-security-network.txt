SECURITY RISKS:
- ⚠ Port 4443 (HTTPS direct) has NO authentication middleware
- ⚠ Port 8080 (health/consumer) is intentionally unauthenticated
  - Inference data ingestion via CloudEvents has no auth gate
  - Relies on network-level isolation (NetworkPolicy not in this repo)
- ⚠ No NetworkPolicy defined in this repository
- ⚠ hashlib.md5 used in PrometheusPublisher (non-security, UUID generation)

Secrets:
- DATABASE_PASSWORD (env var) - MariaDB authentication, operator-provisioned, no auto-rotate
- DATABASE_USERNAME (env var) - MariaDB authentication, operator-provisioned, no auto-rotate
- TLS_CERT_FILE (file mount, /etc/tls/internal/) - HTTPS server certificate, cert-manager
- TLS_KEY_FILE (file mount, /etc/tls/internal/) - HTTPS server private key, cert-manager
- DATABASE_TLS_CA_CERT (file mount) - CA certificate for MariaDB TLS, operator-provisioned

TLS Configuration:
- PolicyAwareConfig delegates cipher/version to OS crypto policy
- No hardcoded cipher suites or TLS versions
- FIPS-compliant when cluster crypto policy is FIPS
- Containerfile sets DEFAULT:PQ for post-quantum crypto (non-Konflux build)

RBAC:
- No RBAC manifests in this repository
- RBAC is managed by the trustyai-service-operator
- kube-rbac-proxy enforces Kubernetes RBAC for main API access
