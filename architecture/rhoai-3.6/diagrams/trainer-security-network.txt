Secrets:
- kubeflow-trainer-webhook-cert (Opaque, kustomize secretGenerator)
  - Purpose: TLS certificates for webhook, metrics, and status servers
  - Provisioned by: cert-controller (OPA)
  - Auto-rotate: Yes
  - Shared across: webhook (9443), metrics (8443), status-server (10443)

TLS Configuration:
- Cluster TLS profile resolution from OpenShift APIServer config
  - Fallback: Intermediate profile on non-OpenShift clusters
  - Profile watcher triggers graceful controller restart on change
  - Configurable cipher suites and min TLS version via Configuration CRD
- HTTP/2 disabled by default (CVE-2023-44487, CVE-2023-39325 mitigation)
  - Opt-in via Configuration CRD TLSOptions.NextProtos field

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1, dynamic linking
- Base image: ubi9/ubi-minimal-pqc (post-quantum cryptography variant)
- Runtime: OpenSSL via Go stdlib crypto/tls in FIPS mode
- InsecureSkipVerify: Used ONLY for local probe dial (annotated nolint, documented)
