RBAC Summary:
- No ClusterRole or ClusterRoleBinding definitions bundled in the repository
- ServiceAccount created by Helm chart for Kubernetes API access
- Metrics endpoint uses controller-runtime RBAC filters (authentication + authorization)

Secrets:
- Redis/Valkey URL Secret (Opaque) - Message queue connection URL with embedded credentials
  - Provisioned by: Helm chart (auto-created or referenced)
  - Rotation: Manual
- TLS Secret (kubernetes.io/tls) - Client certificate/key for mTLS to inference gateway
  - Provisioned by: Manual or cert-manager
  - Rotation: Manual

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1 (dynamic linking)
- Base Image: UBI 9-minimal-pqc (post-quantum crypto, OpenSSL included)
- TLS: crypto/tls with MinVersion TLS 1.2 (OpenSSL backend under FIPS)
- Risk: InsecureSkipVerify option exists (dev/test only, not default)

Multi-Tenancy:
- Tenant boundary: per-attribute (configurable, default "userid")
- Isolation: per-queue result routing, redis-quota gate for per-attribute limits
- Shared: Redis/Valkey instance, Prometheus, network context
- Gap: No per-tenant network policies; quotas are best-effort
