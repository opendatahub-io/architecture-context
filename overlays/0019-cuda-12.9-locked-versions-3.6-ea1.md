## Fact

For RHOAI 3.6 EA1, the AIPCC base image rebase from RHEL 9.6 to RHEL 9.8
(referenced in overlay [0017](0017-aipcc-base-images.md), which documents
RHEL 9.6 as the base for the current 3.5 CUDA 12.9 image) is a
**platform-wide AIPCC effort**, not a per-variant change owned by any
single strategy. All CUDA variants rebase together for 3.6 EA1.

The compiler toolchain for building CUDA 12.9 packages remains **gcc14**,
unchanged from prior releases.

The speculators package is being upgraded as part of the 3.6 EA1 CUDA
12.9 work, locked to version **0.6.0**, confirmed by the owning team.

## Impact on Strategies

- Strategies for the CUDA 12.9 / RHOAI 3.6 EA1 stack should treat the
  RHEL 9.8 rebase as a platform-wide AIPCC dependency, not something the
  strategy itself owns or drives — this resolves an open question raised
  in RHAISTRAT-2366 ("Is the RHEL 9.8 rebase a platform-wide AIPCC effort
  or per-variant?").
- Build/test/CI assumptions for this stack should continue to assume
  gcc14 as the compiler toolchain — no change from prior releases.
- Strategies referencing speculators for the CUDA 12.9 / 3.6 EA1 stack
  should cite version 0.6.0 as locked, rather than leaving the version
  unpinned.

## Context

RHAISTRAT-2366 ("CUDA 12.9 Support for Red Hat AI 3.6 EA1") independently
identified the RHEL 9.8 rebase scope as an open question and left the
speculators version unpinned. This overlay records the platform-wide
scope and the speculators version once confirmed by SMEs, so other
strategies touching this stack don't have to re-derive or re-ask the
same questions.
