## Fact

For RHOAI 3.6 EA1, the CUDA 12.9 build stack has been locked to the
following component versions:

| Component | Version | Confidence |
|---|---|---|
| llm-compressor | 0.12.0 | Confirmed |
| speculators | 0.6.0 | Unconfirmed — needs verification |
| gcc | 14 | Confirmed |
| RHEL | 9.8 | Confirmed |

This is scoped to the 3.6 EA1 release specifically. It does not change
the CUDA 12.9 base image for the current 3.5 release, which overlay
[0017](0017-aipcc-base-images.md) documents as RHEL 9.6 — RHEL 9.8 is
the 3.6 EA1 base.

## Impact on Strategies

- Strategies referencing the llm-compressor or speculators packages,
  quantization, or speculative decoding for the CUDA 12.9 / RHOAI 3.6 EA1
  stack must cite these pinned versions instead of leaving them unfixed
  or TBD.
- Build/test/CI assumptions for this stack should target RHEL 9.8 with
  gcc14, not the RHEL 9.6 base used for the current 3.5 CUDA 12.9 image.
- The speculators 0.6.0 version is unconfirmed — strategies should flag
  it as an open question pending confirmation rather than treating it as
  final.

## Context

At the time RHAISTRAT-2366 was created, component versions for this
stack had not yet been fixed. They have since been locked for the 3.6
EA1 timeframe. This overlay records that fact so any strategy touching
this stack (not just RHAISTRAT-2366) picks up the correct pinned
versions once merged upstream.
