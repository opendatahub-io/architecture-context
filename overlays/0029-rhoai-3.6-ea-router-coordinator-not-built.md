## Fact

For the RHOAI downstream repository `red-hat-data-services/llm-d-router`, the
coordinator source first exists in RHOAI 3.5 GA. The source remains present in
RHOAI 3.6-ea.1 and 3.6-ea.2, but neither release builds the coordinator image.
The coordinator is first built and used in RHOAI 3.6 GA, represented by the
current `rhoai.next` target.

This release timeline does not apply to `opendatahub-io/llm-d-router`.

## Impact on Strategies

- Do not infer a shipped coordinator runtime from source presence in RHOAI 3.5 GA.
- Do not model the coordinator as a built image, deployed workload, Service, or active request path in RHOAI 3.6-ea.1 or EA2.
- Include the coordinator in RHOAI 3.6 GA router deployment and workflow designs only.

## Context

The architecture generator analyzed the complete downstream `llm-d-router`
checkout and reported the coordinator source even though its image is not built
until GA. This overlay separates source history from RHOAI downstream build and
runtime availability without editing generated architecture files.
